= 了解 Active IQ Unified Manager 中的节点事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
节点事件提供了有关节点状态的信息，可用于监控潜在的问题。事件按影响区域进行分组，并可提供事件和陷阱名称、影响级别、源类型和严重性。

星号（*）用于标识已转换为 Unified Manager 事件的 EMS 事件。
