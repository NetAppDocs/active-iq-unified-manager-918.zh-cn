= 了解 Active IQ Unified Manager 中的事件严重性类型
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
每个事件都与严重程度类型相关联，以帮助您对需要立即采取纠正措施的事件进行优先级排序。

* *严重*
+
发生了一个问题，如果不立即采取纠正措施，可能会导致服务中断。

+
性能关键事件仅从用户定义的阈值发送。

* *错误*
+
事件源仍在运行；但是，需要采取纠正措施以避免服务中断。

* *警告*
+
事件源发生了您应注意的事件，或者集群对象的性能计数器超出正常范围，应进行监控以确保其未达到严重级别。此严重程度的事件不会导致服务中断，可能不需要立即采取纠正措施。

+
性能警告事件从用户定义、系统定义或动态阈值发送。

* *信息*
+
当发现新对象或执行用户操作时，会发生此事件。例如，当删除任何存储对象或发生任何配置更改时，将生成严重性类型为“信息”的事件。

+
当检测到配置更改时，信息事件将直接从 ONTAP 发送。
