= 了解 Active IQ Unified Manager 中的事件管理清单页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
事件管理清单页面使您能够查看当前事件及其属性的列表。您可以执行确认、解决和分配事件等任务。您还可以为特定事件添加警报。

此页面上的信息每 5 分钟自动刷新一次，以确保显示最新的新事件。



[[filter-components]]
== 筛选组件

使您能够自定义事件列表中显示的信息。可以使用以下组件优化显示的事件列表：

* 查看菜单可从预定义的筛选器选择列表中进行选择。
+
这包括所有活动（新建和确认）事件、活动性能事件、分配给我（登录用户）的事件以及所有维护期间生成的所有事件等项目。

* 搜索窗格，用于通过输入完整或部分术语来细化事件列表。
* 用于启动“筛选器”窗格的“筛选器”按钮，以便您可以从每个可用的字段和字段属性中进行选择以优化事件列表。




[[command-buttons]]
== 命令按钮

这些命令按钮可用来执行下列任务：

* *分配给*
+
使您能够选择要将事件分配给的用户。将事件分配给用户时，用户名和分配事件的时间将添加到所选事件的事件列表中。

+
** 自己
+
将事件分配给当前登录的用户。

** 其他用户
+
显示“分配所有者”对话框，通过该对话框可以将事件分配或重新分配给其他用户。您也可以将所有权字段留空以取消分配事件。



* *确认*
+
确认选定事件。

+
当您确认事件时，您的用户名和确认事件的时间将添加到选定事件的事件列表中。当您确认某个事件时，您有责任管理该事件。

+
[NOTE]
====
您无法确认信息事件。

====
* *标记为已解决*
+
使您能够将事件状态更改为已解决。

+
解决事件时，您的用户名和解决该事件的时间将添加到所选事件的事件列表中。对事件采取纠正措施后，必须将该事件标记为已解决。

* *添加警报*
+
显示“添加警报”对话框，用于为选定事件添加警报。

* *报告*
+
使您能够将当前事件视图的详细信息导出为逗号分隔值 (.csv) 文件或 PDF 文档。

* *显示/隐藏列选择器*
+
使您能够选择在页面上显示的列，并选择它们的显示顺序。





[[events-list]]
== 事件列表

显示按触发时间排序的所有事件的详细信息。

默认情况下，将显示所有活动事件视图，以显示前七天具有事件或风险影响级别的新事件和已确认事件。

* *触发时间*
+
生成事件的时间。

* *严重程度*
+
事件严重性：Critical （严重）（image:../media/sev_critical_um60.png[""]）、Error （错误）（image:../media/sev_error_um60.png[""]）、Warning （警告）（image:../media/sev_warning_um60.png[""]）和 Information （信息）（image:../media/sev_information_um60.gif[""]）。

* *State*
+
事件状态：新建、已确认、已解决或已废弃。

* *影响级别*
+
事件影响级别：突发事件、风险、事件或升级。

* *影响区域*
+
事件影响区域：可用性、容量、性能、保护、配置或安全性。

* *名称*
+
事件名称。您可以选择名称以显示该事件的“事件详细信息”页面。

* *源*
+
已发生事件的对象名称。您可以选择名称以显示该对象的运行状况或性能详细信息页面。

+
当发生共享 QoS 策略违规时，此字段中仅显示占用最多 IOPS 或 MB/s 的工作负载对象。使用此策略的其他工作负载将显示在事件详细信息页面中。

* *源类型*
+
与事件关联的对象类型（例如，Storage VM、卷或 Qtree）。

* *分配给*
+
事件分配到的用户名称。

* *事件起源*
+
事件是源自“Active IQ Portal”还是直接源自“Active IQ Unified Manager”。

* *注释名称*
+
分配给存储对象的批注的名称。

* *备注*
+
为事件添加的注释数。

* *待处理天数*
+
事件最初生成后的天数。

* *分配时间*
+
事件分配给用户后经过的时间。如果经过的时间超过一周，则会显示事件分配给用户的时间戳。

* *确认人*
+
确认此事件的用户的名称。如果事件未确认，此字段为空。

* *确认时间*
+
事件确认后经过的时间。如果经过的时间超过一周，则会显示事件确认的时间戳。

* *解决者*
+
解决事件的用户的名称。如果事件未解决，则此字段为空。

* *解决时间*
+
事件解决后经过的时间。如果经过的时间超过一周，则会显示事件解决的时间戳。

* *废弃时间*
+
事件状态变为已过时的时间。
