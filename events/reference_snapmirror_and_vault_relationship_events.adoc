= 了解 Active IQ Unified Manager 中的异步镜像和 Vault 关系事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
异步镜像和 Vault 关系事件为您提供有关异步 SnapMirror 和 Vault 关系状态的信息，以便您可以监控潜在问题。卷和 Storage VM 保护关系均支持异步镜像和 Vault 关系事件。但是，只有 Vault 关系不支持 Storage VM 灾难恢复。事件按影响区域分组，包括事件和 trap 名称、影响级别、源类型和严重程度。



[[impact-area-protection]]
