= 使用 Active IQ Unified Manager 中的自动修复功能修复问题
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 可以使用 *Fix It* 按钮彻底诊断某些事件并提供单一解决方案。如果可用，这些解决方案将显示在仪表板、事件详细信息页面和左侧导航菜单上的工作负载分析选项中。

大多数事件都有各种可能的解决方案，这些解决方案显示在事件详细信息页面中，因此您可以使用 ONTAP System Manager 或 ONTAP CLI 实施最佳解决方案。当 Unified Manager 确定存在解决此问题的单一解决方案，并且可以使用 ONTAP CLI 命令解决此问题时，可以使用 *Fix It* 操作。

.步骤
. 要查看可通过*仪表板*修复的事件，请点击*仪表板*。
+
image::../media/management_actions.png[显示如何从仪表板查看和修复事件的 UI 屏幕截图。]

. 要解决 Unified Manager 可以修复的任何问题，请单击 *修复它* 按钮。要修复多个对象上存在的问题，请单击 *全部修复* 按钮。


有关可通过自动修正修复的问题的信息，请参见 link:..//storage-mgmt/reference_what_ontap_issues_can_unified_manager_fix.html["Unified Manager 可以解决哪些问题"]。
