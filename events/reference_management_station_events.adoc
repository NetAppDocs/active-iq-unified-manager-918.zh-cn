[NOTE]
====
最后两个性能事件仅适用于 Unified Manager 7.2。如果这些事件中的任何一个处于“新建”状态，然后您升级到较新版本的 Unified Manager 软件，则不会自动清除这些事件。您需要手动将事件移至“已解决”状态。
