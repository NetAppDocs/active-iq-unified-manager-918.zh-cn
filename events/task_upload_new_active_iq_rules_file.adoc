= 在 Active IQ Unified Manager 中上传新的 Active IQ 规则文件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 会自动检查新的 Active IQ 事件（规则）文件，并在有更新规则时下载新文件。但是，在没有外部网络访问权限的站点中，您需要手动上传规则文件。


NOTE: Active IQ 规则也称为 Config Advisor （CA） 安全规则。

当您在没有网络连接的站点中将 Unified Manager 安装或升级到特定版本时，捆绑的 Active IQ 规则将自动可用于上传。但是，建议您大约每月从 NetApp 支持站点下载一次新的规则文件，以确保生成更新的事件，并且您的存储系统继续保持最佳性能。

.开始之前
* 必须启用 Active IQ 门户事件报告。默认情况下，此功能处于启用状态。有关信息，请参见 link:../config/concept_active_iq_platform_events.html["启用 Active IQ 门户事件"]。
* 您必须从 NetApp 支持站点下载规则文件。
+
规则文件位于： https://mysupport.netapp.com/api/content-service/staticcontents/content/public/tools/unifiedmanager/ca/secure_rules.zip[]



.步骤
. 在具有网络访问权限的计算机上，导航到 NetApp 支持站点并下载当前规则 `.zip`文件。
+
捆绑的规则包包括规则存储库、数据源和 NetApp 知识库文章。

+

NOTE: 在 Windows 系统上，在没有网络连接的站点中，默认情况下，NetApp 知识库文章不会与安装程序捆绑在一起。您可以从支持站点下载 _secure_rules.zip_ 文件并上传，以查看所有规则的知识库文章。

. 将规则文件传输到您可以带入安全区域的某些介质，然后将其复制到安全区域的系统上。
. 在左侧导航窗格中，单击*存储管理* > *事件设置*。
. 在 *Event Setup* 页面中，单击 *Upload Rules* 按钮。
. 在*上传规则*对话框中，导航到并选择您下载的规则 `.zip`文件，然后单击*上传*。
+
此过程可能需要几分钟时间。



规则文件将在 Unified Manager 服务器上解压缩。在您的托管集群于午夜后生成 AutoSupport 文件后，Unified Manager 将根据规则文件检查集群，并根据需要生成新的风险和突发事件。

有关详细信息，请参见此知识库（KB）文章： https://kb.netapp.com/Advice_and_Troubleshooting/Data_Infrastructure_Management/Active_IQ_Unified_Manager/How_to_update_AIQCASecure_rules_manually_in_Active_IQ_Unified_Manager["如何在 Active IQ Unified Manager 中手动更新 AIQCASecure 规则"]。
