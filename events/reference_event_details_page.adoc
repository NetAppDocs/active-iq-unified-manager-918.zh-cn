= 了解 Active IQ Unified Manager 中的事件详细信息页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
从“事件详细信息”页面，您可以查看所选事件的详细信息，例如事件严重程度、影响级别、影响区域和事件源。您还可以查看有关可能的修复措施的其他信息，以解决此问题。

* *事件名称*
+
事件的名称和上次发现事件的时间。

+
对于非性能事件，当事件处于“新建”或“已确认”状态时，最后看到的信息未知，因此被隐藏。

* *事件描述*
+
对事件的简要描述。

+
在某些情况下，事件触发的原因会在事件描述中提供。

* *争用组件*
+
对于动态性能事件，此部分显示表示集群的逻辑和物理组件的图标。如果组件处于争用状态，其图标将带圆圈并突出显示为红色。

+
有关此处显示的组件的说明，请参阅 _Cluster components and why they can be in contention_。



事件信息、系统诊断和建议操作部分在其他主题中进行了说明。



[[command-buttons]]
== 命令按钮

这些命令按钮可用来执行下列任务：

* *备注图标*
+
使您可以添加或更新有关事件的备注，并查看其他用户留下的所有备注。



*操作菜单*

* *分配给我*
+
将此事件分配给您。

* *分配给其他人*
+
打开“分配所有者”对话框，用于将事件分配或重新分配给其他用户。

+
将事件分配给用户时，用户的名称和事件分配的时间将添加到选定事件的事件列表中。

+
您也可以将所有权字段留空，以取消分配事件。

* *确认*
+
确认所选事件，这样您就不会继续收到重复警报通知。

+
当您确认事件时，您的用户名和确认事件的时间将添加到选定事件的事件列表（确认人）中。当您确认某个事件时，您负责管理该事件。

* *标记为已解决*
+
使您能够将事件状态更改为“已解决”。

+
当您解决事件时，您的用户名和解决该事件的时间将添加到所选事件的事件列表（解决者）中。对事件采取纠正措施后，必须将该事件标记为已解决。

* *添加警报*
+
显示“添加警报”对话框，用于为选定事件添加警报。
