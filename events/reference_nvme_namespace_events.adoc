= 了解 Active IQ Unified Manager 中的 NVMe 命名空间事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NVMe 命名空间事件可为您提供有关命名空间状态的信息，以便您可以监视潜在问题。事件按影响区域分组，包括事件和陷阱名称、影响级别、来源类型和严重程度。

星号（*）用于标识已转换为 Unified Manager 事件的 EMS 事件。
