= 在 Active IQ Unified Manager 中添加警报的准则
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以根据资源（如群集、节点、聚合或卷）以及特定严重性类型的事件添加警报。作为最佳做法，您可以在添加对象所属的群集后，为任何关键对象添加警报。

您可以使用以下指南和注意事项来创建警报，以有效地管理您的系统：

* 警报说明
+
您应提供警报的描述，以帮助您有效跟踪警报。

* 资源
+
您应该决定哪个物理或逻辑资源需要警报。您可以根据需要包括和排除资源。例如，如果要通过配置警报来密切监视聚合，则必须从资源列表中选择所需的聚合。

+
如果您选择一个资源类别，例如 *+<<All User or Group Quotas>>+*，则您将收到该类别中所有对象的警报。

+
[NOTE]
====
选择集群作为资源不会自动选择该集群中的存储对象。例如，如果您为所有集群的所有严重事件创建警报，则只会收到集群严重事件的警报。您不会收到有关节点、聚合等严重事件的警报。

====
* 事件严重性
+
您应该决定指定严重程度类型（严重、错误、警告）的事件是否应触发警报，如果是，则决定哪种严重程度类型。

* 选定事件
+
如果根据生成的事件类型添加警报，则应决定哪些事件需要警报。

+
如果您选择事件严重程度，但未选择任何单个事件（如果将“所选事件”列留空），则您将收到该类别中所有事件的警报。

* 操作
+
您必须提供接收通知的用户的用户名和电子邮件地址。您还可以将 SNMP 陷阱指定为通知模式。您可以将脚本与警报相关联，以便在生成警报时执行。

* 通知频率
+
您可以将警报配置为在指定时间内重复向收件人发送通知。您应该确定警报的事件通知处于活动状态的时间。如果要在事件被确认之前重复事件通知，则应确定重复通知的频率。

* 执行脚本
+
您可以将脚本与警报相关联。生成警报时会执行脚本。
