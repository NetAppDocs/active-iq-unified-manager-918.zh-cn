= 安排维护时段以禁用 Active IQ Unified Manager 中的集群事件通知
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您有计划的群集停机时间，例如升级群集或移动其中一个节点，则可以通过安排 Unified Manager 维护窗口来抑制通常在该时间范围内生成的事件和警报。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

在维护窗口期间，仍会生成与该集群上的所有对象相关的事件，但它们不会显示在事件页面中，并且不会为这些事件发送警报或其他类型的通知。

您为维护时段输入的时间基于 Unified Manager 服务器的时间。

.步骤
. 在左侧导航窗格中，单击*存储管理* > *集群设置*。
. 在集群的*维护模式*列中，选择滑块按钮并将其向右移动。
+
此时将显示日历窗口。

. 选择维护窗口的开始和结束日期和时间，然后单击*应用*。
+
“Scheduled” 消息出现在滑块按钮旁边。



到达开始时间时，集群进入维护模式，并生成“对象维护窗口已启动”事件。
