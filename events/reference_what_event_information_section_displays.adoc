= 了解 Active IQ Unified Manager 中的事件信息部分
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用事件详细信息页面上的"事件信息"部分，查看有关所选事件的详细信息，例如事件严重性、影响级别、影响区域和事件源。

不适用于该事件类型的字段将被隐藏。您可以查看以下事件详细信息：

* *事件触发时间*
+
生成事件的时间。

* *State*
+
事件状态：新建、已确认、已解决或已废弃。

* *废弃原因*
+
导致事件被废弃的操作，例如，问题已修复。

* *事件持续时间*
+
对于活动（新建和已确认）事件，这是检测到事件与上次分析事件之间的时间。对于过时的事件，这是检测到事件和解决事件之间的时间。

+
此字段针对所有性能事件显示，对于其他事件类型，仅在它们已解决或已过时后才显示。

* *上次查看时间*
+
上次将事件显示为活动的日期和时间。

+
对于性能事件，此值可能比事件触发时间更新，因为只要事件处于活动状态，此字段就会在每次新的性能数据收集之后更新。对于其他类型的事件，当处于“新建”或“已确认”状态时，此内容不会更新，因此该字段将被隐藏。

* *严重程度*
+
事件严重性：Critical （严重）（image:../media/sev_critical_um60.png[""]）、Error （错误）（image:../media/sev_error_um60.png[""]）、Warning （警告）（image:../media/sev_warning_um60.png[""]）和 Information （信息）（image:../media/sev_information_um60.gif[""]）。

* *影响级别*
+
事件影响级别：突发事件、风险、事件或升级。

* *影响区域*
+
事件影响区域：可用性、容量、性能、保护、配置或安全性。

* *源*
+
发生事件的对象的名称。

+
查看共享 QoS 策略事件的详细信息时，此字段中最多会列出三个消耗 IOPS 或 MBps 最多的工作负载对象。

+
您可以单击源名称链接来显示该对象的运行状况或性能详细信息页面。

* *源注释*
+
显示与事件关联的对象的批注名称和值。

+
此字段仅对群集、SVM 和卷上的运行状况事件显示。

* *源组*
+
显示受影响对象所属的所有组的名称。

+
此字段仅对群集、SVM 和卷上的运行状况事件显示。

* *源类型*
+
与事件关联的对象类型（例如 SVM、Volume 或 Qtree）。

* *在集群上*
+
发生事件的集群的名称。

+
您可以单击集群名称链接来显示该集群的运行状况或性能详细信息页面。

* *受影响对象计数*
+
受此事件影响的对象数。

+
您可以单击对象链接来显示包含当前受此事件影响的对象的清单页面。

+
此字段仅针对性能事件显示。

* *受影响的卷*
+
受此事件影响的卷数。

+
此字段仅针对节点或聚合上的性能事件显示。

* *触发策略*
+
发出事件的阈值策略的名称。

+
您可以将光标悬停在策略名称上，以查看阈值策略的详细信息。对于自适应 QoS 策略，还会显示定义的策略、块大小和分配类型（分配空间或已用空间）。

+
此字段仅针对性能事件显示。

* *规则 ID*
+
对于 Active IQ 平台事件，这是触发生成此事件的规则编号。

* *确认人*
+
确认该事件的人员的姓名和确认该事件的时间。

* *解决者*
+
解决事件的人员姓名和事件解决的时间。

* *分配给*
+
被指派处理该事件的人员的姓名。

* *警报设置*
+
此时将显示有关警报的以下信息：

+
** 如果没有与选定事件关联的警报，则会显示*添加警报*链接。
+
您可以通过单击链接打开“添加警报”对话框。

** 如果有一个警报与所选事件关联，则会显示警报名称。
+
您可以通过单击链接打开“编辑警报”对话框。

** 如果有多个警报与所选事件相关联，则会显示警报数量。
+
您可以通过单击链接打开“警报设置”页面，以查看有关这些警报的更多详细信息。



+
已禁用的警报不会显示。

* *上次发送的通知*
+
发送最新警报通知的日期和时间。

* *发送方式*
+
用于发送警报通知的机制：电子邮件或 SNMP 陷阱。

* *上次脚本运行*
+
生成警报时所执行脚本的名称。
