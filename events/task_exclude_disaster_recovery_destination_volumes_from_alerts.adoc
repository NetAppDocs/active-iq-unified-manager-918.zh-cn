= 在 Active IQ Unified Manager 中排除灾难恢复目标卷以避免生成警报
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
配置卷警报时，您可以在“警报”对话框中指定一个字符串来标识一个卷或一组卷。但是，如果您已为 SVM 配置了灾难恢复，则源卷和目标卷具有相同的名称，因此您将收到两个卷的警报。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

可以通过排除具有目标 SVM 名称的卷来禁用灾难恢复目标卷的警报。这是可行的，因为卷事件的标识符同时包含 SVM 名称和卷名称，格式为“<svm_name>:/<volume_name>”。

以下示例显示如何在主 SVM “vs1” 上为卷 “vol1” 创建警报，但排除在 SVM “vs1-dr” 上的同名卷上生成警报。

请在添加警报对话框中执行以下步骤：

.步骤
. 单击*名称*并输入警报的名称和描述。
. 单击*资源*，然后选择*包括*选项卡。
+
.. 从下拉列表中选择*卷*，然后在*名称包含*字段中输入 *`vol1`*，以显示名称包含 "vol1" 的卷。
.. 从*可用资源*区域选择 *+<<All Volumes whose name contains 'vol1'>>+*，并将其移动到*选定资源*区域。


. 选择 *Exclude* 选项卡，选择 *Volume*，在 *Name contains* 字段中输入 *`vs1-dr`*，然后单击 *Add*。
+
这排除了在 SVM "vs1-dr" 上为卷 "vol1" 生成的警报。

. 单击*事件*并选择要应用于卷的事件。
. 单击*操作*，然后在*提醒这些用户*字段中选择将接收警报电子邮件的用户的名称。
. 配置此页面上用于发出 SNMP 陷阱和执行脚本的任何其他选项，然后单击 *保存*。
