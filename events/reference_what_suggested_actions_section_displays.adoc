= 了解 Active IQ Unified Manager 中的建议操作
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
“事件详细信息”页面的“建议操作”部分提供了此事件的可能原因，并建议了一些操作，以便您可以尝试自行解决此事件。建议的操作是根据已违反的事件类型或阈值类型进行自定义的。

此区域仅针对某些类型的事件显示。

在某些情况下，页面上提供的*帮助*链接会引用许多建议操作的其他信息，包括执行特定操作的说明。其中一些操作可能涉及使用 Unified Manager、ONTAP System Manager、OnCommand Workflow Automation、ONTAP CLI 命令或这些工具的组合。

此处建议的操作仅供解决事件时参考。您应根据具体环境情况来确定用于解决此事件的操作。

如果要更详细地分析对象和事件，请单击*分析工作负载*按钮以显示工作负载分析页面。

Unified Manager 可以彻底诊断某些事件并提供单一解决方案。如果可用，这些解决方案将通过 *修复* 按钮显示。单击此按钮可让 Unified Manager 修复导致此事件的问题。

对于 Active IQ 平台事件，此部分可能包含指向 NetApp 知识库文章的链接（如果可用），该文章描述了问题和可能的解决方案。在没有外部网络访问权限的站点中，知识库文章的 PDF 将在本地打开；该 PDF 是手动下载到 Unified Manager 实例的规则文件的一部分。
