= 在 Active IQ Unified Manager 中编辑警报属性
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以编辑警报属性，例如与警报关联的资源、事件、脚本和通知选项。



[[name]]
== 名称

通过此区域，您可以编辑警报的名称和描述。

* *警报名称*
+
使您可以编辑警报名称。

* *警报说明*
+
使您能够指定警报的描述。

* *警报状态*
+
用于启用或禁用警报。





[[resources]]
== 资源

此区域允许您选择单个资源，或根据要触发警报的动态规则对资源进行分组。您可以通过从下拉列表中选择资源类型来搜索资源，也可以指定确切的资源名称以显示特定资源。

* *包括*
+
使您能够包含要为其触发警报的资源。您可以指定文本字符串来对与该字符串匹配的资源进行分组，并选择要包含在警报中的此组。例如，您可以对名称包含 "`vol0`" 字符串的所有卷进行分组。

* *排除*
+
使您能够排除不希望触发警报的资源。例如，您可以排除名称包含“`xyz`”字符串的所有卷。

+
[NOTE]
====
仅当您选择特定资源类型的所有资源（例如，+<<All Volumes>>+ 或 +<<All Volumes whose name contains 'xyz'>>+）时，“排除”选项卡才会显示。

====




[[events]]
== 事件

此区域可让您选择要触发警报的事件。您可以根据特定严重程度或针对一组事件触发事件警报。

* *事件严重程度*
+
使您能够根据严重程度类型选择事件，严重程度类型可以是“严重”、“错误”或“警告”。

* *事件名称包含*
+
使您能够选择名称包含指定字符的事件。





[[actions]]
== 操作

通过此区域，您可以指定通知方法和通知频率。

* *提醒这些用户*
+
使您能够编辑电子邮件地址或用户名，或指定新电子邮件地址或用户名以接收通知。

* *通知频率*
+
使您能够编辑管理服务器发送通知的频率，直到事件被确认、解决或移至过时状态。

+
您可以选择以下通知方法：

+
** 仅通知一次
** 以指定频率通知
** 在指定时间范围内以指定频率发送通知


* *发出 SNMP 陷阱*
+
使您能够指定是否应将 SNMP 陷阱发送到全局配置的 SNMP 主机。

* *执行脚本*
+
使您能够将脚本与警报相关联。此脚本在生成警报时执行。





[[command-buttons]]
== 命令按钮

* *保存*
+
保存更改并关闭对话框。

* *取消*
+
放弃更改并关闭对话框。
