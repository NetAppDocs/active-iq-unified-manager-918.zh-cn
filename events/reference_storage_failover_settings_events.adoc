= 了解 Active IQ Unified Manager 中的存储故障转移设置事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
存储故障转移（SFO）设置事件可为您提供有关存储故障转移是否已禁用或未配置的信息，以便您可以监控潜在问题。事件按影响区域分组，包括事件和陷阱名称、影响级别、来源类型和严重程度。
