= 了解 Active IQ Unified Manager 中的事件影响级别
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
每个事件都与影响级别（突发事件、风险、事件或升级）相关联，以帮助您优先处理需要立即采取纠正措施的事件。

* *事件*
+
事件是一组可能导致集群停止向客户端提供数据并耗尽数据存储空间的事件。影响级别为"事件"的事件最为严重。应立即采取纠正措施，以避免服务中断。

* *风险*
+
风险是一组事件，这些事件可能会导致集群停止向客户端提供数据，并耗尽用于存储数据的空间。影响级别为“风险”的事件可能会导致服务中断。可能需要采取纠正措施。

* *事件*
+
事件是存储对象及其属性的状态或状态更改。影响级别为“事件”的事件仅供参考，无需采取纠正措施。

* *升级*
+
升级事件是 Active IQ 平台报告的特定类型的事件。这些事件指出的问题，其解决方案需要您升级 ONTAP 软件、节点固件或操作系统软件（针对安全公告）。您可能需要立即对其中一些问题采取纠正措施，而其他问题则可以等到下一次计划内维护时再处理。
