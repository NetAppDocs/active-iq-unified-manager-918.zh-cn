= Active IQ Unified Manager 如何计算对象状态
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
对象状态由当前处于“新建”或“已确认”状态的最严重事件确定。例如，如果对象状态为 Error，则对象的某个事件的严重性类型为 Error。采取纠正措施后，事件状态将变为“已解决”。
