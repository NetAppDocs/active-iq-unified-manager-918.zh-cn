= 了解 Active IQ Unified Manager 中的 SnapMirror 关系事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SnapMirror 关系事件为您提供有关异步和同步 SnapMirror 关系状态的信息，以便您可以监控潜在问题。异步 SnapMirror 关系事件是为 Storage VM 和卷生成的，而同步 SnapMirror 关系事件仅为卷关系生成。不会为属于 Storage VM 灾难恢复关系的组成卷生成任何事件。事件按影响区域分组，包括事件和陷阱名称、影响级别、源类型和严重程度。
