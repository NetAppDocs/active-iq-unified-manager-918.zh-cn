= 了解 Active IQ Unified Manager 中的事件管理系统事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Event Management System (EMS) 从 ONTAP 内核的不同部分收集事件数据，并提供事件转发机制。这些 ONTAP 事件可以在 Unified Manager 中报告为 EMS 事件。集中式监控和管理简化了基于这些 EMS 事件的关键 EMS 事件和警报通知的配置。

将集群添加到 Unified Manager 时，会将 Unified Manager 地址作为通知目标添加到集群。EMS 事件在集群中发生后立即报告。

在 Unified Manager 中接收 EMS 事件有两种方法：

* 一定数量的重要 EMS 事件会自动报告。
* 您可以订阅接收单个 EMS 事件。


Unified Manager 生成的 EMS 事件会根据生成事件的方法进行不同的报告：

[NOTE]
====
一些新的自动 EMS 事件是指示先前事件已解决的信息事件。例如，“FlexGroup Constituents Space Status All OK”信息事件指示“FlexGroup Constituents Have Space Issues”错误事件已解决。信息事件不能使用与其他事件严重性类型相同的事件生命周期来管理，但是，如果同一卷收到另一个“`Space Issues`”错误事件，则该事件将自动废弃。
