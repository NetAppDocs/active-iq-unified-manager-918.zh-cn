= 了解 Active IQ Unified Manager 中的系统诊断
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
“事件详细信息”页面的“系统诊断”部分提供了可以帮助您诊断可能导致该事件的问题的信息。

此区域仅针对某些事件显示。

某些性能事件会提供与已触发的特定事件相关的图表。通常，这包括前十天的 IOPS 或 MBps 图表以及延迟图表。以这种方式排列后，您可以看到在事件处于活动状态时，哪些存储组件对延迟的影响最大，或受延迟影响最大。

对于动态性能事件，将显示以下图表：

* 工作负载延迟 - 显示处于争用状态的组件中最严重的受害者、欺凌者或鲨鱼工作负载的延迟历史记录。
* 工作负载活动 - 显示有关处于争用状态的集群组件的工作负载使用情况的详细信息。
* 资源活动 - 显示争用中的集群组件的历史性能统计信息。


当某些集群组件处于争用状态时，将显示其他图表。

其他事件提供了系统对存储对象执行的分析类型的简要描述。在某些情况下，会有一行或多行；对于分析多个性能计数器的系统定义性能策略，每个已分析的组件对应一行。在这种情况下，诊断旁边将显示一个绿色或红色图标，以指示在该特定诊断中是否发现了问题。
