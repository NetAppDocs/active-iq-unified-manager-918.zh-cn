= 了解 Active IQ Unified Manager 中的"警报设置"页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
警报设置页面显示警报列表，并提供有关警报名称、状态、通知方法和通知频率的信息。您还可以从此页面添加、编辑、删除、启用或禁用警报。

您必须具有应用程序管理员或存储管理员角色。



[[command-buttons]]
== 命令按钮

* *添加*
+
显示用于添加新警报的“添加警报”对话框。

* *编辑*
+
显示编辑警报对话框，用于编辑选定的警报。

* *删除*
+
删除选定的警报。

* *启用*
+
启用选定警报以发送通知。

* *禁用*
+
当您想要暂时停止发送通知时，禁用选定的警报。

* *测试*
+
测试选定警报，以在添加或编辑后验证其配置。

* *针对已解决和已废弃的事件发出的警报*
+
允许您在事件移动到“已解决”或“已过时”状态时启用或禁用发送警报。这可以帮助用户避免收到不必要的通知。





[[list-view]]
== 列表视图

列表视图以表格格式显示有关创建的警报的信息。您可以使用列筛选器自定义显示的数据。您还可以选择一个警报，以便在详细信息区域中查看有关该警报的更多信息。

* *状态*
+
指定警报是启用（image:../media/alert_status_enabled.gif[""]）还是禁用（image:../media/alert_status_disabled.gif[""]）。

* *警报*
+
显示警报的名称。

* *说明*
+
显示警报的说明。

* *通知方法*
+
显示为警报选择的通知方法。您可以通过电子邮件或 SNMP 陷阱通知用户。

* *通知频率*
+
指定管理服务器继续发送通知的频率（分钟），直到事件被确认、解决或移至“已过时”状态。





[[details-area]]
== 详细信息区域

详细信息区域提供有关所选警报的更多信息。

* *警报名称*
+
显示警报的名称。

* *警报说明*
+
显示警报的说明。

* *事件*
+
显示要触发警报的事件。

* *资源*
+
显示要触发警报的资源。

* *包括*
+
显示要为其触发警报的资源组。

* *不包括*
+
显示不希望触发警报的资源组。

* *通知方法*
+
显示该警报的通知方法。

* *通知频率*
+
显示管理服务器继续发送警报通知的频率，直到事件被确认、解决或移至“已过时”状态。

* *脚本名称*
+
显示与所选警报关联的脚本的名称。生成警报时执行此脚本。

* *电子邮件收件人*
+
显示接收警报通知的用户的电子邮件地址。
