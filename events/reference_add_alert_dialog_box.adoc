= 了解 Active IQ Unified Manager 中的"添加警报"对话框
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以创建警报以在生成特定事件时通知您，以便快速解决问题，从而最大限度地减少对环境的影响。您可以为单个资源或一组资源以及特定严重性类型的事件创建警报。您还可以指定警报的通知方法和频率。

您必须具有应用程序管理员或存储管理员角色。



[[name]]
== 名称

通过此区域，您可以指定警报的名称和描述：

* *警报名称*
+
使您可以指定警报名称。

* *警报说明*
+
使您能够指定警报的描述。





[[resources]]
== 资源

此区域允许您选择单个资源，或根据要为其触发警报的动态规则对资源进行分组。_动态规则_是根据您指定的文本字符串筛选出的一组资源。您可以通过从下拉列表中选择资源类型来搜索资源，也可以指定确切的资源名称以显示特定资源。

如果从任何存储对象详细信息页面创建警报，则存储对象将自动包含在警报中。

* *包括*
+
使您能够包含要为其触发警报的资源。您可以指定文本字符串来对与该字符串匹配的资源进行分组，并选择将此组包含在警报中。例如，您可以对名称包含“abc”字符串的所有卷进行分组。

* *排除*
+
使您能够排除不希望触发警报的资源。例如，您可以排除名称包含“xyz”字符串的所有卷。

+
仅当您选择特定资源类型的所有资源时，才会显示“排除”选项卡：例如，+<<All Volumes>> 或 <<All Volumes whose name contains 'xyz'>>+。

+
如果资源同时符合您指定的包含和排除规则，则排除规则优先于包含规则，并且不会为该事件生成警报。





[[events]]
== 事件

此区域可让您选择要为其创建警报的事件。您可以根据特定严重程度为事件创建警报，也可以为一组事件创建警报。

要选择多个事件，请在进行选择时按住 Ctrl 键。

* *事件严重程度*
+
使您能够根据严重程度类型选择事件，严重程度类型可以是“严重”、“错误”或“警告”。

* *事件名称包含*
+
使您能够选择名称包含指定字符的事件。





[[actions]]
== 操作

通过此区域，您可以指定触发警报时要通知的用户。您还可以指定通知方法和通知频率。

* *提醒这些用户*
+
允许您指定要接收通知的用户的电子邮件地址或用户名。

+
如果修改为用户指定的电子邮件地址并重新打开警报进行编辑，则“名称”字段将显示为空白，因为修改后的电子邮件地址不再映射到先前选择的用户。此外，如果已从“用户”页面修改所选用户的电子邮件地址，则不会为所选用户更新已修改的电子邮件地址。

* *通知频率*
+
使您能够指定管理服务器在事件被确认、解决或移至过时状态之前发送通知的频率。

+
您可以选择以下通知方法：

+
** 仅通知一次
** 以指定频率通知
** 在指定时间范围内以指定频率发送通知


* *发出 SNMP 陷阱*
+
选中此框可指定是否应将 SNMP 陷阱发送到全局配置的 SNMP 主机。

* *执行脚本*
+
使您能够将自定义脚本添加到警报。此脚本在生成警报时执行。

+
[NOTE]
====
如果在用户界面中看不到此功能，则是因为管理员已禁用此功能。如果需要，您可以从*存储管理* > *功能设置*启用此功能。

====




[[command-buttons]]
== 命令按钮

* *保存*
+
创建警报并关闭此对话框。

* *取消*
+
放弃更改并关闭对话框。
