= 在 Active IQ Unified Manager 中查看 FabricPool 容量信息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在这些对象的容量和性能清单以及详细信息页面上查看集群、聚合和卷的 FabricPool 容量信息。配置镜像层后，这些页面还会显示 FabricPool 镜像信息。

这些页面显示以下信息：本地性能层和云层上的可用容量、这两个层中正在使用的容量、哪些聚合已附加到云层，以及哪些卷正在通过将某些信息移动到云层来实施 FabricPool 功能。

当云层镜像到另一个云提供商（"`镜像层`"）时，两个云层都会显示在聚合/运行状况详细信息页面中。

.步骤
. 执行以下操作之一：
+
[cols="2*"]
|===
| 要查看……的容量信息 | 操作 


 a| 
集群
 a| 
.. 在“容量：所有集群”视图中，单击集群。
.. 在集群/运行状况详细信息页面上，单击 *配置* 选项卡。
+
显示屏显示此集群连接到的任何云层的名称。





 a| 
聚合
 a| 
.. 在“容量：所有聚合”视图中，单击“类型”字段指示“`SSD (FabricPool)`”或“`HDD (FabricPool)`”的聚合。
.. 在聚合/健康详细信息页面上，单击*容量*选项卡。
+
此显示屏显示云层中使用的总容量。

.. 单击*磁盘信息*选项卡。
+
显示屏会显示云层的名称和已用容量。

.. 单击 *Configuration* 选项卡。
+
此显示屏显示云层的名称以及有关云层的其他详细信息。





 a| 
卷
 a| 
.. 在“容量：所有卷”视图上，单击“分层策略”字段中显示策略名称的卷。
.. 在“卷/运行状况详细信息”页面上，单击 *配置* 选项卡。
+
显示屏显示分配给该卷的 FabricPool 分层策略的名称。



|===
. 在*工作负载分析*页面中，您可以在*容量趋势*区域中选择 "`云层视图`"，以查看上个月本地性能层和云层中使用的容量。


有关 FabricPool 聚合的更多信息，请参见 https://docs.netapp.com/us-en/ontap/disks-aggregates/index.html["磁盘和聚合概述"]。
