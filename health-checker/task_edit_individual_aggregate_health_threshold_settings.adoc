= 在 Active IQ Unified Manager 中编辑单个聚合运行状况阈值设置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以编辑一个或多个聚合的聚合容量、增长和 Snapshot 副本的运行状况阈值设置。超过阈值时，将生成警报，您将收到通知。这些通知可帮助您根据生成的事件采取预防措施。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

根据阈值更改，下一监控周期将生成或废弃事件。

当对驻留于聚合上的卷启用自动增长时，系统将根据自动增长设置的最大卷大小（而非原始卷大小）来评估是否超出聚合容量阈值。

.步骤
. 在左侧导航窗格中，单击*存储* > *聚合*。
. 在 *运行状况：所有聚合* 视图中，选择一个或多个聚合，然后单击 *编辑阈值*。
. 在*编辑聚合阈值*对话框中，通过选中相应的复选框，然后修改设置来编辑以下选项之一的阈值设置：容量、增长或 Snapshot 副本。
. 单击 *Save*。
