= 在 Active IQ Unified Manager 中配置全局卷运行状况阈值
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以配置所有卷的全局运行状况阈值，以跟踪任何阈值违规情况。系统会针对运行状况阈值违规生成相应事件，您可以根据这些事件采取预防措施。您可以根据适用于所有受监控卷的阈值最佳实践设置来配置全局值。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

大多数阈值选项都有默认值，以便更好地进行监控。但是，您可以更改这些值以满足您的环境要求。

请注意，当在卷上启用 Autogrow 时，系统将根据 Autogrow 设置的最大卷大小（而不是基于原始卷大小）来判断容量阈值是否已超出。

[NOTE]
====
默认值 1000 个 Snapshot 副本仅适用于 ONTAP 版本为 9.4 或更高版本时的 FlexVol 卷，以及 ONTAP 版本为 9.8 或更高版本时的 FlexGroup 卷。对于安装了较旧版本 ONTAP 软件的集群，每个卷的最大 Snapshot 副本数为 250 个。对于这些较旧版本，Unified Manager 会将 1000（以及 1000 到 250 之间的任何数字）解释为 250；这意味着当 Snapshot 副本数量达到 250 时，您将继续收到事件。如果您希望针对这些较旧版本将此阈值设置为低于 250，则必须在此处、在"运行状况: 所有卷"视图中或在"卷/运行状况详细信息"页面中将阈值设置为 250 或更低。

====
.步骤
. 在左侧导航窗格中，单击*事件阈值* > *卷*。
. 为容量、Snapshot 副本、qtree 配额、卷增长和 inode 配置适当的阈值。
. 单击 *Save*。
