= 访问 Active IQ Unified Manager 中的维护控制台
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果 Unified Manager 用户界面未运行，或者需要执行用户界面中不可用的功能，则可以访问维护控制台来管理 Unified Manager 系统。

.开始之前
您必须已安装并配置 Unified Manager。

15 分钟不活动后，维护控制台会将您注销。

[NOTE]
====
在 VMware 上安装时，如果已经通过 VMware 控制台以维护用户身份登录，则不能同时使用 Secure Shell 登录。

====
.步骤
. 按照下面的步骤访问维护控制台：
+
[cols="2*"]
|===
| 在此操作系统上…… | 按照下面的步骤进行操作...... 


 a| 
VMware
 a| 
.. 使用 Secure Shell，连接到 Unified Manager 虚拟设备的 IP 地址或完全限定的域名。
.. 使用您的维护用户名和密码登录到维护控制台。




 a| 
Linux
 a| 
.. 使用 Secure Shell，连接到 Unified Manager 系统的 IP 地址或完全限定域名。
.. 使用维护用户 (umadmin) 名称和密码登录到此系统。
.. 输入命令 `maintenance_console`并按 Enter 键。




 a| 
Windows
 a| 
.. 使用管理员凭据登录到 Unified Manager 系统。
.. 以 Windows 管理员身份启动 PowerShell。
.. 输入命令 `maintenance_console`并按 Enter 键。


|===
+
此时将显示 Unified Manager 维护控制台菜单。
