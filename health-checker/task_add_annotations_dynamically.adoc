= 在 Active IQ Unified Manager 中动态添加注释
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
创建自定义注释时，Unified Manager 会使用规则将集群、存储虚拟机（SVM）和卷与注释动态关联。这些规则会自动将注释分配给存储对象。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

.步骤
. 在左侧导航窗格中，单击 *存储管理* > *注释*。
. 在*注释*页面中，单击*添加注释*。
. 在*添加注释*对话框中，键入注释的名称和描述。
. 可选：在*注释值*部分，单击*添加*以向注释添加值。
. 单击 *Save*。
