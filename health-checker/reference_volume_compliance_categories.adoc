= 了解 Active IQ Unified Manager 中的卷合规性类别
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
此表描述了 Unified Manager 评估的卷加密参数，以确定卷上的数据是否得到充分保护，防止未经授权的用户访问。

请注意，卷加密参数不影响集群或存储 VM 是否被视为合规。

[cols="2*"]
|===
| 参数 | 问题描述 


 a| 
软件加密
 a| 
显示使用 NetApp 卷加密（NVE）或 NetApp 聚合加密（NAE）软件加密解决方案保护的卷数。



 a| 
硬件加密
 a| 
显示使用 NetApp 存储加密（NSE）硬件加密保护的卷数。



 a| 
软件加密和硬件加密
 a| 
显示受软件和硬件加密保护的卷数。



 a| 
未加密
 a| 
显示未加密的卷数。

|===
