= 在 Active IQ Unified Manager 中检查 MetroCluster 配置中的集群健康状况
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Active IQ Unified Manager （Unified Manager）来检查基于 FC 的 MetroCluster 和基于 IP 的 MetroCluster 配置中集群及其组件的运行状况。如果集群涉及 Unified Manager 检测到的性能事件，则运行状况可以帮助您确定硬件或软件问题是否导致了该事件。

.开始之前
* 您必须具有操作员、应用程序管理员或存储管理员角色。
* 您必须已分析了 MetroCluster 配置的性能事件，并获得了所涉及集群的名称。
* FC 和 IP 上的 MetroCluster 配置中的两个集群必须由同一个 Unified Manager 实例监控。




[[determine-cluster-health-in-metrocluster-over-fc-configuration]]
== 确定 FC 配置中 MetroCluster 的集群运行状况

按照以下步骤确定 MetroCluster over FC 配置中的集群运行状况。

.步骤
. 在左侧导航窗格中，单击*事件管理*以显示事件列表。
. 在过滤器面板中，选择 *源类型* 类别下的所有 MetroCluster 过滤器。您可以看到环境中针对所有 MetroCluster 配置引发的所有事件。
. 在 MetroCluster 事件旁边，单击集群的名称。
+
[NOTE]
====
如果没有显示任何 MetroCluster 事件，您可以使用搜索栏搜索与您的 MetroCluster over FC 配置相关的事件中所涉及的集群名称。

====
+
此时将显示“运行状况：所有群集”视图，其中包含有关此事件的详细信息。

. 选择 *MetroCluster 连接* 选项卡以显示所选集群与其伙伴集群之间的连接运行状况。
+
image::../media/opm_um_mcc_connectivity_tab_png.gif[Unified Manager MetroCluster 连接选项卡]

+
在此示例中，显示本地群集及其伙伴群集的名称和组件。黄色或红色图标表示突出显示的组件的运行状况事件。“连接”图标表示群集之间的链接。您可以将鼠标光标指向一个图标以显示事件信息，或单击该图标以显示事件。任一群集上的运行状况问题可能导致了性能事件。

+
Unified Manager 可监控集群之间链路的 NVRAM 组件。如果本地或合作伙伴集群上的 FC 交换机图标或连接图标为红色，则可能是链路运行状况问题导致了性能事件。

. 选择 *MetroCluster 复制* 选项卡。
+
image::../media/opm_um_mcc_replication_tab_png.gif[Unified Manager MetroCluster 复制选项卡]

+
在此示例中，如果本地或合作伙伴群集上的 NVRAM 图标为黄色或红色，则 NVRAM 的运行状况问题可能导致了性能事件。如果页面上没有红色或黄色图标，则可能是合作伙伴群集上的性能问题导致了性能事件。





[[determine-cluster-health-in-metrocluster-over-ip-configuration]]
== 确定基于 IP 的 MetroCluster 配置中的群集健康状况

请按照以下步骤在 MetroCluster over IP 配置中确定集群健康状况。

.步骤
. 在左侧导航窗格中，单击*事件管理*以显示事件列表。
. 在筛选器面板的*源类型*类别下，选择 `MetroCluster Relationship`筛选器。您可以看到环境中针对所有 MetroCluster 配置引发的所有事件。
+
[NOTE]
====
如果您看不到报告的 MetroCluster 事件，您可以使用搜索栏按与您的基于 IP 的 MetroCluster 配置相关的事件中所涉及的集群名称进行搜索。

====
. 在相关 MetroCluster 事件旁边，单击集群的名称。此时将显示包含该集群详细信息的“集群”页面。有关确定运行状况问题的信息，请参阅link:../storage-mgmt/task_monitor_metrocluster_configurations.html["监控 MetroCluster over IP 配置中的连接问题"]。
