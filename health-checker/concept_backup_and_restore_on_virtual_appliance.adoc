= 在虚拟设备上备份和恢复 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当安装在虚拟设备上时，Unified Manager 的备份和还原模式是捕获和还原完整虚拟应用程序的映像。

通过下列任务可以完成虚拟设备的备份：

. 关闭虚拟机并获取 Unified Manager 虚拟设备的 VMware 快照。
. 在数据存储上创建 NetApp Snapshot 副本以捕获 VMware 快照。
+
如果此数据存储库未托管在运行 ONTAP 软件的系统上，请按照存储供应商准则来为 VMware 快照创建备份。

. 将 NetApp Snapshot 副本或 Snapshot 等效副本复制到备用存储。
. 删除 VMware 快照。


您应该使用这些任务实施备份计划，以确保在出现问题时对 Unified Manager 虚拟设备进行保护。

要还原虚拟机，可以使用所创建的 VMware 快照将虚拟机还原到备份时间点状况。
