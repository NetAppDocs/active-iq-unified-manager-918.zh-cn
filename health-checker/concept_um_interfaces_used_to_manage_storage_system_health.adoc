= 使用 Active IQ Unified Manager 界面管理存储系统运行状况
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead lead"]
这些部分包含有关 Active IQ Unified Manager 为解决数据存储容量、可用性和保护问题而提供的两个用户界面的信息。这两个 UI 是 Unified Manager Web UI 和维护控制台。

如果要在 Unified Manager 中使用保护功能，还必须安装和配置 OnCommand Workflow Automation (WFA)。



[[unified-manager-web-ui]]
== Unified Manager Web UI

Unified Manager Web UI 使管理员能够监控与数据存储容量、可用性和保护相关的集群问题并对其进行故障排除。

这些部分介绍了管理员可以遵循的一些常见工作流程，以便对 Unified Manager Web UI 中显示的存储容量、数据可用性或保护问题进行故障排除。



[[maintenance-console]]
== 维护控制台

Unified Manager 维护控制台使管理员能够监视、诊断和解决与 Unified Manager 服务器本身相关的操作系统问题、版本升级问题、用户访问问题和网络问题。如果 Unified Manager Web UI 不可用，则维护控制台是访问 Unified Manager 的唯一方式。

您可以使用此信息访问维护控制台并使用它来解决与 Unified Manager 服务器功能相关的问题。
