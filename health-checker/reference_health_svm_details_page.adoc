= 在 Active IQ Unified Manager 中查看 Storage VM / 运行状况详细信息页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Storage VM / 运行状况详细信息页面查看有关所选 Storage VM 的详细信息，例如其运行状况、容量、配置、数据策略、逻辑接口（LIF）、LUN、qtree、用户、用户组配额和保护详细信息。您还可以查看有关 Storage VM 的相关对象和相关警报的信息。

[NOTE]
====
您只能监控数据存储 VM。

====


[[command-buttons]]
== 命令按钮

通过命令按钮，您可以为选定的存储 VM 执行以下任务：

* *切换到性能视图*
+
使您能够导航到 Storage VM / 性能详细信息页面。

* *操作*
+
** 添加警报
+
使您能够向选定的 storage VM 添加警报。

** 标注
+
使您能够注释选定的 storage VM。



* *查看 Storage VM*
+
使您能够导航到运行状况：所有 Storage VM 视图。





[[health-tab]]
== 运行状况选项卡

“运行状况”选项卡显示有关各种对象（如卷、聚合、NAS LIF、SAN LIF、LUN、协议、服务、NFS 共享和 CIFS 共享）的数据可用性、数据容量和保护问题的详细信息。

您可以单击某个对象的图形来查看经过筛选的对象列表。例如，可以单击显示警告的卷容量图形来查看容量问题的严重性为“警告”的卷列表。

* *可用性问题*
+
以图形形式显示对象的总数，包括存在可用性问题的对象和不存在任何可用性相关问题的对象。图中的颜色表示问题的不同严重程度。图表下方的信息提供了有关可能影响或已经影响存储 VM 中数据可用性的可用性问题的详细信息。例如，显示有关已关闭的 NAS LIF 和 SAN LIF 以及离线的卷的信息。

+
此外，您还可以查看有关当前正在运行的相关协议和服务以及 NFS 和 CIFS 共享的数量和状态的信息。

* *容量问题*
+
以图形形式显示对象总数，包括存在容量问题的对象和不存在任何与容量相关问题的对象。图中的颜色表示问题的不同严重程度。图表下方的信息提供了有关可能影响或已经影响 storage VM 中数据容量的容量问题的详细信息。例如，显示有关可能超出设定阈值的聚合的信息。

* *保护问题*
+
通过将关系总数显示为字段对话框，提供与存储虚拟机保护相关的运行状况的快速概述，包括存在保护问题的关系和不存在任何保护相关问题的关系。您还可以查看选定存储虚拟机的存储虚拟机 DR 关系的状态。此处显示存储虚拟机 DR 关系事件，单击这些事件将转到事件详细信息页面。当存在未受保护的卷时，单击该链接将转到“运行状况：所有卷”视图，您可以在其中查看存储虚拟机上未受保护卷的过滤列表。图中的颜色表示问题的不同严重程度。单击图表将转到“关系：所有关系”视图，您可以在其中查看保护关系详细信息的筛选列表。图表下方的信息提供了有关可能影响或已经影响存储虚拟机中数据保护的保护问题的详细信息。例如，显示有关 Snapshot 副本预留量接近满的卷的信息或有关 SnapMirror 关系滞后问题的信息。





[[capacity-tab]]
== 容量选项卡

Capacity 选项卡显示有关选定 SVM 的数据容量的详细信息。

对于带有 FlexVol 卷或 FlexGroup 卷的 Storage VM，将显示以下信息：

* *容量*
+
“容量”区域显示有关从所有卷中分配的已用容量和可用容量的详细信息：

+
** 总容量
+
显示 Storage VM 的总容量。

** 已用
+
显示属于 Storage VM 的卷中的数据所使用的空间。

** 保证可用
+
显示 Storage VM 中可用于卷的数据的保证可用空间。

** 无保证
+
显示 Storage VM 中为精简配置卷分配的数据的剩余可用空间。



* *存在容量问题的卷*
+
“存在容量问题的卷”列表以表格形式显示有关具有容量问题的卷的详细信息：

+
** 状态
+
指示卷存在额定严重性的容量相关问题。

+
可以将指针移动到状态上方来查看针对该卷生成的一个或多个事件的详细信息。

+
如果卷的状态由单个事件确定，您可以查看事件名称、触发事件的时间和日期、获分配该事件的管理员名称以及事件原因等信息。您可以使用*查看详细信息*按钮查看有关该事件的更多信息。

+
如果卷的状态由相同严重程度的多个事件确定，则将显示前三个事件，其中包含事件名称、事件触发的时间和日期以及分配事件的管理员的名称等信息。您可以通过单击事件名称查看有关这些事件的更多详细信息。您还可以单击 *查看所有事件* 链接以查看生成的事件列表。

+
[NOTE]
====
一个卷可以具有多个严重性相同或不同的事件。但是，系统将仅显示最高严重性。例如，如果卷具有严重性为“错误”和“警告”的两个事件，则仅显示“错误”严重性。

====
** 卷
+
显示卷的名称。

** 已用数据容量
+
以图形方式显示卷容量使用量（百分比）的信息。

** 达到全满前的天数
+
显示在卷容量达到全满前的预计剩余天数。

** 精简配置
+
显示是否已为选定卷设置空间保证。有效值为“是”或“否”。

** 聚合
+
对于 FlexVol 卷，显示该卷所在聚合的名称。对于 FlexGroup 卷，显示 FlexGroup 中使用的聚合数。







[[configuration-tab]]
== 配置选项卡

“配置”选项卡显示有关所选存储虚拟机的配置详细信息，例如其群集、根卷、其包含的卷类型（FlexVol 卷）、策略以及在存储虚拟机上创建的保护：

* *概述*
+
** 集群
+
显示存储 VM 所属集群的名称。

** 允许的卷类型
+
显示可在存储 VM 中创建的卷类型。类型可以是 FlexVol 或 FlexVol/FlexGroup。

** 根卷
+
显示存储 VM 的根卷名称。

** 允许的协议
+
显示可以在存储 VM 上配置的协议类型。此外，还指示协议是已启动（image:../media/availability_up_um60.gif["LIF 可用性图标 – 正常"]）、已停止（image:../media/availability_down_um60.gif["LIF 可用性图标 – 关闭"]）还是未配置（image:../media/disabled_um60.gif["LIF 可用性图标 – 未知"]）。



* *数据网络接口*
+
** NAS
+
显示与 storage VM 关联的 NAS 接口数。此外，还指示接口是已启动（image:../media/availability_up_um60.gif["LIF 可用性图标 – 正常"]）还是已关闭（image:../media/availability_down_um60.gif["LIF 可用性图标 – 关闭"]）。

** SAN
+
显示与 storage VM 关联的 SAN 接口数。此外，还指示接口是已启动（image:../media/availability_up_um60.gif["LIF 可用性图标 – 正常"]）还是已关闭（image:../media/availability_down_um60.gif["LIF 可用性图标 – 关闭"]）。

** FC-NVMe
+
显示与 Storage VM 关联的 FC-NVMe 接口的数量。此外，还指示接口是已启动（image:../media/availability_up_um60.gif["LIF 可用性图标 – 正常"]）还是已关闭（image:../media/availability_down_um60.gif["LIF 可用性图标 – 关闭"]）。



* *管理网络接口*
+
** 可用性
+
显示与 Storage VM 关联的管理接口数。此外，还指示管理接口是已启动（image:../media/availability_up_um60.gif["LIF 可用性图标 – 正常"]）还是已关闭（image:../media/availability_down_um60.gif["LIF 可用性图标 – 关闭"]）。



* *策略*
+
** Snapshot
+
显示在 Storage VM 上创建的 Snapshot 策略的名称。

** 导出策略
+
如果仅创建了一个策略，则显示该导出策略的名称；如果创建了多个策略，则显示导出策略的数量。



* *保护*
+
** Storage VM 灾难恢复
+
显示所选存储虚拟机是受保护、目标还是未受保护，以及保护该存储虚拟机的目标名称。如果选定的存储虚拟机是目标，则显示源存储虚拟机的详细信息。在扇出情况下，此字段显示保护该存储虚拟机的目标存储虚拟机总数。计数链接将带您进入按源存储虚拟机筛选的存储虚拟机关系网格。

** 受保护的卷
+
显示所选存储 VM 上受保护卷在总卷中的数量。如果您正在查看目标存储 VM，则数字链接适用于所选存储 VM 的目标卷。

** 未受保护的卷
+
显示选定存储虚拟机上未受保护的卷数。



* *服务*
+
** 类型
+
显示在存储虚拟机上配置的服务类型。类型可以是域名系统（DNS）或网络信息服务（NIS）。

** 州/省
+
显示服务的状态，可以是 Up（image:../media/availability_up_um60.gif["LIF 可用性图标 – 正常"]）、Down（image:../media/availability_down_um60.gif["LIF 可用性图标 – 关闭"]）或 Not Configured（image:../media/disabled_um60.gif["LIF 可用性图标 – 未知"]）。

** 域名
+
对于 DNS 服务，显示 DNS 服务器的完全限定域名 (FQDN)；对于 NIS 服务，显示 NIS 服务器的完全限定域名 (FQDN)。如果启用了 NIS 服务器，则显示 NIS 服务器的活动 FQDN。如果禁用了 NIS 服务器，则显示所有 FQDN 的列表。

** IP 地址
+
显示 DNS 或 NIS 服务器的 IP 地址。如果启用了 NIS 服务器，则显示 NIS 服务器的活动 IP 地址。如果禁用了 NIS 服务器，则显示所有 IP 地址的列表。







[[network-interfaces-tab]]
== 网络接口选项卡

“网络接口”选项卡显示有关在选定存储 VM 上创建的数据网络接口（LIF）的详细信息：

* *网络接口*
+
显示在所选存储 VM 上创建的接口的名称。

* *运行状态*
+
显示接口的运行状态，可以是 Up （image:../media/lif_status_up.gif["LIF 状态图标 – 启动"]）、Down （image:../media/lif_status_down.gif["LIF 状态图标 – 关闭"]）或 Unknown （image:../media/hastate_unknown.gif["HA 状态的图标 – 未知"]）。接口的运行状态取决于其物理端口的状态。

* *管理状态*
+
显示接口的管理状态，可以是 Up（image:../media/lif_status_up.gif["LIF 状态图标 – 启动"]）、Down（image:../media/lif_status_down.gif["LIF 状态图标 – 关闭"]）或 Unknown（image:../media/hastate_unknown.gif["HA 状态的图标 – 未知"]）。接口的管理状态由存储管理员控制，以便对配置进行更改或用于维护目的。管理状态可以与操作状态不同。但是，如果接口的管理状态为 Down，则默认情况下运行状态为 Down。

* *IP 地址 / WWPN*
+
显示以太网接口的 IP 地址和 FC LIF 的全球通用端口名称 (WWPN)。

* *协议*
+
显示为接口指定的数据协议（例如 CIFS、NFS、iSCSI、FC/FCoE、FC-NVMe 和 FlexCache）的列表。

* *角色*
+
显示接口角色。角色可以是“数据”或“管理”。

* *主端口*
+
显示最初与接口关联的物理端口。

* *当前端口*
+
显示当前与接口关联的物理端口。如果接口已迁移，则当前端口可能与主端口不同。

* *端口集*
+
显示接口所映射到的端口集。

* *故障转移策略*
+
显示为接口配置的故障转移策略。对于 NFS、CIFS 和 FlexCache 接口，默认故障转移策略为“下一个可用”。故障转移策略不适用于 FC 和 iSCSI 接口。

* *路由组*
+
显示路由组的名称。可以单击路由组名称来查看有关路由和目标网关的详细信息。

+
ONTAP 8.3 或更高版本不支持路由组，因此对这些集群显示空列。

* *故障转移组*
+
显示故障转移组的名称。





[[qtrees-tab]]
== Qtrees 选项卡

Qtrees 选项卡显示有关 qtree 及其配额的详细信息。如果要编辑一个或多个 qtree 的 qtree 容量的健康阈值设置，可以单击 *编辑阈值* 按钮。

使用 *导出* 按钮创建一个包含所有受监控 qtrees 详细信息的逗号分隔值 (.csv) 文件。导出到 CSV 文件时，您可以选择为当前存储 VM、当前集群中的所有存储 VM 或数据中心内所有集群中的所有存储 VM 创建 qtrees 报告。导出的 CSV 文件中会显示一些其他 qtrees 字段。

* *状态*
+
显示 qtree 的当前状态。状态可以是 Critical（image:../media/sev_critical_um60.png["事件严重性图标 – 严重"]）、Error（image:../media/sev_error_um60.png["事件严重性图标 – 错误"]）、Warning（image:../media/sev_warning_um60.png["事件严重性图标 – 警告"]）或 Normal（image:../media/sev_normal_um60.png["事件严重性图标 – 正常"]）。

+
您可以将鼠标指针移动到状态图标上方来查看有关为 qtree 生成的一个或多个事件的详细信息。

+
如果 qtree 的状态由单个事件确定，则可以查看事件名称、触发事件的时间和日期、将事件分配给的管理员的名称以及事件的原因等信息。您可以使用*查看详细信息*查看有关此事件的更多信息。

+
如果 qtree 的状态由相同严重程度的多个事件确定，则显示前三个事件，其中包含事件名称、事件触发的时间和日期以及分配事件的管理员的名称等信息。您可以通过单击事件名称查看有关这些事件的更多详细信息。您还可以使用 *查看所有事件* 来查看生成的事件列表。

+
[NOTE]
====
一个 qtree 可以具有多个严重性相同或不同的事件。但是，系统将仅显示最高严重性。例如，如果 qtree 具有严重性为“错误”和“警告”的两个事件，则仅显示“错误”严重性。

====
* *Qtree*
+
显示 qtree 的名称。

* *集群*
+
显示 qtree 所在集群的名称。仅显示在导出的 CSV 文件中。

* *Storage Virtual Machine*
+
显示包含 qtree 的Storage Virtual Machine （SVM）名称。仅显示在导出的 CSV 文件中。

* *卷*
+
显示 qtree 所在卷的名称。

+
可以将指针移动到卷名称上方来查看卷的详细信息。

* *配额集*
+
指示 qtree 的配额是启用还是禁用。

* *配额类型*
+
指定配额针对用户、用户组还是 qtree。仅显示在导出的 CSV 文件中。

* *用户或组*
+
显示用户或用户组的名称。每个用户和用户组将有多行。如果配额类型是 qtree 或者未设置配额，则该列为空。仅显示在导出的 CSV 文件中。

* *磁盘已用%*
+
显示已用磁盘空间的百分比。如果设置了磁盘硬限制，则此值基于磁盘硬限制。如果配额设置为无磁盘硬限制，则该值基于卷数据空间。如果未设置配额或 qtree 所属卷上的配额已关闭，则网格页面中将显示“`不适用`”，CSV 导出数据中的字段为空。

* *磁盘硬限制*
+
显示分配给 qtree 的最大磁盘空间量。当达到此限制时，Unified Manager 将生成一个严重事件，并且不允许进一步的磁盘写入。在以下情况下，该值将显示为 "`Unlimited`"：如果设置了配额但没有磁盘硬限制，如果未设置配额，或者 qtree 所属卷上的配额已关闭。

* *磁盘软限制*
+
显示在生成警告事件之前为 qtree 分配的磁盘空间量。在以下情况下，此值将显示为 "`Unlimited`"：如果设置了配额但没有磁盘软限制，如果未设置配额，或者 qtree 所属的卷已关闭配额。默认情况下，此列处于隐藏状态。

* *磁盘阈值*
+
显示磁盘空间上设置的阈值。在以下情况下，该值将显示为 "`Unlimited`"：如果设置了配额但没有磁盘阈值限制，如果未设置配额，或者 qtree 所属卷上的配额已关闭。默认情况下，此列处于隐藏状态。

* *文件已用 %*
+
显示 qtree 中使用的文件的百分比。如果设置了文件硬限制，则此值基于文件硬限制。如果设置的配额没有文件硬限制，则不显示任何值。如果未设置配额或 qtree 所属卷上的配额已关闭，则网格页面中将显示 "`不适用`"，CSV 导出数据中的字段为空。

* *文件硬限制*
+
显示 qtree 上允许的文件数的硬限制。在以下情况下，该值将显示为 "`Unlimited`"：如果设置的配额没有文件硬限制，如果未设置配额，或者 qtree 所属卷上的配额已关闭。

* *文件软限制*
+
显示 qtree 上允许的文件数的软限制。在以下情况下，该值将显示为 "`Unlimited`"：如果设置了配额但没有文件软限制，如果未设置配额，或者 qtree 所属的卷上的配额已关闭。默认情况下，此列是隐藏的。





[[user-and-group-quotas-tab]]
== 用户和组配额选项卡

显示有关所选存储 VM 的用户和用户组配额的详细信息。您可以查看配额状态、用户或用户组的名称、对磁盘和文件设置的软限制和硬限制、磁盘空间量和使用的文件数以及磁盘阈值等信息。您还可以更改与用户或用户组关联的电子邮件地址。

* *编辑电子邮件地址命令按钮*
+
打开“编辑电子邮件地址”对话框，其中显示所选用户或用户组的当前电子邮件地址。您可以修改电子邮件地址。如果**编辑电子邮件地址**字段为空，则会使用默认规则为所选用户或用户组生成电子邮件地址。

+
如果多个用户的配额相同，这些用户的名称将显示为逗号分隔值。此外，默认规则不用于生成电子邮件地址，因此，您必须为要发送的通知提供所需的电子邮件地址。

* *配置电子邮件规则命令按钮*
+
使您能够创建或修改规则，为存储 VM 上配置的用户或用户组配额生成电子邮件地址。当发生配额违规时，会向指定的电子邮件地址发送通知。

* *状态*
+
显示配额的当前状态。状态可以是 Critical （image:../media/sev_critical_um60.png["事件严重性图标 – 严重"]）、Warning （image:../media/sev_warning_um60.png["事件严重性图标 – 警告"]）或 Normal （image:../media/sev_normal_um60.png["事件严重性图标 – 正常"]）。

+
可以将指针移动到状态图标上方来查看有关为配额生成的一个或多个事件的详细信息。

+
如果配额的状态由单个事件确定，您可以查看事件名称、触发事件的时间和日期、被分配该事件的管理员名称以及事件原因等信息。您可以使用*查看详细信息*查看有关该事件的更多信息。

+
如果配额的状态由相同严重程度的多个事件确定，则显示前三个事件，其中包含事件名称、触发事件的时间和日期以及分配事件的管理员的名称等信息。您可以通过单击事件名称查看有关这些事件的更多详细信息。您还可以使用*查看所有事件*来查看生成的事件列表。

+
[NOTE]
====
一个配额可以具有多个严重性相同或不同的事件。但是，系统将仅显示最高严重性。例如，如果配额具有严重性为“错误”和“警告”的两个事件，则仅显示“错误”严重性。

====
* *用户或组*
+
显示用户或用户组的名称。如果多个用户的配额相同，这些用户的名称将显示为逗号分隔值。

+
当 ONTAP 由于 SecD 错误而未提供有效的用户名时，该值将显示为 "`Unknown`"。

* *类型*
+
指定配额针对用户还是用户组。

* *Volume 或 Qtree*
+
显示指定了用户或用户组配额的卷或 qtree 的名称。

+
可以将指针移动到卷或 qtree 名称上方来查看卷或 qtree 的详细信息。

* *磁盘已用%*
+
显示已使用磁盘空间的百分比。如果配额设置为无磁盘硬限制，则该值显示为 "`Not applicable`"。

* *磁盘硬限制*
+
显示分配给配额的最大磁盘空间量。当达到此限制且不允许进一步的磁盘写入时，Unified Manager 会生成一个严重事件。如果配额设置为无磁盘硬限制，则该值显示为 "`Unlimited`"。

* *磁盘软限制*
+
显示在生成警告事件之前为配额分配的磁盘空间量。如果配额设置为无磁盘软限制，则该值显示为 "`Unlimited`"。默认情况下，此列是隐藏的。

* *磁盘阈值*
+
显示磁盘空间上设置的阈值。如果配额设置为无磁盘阈值限制，则该值显示为 "`Unlimited`"。默认情况下，此列处于隐藏状态。

* *文件已用 %*
+
显示 qtree 中使用的文件的百分比。如果配额设置为无文件硬限制，则该值显示为 "`Not applicable`"。

* *文件硬限制*
+
显示配额允许的文件数的硬限制。如果配额未设置文件硬限制，则该值显示为 "`Unlimited`"。

* *文件软限制*
+
显示配额上允许的文件数的软限制。如果配额设置为无文件软限制，则该值显示为 "`Unlimited`"。默认情况下，此列处于隐藏状态。

* *电子邮件地址*
+
显示违反配额时将通知发送到的用户或用户组的电子邮件地址。





[[nfs-shares-tab]]
== NFS 共享选项卡

“NFS 共享”选项卡显示有关 NFS 共享的信息，例如其状态、与卷（FlexGroup 卷或 FlexVol 卷）关联的路径、客户端对 NFS 共享的访问级别以及为导出的卷定义的导出策略。在以下情况下不会显示 NFS 共享：卷未挂载，或者与卷的导出策略关联的协议不包含 NFS 共享。

* *状态*
+
显示 NFS 共享的当前状态。状态可以是 Error （image:../media/sev_error_um60.png["事件严重性图标 – 错误"]）或 Normal （image:../media/sev_normal_um60.png["事件严重性图标 – 正常"]）。

* *接合路径*
+
显示卷的挂载路径。如果将显式 NFS 导出策略应用到 qtree，则该列显示用于访问 qtree 的卷路径。

* *接合路径活动*
+
显示用于访问已挂载卷的路径处于活动状态还是非活动状态。

* *Volume 或 Qtree*
+
显示 NFS 导出策略应用到的卷或 qtree 的名称。如果将 NFS 导出策略应用到卷中的 qtree，则该列显示卷和 qtree 的名称。

+
您可以单击此链接，在相应的详细信息页面中查看对象的详细信息。如果对象是 qtree，将为 qtree 和卷显示链接。

* *卷状态*
+
显示要导出的卷的状况。该状况可以是“脱机”、“联机”、“受限”或“混合”。

+
** 脱机
+
不允许对卷进行读写访问。

** 联机
+
允许对卷进行读写访问。

** 受限
+
允许执行有限的操作（如奇偶校验重建），但不允许数据访问。

** 混合
+
FlexGroup 卷的成分卷并非都处于相同状况。



* *安全风格*
+
显示已导出卷的访问权限。安全模式可以是“UNIX”、“统一”、“NTFS”或“混合”。

+
** UNIX（NFS 客户端）
+
卷中的文件和目录具有 UNIX 权限。

** 统一
+
卷中的文件和目录具有统一安全模式。

** NTFS（CIFS 客户端）
+
卷中的文件和目录具有 Windows NTFS 权限。

** 混合
+
卷中的文件和目录可以具有 UNIX 权限或 Windows NTFS 权限。



* *UNIX 权限*
+
以八进制字符串格式显示为已导出卷设置的 UNIX 权限位。这与 UNIX 模式权限位类似。

* *导出策略*
+
显示用于为已导出卷定义访问权限的规则。您可以单击链接查看有关与导出策略关联的规则的详细信息，例如身份验证协议和访问权限。

[[related-annotations-pane]]
== 相关标注窗格

Related Annotations （相关批注）窗格用于查看与所选存储虚拟机关联的批注详细信息。详细信息包括应用于存储虚拟机的批注名称和批注值。您还可以从 Related Annotations （相关批注）窗格中删除手动批注。



[[related-devices-pane]]
== 相关设备窗格

Related Devices 窗格用于查看与存储 VM 相关的群集、聚合和卷：

* *集群*
+
显示 storage VM 所属集群的健康状态。

* *聚合*
+
显示属于所选存储 VM 的聚合数。还会根据最高严重性级别显示聚合的健康状态。例如，如果存储 VM 包含十个聚合，其中五个显示“警告”状态，其余五个显示“严重”状态，则显示的状态为“严重”。

* *分配的聚合*
+
显示分配给 storage VM 的聚合数。还会根据最高严重性级别显示聚合的健康状态。

* *卷*
+
显示属于所选存储虚拟机的卷的数量和容量。系统还会根据最高严重性级别显示卷的运行状况。当存储虚拟机中有 FlexGroup 卷时，计数还包括 FlexGroups；它不包括 FlexGroup 成分。
