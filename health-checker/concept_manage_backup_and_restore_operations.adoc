= 在 Active IQ Unified Manager 中管理备份和还原操作
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以创建 Active IQ Unified Manager 的备份，并使用还原功能将备份还原到同一（本地）系统或新的（远程）系统，以防发生系统故障或数据丢失。

有三种备份和还原方法，具体取决于已安装 Unified Manager 的操作系统，以及要管理的群集和节点的数量：

[cols="3*"]
|===
| 操作系统 | 部署规模 | 建议的备份方法 


 a| 
VMware vSphere
 a| 
任意
 a| 
Unified Manager 虚拟设备的 VMware 快照



.2+| Red Hat Enterprise Linux  a| 
小型
 a| 
Unified Manager MySQL 数据库转储



 a| 
大型
 a| 
Unified Manager 数据库的 NetApp 快照



.2+| Microsoft Windows  a| 
小型
 a| 
Unified Manager MySQL 数据库转储



 a| 
大型
 a| 
使用 iSCSI 协议的 Unified Manager 数据库的 NetApp 快照

|===
下面几节将介绍这些不同的方法。
