= 在 Active IQ Unified Manager 中管理集群安全目标
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 提供了一个仪表板，用于根据 _NetApp Security Hardening Guide for ONTAP 9_ 中定义的建议，确定您的 ONTAP 集群、存储虚拟机（SVM）和卷的安全程度。

安全控制面板的目标是显示您的 ONTAP 集群与 NetApp 建议指南不一致的任何区域，以便您可以解决这些潜在问题。在大多数情况下，您可以使用 ONTAP System Manager 或 ONTAP CLI 解决问题。您的组织可能不会遵循所有建议，因此在某些情况下，您无需进行任何更改。

有关详细建议和解决方法，请参见 https://www.netapp.com/pdf.html?item=/media/10674-tr4569pdf.pdf["适用于 ONTAP 9 的 NetApp 安全强化指南"^]（TR-4569）。

除了报告安全状态之外，Unified Manager 还会为存在安全违规的任何群集或 SVM 生成安全事件。您可以在“事件管理清单”页面中跟踪这些问题，还可以为这些事件配置警报，以便在发生新安全事件时通知存储管理员。

有关详细信息，请参见link:../health-checker/concept_what_security_criteria_is_being_evaluated.html["正在评估哪些安全标准"]。
