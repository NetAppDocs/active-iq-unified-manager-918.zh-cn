= 在 Active IQ Unified Manager 中查看集群/运行状况详细信息页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
集群/运行状况详细信息页面提供有关选定集群的详细信息，例如运行状况、容量和配置详细信息。您还可以查看有关集群的网络接口（LIF）、节点、磁盘、相关设备和相关警报的信息。

集群名称旁边的状态（例如“良好”）表示通信状态；Unified Manager 是否可以与集群通信。它不代表集群的故障转移状态或整体状态。



[[command-buttons]]
== 命令按钮

命令按钮可用于对选定集群执行以下任务：

* *切换到性能视图*
+
使您能够导航到“集群/性能详细信息”页面。

* *操作*
+
** 添加警报：打开“添加警报”对话框，通过该对话框可以将警报添加到选定集群。
** 重新发现：启动集群的手动刷新，使 Unified Manager 能够发现集群的最新更改。
+
如果 Unified Manager 与 OnCommand Workflow Automation 配对，则重新发现操作还会从 WFA（如果有）重新获取缓存数据。

+
启动重新发现操作后，将显示指向相关作业详细信息的链接，以便跟踪作业状态。

** 注释：使您能够对选定集群进行注释。


* *查看集群*
+
使您能够导航到“运行状况：所有群集”视图。





[[health-tab]]
== 运行状况选项卡

显示有关各种集群对象（如节点、SVM 和聚合）的数据可用性和数据容量问题的详细信息。可用性问题与集群对象的数据服务能力有关。容量问题与集群对象的数据存储能力有关。

您可以单击对象的图形来查看对象的过滤列表。例如，您可以单击显示警告的 SVM 容量图来查看已筛选的 SVM 列表。此列表包含具有卷或 qtree 的 SVM，这些卷或 qtree 具有严重程度为“警告”的容量问题。您还可以单击显示警告的 SVM 可用性图表，以查看存在严重程度为“警告”的可用性问题的 SVM 列表。



[[availability-issues]]
=== 可用性问题

以图形方式显示对象总数，包括存在可用性问题的对象和不存在任何可用性相关问题的对象。图中的颜色表示问题的不同严重程度。图表下方的信息提供了有关可能影响或已经影响集群中数据可用性的可用性问题的详细信息。例如，显示有关已关闭的磁盘架和离线的聚合的信息。

[NOTE]
====
SFO 条形图显示的数据基于节点的 HA 状态。系统将根据生成的事件计算所有其他条形图显示的数据。

====


[[capacity-issues]]
=== 容量问题

以图形方式显示对象总数，包括存在容量问题的对象和不存在任何容量相关问题的对象。图中的颜色表示问题的不同严重程度。图表下方的信息提供了有关可能影响或已经影响集群中数据容量的容量问题的详细信息。例如，显示有关可能违反设定阈值的聚合的信息。



[[capacity-tab]]
== 容量选项卡

显示有关选定集群容量的详细信息。



[[capacity]]
=== 容量

显示所有分配聚合的已用容量和可用容量的数据容量图：

* 已用逻辑空间
+
此集群上所有聚合中存储的数据的实际大小，未应用使用 ONTAP 存储效率技术所节省的空间。这不包括 Snapshot 副本。

* 数据缩减
+
显示不包含 Snapshot 副本且保留两位有效数字的比率，例如 1.8 比 1。此比率基于配置的 ONTAP 存储效率设置。

* 已用
+
所有聚合上的数据所使用的物理容量。这不包括用于奇偶校验、适当调整大小和预留的容量。

* 可用
+
显示可用于数据的容量。

* 备用
+
显示所有备用磁盘中可用于存储的可存储容量。

* 已配置
+
显示为所有底层卷配置的容量。





[[details]]

* 总容量
+
显示集群的总容量。这不包括为奇偶校验分配的容量。

* 已用
+
显示数据使用的容量。这不包括用于奇偶校验、规模调整和预留的容量。

* 可用
+
显示可用于数据的容量。

* 已配置
+
显示为所有底层卷配置的容量。

* 备用
+
显示所有备用磁盘中可用于存储的可存储容量。





[[cloud-tier]]
=== 云层

显示已使用的云层总容量，以及集群上启用了 FabricPool 的聚合的每个已连接云层所使用的容量。FabricPool 可以是已获得许可的，也可以是未获得许可的。



[[physical-capacity-breakout-by-disk-type]]
=== 物理容量细分 (按磁盘类型)

“按磁盘类型划分的物理容量”区域显示有关集群中各种类型磁盘的磁盘容量的详细信息。通过单击磁盘类型，您可以从“磁盘”选项卡中查看有关该磁盘类型的更多信息。

* 总可用容量
+
显示数据磁盘的可用容量和备用容量。

* HDD
+
以图形方式显示集群中所有 HDD 数据磁盘的使用容量和可用容量。虚线表示 HDD 中数据磁盘的备用容量。

* 闪存
+
** SSD Data
+
以图形方式显示集群中 SSD 数据磁盘的使用容量和可用容量。

** SSD 缓存
+
以图形方式显示集群中 SSD 缓存磁盘的可存储容量。

** SSD 备用
+
以图形方式显示集群中 SSD、数据和缓存磁盘的备用容量。



* 未分配磁盘
+
显示集群中未分配磁盘的数量。





[[aggregates-with-capacity-issues-list]]
=== 存在容量问题的聚合列表

以表格形式显示有关存在容量风险问题的聚合的已用容量和可用容量的详细信息。

* 状态
+
表示聚合存在一定严重程度的容量相关问题。

+
您可以将指针移到状态上，查看有关为聚合生成的事件的详细信息。

+
如果聚合的状态由单个事件确定，则可以查看事件名称、触发事件的时间和日期、获分配该事件的管理员名称以及事件原因等信息。您可以单击*查看详细信息*按钮查看有关此事件的更多信息。

+
如果聚合的状态由相同严重程度的多个事件确定，则会显示前三个事件，其中包含事件名称、触发事件的时间和日期以及事件所分配的管理员名称等信息。您可以通过单击事件名称查看有关每个事件的更多详细信息。您还可以单击 *查看所有事件* 链接以查看生成的事件列表。

+
[NOTE]
====
聚合可以具有相同严重程度或不同严重程度的多个与容量相关的事件。但是，只会显示最高的严重程度。例如，如果聚合有两个事件，其严重程度级别为 Error 和 Critical，则仅显示 Critical 严重程度。

====
* 聚合
+
显示聚合的名称。

* 已用数据容量
+
以图形方式显示有关聚合容量使用情况的信息（百分比）。

* 达到全满前的天数
+
显示聚合达到满载之前的预计剩余天数。

[[metrocluster-overview]]

+

+

[[metrocluster-connectivity-tab]]
== MetroCluster 连接选项卡

显示 MetroCluster over FC 配置中集群组件的问题和连接状态。当集群的灾难恢复合作伙伴出现问题时，集群将显示在红色框中。

[NOTE]
====
MetroCluster 连接选项卡仅对采用 MetroCluster over FC 配置的集群显示。

====
您可以通过单击远程集群的名称导航到远程集群的详细信息页面。您还可以通过单击组件的计数链接查看组件的详细信息。例如，单击集群中节点的计数链接会显示集群详细信息页面中的节点选项卡。单击远程集群中磁盘的计数链接会在远程集群的详细信息页面中显示磁盘选项卡。

[NOTE]
====
管理八节点 MetroCluster 配置时，单击“磁盘架”组件的计数链接仅显示默认 HA 对的本地磁盘架。此外，无法显示另一个 HA 对上的本地磁盘架。

====
您可以将指针移到组件上，以便在出现任何问题时查看集群的详细信息和连接状态，并查看有关针对该问题生成的事件的更多信息。

如果组件之间的连接问题的状态由单个事件确定，则可以查看事件名称、触发事件的时间和日期、将事件分配给的管理员的名称以及事件的原因等信息。“查看详细信息”按钮提供有关事件的详细信息。

如果组件之间的连接问题的状态由相同严重程度的多个事件确定，则显示前三个事件，其中包含事件名称、触发事件的时间和日期以及事件分配给的管理员的名称等信息。您可以通过单击事件名称查看有关这些事件的更多详细信息。您还可以单击*查看所有事件*链接以查看生成的事件列表。



[[metrocluster-replication-tab]]
== MetroCluster 复制选项卡

显示在基于 FC 的 MetroCluster 配置中正在复制的数据的状态。您可以使用“MetroCluster 复制”选项卡，通过与已对等集群同步镜像数据来确保数据保护。当集群的灾难恢复合作伙伴出现问题时，集群将显示在红色框中。

[NOTE]
====
MetroCluster 复制选项卡仅对采用 MetroCluster over FC 配置的集群显示。

====
在 MetroCluster 环境中，您可以使用此选项卡验证本地集群与远程集群的逻辑连接和对等关系。您可以查看集群组件及其逻辑连接的客观表示。这有助于识别元数据和数据镜像过程中可能发生的问题。

在 MetroCluster 复制选项卡中，本地集群提供所选集群的详细图形表示，MetroCluster 合作伙伴是指远程集群。

显示接口的运行状态，可以是 Up（image:../media/lif_status_up.gif["LIF 状态图标 – 启动"]）、Down（image:../media/lif_status_down.gif["LIF 状态图标 – 关闭"]）或 Unknown（image:../media/hastate_unknown.gif["HA 状态的图标 – 未知"]）。网络接口的运行状态取决于其物理端口的状态。

[[failover-group]]

[[nodes-tab]]
== 节点选项卡

显示有关选定集群中节点的信息。您可以查看有关 HA 对、磁盘架和端口的详细信息：



[[ha-details]]
=== HA 详细信息

提供 HA 对中节点的 HA 状态和健康状态的图示。节点的健康状态由以下颜色表示：

* *绿色*
+
节点处于工作状态。

* *黄色*
+
此节点已接管配对节点或此节点面临一些环境问题。

* *红色*
+
此节点已关闭。



您可以查看有关 HA 对可用性的信息，并采取必要的措施来防止任何风险。例如，在可能发生接管操作的情况下，将显示以下消息：可能发生存储故障转移。

您可以查看与 HA 对及其环境相关的事件列表，例如风扇、电源、NVRAM 电池、闪存卡、服务处理器和磁盘架连接。您还可以查看触发事件的时间。

您可以查看其他与节点相关的信息，例如型号。

如果存在单节点群集，还可以查看有关节点的详细信息。



[[disk-shelves]]
=== 磁盘架

显示有关 HA 对中磁盘盘架的信息。

您还可以查看为磁盘架和环境组件生成的事件，以及事件触发的时间。

* *磁盘架 ID*
+
显示磁盘所在的盘架的 ID。

* *组件状态*
+
显示磁盘架的环境详细信息，例如电源、风扇、温度传感器、电流传感器、磁盘连接和电压传感器。环境详细信息显示为以下颜色的图标：

+
** *绿色*
+
环境组件工作正常。

** *灰色*
+
没有可用于环境组件的数据。

** *红色*
+
某些环境组件已关闭。



* *State*
+
显示磁盘架的状态。可能的状态为 Offline、Online、No status、Initialization required、Missing 和 Unknown。

* *型号*
+
显示磁盘架的型号。

* *本地磁盘架*
+
指示磁盘架是位于本地集群还是远程集群上。此列仅为 MetroCluster 配置中的集群显示。

* *唯一 ID*
+
显示磁盘架的唯一标识符。

* *固件版本*
+
显示磁盘架的固件版本。





[[ports]]
=== 端口

显示有关关联 FC、FCoE 和以太网端口的信息。您可以通过单击端口图标查看有关端口和相关 LIF 的详细信息。

您还可以查看为端口生成的事件。

您可以查看以下端口详细信息：

* 端口 ID
+
显示端口的名称。例如，端口名称可以为 e0M、e0a 和 e0b。

* 角色
+
显示端口的角色。可能的角色包括 Cluster、Data、Intercluster、Node-Management 和 Undefined。

* 类型
+
显示用于端口的物理层协议。可能的类型有以太网、光纤通道和 FCoE。

* WWPN
+
显示端口的全球通用端口名称（WWPN）。

* 固件修订版
+
显示 FC/FCoE 端口的固件版本。

* 状态
+
显示端口的当前状态。可能的状态为 Up、Down、Link Not Connected 或 Unknown（image:../media/hastate_unknown.gif["HA 状态的图标 – 未知"]）。

+
您可以从事件列表中查看与端口相关的事件。您还可以查看关联的 LIF 详细信息，例如 LIF 名称、运行状态、IP 地址或 WWPN、协议、与 LIF 关联的 SVM 的名称、当前端口、故障转移策略和故障转移组。





[[disks-tab]]
== 磁盘选项卡

显示选定集群中磁盘的详细信息。您可以查看与磁盘相关的信息，例如使用的磁盘数、备用磁盘数、损坏的磁盘数和未分配的磁盘数。您还可以查看其他详细信息，例如磁盘名称、磁盘类型和磁盘的所有者节点。



[[disk-pool-summary]]
=== 磁盘池摘要

显示按有效类型（FCAL、SAS、SATA、MSATA、SSD、NVMe SSD、SSD CAP、阵列 LUN 和 VMDISK）分类的磁盘数量以及磁盘的状态。您还可以查看其他详细信息，例如聚合、共享磁盘、备用磁盘、损坏的磁盘、未分配的磁盘和不受支持的磁盘的数量。如果单击有效磁盘类型计数链接，则会显示所选状态和有效类型的磁盘。例如，如果单击磁盘状态为 Broken 且有效类型为 SAS 的计数链接，则会显示磁盘状态为 Broken 且有效类型为 SAS 的所有磁盘。



[[disk]]
=== 磁盘

显示磁盘的名称。



[[raid-groups]]
=== RAID Groups

显示 RAID 组的名称。



[[owner-node]]
=== 所有者节点

显示磁盘所属节点的名称。如果磁盘未分配，则此列中不显示任何值。



[[state]]
=== 州/省

显示磁盘的状态：聚合、共享、备用、损坏、未分配、不支持或未知。默认情况下，此列按以下顺序排列以显示状态：损坏、未分配、不支持、备用、聚合和共享。



[[local-disk]]
=== 本地磁盘

显示“是”或“否”以指示磁盘位于本地集群还是远程集群上。此列仅对 MetroCluster 配置中的集群显示。



[[position]]
=== 位置

根据其容器类型显示磁盘的位置：例如，复制、数据或奇偶校验。默认情况下，此列处于隐藏状态。



[[impacted-aggregates]]
=== 受影响聚合

显示因磁盘故障而受影响的聚合数。您可以将指针悬停在计数链接上以查看受影响的聚合，然后单击聚合名称以查看聚合的详细信息。您还可以单击聚合计数，以在“运行状况：所有聚合”视图中查看受影响的聚合列表。

对于以下情况，此列中不显示任何值：

* 对于包含此类磁盘的群集添加到 Unified Manager 时损坏的磁盘
* 无故障磁盘时




[[storage-pool]]
=== 存储池

显示 SSD 所属的存储池的名称。可以将指针移动到存储池名称上，以查看存储池的详细信息。



[[storable-capacity]]
=== 可存储容量

显示可用磁盘容量。



[[raw-capacity]]
=== 原始容量

显示在正确调整大小和 RAID 配置之前的原始未格式化磁盘的容量。默认情况下，此列处于隐藏状态。



[[type]]
=== 类型

显示磁盘类型：例如 ATA、SATA、FCAL 或 VMDISK。



[[effective-type]]
=== 有效类型

显示由 ONTAP 分配的磁盘类型。

出于创建和添加到聚合以及备用管理的目的，某些 ONTAP 磁盘类型被认为是等效的。ONTAP 为每种磁盘类型分配有效的磁盘类型。



[[spare-blocks-consumed]]
=== 已用备用数据块 %

以百分比显示 SSD 磁盘中已消耗的备用块。对于 SSD 磁盘以外的磁盘，此列为空白。



[[rated-life-used]]
=== 已用额定寿命 %

根据实际 SSD 使用情况和制造商对 SSD 寿命的预测，以百分比形式显示已使用的 SSD 寿命估计值。值大于 99 表示估计的耐用度已耗尽，但可能并不表示 SSD 发生故障。如果该值未知，则忽略该磁盘。



[[firmware]]
=== 固件

显示磁盘的固件版本。



[[rpm]]
=== RPM

显示磁盘的每分钟转数（RPM）。默认情况下，此列处于隐藏状态。



[[model]]
=== 型号

显示磁盘的型号。默认情况下，此列处于隐藏状态。



[[vendor]]
=== 供应商

显示磁盘供应商的名称。默认情况下，此列处于隐藏状态。



[[shelf-id]]
=== 磁盘架 ID

显示磁盘所在的盘架的 ID。



[[bay]]
=== 托架

显示磁盘所在托架的 ID。



[[related-annotations-pane]]

可让您查看与选定集群相关联的批注详细信息。详细信息包括应用于集群的批注名称和批注值。您还可以从“相关批注”窗格中删除手动批注。



[[related-devices-pane]]
== 相关设备窗格

使您能够查看与选定集群关联的设备详细信息。

详细信息包括连接到集群的设备的属性，例如设备类型、大小、数量和运行状况。您可以单击数量链接，对该特定设备进行进一步分析。

您可以使用 MetroCluster 合作伙伴窗格获取远程 MetroCluster 合作伙伴及其相关集群组件（如节点、聚合和 SVM）的计数和详细信息。仅为采用 MetroCluster 配置的集群显示 MetroCluster 合作伙伴窗格。

Related Devices 窗格用于查看和导航到与群集相关的节点、SVM 和聚合：



[[metrocluster-partner]]
=== MetroCluster 配对集群

显示 MetroCluster 配对节点的健康状态。使用计数链接，您可以进一步导航并获取有关集群组件运行状况和容量的信息。



[[nodes]]
=== 节点

显示属于选定集群的节点的数量、容量和健康状况。容量表示总可用容量与可用容量之比。



[[storage-virtual-machines]]
=== Storage Virtual Machines

显示属于选定集群的 SVM 数量。



[[aggregates]]
=== 聚合

显示属于选定集群的聚合的数量、容量和运行状况。
