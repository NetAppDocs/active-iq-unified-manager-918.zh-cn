= 在 Active IQ Unified Manager 中为非受管保护关系配置滞后阈值
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以编辑非托管保护关系的全局默认延迟警告和错误运行状况阈值设置，以便按照适合您需要的时间间隔生成事件。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

滞后时间不得超过定义的传输计划间隔。例如，如果传输计划为每小时一次，则滞后时间不得超过一小时。滞后阈值指定了滞后时间不得超过的百分比。以一小时为例，如果滞后阈值定义为 150%，则当滞后时间超过 1.5 小时时，您将收到一个事件。

此任务中描述的设置将全局应用于所有非托管保护关系。这些设置无法专门指定并仅应用于某一个非托管保护关系。

.步骤
. 在左侧导航窗格中，单击*事件阈值* > *关系*。
. 根据需要增加或减少全局默认警告或错误滞后时间百分比。
. 要禁用从任何延迟阈值触发的警告或错误事件，请取消选中 *已启用* 旁边的复选框。
. 单击 *Save*。
