= 在 Active IQ Unified Manager 中查看安全事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
安全事件根据 _NetApp Security Hardening Guide for ONTAP 9_ 中定义的参数，为您提供有关 ONTAP 集群、存储虚拟机（SVM）和卷的安全状态信息。这些事件会通知您潜在的问题，以便您评估其严重程度，并在必要时解决问题。

安全事件按源类型分组，包括事件和陷阱名称、影响级别和严重程度。这些事件出现在集群和存储 VM 事件类别中。
