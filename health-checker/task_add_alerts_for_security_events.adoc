= 在 Active IQ Unified Manager 中添加安全事件警报
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以为单个安全事件配置警报，就像 Unified Manager 接收的任何其他事件一样。此外，如果您希望以相同方式处理所有安全事件，并将电子邮件发送给同一个人，则可以创建单个警报，以便在触发任何安全事件时通知您。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

下面的示例演示如何为“`Telnet Protocol Enabled`”安全事件创建警报。如果将 Telnet 访问配置为对集群进行远程管理访问，这将发送警报。您可以使用相同的方法为所有安全事件创建警报。

.步骤
. 在左侧导航窗格中，单击*存储管理* > *警报设置*。
. 在*警报设置*页面中，单击*添加*。
. 在*添加警报*对话框中，单击*名称*，并输入警报的名称和描述。
. 单击*资源*并选择要启用此警报的集群或集群。
. 单击 *事件* 并执行以下操作：
+
.. 在事件严重程度列表中，选择*警告*。
.. 在匹配事件列表中，选择 *Telnet Protocol Enabled*。


. 单击*操作*，然后在*提醒这些用户*字段中选择将接收警报电子邮件的用户的名称。
. 在此页面上配置有关通知频率、发出 SNMP 陷阱和执行脚本的任何其他选项。
. 单击 *Save*。
