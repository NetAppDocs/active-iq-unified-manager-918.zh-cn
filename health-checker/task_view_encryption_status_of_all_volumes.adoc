= 查看 Active IQ Unified Manager 中所有卷的加密状态
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看所有卷及其当前加密状态的列表，以便确定卷上的数据是否受到充分保护，防止未经授权的用户访问。

.开始之前
您必须具有操作员、应用程序管理员或存储管理员角色。

可以应用于卷的加密类型包括：

* 软件 — 使用 NetApp 卷加密 (NetApp Volume Encryption, NVE) 或 NetApp 聚合加密 (NetApp Aggregate Encryption, NAE) 软件加密解决方案进行保护的卷。
* 硬件 — 使用 NetApp 存储加密 (NetApp Storage Encryption, NSE) 硬件加密进行保护的卷。
* 软件和硬件 — 同时使用软件和硬件加密进行保护的卷。
* 无 — 未加密的卷。


.步骤
. 在左侧导航窗格中，单击 *Storage* > *Volumes*。
. 在 View 菜单中，选择 *Health* > *Volumes Encryption*
. 在*运行状况：卷加密*视图中，对*加密类型*字段进行排序，或使用筛选器显示具有特定加密类型或未加密的卷（加密类型为 "`None`"）。
