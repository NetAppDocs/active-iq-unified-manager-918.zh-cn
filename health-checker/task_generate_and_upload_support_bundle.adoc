= 从 Active IQ Unified Manager 生成并上传支持包
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以生成包含诊断信息的支持包，以便将其发送到技术支持以获得故障排除帮助。

从 Unified Manager 9.8 开始，如果您的 Unified Manager 服务器已连接到互联网，您还可以从维护控制台向 NetApp 上传支持包。

.开始之前
您必须能够以维护用户的身份访问维护控制台。

由于某些类型的支持数据可能会占用大量集群资源或需要很长时间才能完成，因此在选择完整支持包时，您可以指定要包含或排除的数据类型，以减小支持包的大小。您还可以选择创建一个仅包含 30 天日志和配置数据库记录的轻量级支持包——它不包含性能数据、采集记录文件和服务器堆转储。

Unified Manager 仅存储最近生成的两个支持捆绑包。较早的支持捆绑包将从系统中删除。

.步骤
. 在维护控制台*主菜单*中，选择*支持/诊断*。
. 根据您希望在支持捆绑包中包含的详细信息级别，选择*生成轻量级支持捆绑包*或*生成支持捆绑包*。
. 如果选择完整支持包，请选择或取消选择要在支持包中包含或排除的以下数据类型：
+
** *数据库转储*
+
MySQL Server 数据库的转储。

** *堆转储*
+
主要 Unified Manager 服务器进程的状态快照。此选项默认处于禁用状态，只有在客户支持提出请求时才应选择此选项。

** *采集记录*
+
Unified Manager 与被监控集群之间的所有通信的记录。



+
[NOTE]
====
如果取消选择所有数据类型，则仍会与其他 Unified Manager 数据一起生成支持包。

====
. 键入 `g`，然后按 Enter 生成支持包。
+
由于生成支持捆绑包是一项内存密集型操作，因此系统会提示您确认此时是否确实要生成支持捆绑包。

. 键入 `y`，然后按 Enter 生成支持捆绑包。
+
如果此时不想生成支持捆绑包，请键入 `n`，然后按 Enter。

. 如果在完整支持捆绑包中包含了数据库转储文件，系统将提示您指定要包含性能统计信息的时间段。包含性能统计信息可能需要大量的时间和空间，因此您也可以在不包含性能统计信息的情况下转储数据库：
+
.. 以 YYYYMMDD 格式输入开始日期。
+
例如，输入 `20210101`表示 2021 年 1 月 1 日。如果不希望包含性能统计信息，请输入 `n`。

.. 输入要包括的统计天数，从指定开始日期的凌晨 12 点开始。
+
您可以输入一个从 1 到 10 的数字。



+
如果包含性能统计信息，系统将显示将收集性能统计信息的时间段。

. 创建支持捆绑包后，系统会提示您是否要将其上传到 NetApp。键入 `y`，然后按 Enter。
+
系统会提示您输入支持案例编号。

. 如果您已有案例编号，请输入该编号并按 Enter 键。否则，只需按 Enter 键。
+
支持包已上传到 NetApp。



如果您的 Unified Manager 服务器未连接到互联网，或者由于任何其他原因无法上传支持包，则可以检索并手动发送。您可以使用 SFTP 客户端或使用 UNIX 或 Linux CLI 命令检索它。在 Windows 安装中，可以使用远程桌面（RDP）检索支持包。

生成的支持捆绑包位于 VMware 系统上的 /support 目录、Linux 系统上的 /opt/netapp/data/support/ 以及 Windows 系统上的 ProgramData\NetApp\OnCommandAppData\ocum\support 中。
