= 了解 Active IQ Unified Manager 中组的组规则工作方式
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
组规则是您为使存储对象（卷、群集或 SVM）包含在特定组中而定义的标准。您可以使用条件组或条件来定义组的组规则。

* 您必须将组规则关联到组。
* 您必须为组规则关联对象类型；只有一个对象类型与组规则关联。
* 在每个监控周期之后，或者在创建、编辑或删除规则时，存储对象将被添加到组中或从组中移除。
* 组规则可以有一个或多个条件组，每个条件组可以有一个或多个条件。
* 存储对象可以根据您创建的组规则属于多个组。




[[conditions]]
== 条件

您可以创建多个条件组，每个条件组可以有一个或多个条件。您可以将组规则中定义的所有条件组应用于组，以指定组中包括哪些存储对象。

条件组中的条件使用逻辑 AND 执行。必须满足条件组中的所有条件。创建或修改组规则时，将创建一个条件，该条件仅适用、选择和分组满足条件组中所有条件的存储对象。如果要缩小要在组中包含哪些存储对象的范围，则可以在条件组中使用多个条件。

您可以使用以下操作数和运算符并指定所需的值，使用存储对象创建条件。

[cols="2*"]
|===
| 存储对象类型 | 适用的操作数 


 a| 
卷
 a| 
* 对象名称
* 所属集群名称
* 所属 SVM 名称
* 标注




 a| 
SVM
 a| 
* 对象名称
* 所属集群名称
* 标注




 a| 
集群
 a| 
* 对象名称
* 标注


|===
当您选择批注作为任何存储对象的操作数时，“`Is`”运算符可用。对于所有其他操作数，您可以选择“`Is`”或“`Contains`”作为运算符。

* 操作数
+
Unified Manager 中的操作数列表会根据选定对象类型进行更改。该列表包括对象名称、拥有群集名称、拥有 SVM 名称以及您在 Unified Manager 中定义的注释。

* 运算符
+
运算符列表会根据为条件选择的操作数而变化。Unified Manager 支持的运算符为 "`Is`" 和 "`Contains`"。

+
当您选择“`Is`”运算符时，将对该条件进行评估，以确保操作数值与为选定操作数提供的值完全匹配。

+
当您选择“`包含`”运算符时，条件将被评估为满足以下条件之一：

+
** 操作数值与为选定操作数提供的值完全匹配
** 操作数值包含为选定操作数提供的值


* 值
+
值字段将根据所选操作数进行更改。





[[example-of-a-group-rule-with-conditions]]
== 带条件的组规则示例

考虑具有以下两个条件的卷的条件组：

* 名称包含 "`vol`"
* SVM 名称为 "`data_svm`"


此条件组选择所有在其名称中包含“`vol`”且托管在名为“`data_svm`”的 SVM 上的卷。



[[condition-groups]]
== 条件组

条件组使用逻辑 OR 执行，然后应用于存储对象。存储对象必须满足其中一个条件组才能包含在组中。所有条件组的存储对象将组合在一起。您可以使用条件组来扩大要包含在组中的存储对象的范围。



[[example-of-a-group-rule-with-condition-groups]]
== 带条件组的组规则示例

考虑一个卷的两个条件组，每个组包含以下两个条件：

* 条件组 1
+
** 名称包含 "`vol`"
** SVM 名称为“`data_svm`”条件组 1 选择名称中包含“`vol`”且托管在名为“`data_svm`”的 SVM 上的所有卷。


* 条件组 2
+
** 名称包含 "`vol`"
** 数据优先级的批注值为 "`critical`" 条件组 2 选择名称中包含 "`vol`" 且使用数据优先级批注值标注为 "`critical`" 的所有卷。




如果对存储对象应用包含这两个条件组的组规则，则会将以下存储对象添加到所选组：

* 所有在名称中包含“`vol`”且托管在名为“`data_svm`”的 SVM 上的卷。
* 所有在其名称中包含“`vol`”且使用数据优先级标注值“`critical`”进行标注的卷。
