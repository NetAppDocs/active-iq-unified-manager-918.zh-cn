= 确定卷是否因 Active IQ Unified Manager 中的磁盘损坏而脱机
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Unified Manager Web UI 确认或排除卷脱机是由于 RAID 磁盘问题导致其主机聚合脱机这一可能性。

.开始之前
您必须具有操作员、应用程序管理员或存储管理员角色。

要确定卷脱机状态是否由使托管聚合脱机的 RAID 磁盘问题引起，请执行以下操作：

.步骤
. 在 *Volume / Health* 详细信息页面的 *Related Devices* 窗格中找到并单击显示在 Aggregate 下的超文本链接。
+
聚合/运行状况详细信息页面显示托管聚合的联机或脱机状态。如果聚合状态为联机，则 RAID 磁盘问题不是卷脱机的原因。

. 如果聚合状态为离线，则单击*磁盘信息*，并在*磁盘信息*选项卡上的*事件*列表中查找损坏的磁盘事件。
. 要进一步识别损坏的磁盘，请单击 *相关设备* 窗格中节点下方显示的超文本链接。
+
此时将显示集群/健康详细信息页面。

. 单击*磁盘*，然后在*过滤器*窗格中选择*已损坏*，以列出所有处于损坏状态的磁盘。
+
如果处于故障状态的磁盘导致主机聚合处于离线状态，则聚合的名称将显示在“受影响的聚合”列中。



在确认卷离线状态是由 RAID 磁盘损坏以及随之而来的离线主机聚合引起之后，请联系相应的管理员或操作员手动更换损坏的磁盘，并使聚合恢复联机。
