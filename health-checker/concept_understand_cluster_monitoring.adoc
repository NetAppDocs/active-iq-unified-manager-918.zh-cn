= 了解 Active IQ Unified Manager 中的集群监控
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以将群集添加到 Unified Manager 数据库，以监视群集的可用性、容量和其他详细信息，例如 CPU 使用情况、接口统计信息、可用磁盘空间、qtree 使用情况和机箱环境。

如果状态异常或超出预定义阈值，则会生成事件。如果配置为执行此操作，则当事件触发警报时， Unified Manager 会向指定的收件人发送通知。
