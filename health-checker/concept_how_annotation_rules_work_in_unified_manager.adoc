= 了解注释规则在 Active IQ Unified Manager 中的工作原理
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
标注规则是您定义的用于标注存储对象（卷、集群或存储虚拟机 (SVM)）的标准。您可以使用条件组或条件来定义标注规则。

* 必须将批注规则与批注相关联。
* 必须为批注规则关联对象类型；只能为批注规则关联一个对象类型。
* Unified Manager 在每个监控周期之后，或者在创建、编辑、删除或重新排序规则时，为存储对象添加或删除注释。
* 注释规则可以有一个或多个条件组，每个条件组可以有一个或多个条件。
* 存储对象可以有多个注释。特定注释的注释规则还可以在规则条件中使用不同的注释，以向已注释的对象添加另一个注释。




[[conditions]]
== 条件

您可以创建多个条件组，每个条件组可以有一个或多个条件。可以在批注的批注规则中应用所有定义的条件组，以便对存储对象进行批注。

条件组中的条件使用逻辑 AND 执行。必须满足条件组中的所有条件。创建或修改批注规则时，将创建一个条件，该条件仅适用、选择和批注满足条件组中所有条件的存储对象。如果要缩小要批注的存储对象的范围，可以在一个条件组中使用多个条件。

您可以使用以下操作数和运算符并指定所需的值，使用存储对象创建条件。

[cols="2*"]
|===
| 存储对象类型 | 适用的操作数 


 a| 
卷
 a| 
* 对象名称
* 所属集群名称
* 所属 SVM 名称
* 标注




 a| 
SVM
 a| 
* 对象名称
* 所属集群名称
* 标注




 a| 
集群
 a| 
* 对象名称
* 标注


|===
当您选择批注作为任何存储对象的操作数时，“`Is`”运算符可用。对于所有其他操作数，您可以选择“`Is`”或“`Contains`”作为运算符。当您选择“`Is`”运算符时，将对条件进行求值，以确保操作数值与为所选操作数提供的值完全匹配。当您选择“`Contains`”运算符时，条件将被评估为满足以下条件之一：

* 操作数值与选定操作数值完全匹配。
* 操作数值包含为选定操作数提供的值。




[[example-of-an-annotation-rule-with-conditions]]
== 带条件的批注规则示例

考虑针对卷的具有一个条件组的注释规则，其中包含以下两个条件：

* 名称包含 "`vol`"
* SVM 名称为 "`data_svm`"


此注释规则使用所选注释和注释类型注释所有在名称中包含“`vol`”且托管在名为“`data_svm`”的 SVM 上的卷。



[[condition-groups]]
== 条件组

条件组使用逻辑 OR 执行，然后应用于存储对象。存储对象必须满足其中一个条件组的要求才能进行标注。满足所有条件组条件的存储对象将被标注。您可以使用条件组来扩大要标注的存储对象的范围。



[[example-of-an-annotation-rule-with-condition-groups]]
== 带条件组的批注规则示例

考虑针对一个卷具有两个条件组的批注规则；每个组包含以下两个条件：

* 条件组 1
+
** 名称包含 "`vol`"
** SVM 名称为 "`data_svm`" 此条件组注释名称中包含 "`vol`" 且托管在名为 "`data_svm`" 的 SVM 上的所有卷。


* 条件组 2
+
** 名称包含 "`vol`"
** 数据优先级的批注值为“`critical`”。此条件组将批注所有名称中包含“`vol`”且数据优先级批注值为“`critical`”的卷。




当对存储对象应用包含这两个条件组的批注规则时，将对以下存储对象进行批注：

* 所有在名称中包含 "`vol`" 且托管在名为 "`data_svm`" 的 SVM 上的卷。
* 所有在名称中包含 "`vol`" 且使用数据优先级标注值标注为 "`critical`" 的卷。
