= 在 Active IQ Unified Manager 中使用 NetApp 快照进行备份和恢复
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Snapshot 副本创建 Unified Manager 数据库和配置文件的时间点映像，您可以使用该映像在系统故障或数据丢失时进行还原。您计划将 Snapshot 副本定期写入 ONTAP 群集之一上的卷，以便始终拥有当前副本。

[NOTE]
====
此功能不适用于安装在虚拟设备上的 Active IQ Unified Manager。

====
