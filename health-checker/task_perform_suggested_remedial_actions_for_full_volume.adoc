= 在 Active IQ Unified Manager 中对卷已满问题执行建议的修复操作
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
收到“`Volume Space Full`”错误事件后，您查看事件详细信息页面上的建议补救措施，并决定执行其中一项建议操作。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

具有任何角色的用户都可以执行此工作流程中使用 Unified Manager 的所有任务。

在此示例中，您在 Unified ManagerEvent Management 清单页面上看到了“卷空间已满”错误事件，并单击了该事件的名称。

您可能对已满的卷执行的补救措施包括以下内容：

* 对卷启用自动增长、重复数据删除或压缩
* 调整大小或移动卷
* 从卷中删除或移动数据


虽然所有这些操作都必须从 ONTAP System Manager 或 ONTAP CLI 执行，但您可以使用 Unified Manager 查找您可能需要的信息，以确定要采取的操作。

.步骤
. 在*事件*详细信息页面中，单击源字段中的卷名称以查看有关受影响卷的详细信息。
. 在*卷/运行状况*详细信息页面上，单击*配置*，看到卷上已启用重复数据删除和压缩。
+
您决定调整此卷的大小。

. 在*相关设备*窗格中，单击托管聚合的名称，以查看聚合是否可以容纳更大的卷。
. 在*聚合/运行状况*详细信息页面上，您可以看到托管已满卷的聚合确实具有足够的未提交容量，因此您可以使用 ONTAP System Manager 调整卷的大小，从而为其提供更多容量。
