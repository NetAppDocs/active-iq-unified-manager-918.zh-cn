= 了解Active IQ Unified Manager运行状况监控功能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 构建在服务器基础架构之上，可提供可扩展性、可支持性以及增强的监控和通知功能。Unified Manager 支持监控运行 ONTAP 软件的系统。

Unified Manager 包括以下功能：

* 安装了 ONTAP 软件的系统的发现、监控和通知：
+
** 物理对象：节点、磁盘、磁盘架、SFO 对、端口和 Flash Cache
** 逻辑对象：集群、存储虚拟机（SVM）、聚合、卷、LUN、命名空间、qtree、LIF、Snapshot 副本、接合路径、NFS 共享、SMB 共享、用户和组配额、QoS 策略组和启动器组
** 协议：CIFS、NFS、FC、iSCSI、NVMe 和 FCoE
** 存储效率：SSD 聚合、Flash Pool 聚合、FabricPool 聚合、重复数据删除和压缩
** 保护：SnapMirror 关系（同步和异步）以及 SnapVault 关系


* 查看集群发现和监控状态
* MetroCluster over FC 和 IP 配置：查看和监控集群组件的配置、问题和连接状态。用于 MetroCluster over FC 配置的 MetroCluster 交换机和网桥
* 增强的警报、事件和阈值基础架构
* LDAP、LDAPS、SAML 身份验证和本地用户支持
* RBAC（用于预定义的角色集）
* AutoSupport 和支持包
* 增强的仪表板可显示环境的容量、可用性、保护和性能健康状况
* 卷移动互操作性、卷移动历史记录和连接路径更改历史记录
* 影响范围区域，以图形方式显示受某些故障磁盘、MetroCluster 聚合镜像降级和 MetroCluster 备用磁盘遗留事件等事件影响的资源
* 显示 MetroCluster 事件效果的可能效果区域
* Suggested Corrective Actions（建议纠正措施）区域，显示可以执行的操作，以解决一些故障磁盘、MetroCluster 聚合镜像降级和 MetroCluster 备用磁盘遗留事件等事件
* 可能受影响的资源区域，显示可能受卷离线事件、卷受限事件和精简配置卷空间存在风险事件等事件影响的资源
* 支持带有 FlexVol 或 FlexGroup 卷的 SVM
* 支持监控节点根卷
* 增强 Snapshot 副本监控，包括计算可回收空间和删除 Snapshot 副本
* 存储对象的注释
* 存储对象信息（例如物理和逻辑容量、利用率、空间节约、性能和相关事件）的报告创建和管理
* 与 OnCommand Workflow Automation 集成以执行工作流
