= 确定卷是否因其主机节点在 Active IQ Unified Manager 中关闭而处于脱机状态
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Unified Manager Web UI 确认或排除卷因其主机节点已关闭且向其 HA 对伙伴的存储故障转移不成功而脱机的可能性。

.开始之前
您必须具有操作员、应用程序管理员或存储管理员角色。

要确定卷离线状态是否由托管节点故障和随后不成功的存储故障转移引起，请执行以下操作：

.步骤
. 在离线卷的 *Volume / Health* 详细信息页面的 *Related Devices* 窗格中，找到并单击 SVM 下显示的超文本链接。
+
Storage VM / Health 详细信息页面显示有关脱机卷的托管 Storage Virtual Machine (SVM) 的信息。

. 在 *Storage VM / Health* 详细信息页面的 *Related Devices* 窗格中，找到并单击 Volumes 下显示的超文本链接。
+
运行状况：所有卷视图显示有关由 SVM 托管的所有卷的信息表。

. 在 *运行状况：所有卷* 视图的“状态”列标题上，单击筛选器符号 image:../media/filtericon_um60.png["列筛选器图标"]，然后选择 *脱机* 选项。
+
仅列出处于离线状态的 SVM 卷。

. 在“运行状况：所有卷”视图中，单击网格符号 image:../media/gridviewicon.gif["网格视图图标"]，然后选择 *集群节点* 选项。
+
您可能需要在网格选择框中滚动以找到*集群节点*选项。

+
集群节点列将添加到卷清单中，并显示托管每个脱机卷的节点的名称。

. 在 *运行状况：所有卷* 视图中，找到离线卷的列表，并在其集群节点列中单击其托管节点的名称。
+
“集群/健康”详细信息页面上的“节点”选项卡显示托管节点所属的 HA 节点对的状态。托管节点的状态和任何集群故障转移操作的成功情况都会予以显示。



在确认由于其主机节点已关闭并且到 HA 对伙伴的存储故障转移失败而存在卷脱机状态后，请联系相应的管理员或操作员以手动重新启动已关闭的节点并修复存储故障转移问题。
