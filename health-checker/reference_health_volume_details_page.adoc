= 在 Active IQ Unified Manager 中查看卷/运行状况详细信息页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用“卷/运行状况详细信息”页面查看有关所选卷的详细信息，例如容量、存储效率、配置、保护、注释和生成的事件。您还可以查看有关该卷的相关对象和相关警报的信息。

您必须具有应用程序管理员或存储管理员角色。



[[command-buttons]]
== 命令按钮

使用命令按钮可以对选定卷执行下列任务：

* *切换到性能视图*
+
使您能够导航到卷/性能详细信息页面。

* *操作*
+
** 添加警报
+
用于向选定卷添加警报。

** 编辑阈值
+
用于修改选定卷的阈值设置。

** 标注
+
用于标注选定卷。

** 保护
+
用于为选定卷创建 SnapMirror 或 SnapVault 关系。

** 关系
+
用于执行以下保护关系操作：

+
*** 编辑
+
启动“编辑关系”对话框，通过该对话框可以更改现有保护关系的现有 SnapMirror 策略、计划和最大传输速率。

*** 中止
+
中止选定关系正在进行的传输。（可选）通过此操作，您可以删除用于非基线传输的重新启动检查点。您无法删除用于基线传输的检查点。

*** 暂停
+
暂时禁用选定关系的计划更新。已在进行的传输必须在此关系暂停之前完成。

*** 中断
+
中断源卷和目标卷之间的关系并将目标更改为读写卷。

*** 删除
+
永久删除选定源和目标之间的关系。这些卷不会销毁，并且卷上的 Snapshot 副本不会删除。此操作无法撤消。

*** 恢复
+
启用已暂停的关系的计划传输。在下一个计划传输间隔会使用重新启动检查点（如果有）。

*** 重新同步
+
用于重新同步之前已断开的关系。

*** 初始化/更新
+
用于对新的保护关系执行首次基线传输，或者如果该关系已初始化，则用于执行手动更新。

*** 反向重新同步
+
用于重新建立之前已断开的保护关系，通过将源设为原始目标的副本反转源和目标的功能。源上的内容将被目标上的内容覆盖，晚于通用 Snapshot 副本中的数据的任何数据都将被删除。



** 还原
+
用于将数据从一个卷还原到另一个卷。有关信息，请参见 link:../data-protection/task_restore_data_use_health_volume_details_page.html["使用卷/运行状况详细信息页面还原数据"]。



+
[NOTE]
====
对于处于同步保护关系的卷，“还原”按钮和“关系”操作按钮将不可用。

====
* *查看卷*
+
使您能够导航到运行状况：所有卷视图。





[[capacity-tab]]
== 容量选项卡

“容量”选项卡会显示有关所选卷的详细信息，例如其物理容量、逻辑容量、阈值设置、配额容量以及有关任何卷移动操作的信息：

* *物理容量*
+
详细描述卷的物理容量：

+
** Snapshot 溢出
+
显示 Snapshot 副本占用的数据空间。

** 已用
+
显示卷中数据的已用空间。

** 警告
+
指示卷中的空间接近全满。如果违反此阈值，则会生成“空间接近全满”事件。

** 错误
+
指示卷中的空间全满。如果违反此阈值，则会生成“空间已满”事件。

** 不可用
+
指示生成了“精简配置卷空间存在风险”事件，精简配置卷中的空间由于聚合容量问题而存在风险。只有精简配置卷才会显示不可用容量。

** 数据图形
+
显示卷的总数据容量和已使用数据容量。

+
如果启用了自动增长，则数据图形还会显示聚合中的可用空间。数据图形显示卷中的数据可以使用的有效存储空间，可以是以下容量之一：

+
*** 下列情况下卷的实际数据容量：
+
**** 禁用了“自动增长”。
**** 启用了“自动增长”的卷已达到大小上限。
**** 启用了“自动增长”的厚配置卷无法再继续增长。


*** 在考虑了卷大小上限之后的卷数据容量（适用于精简配置的卷以及在聚合中的空间允许卷达到大小上限时适用于厚配置卷）
*** 在考虑下一个可能的自动增长大小之后的卷数据容量（适用于具有自动增长百分比阈值的厚配置卷）


** Snapshot 副本图形
+
只有已使用的 Snapshot 容量或 Snapshot 预留不为零时，才会显示此图形。



+
如果已使用的 Snapshot 容量超出 Snapshot 预留，则两个图形都会显示超出 Snapshot 预留的 Snapshot 容量。

* *容量逻辑*
+
显示卷的逻辑空间特征。逻辑空间表示磁盘上所存储数据的实际大小，而不是使用 ONTAP 存储效率技术节省的空间。

+
** 逻辑空间报告
+
显示卷是否配置了逻辑空间报告。该值可以为 Enabled、Disabled 或 Not applicable。对于较旧版本的 ONTAP 或不支持逻辑空间报告的卷，将显示 "`Not applicable`"。

** 已用
+
根据总数据容量显示卷中的数据所使用的逻辑空间量和已用逻辑空间的百分比。

** 强制实施逻辑空间
+
显示是否为精简配置卷配置逻辑空间强制实施。如果设置为“已启用”，则卷的逻辑已用容量不能大于当前设置的物理卷容量。



* *自动增长*
+
显示卷在空间不足的情况下是否会自动增长。

* *空间保证*
+
显示在卷从聚合中删除可用块时的 FlexVol 卷设置控制。这样可以保证这些块可写入卷中的文件。空间保证可设置为下列各项之一：

+
** 无
+
不为卷配置任何空间保证。

** 文件
+
保证稀疏写入文件（例如 LUN）的完整大小。

** 卷
+
保证卷的完整大小。

** 部分
+
FlexCache 卷根据其大小保留空间。如果 FlexCache 卷的大小为 100 MB 或更大，则默认情况下最小空间保证设置为 100 MB。如果 FlexCache 卷的大小小于 100 MB，则最小空间保证设置为 FlexCache 卷的大小。如果 FlexCache 卷的大小稍后增加，则最小空间保证不会增加。



+
[NOTE]
====
卷的类型为“数据缓存”时，空间保证为“部分”。

====
* *详细信息（物理）*
+
显示卷的物理特征。

* *总容量*
+
显示卷的总物理容量。

* *数据容量*
+
显示卷使用的物理空间量（已用容量）以及卷中仍然可用的物理空间量（可用容量）。这些值还以总物理容量的百分比形式显示。

+
为精简配置卷生成“精简配置卷空间存在风险”事件时，将显示卷使用的空间量（已用容量）以及卷中可用、但由于聚合容量问题无法使用的空间量（不可用容量）。

* *Snapshot 预留*
+
显示 Snapshot 副本使用的空间量（已用容量）以及可供卷中 Snapshot 副本使用的空间量（可用容量）。这些值还以 Snapshot 预留总容量的百分比形式显示。

+
为精简配置卷生成“精简配置卷空间存在风险”事件时，将显示 Snapshot 副本使用的空间量（已用容量）以及卷中可用、但由于聚合容量问题无法用于创建 Snapshot 副本的空间量（不可用容量）。

* *卷阈值*
+
显示下列卷容量阈值：

+
** 接近全满阈值
+
指定卷接近全满时的百分比。

** 全满阈值
+
指定卷全满时的百分比。



* *其他详细信息*
+
** 自动增长大小上限
+
显示卷可以自动增长到的大小上限。默认值为卷在创建时的大小的 120%。只有在已为卷启用了自动增长时才会显示此字段。

** qtree 配额已提交的容量
+
显示配额中预留的空间。

** qtree 配额已过量提交的容量
+
显示在系统生成“卷 qtree 配额已过量提交”事件之前可以使用的空间量。

** 预留百分比
+
控制覆盖预留的大小。默认情况下，预留百分比设置为 100，表示会预留全部所需预留空间，从而可以使对象受到全面保护，以免被覆盖。如果预留百分比小于 100%，则为该卷中所有预留空间的文件预留的空间会减少至该预留百分比。

** Snapshot 每日增长率
+
显示选定卷中 Snapshot 副本每 24 小时发生的更改（以百分比或 KB、MB、GB 等表示）。

** Snapshot 达到全满前的天数
+
显示为卷中 Snapshot 副本预留的空间达到指定阈值前的预计剩余天数。

+
在卷中 Snapshot 副本的增长率为零或负数或者没有足够的数据用来计算增长率时，“Snapshot 达到全满前的天数”字段将显示值“不适用”。

** Snapshot 自动删除
+
指定在对卷执行的写入因聚合中空间不足而失败时是否自动删除 Snapshot 副本以释放空间。

** Snapshot 副本
+
显示有关卷中 Snapshot 副本的信息。

+
卷中的 Snapshot 副本数将显示为链接。单击此链接将打开“卷上的 Snapshot Copies”对话框，其中显示 Snapshot 副本的详细信息。

+
Snapshot 副本计数大约每小时更新一次，但 Snapshot 副本列表仅在您单击该图标时才进行更新。这可能会造成拓扑中显示的 Snapshot 副本计数不同于您单击该图标时列出的 Snapshot 副本数量。



* *卷移动*
+
显示当前或最近对卷执行的卷移动操作的状态以及其他详细信息，例如正在进行的卷移动操作目前所处的阶段、源聚合、目标聚合、开始时间、结束时间以及估计结束时间。

+
还显示在所选卷上执行的卷移动操作的数量。您可以通过单击*卷移动历史记录*链接查看有关卷移动操作的更多信息。





[[configuration-tab]]
== 配置选项卡

“配置”选项卡显示有关所选卷的详细信息，例如卷的导出策略、RAID 类型、容量和存储效率相关功能：

* *概述*
+
** 全名
+
显示卷的全名。

** 聚合
+
显示卷所在的聚合的名称或 FlexGroup 卷所在的聚合的数量。

** 分层策略
+
显示为卷设置的分层策略；如果卷部署在已启用 FabricPool 的聚合上。此策略可以为“无”、“仅 Snapshot”、“备份”、“自动”或“全部”。

** Storage VM
+
显示包含卷的 SVM 的名称。

** 接合路径
+
显示路径的状态，该路径可以是活动的或非活动的。此时也会显示卷挂载到的 SVM 中的路径。您可以单击*历史记录*链接以查看对接合路径的最近五次更改。

** 导出策略
+
显示为卷创建的导出策略的名称。您可以单击此链接，查看有关导出策略、身份验证协议以及在属于 SVM 的卷上启用的访问权限的详细信息。

** 模式
+
显示卷模式。卷模式可以为“FlexVol”或“FlexGroup”。

** 类型
+
显示选定卷的类型。卷类型可以为“读写”、“负载共享”、“数据保护”、“数据缓存”或“临时”。

** RAID 类型
+
显示选定卷的 RAID 类型。RAID 类型可以为“RAID0”、“RAID4”或“RAID-DP”或“RAID-TEC”。

+
[NOTE]
====
可能会为 FlexGroup 卷显示多种 RAID 类型，因为 FlexGroup 的成分卷可能位于不同类型的聚合上。

====
** SnapLock 类型
+
显示卷所在聚合的 SnapLock 类型。

** SnapLock 过期时间
+
显示 SnapLock 卷的过期日期。



* *容量*
+
** 精简配置
+
显示是否为卷配置了精简配置。

** 自动增长
+
显示灵活卷是否在聚合内自动增长。

** Snapshot 自动删除
+
指定在对卷执行的写入因聚合中空间不足而失败时是否自动删除 Snapshot 副本以释放空间。

** 配额
+
指定是否为卷启用了配额。



* *效率*
+
** 数据压缩
+
指定是启用还是禁用压缩。

** 重复数据删除
+
指定是启用还是禁用重复数据删除。

** 重复数据删除模式
+
指定对卷启用的重复数据删除操作是手动操作、计划操作，还是基于策略的操作。如果模式设置为“已计划”，则显示操作计划；如果模式设置为某种策略，则显示策略名称。

** 重复数据删除类型
+
指定在卷上运行的重复数据删除操作的类型。如果卷处于某种 SnapVault 关系中，则显示的类型为“SnapVault”。对于任何其他卷，类型显示为“常规”。

** 存储效率策略
+
指定已通过 Unified Manager 分配给此卷的存储效率策略的名称。此策略可以控制压缩和重复数据删除设置。



* *保护*
+
** Snapshot 副本
+
指定是启用还是禁用了自动 Snapshot 副本。







[[protection-tab]]
== 保护选项卡

“保护”选项卡显示有关所选卷的保护详细信息，例如延迟信息、关系类型和关系的拓扑。

* *摘要*
+
显示所选卷的保护关系（SnapMirror、SnapVault 或 Storage VM DR）属性。对于任何其他关系类型，仅显示 Relationship Type 属性。如果选择了主卷，则仅显示托管和本地 Snapshot 副本策略。为 SnapMirror 和 SnapVault 关系显示的属性包括以下内容：

+
** 源卷
+
如果选定卷是目标，则显示该卷的源的名称。

** 滞后状态
+
显示保护关系的更新或传输滞后状态。状态可以是“错误”、“警告”或“严重”。

+
滞后状态不适用于同步关系。

** 滞后持续时间
+
显示镜像中的数据滞后于源的时间。

** 上次成功更新
+
显示最近成功更新保护关系的日期和时间。

+
上次成功更新不适用于同步关系。

** 存储服务成员
+
显示对于卷是否属于存储服务以及由存储服务所托管的选择是“是”还是“否”。

** 版本灵活的复制
+
显示“是”、“是，使用备份选项”或“无”。“是”指示即使源和目标卷运行不同版本的 ONTAP 软件，也有可能进行 SnapMirror 复制。“是，使用备份选项”指示实施 SnapMirror 保护并且能够将多个版本的备份副本保留在目标上。“无”指示“版本灵活的复制”未启用。

** 关系功能
+
指示可用于保护关系的 ONTAP 功能。

** 保护服务
+
如果关系由保护合作伙伴应用程序托管，则显示保护服务的名称。

** 关系类型
+
显示任何关系类型，包括异步镜像、异步存储、异步 MirrorVault、StrictSync 和同步。

** 关系状况
+
显示 SnapMirror 或 SnapVault 关系的状况。该状况可以是“未初始化”、“已执行 SnapMirror”或“已断开”。如果选择源卷，则关系状况不适用，也不会显示。

** 传输状态
+
显示保护关系的传输状态。传输状态可以是下列状态之一：

+
*** 正在中止
+
SnapMirror 传输已启用；但是，正在执行一个传输中止操作，此操作可能需要删除检查点。

*** 正在检查
+
正在对目标卷进行诊断检查，当前未进行传输。

*** 正在完成
+
SnapMirror 传输已启用。卷当前处于增量 SnapVault 传输的传输后阶段。

*** 闲置
+
已启用传输，但当前未进行传输。

*** 同步
+
处于同步关系的两个卷中的数据处于同步状态。

*** 不同步
+
目标卷中的数据与源卷不同步。

*** 正在准备
+
SnapMirror 传输已启用。卷当前处于增量 SnapVault 传输的传输前阶段。

*** 已排队
+
SnapMirror 传输已启用。当前未进行传输。

*** 已暂停
+
SnapMirror 传输已禁用。当前未进行传输。

*** 正在暂停
+
正在进行 SnapMirror 传输。其他传输已禁用。

*** 正在传输
+
已启用 SnapMirror 传输，且传输正在进行中。

*** 正在过渡
+
从源卷到目标卷的异步数据传输完成，并且已开始过渡到同步操作。

*** 正在等待
+
SnapMirror 传输已启动，但某些关联任务正在等待排队。



** 最大传输速率
+
显示关系的最大传输速率。最大传输速率可能是以 KB/秒 (Kbps)、MB/秒 (Mbps)、GB/秒 (Gbps) 或 TB/秒 (Tbps) 为单位的数值。如果显示“无限制”，则关系之间的基线传输无限制。

** SnapMirror 策略
+
显示卷的保护策略。DPDefault 表示默认异步镜像保护策略，XDPDefault 表示默认异步保管库策略，DPSyncDefault 表示默认异步 MirrorVault 策略。StrictSync 表示默认同步严格保护策略，Sync 表示默认同步策略。您可以单击策略名称以查看与该策略关联的详细信息，包括以下信息：

+
*** 传输优先级
*** 忽略访问时间设置
*** 尝试次数限制
*** 注释
*** SnapMirror 标签
*** 保留设置
*** 实际 Snapshot 副本
*** 保留 Snapshot 副本
*** 保留警告阈值
*** 无保留设置的快照副本 在源为数据保护（DP）卷的级联 SnapVault 关系中，仅适用规则“`sm_created`”。


** 更新计划
+
显示分配给关系的 SnapMirror 计划。将光标置于信息图标上方可以显示计划详细信息。

** 本地 Snapshot 策略
+
显示卷的 Snapshot 副本策略。策略可以是“默认”、“无”或者是为自定义策略指定的任何名称。

** 受保护于
+
显示用于所选卷的保护类型。例如，如果卷受一致性组和 SnapMirror 卷关系保护，则此字段会同时显示 SnapMirror 和一致性组。此字段还提供了一个链接，将您重定向到“关系”页面以查看统一的关系状态。此链接仅适用于组成关系。

** 一致性组
+
对于受 SnapMirror 活动同步关系保护的卷，此列显示卷的一致性组。



* *视图*
+
显示选定卷的保护拓扑。拓扑包含与选定卷相关的所有卷的图形表示。选定卷以深灰色框表示，拓扑中卷之间的直线表示保护关系类型。拓扑中的关系方向是按从左到右显示，每个关系的源在左侧，目标在右侧。

+
双粗线表示异步镜像关系，单粗线表示异步 Vault 关系，双细线表示异步 MirrorVault 关系，粗线和细线表示同步关系。下表指明同步关系是 StrictSync 还是 Sync。

+
右键单击某个卷将显示一个菜单，从中可以选择保护该卷或将数据还原到该卷。右键单击某个关系将显示一个菜单，从中可以选择编辑、中止、暂停、中断、删除或恢复关系。

+
在以下情况下，不会显示菜单：

+
** RBAC 设置不允许执行此操作，例如您只有操作员权限
** 卷处于同步保护关系
** 当卷 ID 未知时，例如，当您具有集群间关系并且尚未发现目标集群时，单击拓扑中的另一个卷将选择并显示该卷的信息。卷左上角的问号（image:../media/hastate_unknown.gif["HA 状态的图标 – 未知"] ）表示该卷缺失或尚未被发现。这也可能表明容量信息缺失。将光标悬停在问号上会显示其他信息，包括补救措施建议。


+
如果拓扑符合几个常用拓扑模板之一，则会显示有关卷容量、滞后、Snapshot 副本及上次成功传输数据的信息。如果拓扑不符合这些模板之一，则有关卷滞后及上次成功传输数据的信息将显示在拓扑下面的关系表中。在这种情况下，表中突出显示的行指示选定卷，而在拓扑视图中，有蓝点的粗线指示选定卷与其源卷之间的关系。



拓扑视图包含下列信息：

* 容量
+
显示卷使用的总容量。将光标置于拓扑中的某个卷上，会在“当前阈值设置”对话框中显示该卷的当前警告和严重阈值设置。您还可以通过单击“当前阈值设置”对话框中的*编辑阈值*链接来编辑阈值设置。清除*容量*复选框将隐藏拓扑中所有卷的所有容量信息。

* 滞后
+
显示传入保护关系的延迟持续时间和延迟状态。清除*延迟*复选框会隐藏拓扑中所有卷的所有延迟信息。当*延迟*复选框变暗时，所选卷的延迟信息以及所有相关卷的延迟信息将显示在拓扑下方的关系表中。

* Snapshot
+
显示可用于卷的 Snapshot 副本数。清除 *Snapshot* 复选框将隐藏拓扑中所有卷的所有 Snapshot 副本信息。单击 Snapshot 副本图标（ image:../media/icon_snapshot_list.gif["与卷关联的 Snapshot 副本列表图标"] ）将显示卷的 Snapshot 副本列表。图标旁边显示的 Snapshot 副本计数大约每小时更新一次；但是，Snapshot 副本列表会在单击图标时更新。这可能会导致拓扑中显示的 Snapshot 副本计数与单击图标时列出的 Snapshot 副本数之间存在差异。

* 上次成功传输
+
显示上次成功数据传输的数据量、持续时间、时间和日期。当 *上次成功传输* 复选框灰显时，所选卷的上次成功传输信息以及所有相关卷的上次成功传输信息将显示在拓扑下方的关系表中。

+
** *历史记录*
+
在图形中显示所选卷的传入 SnapMirror 和 SnapVault 保护关系的历史记录。有三种历史记录图可用：传入关系延迟持续时间、传入关系传输持续时间和传入关系传输大小。仅当您选择目标卷时，才会显示历史记录信息。如果选择主卷，则图形为空，并显示消息“未找到数据”。如果卷受一致性组和 SnapMirror 同步关系保护，则不会显示关系传输持续时间和关系传输大小的信息。



+
您可以从“历史记录”窗格顶部的下拉列表中选择图形类型。您也可以选择 1 周、1 个月或 1 年，查看特定时间段的详细信息。历史图表可以帮助您识别趋势：例如，如果在一天或一周的同一时间传输大量数据，或者持续超出滞后警告或滞后错误阈值，您可以采取适当的措施。此外，您可以单击 *导出* 按钮，为您正在查看的图表创建 CSV 格式的报告。



保护历史记录图显示下列信息：

* *关系滞后持续时间*
+
在纵轴 (y) 上显示秒数、分钟数或小时数，在横轴 (x) 上显示天数、月数或年数，具体取决于选定的持续时间段。y 轴上的最大值表示在 x 轴上所显示的持续时间段内达到的最大滞后持续时间。图形中的橙色水平线表示滞后错误阈值，黄色水平线表示滞后警告阈值。将光标置于这些线上方可以显示阈值设置。蓝色水平线表示滞后持续时间。可以通过将光标置于感兴趣区域上方来查看图中特定点的详细信息。

* *关系转移持续时间*
+
在纵轴 (y) 上显示秒数、分钟数或小时数，在横轴 (x) 上显示天数、月数或年数，具体取决于选定的持续时间段。y 轴上的最大值表示在 x 轴上所显示的持续时间段内达到的最大传输持续时间。可以通过将光标置于感兴趣区域上方来查看图中特定点的详细信息。

+
[NOTE]
====
对于处于同步保护关系中的卷，不会显示此图表。

====
* *关系传输大小*
+
根据传输大小在纵轴 (y) 上显示字节数、千字节数、兆字节数等数字，根据选定时间段在横轴 (x) 上显示天数、月数或年数。y 轴上的最大值表示在 x 轴上所显示的持续时间段内达到的最大传输大小。可以通过将光标置于感兴趣区域上方来查看图中特定点的详细信息。

+
[NOTE]
====
对于处于同步保护关系中的卷，不会显示此图表。

====




[[history-area]]
== 历史记录区域

历史记录区域显示图形，提供有关选定卷的容量和空间预留的信息。此外，您可以点击*导出*按钮，以 CSV 格式为您正在查看的图表创建报告。

当数据或卷的状态在一段时间内保持不变时，图形可能为空，并且会显示“未找到数据”消息。

您可以从“历史记录”窗格顶部的下拉列表中选择图形类型。您也可以选择 1 周、1 个月或 1 年，查看特定时间段的详细信息。历史记录图表可以帮助您识别趋势——例如，如果卷使用量始终突破“几乎已满”阈值，您可以采取适当的操作。

历史记录图显示下列信息：

* *已用卷容量*
+
在纵轴 (y) 上以折线图的形式显示卷中的已用容量和基于使用情况历史记录使用卷容量的趋势（以字节、千字节、兆字节等表示）。时间段显示在横轴 (x) 上。您可以选择一周、一个月或一年作为时间段。可以通过将光标置于特定区域上方来查看图中特定点的详细信息。您可以通过单击相应的图例来隐藏或显示折线图。例如，单击“已用卷容量”图例时，“已用卷容量”图形线条处于隐藏状态。

* *已用卷容量与总卷容量*
+
在纵轴 (y) 上以折线图的形式显示基于使用情况历史记录使用卷容量的趋势，以及已用容量、总容量和通过重复数据删除和数据压缩节省的空间的详细信息（以字节、千字节、兆字节等表示）。时间段显示在横轴 (x) 上。您可以选择一周、一个月或一年作为时间段。可以通过将光标置于特定区域上方来查看图中特定点的详细信息。您可以通过单击相应的图例来隐藏或显示折线图。例如，单击“Trend Capacity Used”图例时，“Trend Capacity Used”图形线条处于隐藏状态。

* *已用卷容量（%）*
+
在纵轴 (y) 上以折线图的形式显示卷中的已用容量和基于使用情况历史记录使用卷容量的趋势（以百分比表示）。时间段显示在横轴 (x) 上。您可以选择一周、一个月或一年作为时间段。可以通过将光标置于特定区域上方来查看图中特定点的详细信息。您可以通过单击相应的图例来隐藏或显示折线图。例如，单击“已用卷容量”图例时，“已用卷容量”图形线条处于隐藏状态。

* *已用快照容量（%）*
+
在纵轴 (y) 上以折线图的形式显示 Snapshot 预留和 Snapshot 警告阈值，并以面积图的形式显示 Snapshot 副本使用的容量。Snapshot 溢出用不同的颜色表示。时间段显示在横轴 (x) 上。您可以选择一周、一个月或一年作为时间段。可以通过将光标置于特定区域上方来查看图中特定点的详细信息。您可以通过单击相应的图例来隐藏或显示折线图。例如，单击“Snapshot 预留”图例时，“Snapshot 预留”图形线条处于隐藏状态。

[[related-devices-pane]]
== 相关设备窗格

使用“相关设备”窗格，您可以查看并导航到与卷相关的 SVM、聚合、qtree、LUN 和 Snapshot 副本：

* *Storage Virtual Machine*
+
显示包含所选卷的 SVM 的容量和运行状况状态。

* *聚合*
+
显示选定卷所在聚合的容量和运行状况。对于 FlexGroup 卷，列出包含 FlexGroup 的聚合数。

* *聚合中的卷*
+
显示属于选定卷父聚合的所有卷的数量和容量。此外，系统还将基于最高严重性级别显示卷的运行状况。例如，如果一个聚合包含十个卷，其中五个显示“警告”状态，其余五个显示“严重”状态，则显示的状态为“严重”。对于 FlexGroup 卷，不会显示此组件。

* *Qtrees*
+
显示选定卷包含的 qtree 数量以及选定卷包含的具有配额的 qtree 容量。系统将相对于卷数据容量来显示具有配额的 qtree 容量。此外，系统还将基于最高严重性级别显示 qtree 的运行状况。例如，如果一个卷有十个 qtree，五个为“警告”状态，其余五个为“严重”状态，则显示的状态为“严重”。

* *NFS 共享*
+
显示与卷关联的 NFS 共享的数量和状态。

* *SMB 共享*
+
显示 SMB/CIFS 共享的数量和状态。

* *LUN*
+
显示选定卷中所有 LUN 的数量和总大小。此外，系统还将基于最高严重性级别显示 LUN 的运行状况。

* *用户和组配额*
+
显示与卷及其 qtree 关联的用户和用户组配额的数量和状态。

* *FlexClone 卷*
+
显示选定卷的所有克隆卷的数量和容量。只有当选定卷包含克隆卷时，才会显示此数量和容量。

* *父卷*
+
显示选定 FlexClone 卷的父卷的名称和容量。只有当选定卷为 FlexClone 卷时，才会显示父卷。
