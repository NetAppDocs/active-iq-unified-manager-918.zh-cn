= 了解常见 Active IQ Unified Manager 运行状况工作流程和任务
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
与 Unified Manager 相关的一些常见管理工作流程和任务包括选择要监控的存储集群；诊断对数据可用性、容量和保护产生不利影响的条件；恢复丢失的数据；配置和管理卷；以及捆绑诊断数据并将其发送给技术支持（必要时）。

Unified Manager 使存储管理员能够查看仪表板，评估托管存储集群的整体容量、可用性和保护运行状况，然后快速识别、定位、诊断并分配可能出现的任何特定问题以进行解决。

与群集、存储虚拟机（SVM）、卷或 FlexGroup 卷相关的影响托管存储对象的存储容量或数据可用性的最重要问题将显示在仪表板页面的系统运行状况图和事件中。当发现关键问题时，此页面会提供支持适当故障排除工作流程的链接。

Unified Manager 也可以包含在包含相关可管理性工具（例如 OnCommand Workflow Automation (WFA)）的工作流中，以支持直接配置存储资源。

本文档介绍了与以下管理任务相关的常见工作流程：

* 诊断和管理可用性问题
+
如果硬件故障或存储资源配置问题导致在“仪表板”页面中显示数据可用性事件，则存储管理员可以按照嵌入式链接查看有关受影响存储资源的连接信息，查看故障排除建议，并将问题解决方案分配给其他管理员。

* 配置和监控性能事件
+
管理员可以监控和管理正在受监控的存储系统资源的性能。有关详细信息，请参见 link:../performance-checker/concept_introduction_to_unified_manager_performance_monitoring.html["Active IQ Unified Manager 性能监控简介"]。

* 诊断和管理卷容量问题
+
如果在“仪表板”页面中显示卷存储容量问题，存储管理员可以按照嵌入式链接查看与受影响卷的存储容量相关的当前和历史趋势，查看故障排除建议，并将问题解决方案分配给其他管理员。

* 配置、监控和诊断保护关系问题
+
在创建和配置保护关系后，存储管理员可以查看与保护关系相关的潜在问题、保护关系的当前状态、有关受影响关系的当前和历史保护作业成功信息以及故障排除建议。有关详细信息，请参见 link:../data-protection/concept_manage_and_monitor_protection_relationships.html["了解如何管理和监控保护关系"]。

* 创建备份文件并从备份文件还原数据。
* 将存储对象与标注关联
+
通过将存储对象与批注相关联，存储管理员可以筛选和查看与存储对象相关的事件，这使存储管理员能够确定优先级并解决与事件相关联的问题。

* 使用 REST API 通过查看 Unified Manager 捕获的运行状况、容量和性能信息来帮助管理集群。有关详细信息，请参见link:../api-automation/concept_get_started_with_um_apis.html["Active IQ Unified Manager REST API 入门"]。
* 向技术支持发送支持包
+
存储管理员可以使用维护控制台检索支持包并将其发送给技术支持。当问题需要比 AutoSupport 消息提供的更详细的诊断和故障排除时，必须将支持包发送给技术支持。
