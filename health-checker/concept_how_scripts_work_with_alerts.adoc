= 了解脚本如何与 Active IQ Unified Manager 中的警报配合使用
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以将警报与脚本关联，以便在 Unified Manager 中引发事件警报时执行脚本。您可以使用脚本来解决存储对象的问题或识别哪些存储对象正在生成事件。

在 Unified Manager 中为事件生成警报时，将向指定收件人发送警报电子邮件。如果您将警报与脚本相关联，则会执行脚本。您可以从警报电子邮件中获取传递给脚本的参数的详细信息。

[NOTE]
====
如果您已创建自定义脚本并将其与特定事件类型的警报相关联，则将根据该事件类型的自定义脚本采取操作，默认情况下，“管理操作”页面或 Unified Manager 仪表板上的“*修复它*”操作不可用。

====
该脚本使用以下参数执行：

* `-eventID`
* `-eventName`
* `-eventSeverity`
* `-eventSourceID`
* `-eventSourceName`
* `-eventSourceType`
* `-eventState`
* `-eventArgs`


您可以在脚本中使用参数并收集相关事件信息或修改存储对象。



[[example-for-obtaining-arguments-from-scripts]]
== 从脚本中获取参数的示例

[listing]
----
print "$ARGV[0] : $ARGV[1]\n"
print "$ARGV[7] : $ARGV[8]\n"
----
生成警报时，系统将执行此脚本并显示以下输出：

[listing]
----
-eventID : 290
-eventSourceID : 4138
----
