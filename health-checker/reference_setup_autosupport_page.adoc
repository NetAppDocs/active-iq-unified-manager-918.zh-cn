= 在 Active IQ Unified Manager 中向技术支持发送 AutoSupport 消息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
通过 AutoSupport 页面，您可以向技术支持团队发送预定义和按需的 AutoSupport 消息，以确保环境正常运行，并帮助您维护环境的完整性。默认情况下，AutoSupport 处于启用状态，不应将其禁用，以便您获得 NetAppActive IQ 的优势。

您可以根据需要在消息中发送有关 Unified Manager 服务器的诊断系统信息和详细数据，安排定期发送消息，甚至生成并向技术支持团队发送支持包。

[NOTE]
====
具有存储管理员角色的用户可以生成按需 AutoSupport 消息和支持捆绑包并将其发送给技术支持。但是，只有管理员或维护用户才能启用或禁用定期 AutoSupport 并配置 HTTP 设置，如设置 HTTP 代理服务器一节所述。在需要使用 HTTP 代理服务器的环境中，应在存储管理员向技术支持发送按需 AutoSupport 消息和支持捆绑包之前完成配置。

====


[[send-on-demand-autosupport-messages]]
== 发送按需 AutoSupport 消息

您可以生成按需消息并将其发送给技术支持人员、指定的电子邮件收件人或两者。

.步骤
. 导航至 *常规* > *AutoSupport*，并执行以下一项或两项操作：
. 如果要将 AutoSupport 消息发送给技术支持，请选中*发送给技术支持*复选框。
. 如果要将 AutoSupport 消息发送给特定的电子邮件收件人，请选中 *发送给电子邮件收件人* 复选框，然后输入收件人的电子邮件地址。
. 单击 *Save*。
. 单击 *生成并发送 AutoSupport*。




[[enable-periodic-autosupport]]
== 启用定期 AutoSupport

您可以定期向技术支持发送特定的预定义消息，以进行问题诊断和解决。默认情况下，此功能处于启用状态。如果已禁用，管理员或维护用户可以启用这些设置。

.步骤
. 导航到*常规* > *AutoSupport*。
. 在定期 AutoSupport 部分中，选中 *启用定期向 Active IQ 发送 AutoSupport 数据* 复选框。
. 如果需要，请定义 HTTP 代理服务器的名称、端口和身份验证信息，如设置 HTTP 代理服务器一节所述。
. 单击 *Save*。




[[upload-on-demand-support-bundle]]
== 上传按需支持包

您可以根据故障排除要求生成支持包并将其发送给技术支持。Unified Manager 仅存储最近生成的两个支持包。较早的支持包已从系统中删除。

由于某些类型的支持数据可能占用大量集群资源或需要很长时间才能完成，因此在选择完整支持捆绑包时，您可以包含或排除特定数据类型以减小支持捆绑包的大小。您还可以选择创建仅包含 30 天日志和配置数据库记录的轻量级支持捆绑包——它不包括性能数据、采集记录文件和服务器堆转储。

.步骤
. 导航到*常规* > *AutoSupport*。
. 在按需支持捆绑包部分，单击*生成并发送支持捆绑包*。
. 要向技术支持发送轻型支持捆绑包，请在生成和发送支持捆绑包弹出窗口中，选中**生成轻型支持捆绑包**复选框。
. 或者，要发送完整支持捆绑包，请选中*生成完整支持捆绑包*复选框。选择要包含在支持捆绑包中或从中排除的特定数据类型。
+
[NOTE]
====
即使未选择任何数据类型，支持捆绑包仍会与其他 Unified Manager 数据一起生成。

====
. 请选中 *将捆绑包发送给技术支持* 复选框，以生成捆绑包并将其发送给技术支持。如果不选中此复选框，则会生成捆绑包并将其本地存储在 Unified Manager 服务器中。生成的支持包可在 VMware 系统上的 /support 目录中、Linux 系统上的 `/opt/netapp/data/support/`中以及 Windows 系统上的 `ProgramData\NetApp\OnCommandAppData\ocum\support`中供以后使用。
. 单击*发送*。




[[set-up-http-proxy-server]]
== 设置 HTTP 代理服务器

如果您的环境不提供从 Unified Manager 服务器的直接访问，您可以指定代理来提供 Internet 访问，以便向技术支持发送 AutoSupport 内容。此部分仅适用于管理员和维护用户。

* *使用 HTTP 代理*
+
选中此框以确定要用作 HTTP 代理的服务器。

+
输入代理服务器的主机名或 IP 地址，以及用于连接到该服务器的端口号。

* *使用身份验证*
+
如果需要提供身份验证信息来访问用作 HTTP 代理的服务器，请选中此框。

+
输入向 HTTP 代理进行身份验证所需的用户名和密码。



[NOTE]
====
不支持仅提供基本身份验证的 HTTP 代理。
