= 通过 Active IQ Unified Manager 中的通知铃查看活动事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
菜单栏中的通知铃（image:../media/notification_bell.png[""]）提供了一种快速查看 Unified Manager 正在跟踪的最重要活动事件的方法。

活动事件列表提供了一种查看所有集群上的关键事件、错误事件、警告事件和升级事件总数的方法。此列表包括过去 7 天的事件，不包括信息事件。您可以单击链接以显示您最感兴趣的事件列表。

请注意，当无法访问集群时，Unified Manager 会在此页面中显示此信息。您可以通过单击 *详细信息* 按钮查看有关无法访问的集群的详细信息。此操作将打开事件详细信息页面。此页面上还会显示规模监控问题，例如管理站上的空间或 RAM 不足。

.步骤
. 从菜单栏中，单击 image:../media/notification_bell.png[""]。
. 要查看任何活动事件的详细信息，请单击事件文本链接，例如“2 个容量”或“4 个性能”。
