= 了解 Active IQ Unified Manager 中的工作负载仪表板
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
工作负载表示存储对象（如卷或 LUN）的输入/输出（I/O）操作。存储的调配方式取决于预期的工作负载要求。只有在存储对象之间存在流量后，Active IQ Unified Manager 才会跟踪工作负载统计信息。例如，工作负载 IOPS 和延迟值在用户开始使用数据库或电子邮件应用程序后可用。

工作负载页面显示由 Unified Manager 管理的 ONTAP 群集的存储工作负载摘要。它提供了有关符合性能服务级别的存储工作负载以及不符合要求的存储工作负载的一目了然的累积信息。它还使您能够评估整个数据中心内群集的总体、可用和已用容量以及性能（IOPS）。

[NOTE]
====
建议您评估不符合、不可用或不由任何性能服务级别管理的存储工作负载的数量，并采取必要措施以确保其符合性、容量使用率和 IOPS。

====
Workloads 页面包括以下两个部分：

* 工作负载概述：概述由 Unified Manager 管理的 ONTAP 集群上的存储工作负载数量。
* 数据中心概况：提供数据中心存储工作负载的容量和 IOPS 概况。相关数据在数据中心级别以及针对各个单独的项进行显示。




[[workloads-overview-section]]
== 工作负载概述部分

工作负载概述部分提供了存储工作负载的累积概览信息。存储工作负载的状态将根据已分配和未分配的性能服务级别进行显示。

* *已分配*：针对已分配性能服务级别的存储工作负载报告以下状态：
+
** *合规*：存储工作负载的性能基于分配给它们的 Performance Service Levels。如果存储工作负载处于相关 Performance Service Levels 中定义的阈值延迟范围内，则将其标记为 "`conforming`"。合规的工作负载以蓝色标记。
** *不符合*：在性能监控期间，如果存储工作负载延迟超过关联性能服务级别中定义的阈值延迟，则存储工作负载将被标记为 "`non-conforming`"。不符合要求的工作负载以橙色标记。
** *不可用*：如果存储工作负载处于脱机状态或无法访问相应的集群，则将其标记为 "`unavailable`"。不可用的工作负载标记为红色。


* *未分配*：未分配性能服务级别的存储工作负载报告为 "`unassigned`"。该数字由信息图标表示。


总工作负载计数是已分配和未分配工作负载的总和。

您可以单击此部分中显示的工作负载总数，然后在“工作负载”页面上查看它们。

“按性能服务级别划分的遵从性”小节显示可用存储工作负载的总数：

* 符合每种性能服务级别
* 分配的性能服务级别与建议的性能服务级别不匹配




[[data-center-overview-section]]
== 数据中心概述部分

数据中心概述部分以图形方式表示数据中心中所有集群的可用和已用容量以及 IOPS。通过使用此数据，您应该管理存储工作负载的容量和 IOPS。该部分还显示所有集群中存储工作负载的以下信息：

* 数据中心中所有集群的总容量、可用容量和已用容量
* 数据中心中所有集群的总 IOPS、可用 IOPS 和已用 IOPS
* 基于每个性能服务级别的可用和已用容量
* 基于每个性能服务级别的可用和已用 IOPS
* 未分配任何性能服务级别的工作负载使用的总空间和 IOPS


*如何根据性能服务级别计算数据中心容量和性能*

将根据集群中所有存储工作负载的总已用容量和性能来检索已用容量和 IOPS。

系统将根据节点上的预期延迟和推荐的性能服务级别来计算可用的 IOPS。它包括预期延迟小于或等于其自身预期延迟的所有性能服务级别的可用 IOPS。

系统将根据聚合上的预期延迟和推荐的性能服务级别来计算可用容量。它包括预期延迟小于或等于其自身预期延迟的所有性能服务级别的可用容量。
