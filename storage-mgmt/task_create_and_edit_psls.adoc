= 在 Active IQ Unified Manager 中创建和编辑性能服务级别
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当系统定义的性能服务级别与您的工作负载要求不匹配时，您可以创建自己的性能服务级别，以针对您的工作负载进行优化。

.开始之前
* 您必须具有应用程序管理员角色。
* 性能服务级别名称必须是唯一的，并且不能使用以下保留关键字：
+
`Prime`、 `Extreme`、 `Performance`、 `Value`、 `Unassigned`、 `Learning`、 `Idle`、 `Default` 和 `None`。



您可以通过定义访问存储的应用程序所需的服务级别目标，在“性能服务级别”页面中创建和编辑自定义性能服务级别。

[NOTE]
====
如果性能服务级别当前已分配给工作负载，则无法对其进行修改。

====
.步骤
. 在*设置*下的左侧导航窗格中，选择*策略* > *性能服务级别*。
. 在*性能服务级别*页面中，根据您是要创建新的性能服务级别还是要编辑现有的性能服务级别，单击相应的按钮。
+
|===
| 目的 | 按照下面的步骤进行操作...... 


 a| 
创建新的性能服务级别
 a| 
单击 *Add*。



 a| 
编辑现有性能服务级别
 a| 
选择一个现有的性能服务级别，然后单击*编辑*。

|===
+
将显示用于添加或编辑性能服务级别的页面。

. 通过指定性能目标自定义性能服务级别，然后单击*提交*以保存性能服务级别。


您可以从工作负载页面或在调配新工作负载时将新的或更改的性能服务级别应用于工作负载（LUN、NFS 文件共享、CIFS 共享）。
