= 了解 Active IQ Unified Manager 中的"Fix It"和"Fix All"按钮选项
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
管理操作页面为您提供*修复它*或*全部修复*按钮，以修复通过事件通知 Unified Manager 的问题。

我们建议您根据需要单击按钮以解决问题。但是，如果您不确定是否要按照 Unified Manager 的建议解决此问题，则可以执行以下操作：

|===
| 您希望做什么？ | *操作* 


 a| 
让 Unified Manager 解决所有已识别对象上的问题。
 a| 
单击 *全部修复* 按钮。



 a| 
此时请勿修复任何已识别对象的问题，并在再次引发事件之前隐藏此管理操作。
 a| 
单击向下箭头并单击*全部关闭*。



 a| 
仅修复部分已识别对象上的问题。
 a| 
单击管理操作的名称以展开列表并显示所有单个 *Fix It* 操作。然后按照步骤修复或取消单个管理操作。

|===
|===
| 您希望做什么？ | 操作 


 a| 
让 Unified Manager 解决此问题。
 a| 
单击 *Fix It* 按钮。



 a| 
目前不要修复此问题，并在再次引发事件之前隐藏此管理操作。
 a| 
单击向下箭头并单击 *Dismiss*。



 a| 
显示此事件的详细信息以更好地了解此问题。
 a| 
* 单击 *Fix It* 按钮，并在生成的对话框中查看将要应用的修复。
* 单击向下箭头，然后单击*查看事件详细信息*以显示事件详细信息页面。


然后，如果您想解决此问题，请在任意一个结果页面中单击 *修复它*。



 a| 
显示此存储对象的详细信息以更好地了解此问题。
 a| 
单击存储对象的名称可在“性能资源管理器”或“运行状况详细信息”页面中显示详细信息。

|===
在某些情况下，修复会反映在接下来的 15 分钟配置轮询中。在其他情况下，可能需要长达数小时才能验证配置更改并使事件过时。

要查看已完成或正在进行的管理操作列表，请单击过滤器图标并选择*已完成*或*正在进行*。

修复所有操作以串行方式运行，因此当您查看 *进行中* 面板时，某些对象的状态将为 *进行中*，而其他对象的状态将为 *计划*；这意味着它们仍在等待实施。
