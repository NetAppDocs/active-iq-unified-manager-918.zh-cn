= 解决 Active IQ Unified Manager 中的"用户未找到"错误
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
执行与身份验证相关的操作（如添加、编辑、删除或测试远程用户或组）时，将显示以下错误消息： `User not found.`

*原因*

如果用户存在于 AD 服务器或 LDAP 服务器中，并且您将基本可分辨名称设置为了不正确的值，则可能会出现此问题。

*更正操作*

. 在左侧导航窗格中，单击*常规* > *远程身份验证*。
. 输入基本可分辨名称的相应信息。
. 单击 *Save*。
