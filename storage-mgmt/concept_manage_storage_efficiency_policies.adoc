= 在 Active IQ Unified Manager 中管理存储效率策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
存储效率策略（ SEP ）使您能够定义工作负载的存储效率特性。您可以在最初创建工作负载时将 SEP 分配给工作负载，也可以在之后通过编辑工作负载进行分配。

存储效率包括使用可提高存储利用率和降低存储成本的技术，例如精简配置、重复数据删除和数据压缩。在创建 SEP 时，您可以单独或一起使用这些节省空间的技术，以实现最大的存储效率。将策略与存储工作负载关联时，将为它们分配指定的策略设置。Unified Manager 使您能够分配系统定义和用户定义的 SEP，以优化数据中心的存储资源。

Unified Manager 提供两个系统定义的 SEP：高和低。这些 SEP 适用于数据中心中的大多数存储工作负载，但是，如果系统定义的 SEP 不满足您的要求，您可以创建自己的策略。

您无法修改系统定义的或当前分配给工作负载的 SEP。您无法删除分配给工作负载的 SEP，如果它是唯一可用的 SEP，也无法删除。

存储效率策略页面列出了可用的 SEP，并允许您添加、编辑和删除自定义的 SEP。此页面显示下列信息：

|===
| 字段 | 问题描述 


 a| 
名称
 a| 
SEP 的名称。



 a| 
类型
 a| 
此策略是系统定义的还是用户定义的。



 a| 
空间预留
 a| 
此卷是精简配置还是厚配置。



 a| 
重复数据删除
 a| 
是否在工作负载上启用重复数据删除：

* 内联：在工作负载上写入时发生重复数据删除
* 背景：重复数据删除发生在工作负载中
* 禁用：在工作负载上已禁用重复数据删除




 a| 
数据压缩
 a| 
是否在工作负载上启用数据压缩：

* 内联：在写入工作负载时发生数据压缩
* 背景：数据压缩发生在工作负载中
* 禁用：在工作负载上已禁用数据压缩




 a| 
工作负载
 a| 
已分配给 SEP 的存储工作负载数

|===

== 创建自定义存储效率策略的准则

如果现有 SEP 不符合存储工作负载的策略要求，则可以创建自定义 SEP。但是，建议尝试对存储工作负载使用系统定义的 SEP，并且仅在必要时创建自定义 SEP。

您可以在所有工作负载页面和卷/运行状况详细信息页面中查看分配给工作负载的 SEP。您可以在仪表板的“容量”面板和“容量：所有集群”视图中查看基于这些存储效率的集群级数据缩减率（不包括 Snapshot 副本）。
