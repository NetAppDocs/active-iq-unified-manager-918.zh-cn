= 在 Active IQ Unified Manager 中收藏您喜爱的帮助主题
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在“帮助收藏夹”选项卡中，您可以将经常使用的帮助主题添加到书签中。帮助书签可快速访问您喜爱的主题。

.步骤
. 导航到要添加为收藏夹的“帮助”主题。
. 单击*收藏夹*，然后单击*添加*。
