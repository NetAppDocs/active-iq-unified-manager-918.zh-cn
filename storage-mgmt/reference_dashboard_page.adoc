= 了解 Active IQ Unified Manager 仪表板页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
仪表板页面有“面板”，显示您正在监控的集群的高级容量、性能和安全运行状况。此页面还提供了一个管理操作面板，其中列出了 Unified Manager 可以为解决某些事件而进行的修复。

大多数面板还显示该类别中的活动事件数，以及过去 24 小时内添加的新事件数。此信息可帮助您确定可能需要进一步分析以解决事件的集群。单击事件会显示热门事件，并提供指向事件管理清单页面的链接，该页面已过滤以显示该类别中的活动事件。

在仪表板的顶部，您可以选择面板是否显示所有受监控集群（“所有集群”）或单个集群的信息。您可以先查看所有集群的状态，然后在需要查看详细信息时深入查看单个集群。

[NOTE]
====
下面列出的一些面板根据您的配置显示在控制面板上。

====


[[management-actions-panel]]
== 管理操作面板

Unified Manager 可以彻底诊断某些问题并提供单一解决方案。如果可用，这些解决方案将通过 *Fix It* 或 *Fix All* 按钮显示在此面板中。您可以立即从 Unified Manager 修复这些问题，而不必使用 ONTAP System Manager 或 ONTAP CLI。要查看所有问题，请单击“请参见” link:concept_fix_ontap_issues_directly_from_unified_manager.html["直接从 Unified Manager 修复 ONTAP 问题"] 以了解更多信息。



[[capacity-panel]]
== 容量面板

查看所有集群时，此面板显示每个集群的物理已用容量（应用存储效率节约后）和物理可用容量（不包括潜在的存储效率节约）、预计磁盘已满的天数以及基于配置的 ONTAP 存储效率设置的数据缩减率（不包括 Snapshot 副本）。它还列出了任何已配置云层的已用容量。单击条形图将转到该集群的聚合清单页面。单击“Days To Full”文本将显示一条消息，标识剩余容量天数最少的聚合；单击聚合名称可查看更多详细信息。

查看单个集群时，此面板显示按本地层上的每个单独磁盘类型排序的数据聚合以及云层的物理已用容量和物理可用容量。单击磁盘类型的条形图将转到使用该磁盘类型的卷的卷清单页面。



[[performance-capacity-panel]]
== 性能容量面板

查看所有集群时，此面板显示每个集群的性能容量值（过去 1 小时的平均值）以及性能容量达到上限（基于每日增长率）的天数。单击条形图将转到该集群的节点清单页面。请注意，节点清单页面显示过去 72 小时的平均性能容量。单击“Days To Full”文本将显示一条消息，标识剩余性能容量天数最少的节点；单击节点名称可查看更多详细信息。

查看单个集群时，此面板会显示集群性能容量使用百分比、总 IOPS 和总吞吐量 (MB/s) 值，以及这三个指标预计将达到上限的天数。



[[workload-iops-panel]]
== Workload IOPS 面板

查看单个集群时，此面板显示当前在特定 IOPS 范围内运行的工作负载总数，并在将光标悬停在图表上时显示每种磁盘类型的数量。



[[workload-performance-panel]]
== 工作负载性能面板

此面板显示分配给每个性能服务级别（PSL）策略的符合和不符合的工作负载的总数。它还显示未分配 PSL 的工作负载数量。单击条形图将转到“工作负载”页面中分配给该策略的符合的工作负载。单击条形图后面的数字将转到分配给该策略的符合和不符合的工作负载。



[[security-panel]]
== 安全面板

安全面板显示所有群集或单个群集的高级安全状态，具体取决于您当前的视图。此面板显示：

* 过去 24 小时内收到的安全事件列表。单击某个事件可在“事件详细信息”页面上查看详细信息
* 集群安全状态（合规和不合规集群的计数）
* storage VM 安全状态（合规和不合规的 storage VM 计数）
* 卷加密状态（已加密或未加密的卷的计数）
* 卷反勒索软件状态（启用或禁用反勒索软件的卷数）


您可以单击合规和不合规集群、存储 VM、加密和未加密卷以及卷防勒索软件状态的条形图，转到相应页面并查看已过滤集群、存储 VM 和卷的安全详细信息。

合规性基于 https://www.netapp.com/pdf.html?item=/media/10674-tr4569pdf.pdf["适用于 ONTAP 9 的 NetApp 安全强化指南"^]。单击面板顶部的右箭头可查看安全页面上所有集群的安全详细信息。有关信息，请参见link:../health-checker/task_view_detailed_security_status_for_clusters_and_svms.html["查看集群和 Storage VM 的详细安全状态"]。



[[data-protection-panel]]
== 数据保护面板

此面板显示数据中心中单个或所有集群的数据保护摘要。它显示过去24小时内在 ONTAP 中引发的数据保护事件、MetroCluster 事件以及活动事件的总数。单击每个事件的链接将转到“事件详细信息”页面。您可以单击 *查看全部* 链接，在事件管理清单页面中查看所有活动保护事件。该面板显示：

* 受 Snapshot 副本保护的集群或数据中心内所有集群中的卷数。
* 受 SnapMirror 关系保护的集群或数据中心内所有集群中的卷数。对于 SnapMirror 关系，将考虑源集群上的卷数。
* 通过 IP 或 FC MetroCluster 配置保护的数据中心中的集群或所有集群的数量。
* 基于延迟状态的具有 SnapMirror 恢复点目标（RPO）延迟的卷关系数量。


您可以悬停鼠标以查看相应的计数和图例。您可以单击面板顶部的右箭头，查看数据保护页面上单个或所有集群的详细信息。此外，您还可以单击：

* 未受保护卷和受 Snapshot 副本保护的卷的条形图，转到“卷”页面并查看详细信息。
* 受 MetroCluster 配置保护或不受保护的集群的条形图，转到“集群”页面并查看详细信息。
* 所有关系的条形图可转到“关系”页面，其中的详细信息将根据源集群进行筛选。


有关详细信息，请参见link:../data-protection/view-protection-status.html["查看卷保护状态"]。



[[usage-overview-panel]]
== 使用概述面板

在查看所有集群时，您可以选择按最高 IOPS、最高吞吐量（MB/秒）或最高已用物理容量对集群进行排序。

在查看单个集群时，您可以选择按最高 IOPS、最高吞吐量（MB/s）或最高已用逻辑容量对工作负载进行排序。
