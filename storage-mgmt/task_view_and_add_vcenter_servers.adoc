= 在 Active IQ Unified Manager 中查看和添加 vCenter Servers
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要查看虚拟机（VM）的性能并进行故障排除，必须在您的 Active IQ Unified Manager 实例上添加关联的 vCenter Server。

.开始之前
在添加或查看 vCenter 服务器之前，请确保执行以下操作：

* 您知道 vCenter 服务器名称。
* 您知道 vCenter Server 的 IP 地址并拥有所需的凭据。凭据必须是 vCenter Server 管理员或对 vCenter Server 具有只读访问权限的 root 用户。
* 您要添加的 vCenter Server 运行 vSphere 6.5 或更高版本。
+

NOTE: 适用于 VMware ESXi 和 vCenter Server 的 Unified Manager 支持提供英语和日语版本。

* vCenter Server 中的数据收集设置已设置为统计级别 `_Level 3_`，以确保为所有受监控对象收集所需级别的指标。间隔时间应为 `_5 minutes_`，保存期限应为 `_1 day_`。
+
有关详细信息，请参见 VMware 文档中 _vSphere Monitoring and Performance Guide_ 的“`Data Collection Levels`”部分。

* vCenter Server 中的延迟值以毫秒为单位配置，而不是以微秒为单位配置，以便成功计算延迟值。
* 将数据存储添加到 vCenter Server 时，您可以使用主机的 IP 地址或完全限定域名（FQDN）。如果要添加 FQDN，请确保 Unified Manager 服务器可以解析该域名。例如，对于 Linux 安装，请确保在 `/etc/resolv.conf` 文件中添加了域名。
* vCenter 服务器的当前时间与 vCenter 服务器时区同步。
* vCenter Server 可访问，以便成功发现。
* 将 vCenter Server 添加到 Unified Manager 时，您具有对 VMware SDK 的读取权限。这是配置轮询所必需的。


对于添加和发现的每个 vCenter 服务器，Unified Manager 都会收集配置数据，例如 vCenter 服务器和 ESXi 服务器详细信息、ONTAP 映射、数据存储区详细信息以及托管的 VM 数量。它还收集组件的性能指标。

.步骤
. 转到 *VMWARE* > *vCenter*，检查您的 vCenter Server 是否在列表中可用。
+
[NOTE]
====
如果您的 vCenter 服务器不可用，则必须添加 vCenter 服务器。

====
+
.. 单击 *Add*。
.. 为 vCenter Server 添加正确的 IP 地址，并确保设备可访问。
.. 添加对 vCenter Server 具有只读访问权限的管理员或 root 用户的用户名和密码。
.. 如果您使用默认 443 以外的任何端口，请添加自定义端口号。
.. 单击 *Save*。
+
成功发现后，系统将显示一个服务器证书，您可以接受此证书。

+
接受证书时，vCenter 服务器将添加到可用 vCenter 服务器列表中。添加设备不会导致对关联的虚拟机进行数据收集，收集将在计划的时间间隔进行。



. 如果您的 vCenter Server 在 *vCenters* 页面上可用，请将鼠标悬停在 *状态* 字段上以检查其状态，从而显示您的 vCenter Server 是否按预期运行，或者是否存在警告或错误。
+
[NOTE]
====
添加 vCenter Server 可让您查看以下状态。但是，在添加 vCenter Server 后，相应虚拟机的性能和延迟数据可能需要长达一小时才能准确反映。

====
+
** 绿色：“正常”，表示已发现 vCenter 服务器，已成功收集性能指标
** 黄色：“警告”（例如，当 vCenter 服务器的统计级别未设置为 3 或更高以获取每个对象的统计信息时）
** 橙色：“错误”（表示任何内部错误，例如异常、配置数据收集失败或无法访问 vCenter 服务器）您可以单击列显示图标（*显示/隐藏*）以查看 vCenter 服务器状态的状态消息并排除故障。


. 如果无法访问 vCenter 服务器或凭据已更改，请通过选择 *vCenter* > *编辑* 来编辑 vCenter 服务器详细信息。
. 在*编辑 VMware vCenter 服务器*页面上进行必要的更改。
. 单击 *Save*。


*vCenter Server 数据收集开始*

vCenter Server 收集实时的 20 秒性能数据样本，并将其汇总为 5 分钟样本。Unified Manager 的性能数据收集计划基于 vCenter Server 的默认设置。Unified Manager 处理从 vCenter Server 获取的 5 分钟样本，并计算虚拟磁盘、虚拟机和主机的 IOPS 和延迟的每小时平均值。对于数据存储，Unified Manager 根据从 ONTAP 获取的样本计算 IOPS 和延迟的每小时平均值。这些值在整点时可用。添加 vCenter Server 后，性能指标不会立即可用，只有在下一个小时开始时才可用。在完成一个配置数据收集周期后，性能数据轮询即会开始。

对于轮询 vCenter Server 配置数据，Unified Manager 遵循与收集集群配置数据相同的计划。有关 vCenter Server 配置和性能数据收集计划的信息，请参见“集群配置和性能数据收集活动”。
