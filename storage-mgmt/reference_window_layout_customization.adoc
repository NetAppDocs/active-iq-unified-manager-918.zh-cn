= 在 Active IQ Unified Manager 中自定义窗口布局
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager 允许您自定义存储和网络对象页面上的信息布局。通过自定义窗口，您可以控制可查看的数据以及数据的显示方式。

* *排序*
+
您可以单击列标题来更改列条目的排序顺序。当您单击列标题时，该列将显示排序箭头（image:../media/sort_asc_um60.gif["列排序图标 – 升序"] 和 image:../media/sort_desc_um60.gif["列排序图标 – 降序"]）。

* *筛选*
+
您可以单击筛选器图标（image:../media/filtering_icon.gif[""]）应用筛选器来自定义存储和网络对象页面上的信息显示，以便仅显示与所提供的条件匹配的条目。您可以在“筛选器”窗格中应用筛选器。

+
通过“筛选器”窗格，您可以根据所选选项筛选大多数列。例如，在“运行状况：所有卷”视图中，您可以使用“筛选器”窗格，通过在“状态”下选择相应的筛选选项来显示所有离线卷。

+
任何列表中与容量相关的列始终以适当的单位显示容量数据，并四舍五入到小数点后两位。这也适用于过滤容量列。例如，如果使用“运行状况：所有聚合”视图中“总数据容量”列中的筛选器来筛选大于 20.45 GB 的数据，则 20.454 GB 的实际容量将显示为 20.45 GB。同样，如果过滤的数据小于 20.45 GB，则 20.449 GB 的实际容量将显示为 20.45 GB。

+
如果使用“运行状况：所有聚合”视图中“可用数据 %”列中的筛选器来筛选大于 20.45% 的数据，则 20.454% 的实际容量将显示为 20.45%。同样，如果筛选小于 20.45% 的数据，则 20.449% 的实际容量将显示为 20.45%。

* *隐藏或显示列*
+
您可以单击列显示图标（*显示/隐藏*）来选择要显示的列。选择合适的列后，您可以使用鼠标拖动它们来重新排序。

* *搜索*
+
您可以使用搜索框搜索某些对象属性，以帮助细化清单页面中的项目列表。例如，您可以输入 "cloud" 来细化卷清单页面中的卷列表，以查看其中包含单词 "cloud" 的所有卷。

* *导出数据*
+
您可以单击*报告*按钮（或*导出*按钮将数据导出为逗号分隔值 `(.csv)`文件、 `(.pdf)`文档或 Microsoft Excel `(.xlsx)`文件，并使用导出的数据构建报告。
