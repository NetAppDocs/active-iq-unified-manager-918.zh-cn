= 在 Active IQ Unified Manager 中编辑用户和组配额电子邮件地址
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以根据与集群、存储虚拟机（SVM）、卷、qtree、用户或用户组关联的用户配额修改电子邮件地址。当您想要覆盖在“生成用户和组配额电子邮件地址的规则”对话框中指定的规则所生成的电子邮件地址时，可以修改电子邮件地址。

.开始之前
* 您必须具有操作员、应用程序管理员或存储管理员角色。
* 您必须已阅读 link:reference_rules_to_generate_user_and_group_quota.html["创建规则的准则"]。


如果编辑电子邮件地址，则生成用户和组配额电子邮件地址的规则不再适用于配额。要将通知发送到由指定规则生成的电子邮件地址，必须删除该电子邮件地址并保存更改。

.步骤
. 在左侧导航窗格中，单击*存储* > *SVMs*。
. 在 *Health: All Storage VMs* 视图中，选择一个 SVM，然后单击 *User and Group Quotas* 选项卡。
. 单击选项卡行下方的*编辑电子邮件地址*。
. 在*编辑电子邮件地址*对话框中，执行相应的操作：
+
|===
| 条件 | 操作 


 a| 
您希望将通知发送到指定规则生成的电子邮件地址
 a| 
.. 删除*电子邮件地址*字段中的电子邮件地址。
.. 单击 *Save*。
.. 按 F5 刷新浏览器以重新加载“编辑电子邮件地址”对话框。由指定规则生成的电子邮件地址显示在 *电子邮件地址* 字段中。




 a| 
您希望将通知发送到指定的电子邮件地址
 a| 
.. 修改*电子邮件地址*字段中的电子邮件地址。
.. 点击*保存*。生成用户和组配额电子邮件地址的规则不再适用于配额。


|===
