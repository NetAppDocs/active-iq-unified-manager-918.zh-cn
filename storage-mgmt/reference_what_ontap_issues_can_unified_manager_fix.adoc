= 了解 Active IQ Unified Manager 可以解决的 ONTAP 问题
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
通过使用 Active IQ Unified Manager 的自动修复功能，您可以选择通过 Unified Manager 有效解决某些 ONTAP 问题或管理某些 ONTAP 功能，例如反勒索软件监控。

此表介绍了这些 ONTAP 问题或功能，您可以直接通过 Unified Manager Web UI 上的 *Fix It* 或 *Fix All* 按钮进行管理。

|===
| 事件名称和描述 | 管理操作 | “修复”操作 


 a| 
卷空间全满

卷空间即将用尽，并且已超出容量全满阈值。此阈值默认设置为卷大小的 90%。
 a| 
启用卷自动增长
 a| 
Unified Manager 确定此卷未配置卷自动增长功能，因此启用此功能，以便卷在需要时能够扩展容量。



 a| 
索引节点全满

此卷已用完 inode，无法接受任何新文件。
 a| 
增加卷上的 inode 数量
 a| 
将卷上的 inode 数量增加 2%。



 a| 
检测到存储层策略不匹配

卷中有大量非活动数据，当前分层策略设置为“仅快照”或“无”。
 a| 
启用自动云分层
 a| 
由于卷已驻留在 FabricPool 上，因此它将分层策略更改为“auto”，以便将非活动数据移动到成本较低的云层。



 a| 
检测到存储层不匹配

该卷有大量非活动数据，但它不驻留在启用云的存储层（FabricPool）上。
 a| 
更改卷的存储层
 a| 
将卷移动到启用了云的存储层，并将分层策略设置为“auto”，以将非活动数据移动到云层。



 a| 
已禁用审核日志

存储 VM 未启用审核日志
 a| 
为 Storage VM 启用审核日志记录
 a| 
在 Storage VM 上启用审核日志记录。

请注意，存储虚拟机必须已配置本地或远程审核日志位置。



 a| 
已禁用登录横幅

应启用集群的登录横幅，通过明确说明访问限制来提高安全性。
 a| 
为集群设置登录横幅
 a| 
将集群登录横幅设置为“`Access restricted to authorized users`”。



 a| 
已禁用登录横幅

应启用 storage VM 的登录横幅，以通过明确说明访问限制来提高安全性。
 a| 
为存储虚拟机设置登录横幅
 a| 
将 storage VM 登录横幅设置为“仅限授权用户访问”。



 a| 
SSH 正在使用不安全密码

后缀为“-cbc”的密码被认为是不安全的。
 a| 
从集群中删除不安全的密码
 a| 
从集群中删除不安全的密码（如 aes192-cbc 和 aes128-cbc）。



 a| 
SSH 正在使用不安全密码

后缀为“-cbc”的密码被认为是不安全的。
 a| 
从存储虚拟机中删除不安全的密码
 a| 
从存储 VM 中删除不安全的密码套件——例如 aes192-cbc 和 aes128-cbc。



 a| 
已禁用 AutoSupport HTTPS 传输

用于向技术支持发送 AutoSupport 消息的传输协议应加密。
 a| 
将 HTTPS 设置为 AutoSupport 消息的传输协议
 a| 
将 HTTPS 设置为集群上 AutoSupport 消息的传输协议。



 a| 
已超过集群负载不平衡阈值

表示集群中各节点之间的负载不均衡。当节点之间已用性能容量的差异超过 30% 时，将生成此事件。
 a| 
平衡集群工作负载
 a| 
Unified Manager 确定从一个节点移动到另一个节点的最佳卷以缓解不平衡状况，然后移动该卷。



 a| 
已超过集群容量不平衡阈值

指示此集群中的聚合之间的容量不平衡。此事件在聚合之间的已用容量差异超过 70% 时生成。
 a| 
平衡集群容量
 a| 
Unified Manager 确定从一个聚合移动到另一个聚合的最佳卷，以缓解不平衡状况，然后移动卷。



 a| 
已违反性能已用容量阈值

表示如果不降低一个或多个高活动工作负载的利用率，节点上的负载可能会被过度利用。当节点性能容量已用值超过 100% 且持续超过 12 小时时，将生成此事件。
 a| 
限制节点上的高负载
 a| 
Unified Manager 识别具有最高 IOPS 的卷，并使用历史预期和峰值 IOPS 级别应用 QoS 策略，以减少节点上的负载。



 a| 
已违反动态事件警告阈值

表示由于某些工作负载的负载异常高，节点已处于过载状态。
 a| 
减少节点中的过载
 a| 
Unified Manager 识别具有最高 IOPS 的卷，并使用历史预期和峰值 IOPS 级别应用 QoS 策略，以减少节点上的负载。



 a| 
无法接管

当前已禁用故障转移，因此在发生中断或重新启动期间可能无法访问节点的资源，直到节点恢复可用为止。
 a| 
启用节点故障转移
 a| 
Unified Manager 发送适当的命令以在集群中的所有节点上启用故障转移。



 a| 
选项 Cf.takeover.on_panic 已配置为关闭

nodeshell 选项 "cf.takeover.on_panic" 设置为 *off*，这可能会导致 HA 配置的系统出现问题。
 a| 
在系统崩溃时启用接管
 a| 
Unified Manager 向集群发送相应的命令，以将此设置更改为 *on*。



 a| 
禁用 nodeshell 选项 snapmirror.enable

旧的 nodeshell 选项“snapmirror.enable”设置为 *on*，这可能会在升级到 ONTAP 9.3 或更高版本后导致启动过程中出现问题。
 a| 
将 snapmirror.enable 选项设置为 off
 a| 
Unified Manager 向集群发送相应的命令，以将此设置更改为*关闭*。



 a| 
已启用 Telnet

表示可能存在安全问题，因为 Telnet 不安全并以未加密的方式传递数据。
 a| 
禁用 Telnet
 a| 
Unified Manager 向集群发送相应的命令以禁用 Telnet。



 a| 
配置 storage VM 反勒索软件学习

定期检查具有反勒索软件监控许可证的集群。验证存储虚拟机是否仅支持此类集群中的 NFS 或 SMB 卷。
 a| 
将 Storage VM 置于反勒索软件监控 `learning`模式
 a| 
Unified Manager 通过集群管理控制台将存储虚拟机的反勒索软件监控设置为 `learning`状态。在存储虚拟机上创建的所有新卷上的反勒索软件监控将自动移至学习模式。通过此功能，ONTAP 可以了解卷上的活动模式，并检测由于潜在的恶意攻击而导致的异常。



 a| 
配置卷反勒索软件学习

定期检查具有反勒索软件监控许可证的集群。验证卷在此类集群中是否仅支持 NFS 或 SMB 服务。
 a| 
将卷设置为反勒索软件监控 `learning`模式
 a| 
Unified Manager 通过集群管理控制台将这些卷的反勒索软件监控设置为 `learning`状态。通过此功能，ONTAP 可以了解卷上的活动模式，并检测由于潜在恶意攻击而导致的异常。



 a| 
启用卷反勒索软件

定期检查具有反勒索软件监控许可证的群集。检测卷是否处于反勒索软件监控的 `learning`模式超过 45 天，并确定将其置于活动模式的可能性。
 a| 
将卷设置为反勒索软件监控 `active`模式
 a| 
Unified Manager 通过集群管理控制台将卷上的反勒索软件监控设置为 `active`。通过此功能，ONTAP 可以了解卷上的活动模式，检测由于潜在恶意攻击而导致的异常，并为数据保护操作创建警报。



 a| 
禁用卷反勒索软件

定期检查具有反勒索软件监控许可证的集群。在对卷进行主动反勒索软件监控期间检测重复通知（例如，在 30 天内返回有关潜在勒索软件攻击的多个警告）。
 a| 
禁用卷上的反勒索软件监控
 a| 
Unified Manager 通过集群管理控制台禁用对卷的反勒索软件监控。

|===
