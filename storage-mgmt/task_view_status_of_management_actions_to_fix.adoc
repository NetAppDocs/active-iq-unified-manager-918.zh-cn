= 查看要在 Active IQ Unified Manager 中修复的管理操作状态
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在“管理操作”页面中查看您选择修复的所有管理操作的状态。在 Unified Manager 向集群发送 ONTAP 命令后，大多数操作都会很快显示为*已完成*。但是，某些操作（例如移动卷）可能需要更长时间。

“管理操作”页面上有三个可用的筛选器：

* *已完成*显示成功完成的管理操作和失败的管理操作。*失败*的操作提供了失败的原因，以便您可以手动解决问题。
* *进行中*既显示正在实施的管理行动，也显示计划实施的管理行动。
* *推荐*显示当前对所有受监控集群处于活动状态的所有管理操作。


.步骤
. 单击左侧导航窗格中的*管理操作*。或者，单击*仪表板*上*管理操作*面板顶部的 image:../media/more_icon.gif["更多图标"]，然后选择要查看的视图。
+
此时将显示管理操作页面。

. 您可以单击*描述*字段中管理操作旁边的插入符号图标，查看有关问题的详细信息以及用于解决问题的命令。
. 要查看任何*失败*的操作，请对*已完成*视图中的*状态*列进行排序。您可以使用*筛选器*工具来实现相同目的。
. 如果要查看有关失败的管理操作的更多信息，或者如果决定要修复建议的管理操作，则可以在单击管理操作旁边的插入符号图标后，单击展开区域中的*查看事件详细信息*。该页面上提供了一个*修复它*按钮。
