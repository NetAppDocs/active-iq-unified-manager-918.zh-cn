= 在 Active IQ Unified Manager 中创建和编辑存储效率策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当系统定义的存储效率策略与您的工作负载要求不匹配时，您可以创建针对您的工作负载进行优化的自己的存储效率策略。

.开始之前
* 您必须具有应用程序管理员角色。
* 存储效率策略名称必须是唯一的，并且不能使用以下保留关键字：
+
`High`、 `Low`、 `Unassigned`、 `Learning`、 `Idle`、 `Default` 和 `None`。



通过定义将访问存储的应用程序所需的存储效率特性，可以从存储效率策略页面创建和编辑自定义存储效率策略。

[NOTE]
====
如果当前已将存储效率策略分配给工作负载，则无法对其进行修改。

====
.步骤
. 在左侧导航窗格的 *设置* 下，选择 *策略* > *存储效率*。
. 在*存储效率策略*页面中，根据您是要创建新的存储效率策略还是编辑现有存储效率策略，单击相应的按钮。
+
|===
| 目的 | 按照下面的步骤进行操作...... 


 a| 
创建新的存储效率策略
 a| 
点击*添加*



 a| 
编辑现有存储效率策略
 a| 
选择现有存储效率策略并单击*编辑*

|===
+
此时将显示添加或编辑存储效率策略的页面。

. 通过指定存储效率特性自定义存储效率策略，然后单击*提交*以保存存储效率策略。


您可以从工作负载页面或在调配新工作负载时将新的或更改的存储效率策略应用于工作负载（LUN、NFS 文件共享、CIFS 共享）。
