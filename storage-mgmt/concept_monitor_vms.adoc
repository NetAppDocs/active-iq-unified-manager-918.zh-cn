= 了解 Active IQ Unified Manager 如何监控虚拟机
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
对于虚拟机 (VM) 应用程序上的任何延迟问题，您可能需要监控 VM 以分析和排除原因。当其 vCenter Server 和托管 VM 存储的 ONTAP 集群添加到 Unified Manager 时，VM 即可用。

您可以在 *VMWARE* > > *虚拟机* 页面上查看虚拟机的详细信息。将显示可用性、状态、已用和已分配容量、网络延迟，以及虚拟机、数据存储和主机的 IOPS 和延迟等信息。对于支持多个数据存储的虚拟机，网格会显示延迟最差的数据存储的指标，并使用星号图标（*）表示其他数据存储。如果单击该图标，则会显示其他数据存储的指标。其中一些列不可用于排序和筛选。

[NOTE]
====
要查看虚拟机及其详细信息，必须完成 ONTAP 集群的发现（轮询或指标收集）。如果从 Unified Manager 中删除此集群，则在下一个发现周期之后，此虚拟机将不再可用。

====
在此页面中，您还可以查看虚拟机的详细拓扑，显示与虚拟机相关的组件，例如与其连接的主机、虚拟磁盘和数据存储。拓扑视图按以下顺序显示其特定层中的底层组件：*虚拟磁盘* > *虚拟机* > *主机* > *网络* > *数据存储* > *VMDK*。

您可以从拓扑的角度确定 I/O 路径和组件级别延迟问题，并确定此性能问题是否是由于存储而造成的。此拓扑的摘要视图会显示此 I/O 路径，并突出显示存在 IOPS 和延迟问题的组件，以便于您确定故障排除步骤。此外，您还可以通过扩展拓扑视图单独查看各个组件以及此组件的延迟。您可以选择一个组件来确定经过各个层的 I/O 路径。



[[view-summary-topology]]
== 查看摘要拓扑

要通过在摘要拓扑中查看 VM 来确定性能问题，请执行以下操作：

. 转至 *VMWARE* > *Virtual Machines*。
. 在搜索框中输入虚拟机名称以搜索您的虚拟机。您也可以通过单击 *Filter* 按钮，根据特定条件筛选搜索结果。但是，如果找不到您的虚拟机，请确保已添加并发现相应的 vCenter Server。
+
[NOTE]
====
vCenter Server 允许在 vSphere 实体（例如 VM、集群、数据存储、文件夹或文件）的名称中使用特殊字符（例如 %、&、*、$、#、@、!、\、/、:、*、?、"、`、<, >、|、;、'）。VMware vCenter Server 和 ESX/ESXi Server 不会转义显示名称中使用的特殊字符。但是，在 Unified Manager 中处理该名称时，其显示方式会有所不同。例如，在 vCenter Server 中名为  `%$VC_AIQUM_clone_191124%` 的 VM 在 Unified Manager 中将显示为  `%25$VC_AIQUM_clone_191124%25`。在查询名称中包含特殊字符的 VM 时，必须注意此问题。

====
. 检查 VM 的状态。VM 状态是从 vCenter Server 检索的。以下状态可用。有关这些状态的详细信息，请参见 VMware 文档。
+
** 正常
** 警告
** 警报
** 未监控
** 未知


. 单击此虚拟机旁边的向下箭头以查看计算层、网络层和存储层中组件的拓扑摘要视图。存在延迟问题的节点会突出显示。摘要视图会显示延迟状况最差的组件。例如，如果一个虚拟机包含多个虚拟磁盘，则此视图将显示所有虚拟磁盘中延迟状况最差的虚拟磁盘。
. 要分析数据存储在一段时间内的延迟和吞吐量，请单击数据存储对象图标顶部的 *Workload Analyzer* 按钮。您将转到“工作负载分析”页面，您可以在其中选择时间范围并查看数据存储的性能图表。有关工作负载分析器的详细信息，请参见_使用工作负载分析器对工作负载进行故障排除_。

== 查看展开的拓扑

您可以通过查看虚拟机的扩展拓扑来单独查看每个组件的详细信息。

.步骤
. 在摘要拓扑视图中，单击 *展开拓扑*。您可以单独查看每个组件的详细拓扑以及每个对象的延迟数值。如果一个类别中有多个节点，例如数据存储或 VMDK 中的多个节点，则延迟最差的节点将以红色突出显示。
. 要检查特定对象的 IO 路径，请单击此对象以查看此 IO 路径以及相应的映射。例如，要查看某个虚拟磁盘的映射，请单击此虚拟磁盘以查看它与相应 VMDK 的映射，此映射会突出显示。如果这些组件存在性能滞后，您可以从 ONTAP 收集更多数据并对此问题进行故障排除。
+
[NOTE]
====
不会报告 VMDK 的指标。在此拓扑中，只会显示 VMDK 名称，而不会显示相应指标。

====
