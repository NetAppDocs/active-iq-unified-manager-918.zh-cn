= 了解 Active IQ Unified Manager 中的电子邮件通知格式页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
电子邮件通知格式页面显示当存在配额相关问题（超出软限制或达到硬限制）时发送给用户或用户组的电子邮件的规则。

仅当生成以下用户或用户组配额事件时，才会发送电子邮件通知：已超出用户或组配额磁盘空间软限制、已超出用户或组配额文件数软限制、已达到用户或组配额磁盘空间硬限制，或已达到用户或组配额文件数硬限制。

* *发件人*
+
显示发送电子邮件的电子邮件地址，您可以对其进行修改。默认情况下，这是在“通知”页面上指定的电子邮件地址。

* *主题*
+
显示通知电子邮件的主题。

* *电子邮件详细信息*
+
显示通知电子邮件的文本。您可以根据需要修改文本。例如，您可以提供与配额属性相关的信息，并减少关键字数量。但是，您不应修改关键字。

+
有效的关键字如下：

+
** $EVENT_NAME
+
指定导致电子邮件通知的事件名称。

** $QUOTA_TARGET
+
指定适用此配额的 qtree 或卷。

** $QUOTA_USED_PERCENT
+
指定用户或用户组使用的磁盘硬限制、磁盘软限制、文件硬限制或文件软限制的百分比。

** $QUOTA_LIMIT
+
指定用户或用户组达到的磁盘硬限制或文件硬限制，并生成以下事件之一：

+
*** 已达到用户或组配额磁盘空间硬限制
*** 已达到用户或组配额磁盘空间软限制
*** 已达到用户或组配额文件数硬限制
*** 已达到用户或组配额文件数软限制


** $QUOTA_USED
+
指定用户或用户组使用的磁盘空间或创建的文件数。

** $QUOTA_USER
+
指定用户或用户组名称。







[[command-buttons]]
== 命令按钮

命令按钮可用于预览、保存或取消对电子邮件通知格式所做的更改：

* *预览*
+
显示通知电子邮件的预览。

* *还原为出厂默认值*
+
使您能够将通知格式还原为出厂默认值。

* *保存*
+
保存对通知格式所做的更改。
