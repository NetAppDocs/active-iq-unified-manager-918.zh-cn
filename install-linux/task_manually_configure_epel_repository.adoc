= 为 Active IQ Unified Manager 配置 EPEL 存储库
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果要安装 Unified Manager 的系统无权访问 Extra Packages for Enterprise Linux (EPEL) 存储库，则必须手动下载并配置该存储库以成功安装。

EPEL 存储库提供对必须安装在系统上的所需第三方实用程序的访问权限。您可以使用 EPEL 存储库在 Red Hat Enterprise Linux 系统上安装 Unified Manager。

.步骤
. 下载适用于您安装环境的 EPEL 存储库。对于版本 8，请从以下位置下载：
+
`+wget https://dl.fedoraproject.org/pub/epel/epel-release-latest-8.noarch.rpm+`

+
对于版本 9，请从以下位置下载：

+
`wget https://dl.fedoraproject.org/pub/epel/epel-release-latest-9.noarch.rpm`

. 配置 EPEL 存储库：
+
`yum install epel-release-latest-<version>.noarch.rpm`



对于 Red Hat Enterprise Linux 8 系统，如果您有包含模块化 RPM 软件包的内部存储库，例如 `_javapackages-filesystem-<version>.module.rpm_`，请确保模块化软件包的元数据在同一存储库中也可用。
