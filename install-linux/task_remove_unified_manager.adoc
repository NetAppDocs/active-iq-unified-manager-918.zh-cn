= 删除 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
可以使用单个命令从 Red Hat Enterprise Linux 主机停止和卸载 Unified Manager。

.开始之前
* 您必须具有要从中删除 Unified Manager 的服务器的 root 用户访问权限。
* 必须在 Linux 系统上禁用安全增强型 Linux (SELinux)。使用  `setenforce 0` 命令将 SELinux 运行时模式更改为“`Permissive`”。
* 在删除软件之前，必须从 Unified Manager 服务器中删除所有集群（数据源）。
* 您应该手动删除为允许或阻止 MySQL 端口 3306 而创建的防火墙规则。防火墙规则不会自动删除。


.步骤
. 以 root 用户身份登录到要删除 Unified Manager 的服务器。
. 停止并从服务器中删除 Unified Manager：
+
`rpm -e netapp-um`

+
此步骤删除所有关联的 NetApp RPM 包。它不删除必备软件模块，例如 Java、MySQL 和 7zip。

. *可选：*如果适用，请删除支持的软件模块，例如 Java、MySQL 和 7zip：
+
`rpm -e mysql-community-client mysql-community-server mysql-community-common mysql-community-libs java-x.y`



此操作完成后，将删除软件。卸载后， `/opt/netapp/data`目录中的所有数据都会移动到 `/opt/netapp/data/BACKUP`文件夹中。卸载 Unified Manager 也会删除 Java 和 MySQL 软件包，除非系统上的任何其他应用程序需要并使用这些软件包。但是，MySQL 数据不会被删除。
