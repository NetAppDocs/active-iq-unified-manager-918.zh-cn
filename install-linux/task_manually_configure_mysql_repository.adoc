= 配置 Active IQ Unified Manager 的 MySQL 存储库
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果要安装 Unified Manager 的系统无权访问 MySQL Community Edition 存储库，则必须手动下载并配置存储库以成功安装。

MySQL 存储库提供对必须安装在系统上的所需 MySQL 软件的访问权限。

[NOTE]
====
如果系统没有互联网连接，此任务可能会失败。如果要安装 Unified Manager 的系统没有互联网访问权限，请参阅 MySQL 文档。

====
.步骤
. 为您的安装下载适当的 MySQL 存储库。对于版本 8，请从以下位置下载：
+
`wget http://repo.mysql.com/yum/mysql-8.4-community/el/8/x86_64/mysql84-community-release-el8-1.noarch.rpm`

+
对于版本 9，请从以下位置下载：

+
`wget http://repo.mysql.com/yum/mysql-8.4-community/el/9/x86_64/mysql84-community-release-el9-1.noarch.rpm`

. 配置 MySQL 存储库：
+
`yum install mysql84-community-release-.noarch.rpm`



对于 Red Hat Enterprise Linux 8 系统，如果您有包含 java-17-openjdk、7-zip 以及由 AppStream 存储库提供的其他软件包的内部存储库，则必须禁用您的 AppStream 存储库并安装 MySQL Community Server。运行以下命令：

[listing]
----
# sudo yum --disablerepo=rhel-8-for-x86_64-appstream-rpms install  mysql-community-server
----
如果您收到缺少密钥或密钥不匹配的错误，并且安装失败，请尝试以下步骤：

* 在连接的系统上，通过运行以下命令导入更新的 MySQL 密钥：


[listing]
----
rpm --import https://repo.mysql.com/RPM-GPG-KEY-mysql-<xxxx>

for example:

rpm --import https://repo.mysql.com/RPM-GPG-KEY-mysql-2023
----
* 在没有互联网连接的系统上，更新您的 MySQL repo 文件并通过标记 `gpgcheck=0`来禁用 `gpgcheck`。
