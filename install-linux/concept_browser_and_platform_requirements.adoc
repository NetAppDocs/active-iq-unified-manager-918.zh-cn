= 请使用支持的浏览器访问 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要访问 Unified Manager Web UI，请使用受支持的浏览器。

互操作性矩阵包含支持的浏览器版本列表。

http://mysupport.netapp.com/matrix["mysupport.netapp.com/cn/matrix"]

对于所有浏览器，禁用弹出窗口拦截器可确保正确显示软件功能。

如果您计划为 SAML 身份验证配置 Unified Manager，以便身份提供程序（IdP）可以对用户进行身份验证，则还应检查 IdP 支持的浏览器列表。
