= 升级 Linux 上的 OpenJDK for Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在安装了 Unified Manager 的 Linux 服务器上升级到较新版本的 OpenJDK，以获取安全漏洞修复程序。

.开始之前
您必须拥有安装了 Unified Manager 的 Linux 系统的 root 权限。

您可以在发行系列内更新 OpenJDK 发行版。例如，您可以从 OpenJDK 11.0.14 升级到 OpenJDK 11.0.17，但不能直接从 OpenJDK 11 更新到 OpenJDK 12。

.步骤
. 以 root 用户身份登录到 Unified Manager 主机。
. 将相应版本的 OpenJDK（64 位）下载到目标系统。
. 停止 Unified Manager 服务：
+
`systemctl stop ocieau`

+
`systemctl stop ocie`

. 在系统上安装最新的 OpenJDK。
. 启动 Unified Manager 服务：
+
`systemctl start ocie`

+
`systemctl start ocieau`
