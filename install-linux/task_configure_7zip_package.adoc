= 在 Active IQ Unified Manager 中配置 7-zip 软件包
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要在 Red Hat Enterprise Linux 系统上成功安装 Unified Manager，您的系统必须设置为具有 7-zip 软件包的访问权限。如果网络访问可用并且 7-zip URL 未被防火墙阻止，则在安装或升级过程中，7-zip 会自动下载到您的系统。NetApp 建议使用自动下载方法。

确保在防火墙中取消阻止以下 URL，以允许 Unified Manager 自动下载 7-zip 软件包：
`https://7-zip.org/a/7z2301-linux-x64.tar.xz`

或者，您可以预安装 7-zip。



[[pre-install-the-7-zip-package]]
== 预先安装 7-zip 软件包

您可以通过手动下载或使用捆绑脚本预安装 7-zip。从以下两种方法中选择一种：



[[download-using-a-bundled-script]]
=== 使用捆绑脚本下载

.步骤
. 运行 Unified Manager zip 文件中包含的 `install7zip.sh`脚本。




[[download-manually]]
=== 手动下载

请确保您仅从官方网站下载 7-zip 压缩包。

.步骤
. 从官方网站下载 7-zip 包（版本 23.01）：
+
`https://7-zip.org/a/7z2301-linux-x64.tar.xz`

. 将文件复制到您的 RHEL 虚拟机：
+
[source, CLI]
----
7z2301-linux-x64.tar.xz
----
. 解压归档文件：
+
[source, CLI]
----
sudo tar -xf 7z2301-linux-x64.tar.xz
----
. 将 `7zz`文件移动到 `/usr/bin/`目录：
+
[source, CLI]
----
sudo cp 7zz /usr/bin/
----
. 设置可执行权限：
+
[source, CLI]
----
sudo chmod 755 /usr/bin/7zz
----




[[verify-the-installation]]
== 验证安装

验证您的系统是否已成功安装 7-zip 软件包：

[source, CLI]
----
7zz -version
----
