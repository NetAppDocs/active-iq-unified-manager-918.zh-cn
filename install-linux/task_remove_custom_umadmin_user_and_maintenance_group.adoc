= 删除 Active IQ Unified Manager 的自定义 umadmin 用户和 maintenance 组
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果在安装 Unified Manager 之前创建了自定义主目录以定义自己的 umadmin 用户和维护帐户，则应在卸载 Unified Manager 后删除这些项目。

标准的 Unified Manager 卸载不会删除自定义的 umadmin 用户和维护帐户。您必须手动删除这些项目。

.步骤
. 以 root 用户身份登录到 Red Hat Enterprise Linux 服务器。
. 删除 umadmin 用户：
+
`userdel umadmin`

. 删除维护组：
+
`groupdel maintenance`
