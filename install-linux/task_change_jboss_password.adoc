= 在 Active IQ Unified Manager 中更改 JBoss 密码
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以重置在安装过程中设置的特定于实例的 JBoss 密码。如果您的站点需要此安全功能来覆盖 Unified Manager 安装设置，您可以选择重置密码。此操作还会更改 JBoss 用于访问 MySQL 的密码。

* 您必须具有对安装了 Unified Manager 的 Red Hat Enterprise Linux 系统的 root 用户访问权限。
* 您必须能够访问目录 `/opt/netapp/essentials/bin`中由 NetApp 提供的 `password.sh`脚本。


.步骤
. 以 root 用户登录系统。
. 按所示顺序输入以下命令，停止 Unified Manager 服务：
+
`systemctl stop ocieau`

+
`systemctl stop ocie`

+
请勿停止关联的 MySQL 软件。

. 输入以下命令以开始密码更改过程：
+
`/opt/netapp/essentials/bin/password.sh resetJBossPassword`

. 出现提示时，请输入新的 JBoss 密码，然后再次输入以确认。
+
请注意，密码应介于 8 到 16 个字符之间，必须至少包含一个数字、一个大写字母和一个小写字母，并且必须至少包含以下特殊字符之一：

+
`+!@%^*-_+=[]:<>.?/~+`

. 脚本完成后，按所示顺序输入以下命令，以启动 Unified Manager 服务：
+
`systemctl start ocie`

+
`systemctl start ocieau`

. 所有服务启动后，您可以登录到 Unified Manager UI。
