= 在 Active IQ Unified Manager 中向 VMware 虚拟机上的数据磁盘添加空间
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果需要增加 Unified Manager 数据库的数据磁盘上的空间量，可以在安装后通过使用 Unified Manager 维护控制台增加磁盘空间来添加容量。

.开始之前
* 您必须能够访问 vSphere 客户端。
* 虚拟机必须没有本地存储的快照。
* 您必须具有维护用户凭据。


建议您在增加虚拟磁盘大小之前备份虚拟机。

.步骤
. 在 vSphere 客户端中，选择 Unified Manager 虚拟机，然后向数据 `disk 3`添加更多磁盘容量。有关详细信息，请参阅 VMware 文档。
+
在某些罕见情况下，Unified Manager 部署使用 "`Hard Disk 2`" 作为数据磁盘，而不是 "`Hard Disk 3`"。如果在您的部署中发生此情况，请增加较大磁盘的空间。数据磁盘的空间将始终大于另一个磁盘。

. 在 vSphere 客户端中，选择 Unified Manager 虚拟机，然后选择*控制台*选项卡。
. 在控制台窗口中单击，然后使用您的用户名和密码登录到维护控制台。
. 在主菜单中，输入*系统配置*选项的编号。
. 在系统配置菜单中，输入*增加数据磁盘大小*选项的数字。
