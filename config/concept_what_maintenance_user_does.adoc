= 了解 Active IQ Unified Manager 中的维护用户
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
维护用户是在 Red Hat Enterprise Linux 系统上安装 Unified Manager 期间创建的。维护用户名为“`umadmin`”用户。维护用户在 Web UI 中具有应用程序管理员角色，并且该用户可以创建后续用户并为其分配角色。

维护用户（即 umadmin 用户）也可以访问 Unified Manager 维护控制台。
