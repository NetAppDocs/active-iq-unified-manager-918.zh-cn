= 向 Active IQ Unified Manager 添加集群
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以将集群添加到 Active IQ Unified Manager 以便可以监视该集群。这包括能够获取集群信息，例如集群的运行状况、容量、性能和配置，以便您可以查找并解决可能发生的任何问题。

.开始之前
* 您必须具有应用程序管理员或存储管理员角色。
* 您必须具有下列信息：
+
** Unified Manager 支持本地 ONTAP 集群、ONTAP Select、Cloud Volumes ONTAP。
** 主机名或集群管理 IP 地址
+
主机名是 FQDN 或 Unified Manager 用来连接集群的简称。主机名必须解析为集群管理 IP 地址。

+
集群管理 IP 地址必须是管理存储虚拟机（SVM）的集群管理 LIF。如果使用节点管理 LIF，则操作会失败。

** 此集群必须运行 ONTAP 9.1 或更高版本的软件。
** ONTAP 管理员用户名和密码
+
此帐户必须具有 _admin_ 角色，应用程序访问权限设置为 _ontapi_、_amqp_、_console_ 和 _http_。

** 使用 HTTPS 协议连接到集群的端口号（通常为端口 443）
** 您拥有所需的证书：
+
*SSL (HTTPS) 证书*：此证书由 Unified Manager 拥有。全新安装 Unified Manager 时，会生成默认的自签名 SSL (HTTPS) 证书。NetApp 建议将其升级为 CA 签名证书，以获得更好的安全性。如果服务器证书过期，您应重新生成该证书并重新启动 Unified Manager，以便服务采用新证书。有关重新生成 SSL 证书的详细信息，请参见 link:../config/task_generate_an_https_security_certificate_ocf.html["生成 HTTPS 安全证书"]。

+
*EMS 证书*：此证书归 Unified Manager 所有。它在对从 ONTAP 接收的 EMS 通知进行身份验证时使用。

+
*双向 TLS 通信证书*：在 Unified Manager 和 ONTAP 之间的双向 TLS 通信期间使用。系统会根据 ONTAP 版本为集群启用基于证书的身份验证。如果集群运行的 ONTAP 版本低于 9.5，则不会启用基于证书的身份验证。

+
如果您要更新早期版本的 Unified Manager，则不会为集群自动启用基于证书的身份验证。但是，您可以通过修改并保存集群详细信息来启用它。如果证书过期，您应重新生成证书以整合新证书。有关查看和重新生成证书的详细信息，请参见link:../storage-mgmt/task_edit_clusters.html["编辑集群"]。

+
[NOTE]
====
*** 您可以从 Web UI 添加集群，并自动启用基于证书的身份验证。
*** 您可以通过 Unified Manager CLI 添加集群，默认情况下不会启用基于证书的身份验证。如果使用 Unified Manager CLI 添加集群，则需要使用 Unified Manager UI 编辑集群。您可以查看 link:https://docs.netapp.com/us-en/active-iq-unified-manager/events/reference_supported_unified_manager_cli_commands.html["支持的 Unified Manager CLI 命令"] 了解如何使用 Unified Manager CLI 添加集群。
*** 如果为集群启用了基于证书的身份验证，并且您从服务器获取 Unified Manager 的备份并还原到主机名或 IP 地址已更改的另一台 Unified Manager 服务器，则对集群的监控可能会失败。为避免失败，请编辑并保存集群详细信息。有关编辑集群详细信息的更多信息，请参见 link:../storage-mgmt/task_edit_clusters.html["编辑集群"]。


====
+
*集群证书*：此证书归 ONTAP 所有。您无法将证书已过期的集群添加到 Unified Manager，如果证书已过期，则应在添加集群之前重新生成该证书。有关证书生成的信息，请参见知识库（KB）文章 https://kb.netapp.com/Advice_and_Troubleshooting/Data_Storage_Software/ONTAP_OS/How_to_renew_an_SSL_certificate_in_ONTAP_9["如何在 System Manager 用户界面中续订 ONTAP 自签名证书"^]。



* 您必须在 Unified Manager 服务器上有足够的空间。当数据库目录中超过 90% 的空间已被占用时，您将无法向服务器添加集群。


对于 MetroCluster 配置，必须同时添加本地和远程集群，并且必须正确配置集群。

.步骤
. 在左侧导航窗格中，单击*存储管理* > *集群设置*。
. 在“集群设置”页面上，单击*添加*。
. 在添加群集对话框中，指定所需的值，例如群集的主机名或 IP 地址、用户名、密码和端口号。
+
您可以将集群管理 IP 地址从 IPv6 更改为 IPv4，或者从 IPv4 更改为 IPv6。下一个监控周期完成后，新的 IP 地址将反映在集群网格和集群配置页面中。

. 单击*提交*。
. 在 Authorize Host 对话框中，单击 *View Certificate* 可查看集群的证书信息。
. 单击 *Yes*。
+
保存集群详细信息后，可以查看集群的 Mutual TLS 通信证书。

+
如果未启用基于证书的身份验证，Unified Manager 仅在最初添加集群时检查证书。Unified Manager 不会检查对 ONTAP 的每次 API 调用的证书。



发现新集群的所有对象后，Unified Manager 将开始收集前 15 天的历史性能数据。这些统计数据通过数据连续性收集功能进行收集。此功能可在集群添加后立即为您提供超过两周的集群性能信息。数据连续性收集周期完成后，将默认每五分钟收集一次实时集群性能数据。

[NOTE]
====
由于收集 15 天的性能数据是 CPU 密集型的，因此建议您错开添加新集群，以便数据连续性收集轮询不会同时在太多集群上运行。此外，如果您在数据连续性收集期间重新启动 Unified Manager，则收集将暂停，您将看到缺失时间范围内的性能图表中的缺口。

====
[TIP]
====
如果收到无法添加集群的错误消息，请检查两个系统上的时钟是否未同步，以及 Unified Manager HTTPS 证书开始日期是否晚于集群上的日期。您必须确保时钟使用 NTP 或类似服务进行同步。

====
