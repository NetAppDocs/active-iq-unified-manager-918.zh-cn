= 访问 Active IQ Unified Manager 中的 Web UI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
安装 Unified Manager 后，您可以访问 Web UI 以设置 Unified Manager，以便开始监控 ONTAP 系统。

.开始之前
* 如果这是您第一次访问 Web UI，则必须以维护用户（或 Linux 安装的 umadmin 用户）身份登录。
* 如果您计划允许用户使用短名称而不是使用完全限定的域名（FQDN）或 IP 地址访问 Unified Manager，则您的网络配置必须将此短名称解析为有效的 FQDN。
* 如果服务器使用自签名数字证书，则浏览器可能会显示警告，指示该证书不受信任。您可以确认风险并继续访问，也可以安装用于服务器身份验证的证书颁发机构（CA）签名的数字证书。


.步骤
. 请使用安装结束时显示的 URL 从浏览器启动 Unified Manager Web UI。该 URL 是 Unified Manager 服务器的 IP 地址或完全限定域名（FQDN）。
+
链接的格式如下： `\https://URL`。

. 使用维护用户凭据登录到 Unified Manager Web UI。



NOTE: 如果您在一小时内连续三次尝试登录 Web UI 失败，您将被系统锁定，并且需要联系您的系统管理员。这仅适用于本地用户。
