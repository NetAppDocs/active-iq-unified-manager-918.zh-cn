= Active IQ Unified Manager 中的网络配置菜单
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
通过网络配置菜单，您可以管理网络设置。当 Unified Manager 用户界面不可用时，应使用此菜单。

[NOTE]
====
如果 Unified Manager 安装在 Red Hat Enterprise Linux 或 Microsoft Windows 上，则此菜单不可用。

====
提供以下菜单选项。

* *显示 IP 地址设置*
+
显示虚拟设备的当前网络设置，包括 IP 地址、网络、广播地址、网络掩码、网关和 DNS 服务器。

* *更改 IP 地址设置*
+
使您能够更改虚拟设备的任何网络设置，包括 IP 地址、网络掩码、网关或 DNS 服务器。如果使用维护控制台将网络设置从 DHCP 切换到静态网络，则无法编辑主机名。您必须选择 *提交更改* 才能使更改生效。

* *显示域名搜索设置*
+
显示用于解析主机名的域名搜索列表。

* *更改域名搜索设置*
+
使您能够在解析主机名时更改要搜索的域名。您必须选择*提交更改*才能使更改生效。

* *显示静态路由*
+
显示当前静态网络路由。

* *更改静态路由*
+
使您可以添加或删除静态网络路由。必须选择*提交更改*才能使更改生效。

+
** *添加路由*
+
使您可以添加静态路由。

** *删除路由*
+
使您可以删除静态路由。

** *返回*
+
带您返回*主菜单*。

** *退出*
+
退出维护控制台。



* *禁用网络接口*
+
禁用任何可用的网络接口。如果只有一个网络接口可用，则无法禁用它。必须选择*提交更改*才能使更改生效。

* *启用网络接口*
+
启用可用的网络接口。您必须选择*提交更改*才能使更改生效。

* *提交更改*
+
应用对虚拟设备的网络设置所做的任何更改。您必须选择此选项以实施所做的任何更改，否则不会发生更改。

* *Ping 主机*
+
Ping 目标主机以确认 IP 地址更改或 DNS 配置。

* *还原为默认设置*
+
将所有设置重置为出厂默认值。必须选择*提交更改*才能使更改生效。

* *返回*
+
带您返回*主菜单*。

* *退出*
+
退出维护控制台。
