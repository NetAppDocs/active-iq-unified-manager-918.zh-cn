= 了解 Active IQ Unified Manager 中的审核日志
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用审核日志来检测审核日志是否已受损。用户执行的所有活动都将受到监控并记录在审核日志中。审核针对 Active IQ Unified Manager 的所有用户界面和公开的 API 功能执行。

您可以使用*审核日志：文件视图*查看和访问 Active IQ Unified Manager 中可用的所有审核日志文件。审核日志：文件视图中的文件将根据其创建日期列出。此视图显示从安装或升级到目前为止在系统中捕获的所有审核日志的信息。每当您在 Unified Manager 中执行操作时，信息都会更新并在日志中可用。每个日志文件的状态是使用 "`File Integrity Status`" 属性捕获的，该属性受到主动监控，以检测日志文件是否被篡改或删除。当审核日志在系统中可用时，审核日志可以具有以下状态之一：

[cols="2*"]
|===
| 州/省 | 问题描述 


 a| 
处于活动状态
 a| 
当前正在记录日志的文件。



 a| 
正常
 a| 
非活动、压缩并存储在系统中的文件。



 a| 
已篡改
 a| 
已被手动编辑该文件的用户破坏的文件。



 a| 
MANUAL_DELETE
 a| 
已被授权用户删除的文件。



 a| 
ROLLOVER_DELETE
 a| 
由于根据滚动配置策略滚动而被删除的文件。



 a| 
UNEXPECTED_DELETE
 a| 
由于未知原因而被删除的文件。

|===
审核日志页面包含以下命令按钮：

* 配置
* 删除
* 下载


*DELETE* 按钮使您能够删除审核日志视图中列出的任何审核日志。您可以删除审核日志，并可选择提供删除文件的原因，这有助于将来确定有效的删除。REASON 列列出原因以及执行删除操作的用户的名称。

[NOTE]
====
删除日志文件将导致从系统中删除文件，但不会删除 DB 表中的条目。

====
您可以使用审核日志部分中的 *下载* 按钮从 Active IQ Unified Manager 下载审核日志并导出审核日志文件。标记为 "`NORMAL`" 或 "`TAMPERED`" 的文件将以压缩 `.gzip`格式下载。

审核日志文件定期存档并保存到数据库中以供参考。在存档之前，审核日志经过数字签名，以维护安全性和完整性。

生成完整的 AutoSupport 捆绑包时，支持捆绑包将包含已归档和活动的审核日志文件。但是，当生成轻型支持捆绑包时，它仅包含活动的审核日志。不包含已归档的审核日志。
