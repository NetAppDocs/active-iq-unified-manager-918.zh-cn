= 在 Active IQ Unified Manager 中更改 SAML 身份验证标识提供程序
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改 Unified Manager 用来验证远程用户的身份提供程序（IdP）。

.开始之前
* 您必须具有 IdP URL 和元数据。
* 您必须能够访问 IdP。


可以在配置 Unified Manager 之前或之后配置新的 IdP。

.步骤
. 在左侧导航窗格中，单击*常规* > *SAML 身份验证*。
. 请输入将 Unified Manager 服务器连接到 IdP 所需的新 IdP URI 和 IdP 元数据。
+
如果可以直接从 Unified Manager 服务器访问 IdP，您可以在输入 IdP URL 后单击 *获取 IdP 元数据* 按钮，以自动填充 IdP 元数据字段。

. 复制 Unified Manager 元数据 URI，或将元数据保存到 XML 文本文件。
. 单击*保存配置*。
+
此时将显示一个消息框，以确认您要更改配置。

. 单击 *OK*。


请访问新的 IdP 并输入 Unified Manager 服务器 URI 和元数据以完成配置。

下次授权远程用户尝试访问 Unified Manager 图形界面时，他们将在新的 IdP 登录页面而不是旧的 IdP 登录页面中输入其凭据。
