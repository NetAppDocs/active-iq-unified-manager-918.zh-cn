= 在 Active IQ Unified Manager 中编辑用户设置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以编辑为每个用户指定的用户设置（例如电子邮件地址和角色）。例如，您可能希望更改存储操作员用户的角色，并将存储管理员权限分配给该用户。

.开始之前
您必须具有应用程序管理员角色。

当您修改分配给用户的角色时，会在发生以下任一操作时应用更改：

* 用户注销并重新登录到 Unified Manager。
* 已达到 24 小时的会话超时。


.步骤
. 在左侧导航窗格中，单击 *常规* > *用户*。
. 在用户页面中，选择要编辑设置的用户，然后单击*编辑*。
. 在编辑用户对话框中，编辑为此用户指定的相应设置。
. 单击 *Save*。
