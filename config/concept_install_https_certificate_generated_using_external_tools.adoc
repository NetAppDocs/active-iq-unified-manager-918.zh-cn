= 了解在 Active IQ Unified Manager Unified Manager 中使用外部工具生成的 HTTPS 证书
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以安装自签名或 CA 签名的证书，这些证书是使用 OpenSSL、BoringSSL、LetsEncrypt 等外部工具生成的。

您应该将私钥与证书链一起加载，因为这些证书是外部生成的公钥-私钥对。允许的密钥对算法是“`RSA`”和“`EC`”。*安装 HTTPS 证书* 选项在常规部分下的 HTTPS 证书页面中提供。您上传的文件应采用以下输入格式。

. Active IQ Unified Manager 主机所属服务器的私钥
. 与私钥匹配的服务器证书
. 反向直至根证书的 CA 证书，用于签署上述证书




[[format-for-loading-a-certificate-with-an-ec-key-pair]]
== 使用 EC 密钥对加载证书的格式

允许的曲线为“`prime256v1`”和“`secp384r1`”。具有外部生成的 EC 对的证书示例：

[listing]
----
 -----BEGIN EC PRIVATE KEY-----
<EC private key of Server>
-----END EC PRIVATE KEY-----
----
[listing]
----
 -----BEGIN CERTIFICATE-----
 <Server certificate>
 -----END CERTIFICATE-----
 -----BEGIN CERTIFICATE-----
 <Intermediate certificate #1 (if present)>
 -----END CERTIFICATE-----
 -----BEGIN CERTIFICATE-----
 <Intermediate certificate #2 (if present)>
 -----END CERTIFICATE-----
 -----BEGIN CERTIFICATE-----
 <Root signing certificate>
 -----END CERTIFICATE-----
----


[[format-for-loading-a-certificate-with-an-rsa-key-pair]]
== 使用 RSA 密钥对加载证书的格式

属于主机证书的 RSA 密钥对的允许密钥大小为 2048、3072 和 4096。具有外部生成的 *RSA 密钥对* 的证书：

[listing]
----
-----BEGIN RSA PRIVATE KEY-----
 <RSA private key of Server>
 -----END RSA PRIVATE KEY-----
 -----BEGIN CERTIFICATE-----
 <Server certificate>
 -----END CERTIFICATE-----
 -----BEGIN CERTIFICATE-----
 <Intermediate certificate #1 (if present)>
 -----END CERTIFICATE-----
 -----BEGIN CERTIFICATE-----
 <Intermediate certificate #2 (if present)>
 -----END CERTIFICATE-----
 -----BEGIN CERTIFICATE-----
 <Root signing certificate>
 -----END CERTIFICATE-----
----
上传证书后，您应重新启动 Active IQ Unified Manager 实例以使更改生效。



[[checks-while-uploading-externally-generated-certificates]]
== 上传外部生成的证书时的检查

系统在上传使用外部工具生成的证书时会执行检查。如果任何检查失败，则证书将被拒绝。此外，还包括对从产品内的 CSR 生成的证书以及使用外部工具生成的证书的验证。

* 输入中的私钥将根据输入中的主机证书进行验证。
* 根据主机的 FQDN 检查主机证书中的通用名称（CN）。
* 主机证书的公用名称（CN）不应为空或空白，也不应设置为 localhost。
* 有效期开始日期不应为将来日期，证书的有效期到期日期不应为过去日期。
* 如果存在中间 CA 或 CA，则证书的有效期开始日期不应在未来，有效期到期日期不应在过去。


[NOTE]
====
输入中的私钥不应加密。如果存在任何已加密的私钥，则会被系统拒绝。

====
示例 1

[listing]
----
----BEGIN ENCRYPTED PRIVATE KEY-----
<Encrypted private key>
-----END ENCRYPTED PRIVATE KEY-----
----
示例 2

[listing]
----
-----BEGIN RSA PRIVATE KEY-----
Proc-Type: 4,ENCRYPTED
<content here>
-----END RSA PRIVATE KEY-----
----
示例 3

[listing]
----
-----BEGIN EC PRIVATE KEY-----
Proc-Type: 4,ENCRYPTED
<content here>
-----END EC PRIVATE KEY-----
----
如果证书安装失败，请参阅知识库 (KB) 文章：https://kb.netapp.com/mgmt/AIQUM/AIQUM_fails_to_install_externally_generated_certificate["ActiveIQ Unified Manager 无法安装外部生成的证书"^]
