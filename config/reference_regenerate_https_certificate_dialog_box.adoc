= 在 Active IQ Unified Manager 中重新生成 HTTPS 证书对话框
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
通过“重新生成 HTTPS 证书”对话框，您可以自定义安全信息，然后使用该信息生成新的 HTTPS 证书。

此页面上将显示当前证书信息。

“`使用当前证书属性重新生成`”和“`更新当前证书属性`”选项使您可以使用当前信息重新生成证书或使用新信息生成证书。

* *通用名称*
+
必需。要保护的完全限定域名 (FQDN)。

+
在 Unified Manager 高可用性配置中，使用虚拟 IP 地址。

* *电子邮件*
+
可选。用于联系您组织的电子邮件地址；通常是证书管理员或 IT 部门的电子邮件地址。

* *公司*
+
可选。通常是公司的法定名称。

* *部门*
+
可选。公司部门名称。

* *城市*
+
可选。公司所在的城市位置。

* *State*
+
可选。公司所在的州或省/自治区/直辖市位置（非缩写）。

* *国家/地区*
+
可选。公司所在的国家/地区位置。这通常是指国家/地区的两个字母的 ISO 代码。

* *备用名称*
+
必需。除了现有本地主机或其他网络地址以外，还可以使用其他非主域名来访问此服务器。每个替换名称均使用英文逗号进行分隔。

+
如果要从证书的“备用名称”字段中删除本地标识信息，请选中 "`Exclude local identifying information (e.g. localhost)`" 复选框。选中此复选框时，仅在“备用名称”字段中使用您在该字段中输入的内容。留空时，生成的证书将完全没有“备用名称”字段。

* *密钥大小（密钥算法：RSA）*
+
密钥算法设置为 RSA。您可以选择一种密钥大小：2048、3072 或 4096 位。默认密钥大小设置为 2048 位。

* *有效期*
+
默认有效期为 397 天。如果您已从早期版本升级，您可能会看到以前的证书有效期保持不变。



有关详细信息，请参见link:../config/task_generate_an_https_security_certificate_ocf.html["生成 HTTPS 证书"]。
