= 在 Active IQ Unified Manager 中使用身份提供程序
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在将 Unified Manager 配置为使用身份提供程序（IdP）为所有远程用户执行 SAML 身份验证时，您需要了解一些必需的配置设置，以便成功连接到 Unified Manager。

必须在 IdP 服务器中输入 Unified Manager URI 和元数据。您可以从 Unified ManagerSAML 身份验证页面复制此信息。在安全断言标记语言（SAML）标准中，Unified Manager 被视为服务提供程序（SP）。



[[supported-encryption-standards]]
== 支持的加密标准

* 高级加密标准（AES）：AES-128 和 AES-256
* 安全哈希算法（SHA）：SHA-1 和 SHA-256




[[validated-identity-providers]]
== 已验证的身份提供程序

* Shibboleth
* Active Directory 联合身份验证服务（ADFS）




[[adfs-configuration-requirements]]
== ADFS 配置要求

* 必须按以下顺序定义三个声明规则，这些规则是 Unified Manager 解析此依赖方信任项的 ADFS SAML 响应所必需的。
+
[cols="2*"]
|===
| 声明规则 | 值 


 a| 
SAM-account-name
 a| 
名称 ID



 a| 
SAM-account-name
 a| 
urn:oid:0.9.2342.19200300.100.1.1



 a| 
令牌组 -- 未限定名称
 a| 
urn:oid:1.3.6.1.4.1.5923.1.5.1.1

|===
* 您必须将身份验证方法设置为“`表单身份验证`”，否则用户在注销 Unified Manager 时可能会收到错误。按照以下步骤操作：
+
.. 打开 ADFS 管理控制台。
.. 单击左侧树视图上的身份验证策略文件夹。
.. 在右侧的“操作”下，单击“编辑全局主要身份验证策略”。
.. 将 Intranet 身份验证方法设置为“`Forms Authentication`”，而不是默认的“`Windows Authentication`”。


* 在某些情况下，当 Unified Manager 安全证书经过 CA 签名时，通过 IdP 登录会被拒绝。有两种解决方法可以解决此问题：
+
** 按照链接中标识的说明，在 ADFS 服务器上禁用链式 CA 证书关联依赖方的吊销检查：
+
http://www.torivar.com/2016/03/22/adfs-3-0-disable-revocation-check-windows-2012-r2/["禁用每个依赖方信任的吊销检查"]

** 请让 CA 服务器驻留在 ADFS 服务器内，以便对 Unified Manager 服务器证书请求进行签名。






[[other-configuration-requirements]]
== 其他配置要求

* Unified Manager 时钟偏差设置为 5 分钟，因此 IdP 服务器和 Unified Manager 服务器之间的时间差不能超过 5 分钟，否则身份验证将失败。
