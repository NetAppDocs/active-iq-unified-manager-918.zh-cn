= 了解有关配置 Active IQ Unified Manager 的信息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
安装 Active IQ Unified Manager（以前称为 OnCommand Unified Manager）后，必须完成初始设置（也称为首次体验向导）才能访问 Web UI。然后，您可以执行其他配置任务，例如添加集群、配置远程身份验证、添加用户和添加警报。

完成 Unified Manager 实例的初始设置需要执行本手册中描述的部分步骤。其他步骤是推荐的配置设置，这些设置有助于在新实例上进行设置，或者在开始定期监控 ONTAP 系统之前最好能有所了解。
