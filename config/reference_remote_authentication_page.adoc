= 使用 Active IQ Unified Manager 中的远程身份验证页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用“远程身份验证”页面配置 Unified Manager 与您的身份验证服务器进行通信，以对尝试登录到 Unified Manager Web UI 的远程用户进行身份验证。

您必须具有应用程序管理员或存储管理员角色。

选中启用远程身份验证复选框后，可以使用身份验证服务器启用远程身份验证。

* *身份验证服务*
+
使您能够配置管理服务器，以便在目录服务提供程序（如 Active Directory、OpenLDAP）中对用户进行身份验证，或者指定您自己的身份验证机制。仅当启用了远程身份验证时，才能指定身份验证服务。

+
** *Active Directory*
+
*** 管理员名称
+
指定身份验证服务器的管理员名称。

*** 密码
+
指定访问身份验证服务器的密码。

*** 基本可分辨名称
+
指定远程用户在身份验证服务器中的位置。例如，如果身份验证服务器的域名是 +ou@domain.com+，则基本可分辨名称是 *cn=ou,dc=domain,dc=com*。

*** 禁用嵌套组查找
+
指定是启用还是禁用嵌套组查找选项。默认情况下，此选项处于禁用状态。如果使用 Active Directory，则可以通过禁用对嵌套组的支持来加快身份验证速度。

*** 使用安全连接
+
指定用于与身份验证服务器通信的身份验证服务。



** *OpenLDAP*
+
*** 绑定可分辨名称
+
指定与基本可分辨名称一起使用的绑定可分辨名称，以在身份验证服务器中查找远程用户。

*** 绑定密码
+
指定访问身份验证服务器的密码。

*** 基本可分辨名称
+
指定远程用户在身份验证服务器中的位置。例如，如果身份验证服务器的域名是 +ou@domain.com+，则基本可分辨名称是 *cn=ou,dc=domain,dc=com*。

*** 使用安全连接
+
指定使用安全 LDAP 与 LDAP 身份验证服务器进行通信。



** *其他*
+
*** 绑定可分辨名称
+
指定与基本可分辨名称一起使用的 bind 可分辨名称，以在已配置的身份验证服务器中查找远程用户。

*** 绑定密码
+
指定访问身份验证服务器的密码。

*** 基本可分辨名称
+
指定远程用户在身份验证服务器中的位置。例如，如果身份验证服务器的域名是 +ou@domain.com+，则基本可分辨名称是 *cn=ou,dc=domain,dc=com*。

*** 协议版本
+
指定身份验证服务器支持的轻型目录访问协议（LDAP）版本。您可以指定是否必须自动检测协议版本，或将版本设置为 2 或 3。

*** 用户名属性
+
指定身份验证服务器中包含要由管理服务器进行身份验证的用户登录名的属性的名称。

*** 组成员资格属性
+
指定一个值，该值基于用户身份验证服务器中指定的属性和值将管理服务器组成员身份分配给远程用户。

*** UGID
+
如果远程用户作为 GroupOfUniqueNames 对象的成员包含在身份验证服务器中，则此选项使您能够根据该 GroupOfUniqueNames 对象中的指定属性将管理服务器组成员身份分配给远程用户。

*** 禁用嵌套组查找
+
指定是启用还是禁用嵌套组查找选项。默认情况下，此选项处于禁用状态。如果使用 Active Directory，则可以通过禁用对嵌套组的支持来加快身份验证速度。

*** 成员
+
指定身份验证服务器用于存储有关组个别成员的信息的属性名称。

*** 用户对象类
+
指定远程身份验证服务器中用户的对象类。

*** 组对象类
+
指定远程身份验证服务器中所有组的对象类。

+

NOTE: 为 _Member_、_User Object Class_ 和 _Group Object Class_ 属性输入的值应与 Active Directory、OpenLDAP 和 LDAP 配置中添加的值相同。否则，身份验证可能会失败。

*** 使用安全连接
+
指定用于与身份验证服务器通信的身份验证服务。





+
[NOTE]
====
如果要修改身份验证服务，请确保删除所有现有的身份验证服务器并添加新的身份验证服务器。

====




[[authentication-servers-area]]
== 身份验证服务器区域

身份验证服务器区域显示管理服务器与之通信以查找和对远程用户进行身份验证的身份验证服务器。远程用户或组的凭据由身份验证服务器维护。

* *命令按钮*
+
允许您添加、编辑或删除身份验证服务器。

+
** 添加
+
允许您添加身份验证服务器。

+
如果要添加的身份验证服务器是高可用性对的一部分（使用相同的数据库），则还可以添加伙伴身份验证服务器。这使管理服务器能够在其中一个身份验证服务器无法访问时与伙伴通信。

** 编辑
+
允许您编辑所选身份验证服务器的设置。

** 删除
+
删除选定的身份验证服务器。



* *名称或 IP 地址*
+
显示用于对管理服务器上的用户进行身份验证的身份验证服务器的主机名或 IP 地址。

* *端口*
+
显示身份验证服务器的端口号。

* *测试身份验证*
+
此按钮通过对远程用户或组进行身份验证来验证身份验证服务器的配置。

+
在测试期间，如果仅指定用户名，则管理服务器会在身份验证服务器中搜索远程用户，但不会对用户进行身份验证。如果同时指定用户名和密码，则管理服务器将搜索远程用户并对其进行身份验证。

+
如果禁用远程身份验证，则无法测试身份验证。
