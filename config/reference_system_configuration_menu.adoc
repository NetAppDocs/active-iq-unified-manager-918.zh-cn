= 使用 Active IQ Unified Manager 中的系统配置菜单
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
系统配置菜单通过提供各种选项，例如查看服务器状态以及重新启动和关闭虚拟机，使您能够管理虚拟设备。

[NOTE]
====
在 Linux 或 Microsoft Windows 系统上安装 Unified Manager 时，此菜单中仅提供 "`从 Unified Manager 备份还原`" 选项。

====
提供以下菜单选项：

* *显示服务器状态*
+
显示当前服务器状态。状态选项包括运行和未运行。

+
如果服务器未运行，您可能需要与技术支持联系。

* *重新启动虚拟机*
+
重新启动虚拟机，停止所有服务。重新启动后，虚拟机和服务将重新启动。

* *关闭虚拟机*
+
关闭虚拟机，停止所有服务。

+
您只能从虚拟机控制台选择此选项。

* *更改<logged in user>用户密码*
+
更改当前登录的用户的密码，此用户只能是维护用户。

* *增加数据磁盘大小*
+
增加虚拟机中数据磁盘（磁盘 3）的大小。

* *增加交换磁盘大小*
+
增加虚拟机中交换磁盘（磁盘 2）的大小。

* *更改时区*
+
将时区更改为您的位置。

* *更改 NTP 服务器*
+
更改 NTP 服务器设置，例如 IP 地址或完全限定的域名（FQDN）。

* *更改 NTP 服务*
+
在 `ntp`和 `systemd-timesyncd`服务之间切换。

* *从 Unified Manager 备份还原*
+
从以前备份的版本恢复 Unified Manager 数据库和配置设置。

* *重置服务器证书*
+
重置服务器安全证书。

* *更改主机名称*
+
更改安装虚拟设备的主机名称。

* *返回*
+
退出系统配置菜单并返回主菜单。

* *退出*
+
退出维护控制台菜单。
