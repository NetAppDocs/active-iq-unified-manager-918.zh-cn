= 在 Active IQ Unified Manager 中启用基于策略的存储管理
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
*基于策略的存储管理*选项允许基于服务级别目标（SLO）进行存储管理。默认情况下，此选项处于启用状态。

激活此功能后，您可以在添加到 Active IQ Unified Manager 实例的 ONTAP 集群上配置存储工作负载，并根据分配的性能服务级别和存储效率策略管理这些工作负载。

您可以从*常规* > *功能设置* > *基于策略的存储管理*中选择激活或停用此功能。激活此功能后，以下页面可用于操作和监控：

* 配置（存储工作负载配置）
* *策略* > *性能服务级别*
* *策略* > *存储效率*
* “群集设置”页面上的“通过性能服务级别管理的工作负载”列
* *仪表板*上的工作负载性能面板


您可以使用这些屏幕创建性能服务级别和存储效率策略，并配置存储工作负载。您还可以监控符合已分配性能服务级别的存储工作负载，以及不符合的存储工作负载。工作负载性能和工作负载 IOPS 面板还可让您根据在集群上配置的存储工作负载，评估数据中心内各集群的总容量、可用容量和已用容量以及性能 （IOPS）。

激活此功能后，您可以运行 Unified Manager REST API，以执行 *菜单栏* > *帮助按钮* > *API 文档* > *storage-provider* 类别中的某些功能。或者，您可以输入主机名或 IP 地址以及用于访问 REST API 页面的 URL，格式为 +https://<hostname>/docs/api/+

有关 API 的详细信息，请参见 link:../api-automation/concept_get_started_with_um_apis.html["Active IQ Unified Manager REST API 入门"]。
