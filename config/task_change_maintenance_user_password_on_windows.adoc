= 在 Windows 中更改 Active IQ Unified Manager 的维护用户密码
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在需要时更改 Unified Manager 维护用户密码。

.步骤
. 在 Unified Manager Web UI 登录页面中，单击 *忘记密码*。
+
此时将显示一个页面，提示输入要重置密码的用户名。

. 输入用户名并单击*提交*。
+
带有重置密码链接的电子邮件将发送到为该用户名定义的电子邮件地址。

. 单击电子邮件中的*重置密码链接*并定义新密码。
. 返回到 Web UI 并使用新密码登录到 Unified Manager。
