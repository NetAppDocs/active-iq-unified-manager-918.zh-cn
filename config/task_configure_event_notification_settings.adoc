= 在 Active IQ Unified Manager 中配置事件通知设置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以将 Unified Manager 配置为在生成事件或将事件分配给用户时发送警报通知。您可以配置用于发送警报的 SMTP 服务器，也可以设置各种通知机制——例如，警报通知可以作为电子邮件或 SNMP 陷阱发送。

.开始之前
您必须具有下列信息：

* 发送警报通知的电子邮件地址
+
电子邮件地址显示在发送的警报通知中的“`From`”字段中。如果由于任何原因无法发送电子邮件，此电子邮件地址也将用作无法投递邮件的收件人。

* SMTP 服务器主机名，以及访问服务器的用户名和密码
* 将接收 SNMP 陷阱的陷阱目标主机的主机名或 IP 地址，以及 SNMP 版本、出站陷阱端口、团体和其他必需的 SNMP 配置值
+
要指定多个陷阱目标，请使用逗号分隔每个主机。在这种情况下，所有其他 SNMP 设置（例如版本和出站陷阱端口）必须对于此列表中的所有主机都相同。



您必须具有应用程序管理员或存储管理员角色。

.步骤
. 在左侧导航窗格中，单击*常规* > *通知*。
. 在“通知”页面中，配置适当的设置。
+
*备注：*

+
** 如果发件人地址预先填写了地址“+ActiveIQUnifiedManager@localhost.com+”，则应将其更改为真实有效的电子邮件地址，以确保所有电子邮件通知都能成功发送。
** 如果无法解析 SMTP 服务器的主机名，则可以指定 SMTP 服务器的 IP 地址（IPv4 或 IPv6）而不是主机名。


. 单击 *Save*。
. 如果您选择了 *使用 STARTTLS* 或 *使用 SSL* 选项，则单击 *保存* 按钮后会显示证书页面。验证证书详细信息并接受证书以保存通知设置。
+
您可以单击*查看证书详细信息*按钮以查看证书详细信息。如果现有证书已过期，请取消选中*使用 STARTTLS*或*使用 SSL*复选框，保存通知设置，然后再次选中*使用 STARTTLS*或*使用 SSL*复选框以查看新证书。
