= 在 Active IQ Unified Manager 中更改本地用户密码
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改本地用户登录密码，以避免出现可能的安全风险。

.开始之前
必须以本地用户身份登录。

无法使用这些步骤更改维护用户和远程用户的密码。要更改远程用户密码，请联系您的密码管理员。要更改维护用户密码，请参阅 link:task_use_maintenance_console.html["使用维护控制台"]。

.步骤
. 登录到 Unified Manager。
. 在顶部菜单栏中，单击用户图标，然后单击*更改密码*。
+
如果您是远程用户，则不会显示*更改密码*选项。

. 在"更改密码"对话框中，输入当前密码和新密码。
. 单击 *Save*。


如果在高可用性配置中配置了 Unified Manager，则必须在设置的第二个节点上更改密码。两个实例必须具有相同的密码。
