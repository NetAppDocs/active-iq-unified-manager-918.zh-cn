= 使用 API 管理 Active IQ Unified Manager 中的用户
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 `security` 类别中的 API 来控制用户对 Active IQ Unified Manager 中选定集群对象的访问。您可以添加本地用户或数据库用户。您还可以添加属于身份验证服务器的远程用户或组。根据您分配给用户的角色的权限，他们可以管理存储对象或查看 Unified Manager 中的数据。

[NOTE]
====
要运行这些操作，您必须具有应用程序管理员角色。您还可以使用 Unified Manager Web UI 配置这些设置。

====
 `security` 类别下的 API 使用 users 参数（即用户名），而不是 key 参数作为用户实体的唯一标识符。

[cols="3*"]
|===
| HTTP 谓词 | 路径 | 问题描述 


 a| 
`GET`

`POST`
 a| 
`/security/users`

`/security/users`
 a| 
您可以使用这些方法获取用户的详细信息或将新用户添加到 Unified Manager。

您可以根据用户类型向用户添加特定角色。添加用户时，必须提供本地用户、维护用户和数据库用户的密码。



 a| 
`GET`

`PATCH`

`DELETE`
 a| 
`/security/users/\{name}`
 a| 
使用 GET 方法，您可以检索用户的所有详细信息，例如名称、电子邮件地址、角色、授权类型。使用 PATCH 方法，您可以更新详细信息。使用 DELETE 方法，您可以删除用户。

|===
