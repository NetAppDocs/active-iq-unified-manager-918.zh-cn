= 使用 Active IQ Unified Manager 中的 API 查看性能指标
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager 为您提供了一组  `/datacenter` 类别下的 API，使您能够查看数据中心中集群和存储对象的性能数据。这些 API 检索不同存储对象的性能数据，如集群、节点、LUN、卷、聚合、存储 VM、FC 接口、FC 端口、以太网端口和 IP 接口。

 `/metrics` 和  `/analytics` API 提供了性能指标的不同视图，使用这些视图，您可以深入了解数据中心内以下存储对象的不同详细级别：

* 集群
* nodes
* 存储 VM
* 聚合
* volumes
* LUN 数
* FC 接口
* FC 端口
* 以太网端口
* IP 接口


下表就检索到的性能数据详细信息对  `/metrics` 和  `/analytics` API 进行了比较。

[cols="2*"]
|===
| 指标 | 分析 


 a| 
单个对象的性能详细信息。例如， `/datacenter/cluster/clusters/\{key}/metrics` API 要求输入集群键作为路径参数，以便检索该特定集群的指标。
 a| 
数据中心中相同类型的多个对象的性能详细信息。例如， `/datacenter/cluster/clusters/analytics` API 检索数据中心中所有集群的集体指标。



 a| 
基于用于检索的时间间隔参数的存储对象的性能指标示例。
 a| 
特定类型存储对象在一定时间段（72 小时以上）内性能的高级聚合值。



 a| 
将检索对象的基本详细信息，例如节点或集群的详细信息。
 a| 
未检索到任何具体详细信息。



 a| 
检索单个对象的累积计数器（例如最小值、最大值、第 95 个百分位数以及一段时间内的平均性能值），例如读取、写入、总计和其他计数器。
 a| 
相同类型的所有对象都显示单个聚合值。



 a| 
时间范围和样本数据基于以下计划：数据的时间范围。示例可以是 1h、12h、1d、2d、3d、15d、1w、1m、2m、3m、6m。如果范围超过 3 天（72 小时），则获得 1 小时样本，否则为 5 分钟样本。每个时间范围的周期如下：

* 1 小时：在 5 分钟内采样的最近一小时的指标。
* 12h：最近 12 小时的指标，每 5 分钟采样一次。
* 1d：最近一天的指标，采样间隔为 5 分钟。
* 2d：最近 2 天的指标，每 5 分钟采样一次。
* 3d：最近 3 天的指标，采样间隔为 5 分钟。
* 15d：最近 15 天的指标，按 1 小时采样。
* 1w：最近一周的指标，按 1 小时采样。
* 1m：最近一个月的指标，采样间隔为 1 小时。
* 2m：最近 2 个月的指标，按 1 小时进行采样。
* 3m：最近 3 个月的指标，采样间隔为 1 小时。
* 6m：最近 6 个月的指标，采样间隔为 1 小时。
+
可用值：1h、12h、1d、2d、3d、15d、1w、1m、2m、3m、6m

+
默认值：1h


 a| 
72 小时以上。此样本的计算持续时间以 ISO-8601 标准格式表示。

|===

[[list-of-the-available-apis]]
== 可用 API 列表

下表详细介绍了 `/metrics`和 `/analytics` API。

[NOTE]
====
这些 API 返回的 IOPS 和性能指标是双精度值，例如 `100.53`。不支持通过管道（|）和通配符（*）字符过滤这些浮点值。

====
[cols="3*"]
|===
| HTTP 动词 | 路径 | 问题描述 


 a| 
`GET`
 a| 
`/datacenter/cluster/clusters/\{key}/metrics`
 a| 
检索由集群键的输入参数指定的集群的性能数据（样本和摘要）。将返回集群键和 UUID 、时间范围、 IOPS 、吞吐量和样本数等信息。



 a| 
`GET`
 a| 
`/datacenter/cluster/clusters/analytics`
 a| 
检索数据中心中所有集群的高级性能指标。您可以根据所需条件筛选结果。将返回值，例如聚合 IOPS、吞吐量和收集周期（以小时为单位）。



 a| 
`GET`
 a| 
`/datacenter/cluster/nodes/\{key}/metrics`
 a| 
检索由节点键的输入参数指定的节点的性能数据（样本和摘要）。将返回节点 UUID、时间范围、IOPS、吞吐量、延迟和性能的摘要、收集的样本数量以及利用率百分比等信息。



 a| 
`GET`
 a| 
`/datacenter/cluster/nodes/analytics`
 a| 
检索数据中心中所有节点的高级性能指标。您可以根据所需条件筛选结果。将返回节点和集群键等信息，以及聚合 IOPS、吞吐量和收集周期（以小时为单位）等值。



 a| 
`GET`
 a| 
`/datacenter/storage/aggregates/\{key}/metrics`
 a| 
检索由聚合键的输入参数指定的聚合的性能数据（样本和摘要）。将返回时间范围、IOPS 摘要、延迟、吞吐量和性能容量、为每个计数器收集的样本数以及利用率百分比等信息。



 a| 
`GET`
 a| 
`/datacenter/storage/aggregates/analytics`
 a| 
检索数据中心中所有聚合的高级性能指标。您可以根据所需条件筛选结果。将返回聚合和集群键等信息，以及聚合 IOPS、吞吐量和收集周期（以小时为单位）等值。



 a| 
`GET`
 a| 
`/datacenter/storage/luns/\{key}/metrics`

`/datacenter/storage/volumes/\{key}/metrics`
 a| 
检索由 LUN 或卷键的输入参数指定的 LUN 或文件共享（卷）的性能数据（样本和摘要）。将返回相关信息，例如读取、写入和总 IOPS、延迟和吞吐量的最小值、最大值和平均值的摘要，以及为每个计数器收集的样本数。



 a| 
`GET`
 a| 
`/datacenter/storage/luns/analytics`

`/datacenter/storage/volumes/analytics`
 a| 
检索数据中心中所有 LUN 或卷的高级性能指标。您可以根据所需条件筛选结果。将返回存储 VM 和集群密钥等信息，以及聚合 IOPS、吞吐量和收集周期（以小时为单位）等值。



 a| 
`GET`
 a| 
`/datacenter/svm/svms/{key}/metrics`
 a| 
检索由 storage VM 密钥的输入参数指定的 storage VM 的性能数据（示例和摘要）。将返回基于每个受支持协议的 IOPS 摘要，例如 `nvmf, fcp, iscsi,`和 `nfs`、吞吐量、延迟以及收集的样本数。



 a| 
`GET`
 a| 
`/datacenter/svm/svms/analytics`
 a| 
检索数据中心中所有存储 VM 的高级性能指标。您可以根据所需条件筛选结果。将返回存储 VM UUID、聚合 IOPS、延迟、吞吐量和收集周期（以小时为单位）等信息。



 a| 
`GET`
 a| 
`/datacenter/network/ethernet/ports/{key}/metrics`
 a| 
检索由端口键的输入参数指定的特定以太网端口的性能指标。当从支持的范围提供间隔（时间范围）时，API 将返回累计计数器，例如该时间段内的最小值、最大值和平均性能值。



 a| 
`GET`
 a| 
`/datacenter/network/ethernet/ports/analytics`
 a| 
检索数据中心环境中所有以太网端口的高级性能指标。返回端口的集群和节点密钥以及 UUID 、吞吐量、收集周期和利用率百分比等信息。您可以按可用参数筛选结果，例如端口密钥、利用率百分比、集群和节点名称以及 UUID 等。



 a| 
`GET`
 a| 
`/datacenter/network/fc/interfaces/{key}/metrics`
 a| 
检索由接口键的输入参数指定的特定网络 FC 接口的性能指标。当从支持的范围提供间隔（时间范围）时，API 将返回累计计数器，例如该时间段内的最小值、最大值和平均性能值。



 a| 
`GET`
 a| 
`/datacenter/network/fc/interfaces/analytics`
 a| 
检索数据中心环境中所有以太网端口的高级性能指标。将返回相关信息，例如集群和 FC 接口键以及 UUID、吞吐量、IOPS、延迟和存储 VM。您可以按可用参数筛选结果，例如集群和 FC 接口名称和 UUID、存储 VM、吞吐量等。



 a| 
`GET`
 a| 
`/datacenter/network/fc/ports/{key}/metrics`
 a| 
检索由端口键的输入参数指定的特定 FC 端口的性能指标。当从支持的范围提供间隔（时间范围）时，API 将返回累计计数器，例如该时间段内的最小值、最大值和平均性能值。



 a| 
`GET`
 a| 
`/datacenter/network/fc/ports/analytics`
 a| 
检索数据中心环境中所有 FC 端口的高级性能指标。返回端口的集群和节点密钥以及 UUID、吞吐量、收集周期和利用率百分比等信息。您可以按可用参数筛选结果，例如端口密钥、利用率百分比、集群和节点名称以及 UUID 等。



 a| 
`GET`
 a| 
`/datacenter/network/ip/interfaces/{key}/metrics`
 a| 
检索由接口键的输入参数指定的网络 IP 接口的性能指标。当从支持的范围提供间隔（时间范围）时，API 将返回信息，例如样本数、累计计数器、吞吐量以及接收和传输的数据包数。



 a| 
`GET`
 a| 
`/datacenter/network/ip/interfaces/analytics`
 a| 
检索数据中心环境中所有网络 IP 接口的高级性能指标。将返回集群和 IP 接口密钥及 UUID、吞吐量、IOPS 和延迟等信息。您可以按可用参数筛选结果，例如集群和 IP 接口名称及 UUID、IOPS、延迟、吞吐量等。

|===
