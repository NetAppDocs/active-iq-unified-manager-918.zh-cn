= 使用 Active IQ Unified Manager 中的 API 查看作业和系统详细信息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 `jobs`类别下的 `management-server` API 查看异步操作的执行详细信息。 `management-server`类别下的 `system` API 可用于查看 Active IQ Unified Manager 环境中的实例详细信息。



[[view-jobs]]
== 查看作业

在 Active IQ Unified Manager 中，添加和修改资源等操作是通过同步和异步 API 调用执行的。计划异步执行的调用可以由为此调用创建的作业对象进行跟踪。每个作业对象都有一个用于标识的唯一键。每个作业对象都会返回作业对象 URI，供您访问和跟踪作业进度。您可以使用此 API 检索每次执行的详细信息。

通过使用此 API，您可以查询数据中心的所有作业对象，包括历史数据。默认情况下，查询所有作业将返回通过 Web UI 和 API 接口触发的最后 20 个作业的详细信息。使用内置筛选器查看特定作业。您还可以使用 Job 键查询特定作业的详细信息，并对资源运行下一组操作。

[cols="4*"]
|===
| 类别 | HTTP 谓词 | 路径 | 问题描述 


 a| 
management-server
 a| 
GET
 a| 
`/management-server/jobs`
 a| 
返回所有作业的作业详细信息。在未指定任何排序顺序的情况下，最后提交的作业对象将返回在最上方。



 a| 
management-server
 a| 
GET
 a| 
`/management-server/jobs/\{key}`

输入 Job 对象的作业键以查看该作业的具体详细信息。
 a| 
返回特定作业对象的详细信息。

|===


[[view-system-details]]
== 查看系统详细信息

通过使用 `/management-server/system` API，您可以查询 Unified Manager 环境的实例特定详细信息。API 返回有关产品和服务的信息，例如系统上安装的 Unified Manager 版本、UUID、供应商名称、主机操作系统以及在 Unified Manager 实例上运行的服务的名称、描述和状态。

[cols="4*"]
|===
| 类别 | HTTP 谓词 | 路径 | 问题描述 


 a| 
management-server
 a| 
GET
 a| 
`/management-server/system`
 a| 
运行此 API 不需要输入参数。默认情况下，将返回当前 Unified Manager 实例的系统详细信息。

|===
