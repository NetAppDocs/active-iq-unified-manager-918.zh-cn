= 使用 Active IQ Unified Manager API 验证 ONTAP 集群上的 SVM
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在调配文件共享或 LUN 之前，必须验证集群上是否创建了 Storage Virtual Machine （SVM）。

[NOTE]
====
工作流假定 ONTAP 集群已添加到 Unified Manager 中，并且已获取集群密钥。集群应具有在其上调配 LUN 和文件共享所需的许可证。

====
. 验证集群是否创建了 SVM。
+
[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
数据中心
 a| 
GET
 a| 
`/datacenter/svm/svms`
`/datacenter/svm/svms/\{key}`

|===
+
*示例 cURL*

+
[listing]
----
curl -X GET "https://<hostname>/api/datacenter/svm/svms" -H "accept: application/json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. 如果未返回 SVM 密钥，则创建 SVM。要创建 SVM，您需要用于配置 SVM 的群集密钥。您还需要指定 SVM 名称。请按照以下步骤操作。
+
[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
数据中心
 a| 
GET
 a| 
`/datacenter/cluster/clusters`
`/datacenter/cluster/clusters/\{key}`

|===
+
获取集群密钥。

+
*示例 cURL*

+
[listing]
----
curl -X GET "https://<hostname>/api/datacenter/cluster/clusters" -H "accept: application/json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. 从输出中获取 cluster 键，然后将其用作创建 SVM 的输入。
+
[NOTE]
====
在创建 SVM 时，请确保它支持在其上调配 LUN 和文件共享所需的所有协议，例如 CIFS、NFS、FCP 和 iSCSI。如果 SVM 不支持所需的服务，调配工作流可能会失败。建议在 SVM 上也启用相应类型工作负载的服务。

====
+
[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a|

 a| 
POST
 a| 
`/datacenter/svm/svms`

|===
