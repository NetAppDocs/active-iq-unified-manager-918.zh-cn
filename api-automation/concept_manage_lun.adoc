= 使用 Active IQ Unified Manager 中的 API 管理 LUN
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用  `/storage-provider/luns` API 查看、添加、修改和删除数据中心环境中的 LUN。

在配置 LUN 之前，请确保已使用支持的协议创建和配置 SVM。如果在配置时分配性能服务级别（PSL）或存储效率策略（SEP），则应在创建 LUN 之前创建 PSL 或 SEP。



[[view-luns]]
== 查看 LUN

您可以使用以下方法查看 Unified Manager 环境中的 LUN。当您将 ONTAP 集群作为数据源添加到 Active IQ Unified Manager 时，这些集群的存储工作负载将自动添加到您的 Unified Manager 实例中。此 API 检索自动和手动添加到 Unified Manager 实例的所有 LUN。您可以通过使用 LUN 密钥运行此 API 来查看特定 LUN 的详细信息。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
GET
 a| 
`/storage-provider/luns`

`/storage-provider/luns/\{key}`

|===


[[add-luns]]
== 添加 LUN

您可以使用以下方法将 LUN 添加到 SVM。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
POST
 a| 
`/storage-provider/luns`

|===
[NOTE]
====
在 cURL 请求中，如果您为输入中的可选参数 volume_name_tag 提供了值，则在 LUN 创建期间命名卷时将使用该值。此标记可方便地搜索卷。如果您在请求中提供了卷密钥，则会跳过标记。

====


[[delete-luns]]
== 删除 LUN

可以使用以下方法删除特定 LUN。必须提供 LUN 密钥才能删除特定 LUN。

[NOTE]
====
如果您在 ONTAP 中创建了卷，然后通过 Unified Manager 在该卷上调配了 LUN，则当您使用此 API 删除所有 LUN 时，该卷也将从 ONTAP 集群中删除。

====
[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
DELETE
 a| 
`/storage-provider/luns/\{key}`

|===


[[modify-luns]]
== 修改 LUN

可以使用以下方法修改 LUN 并更新其属性。需要提供 LUN 密钥才能修改特定 LUN。还需要输入要更新的 LUN 属性及其值。要使用此 API 更新 LUN 阵列，应查看 "`使用 API 的建议`" 中的建议。

[NOTE]
====
一次调用此 API 只能更新一个属性。对于多次更新，您需要多次运行此 API。

====
|===


| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
PATCH
 a| 
`/storage-provider/luns/\{key}`

|===
