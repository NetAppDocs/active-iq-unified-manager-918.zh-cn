= Active IQ Unified Manager REST API 入门
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager 提供了一组 API，用于通过 RESTful Web 服务接口管理受支持的存储系统上的存储资源，以便进行任何第三方集成。

在这些主题中，您将找到有关 Unified Manager API、用于解决特定问题的示例工作流和一些示例代码的信息。使用此信息，您可以创建用于管理 NetApp 系统的 NetApp 可管理性软件解决方案的 RESTful 客户端。API 基于 Representational State Transfer （REST） 架构风格。支持所有四个 REST 操作 Create、Read、Update 和 Delete （也称为 CRUD）。

有关 Active IQ Unified Manager REST API 优势的更多资源和详细信息，请参见 link:https://docs.netapp.com/us-en/netapp-automation/api/aiqum.html["Active IQ Unified Manager"^]。
