= 使用 Active IQ Unified Manager 中的 API 执行管理任务
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 `administration`类别下的 API 修改备份设置、验证备份文件信息和集群证书，还可以将 ONTAP 集群作为 Active IQ Unified Manager 数据源进行管理。

[NOTE]
====
要运行这些操作，您必须具有应用程序管理员角色。您还可以使用 Unified Manager Web UI 配置这些设置。

====
[cols="3*"]
|===
| HTTP 谓词 | 路径 | 问题描述 


 a| 
`GET`

`PATCH`
 a| 
`/admin/backup-settings`

`/admin/backup-settings`
 a| 
您可以使用  `GET` 方法查看默认情况下在 Unified Manager 中配置的备份计划的设置。您可以验证以下信息：

* 计划是否已启用或禁用
* 计划备份的频率（每日或每周）
* 备份时间
* 应用程序中应保留的最大备份文件数


备份时间采用服务器时区。

默认情况下，数据库备份设置在 Unified Manager 上可用，您无法创建备份计划。但是，您可以使用  `PATCH` 方法修改默认设置。



 a| 
`GET`
 a| 
`/admin/backup-file-info`
 a| 
每次为 Unified Manager 修改备份计划时，都会生成一个备份转储文件。您可以使用此方法验证备份文件是否根据修改后的备份设置生成，以及文件上的信息是否与修改后的设置匹配。



 a| 
`GET`
 a| 
`/admin/datasource-certificate`
 a| 
可以使用此方法从信任存储查看数据源（群集）证书。在将 ONTAP 群集添加为 Unified Manager 数据源之前，需要验证证书。



 a| 
`GET`

`POST`

`PATCH`

`DELETE`
 a| 
`/admin/datasources/clusters`

`/admin/datasources/clusters/\{key}`
 a| 
您可以使用 `GET`方法检索由 Unified Manager 管理的数据源（ONTAP 群集）的详细信息。

您还可以将新集群作为数据源添加到 Unified Manager。要添加集群，您必须知道其主机名、用户名和密码。

要修改和删除由 Unified Manager 作为数据源管理的集群，请使用 ONTAP 集群密钥。

|===
