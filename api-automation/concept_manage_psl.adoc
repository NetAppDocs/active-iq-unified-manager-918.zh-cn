= 在 Active IQ Unified Manager 中使用 API 管理性能服务级别
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以通过使用 Active IQ Unified Manager 上的存储提供程序 API 来查看、创建、修改和删除性能服务级别。



[[view-performance-service-levels]]
== 查看性能服务级别

可以使用以下方法查看性能服务级别，以便将其分配给存储工作负载。API 列出所有系统定义和用户创建的性能服务级别，并检索所有性能服务级别的属性。如果要查询特定的性能服务级别，则需要输入性能服务级别的唯一 ID 以检索其详细信息。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
GET
 a| 
`/storage-provider/performance-service-levels`

`/storage-provider/performance-service-levels/\{key}`

|===


[[add-performance-service-levels]]
== 添加性能服务级别

如果系统定义的性能服务级别未满足存储工作负载所需的服务级别目标（SLO），则可以使用以下方法创建自定义性能服务级别并将其分配给存储工作负载。输入要创建的性能服务级别的详细信息。对于 IOPS 属性，请确保输入有效的值范围。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
POST
 a| 
`/storage-provider/performance-service-levels`

|===


[[delete-performance-service-levels]]
== 删除性能服务级别

您可以使用以下方法删除特定的 Performance Service Level。如果某个 Performance Service Level 已分配给工作负载，或者它是唯一可用的 Performance Service Level，则无法将其删除。您需要提供 Performance Service Level 的唯一 ID 作为输入参数，以删除特定的 Performance Service Level。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
DELETE
 a| 
`/storage-provider/performance-service-levels/\{key}`

|===


[[modify-performance-service-levels]]
== 修改性能服务级别

可以使用以下方法修改性能服务级别并更新其属性。无法修改系统定义或分配给工作负载的性能服务级别。需要提供唯一 ID 才能修改特定性能服务级别。还必须输入要更新的 IOPS 属性以及有效值。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
PATCH
 a| 
`/storage-provider/performance-service-levels/\{key}`

|===


[[view-aggregate-capabilities-based-on-performance-service-levels]]
== 根据性能服务级别查看聚合功能

可以使用以下方法根据性能服务级别查询聚合功能。此 API 返回数据中心中可用的聚合列表，并指示这些聚合中可以支持的性能服务级别方面的功能。在卷上调配工作负载时，可以查看聚合支持特定性能服务级别的功能，并根据该功能调配工作负载。只有在使用 API 调配工作负载时，才能指定聚合。此功能在 Unified Manager Web UI 上不可用。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
GET
 a| 
`/storage-provider/aggregate-capabilities`

`/storage-provider/aggregate-capabilities/\{key}`

|===
