= 使用 Active IQ Unified Manager 中的 API 管理访问端点
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您需要创建访问端点或逻辑接口 (LIF)，这是配置 Storage Virtual Machine (SVM)、LUN 和文件共享所必需的。您可以在 Active IQ Unified Manager 环境中查看、创建、修改和删除 SVM、LUN 或文件共享的访问端点。



[[view-access-endpoints]]
== 查看访问端点

您可以使用以下方法查看 Unified Manager 环境中的访问端点列表。要查询特定 SVM、LUN 或文件共享的访问端点列表，需要输入 SVM、LUN 或文件共享的唯一标识符。您还可以输入唯一访问端点密钥以检索特定访问端点的详细信息。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
GET
 a| 
`/storage-provider/access-endpoints`

`/storage-provider/access-endpoints/\{key}`

|===


[[add-access-endpoints]]
== 添加访问端点

您可以创建自定义访问端点并为其分配所需的属性。您必须输入要创建的访问端点的详细信息作为输入参数。您可以使用此 API，或者 System Manager 或 ONTAP CLI 在每个节点上创建访问端点。创建访问端点支持 IPv4 和 IPv6 地址。

[NOTE]
====
您必须为 SVM 配置每个节点最小数量的访问端点，才能成功配置 LUN 和文件共享。您应该为 SVM 在每个节点上配置至少两个访问端点，一个支持 CIFS 和/或 NFS 协议，另一个支持 iSCSI 或 FCP 协议。

====
[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
POST
 a| 
`/storage-provider/access-endpoints`

|===


[[delete-access-endpoints]]
== 删除访问端点

可以使用以下方法删除特定的访问端点。需要提供访问端点密钥作为输入参数来删除特定访问端点。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
DELETE
 a| 
`/storage-provider/access-endpoints/\{key}`

|===


[[modify-access-endpoints]]
== 修改访问端点

您可以使用以下方法修改访问端点并更新其属性。您需要提供访问端点密钥才能修改特定访问端点。您还需要输入要更新的属性及其值。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
PATCH
 a| 
`/storage-provider/access-endpoints/\{key}`

|===
