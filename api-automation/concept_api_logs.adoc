= 使用 Active IQ Unified Manager 中的系统日志进行故障排除
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
系统日志可用于分析运行 API 时可能出现的故障原因和故障排除问题。

从以下位置检索日志，以解决与 API 调用相关的问题。

[cols="2*"]
|===
| 日志位置 | 用途 


 a| 
`/var/log/ocie/access_log.log`
 a| 
包含所有 API 调用详细信息，例如调用 API 的用户的用户名、开始时间、执行时间、状态和 URL。

您可以使用此日志文件检查常用 API，或对任何 GUI 工作流进行故障排除。您还可以根据执行时间使用它进行缩放分析。



 a| 
`/var/log/ocum/ocumserver.log`
 a| 
包含所有 API 执行日志。

您可以使用此日志文件对 API 调用进行故障排除和调试。



 a| 
`/var/log/ocie/server.log`
 a| 
包含所有 Wildfly 服务器部署和启动/停止服务相关日志。

您可以使用此日志文件查找在 Wildfly 服务器的启动、停止或部署期间发生的任何问题的根本原因。



 a| 
`/var/log/ocie/au.log`
 a| 
包含与采集单元相关的日志。

当您在 ONTAP 中创建、修改或删除了任何对象，但它们未反映在 Active IQ Unified Manager REST API 中时，您可以使用此日志文件。

|===
