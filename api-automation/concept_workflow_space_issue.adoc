= 使用 Active IQ Unified Manager API 确定聚合中的空间问题
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Active IQ Unified Manager 中的数据中心 API 来监控卷中空间的可用性和利用率。您可以确定卷中的空间问题，并识别过度使用或未充分使用的存储资源。

用于聚合的数据中心 API 检索有关可用和已用空间以及节省空间效率设置的相关信息。您还可以根据指定的属性筛选检索到的信息。

确定聚合中是否缺少空间的一种方法是验证环境中是否存在启用了 autosize-mode 的卷。然后，您应该识别哪些卷被过度使用，并执行任何纠正措施。

以下流程图说明了检索有关启用了 autosize-mode 的卷的信息的过程：

image::../media/space_utilization.gif[用于识别集群聚合中过度使用的启用了自动调整大小模式的卷的流程图]

此流程假设集群已在 ONTAP 中创建并添加到 Unified Manager 中。

. 获取集群密钥，除非您知道其值：
+
[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
数据中心
 a| 
GET
 a| 
`/datacenter/cluster/clusters`

|===
. 使用集群键作为筛选参数，查询该集群上的聚合。
+
[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
数据中心
 a| 
GET
 a| 
`/datacenter/storage/aggregates`

|===
. 从响应中，分析聚合的空间使用情况，并确定哪些聚合存在空间问题。对于每个存在空间问题的聚合，请从同一个 JSON 输出中获取聚合键。
. 使用每个聚合键，筛选所有卷，其 autosize.mode 参数值为 `grow.`
+
[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
数据中心
 a| 
GET
 a| 
`/datacenter/storage/volumes`

|===
. 分析哪些卷被过度使用。
. 执行任何必要的纠正措施，例如跨聚合移动卷，以解决卷中的空间问题。您可以从 ONTAP 或 Unified Manager Web UI 执行这些操作。
