= 在 Active IQ Unified Manager 中使用 API 管理 Active Directory 映射
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用此处列出的 API 来管理 SVM 上的 Active Directory 映射，这是在 SVM 上调配 CIFS 共享所必需的。需要配置 Active Directory 映射，以便将 SVM 与 ONTAP 进行映射。



[[view-active-directory-mappings]]
== 查看 Active Directory 映射

您可以通过以下方法查看 SVM Active Directory 映射的配置详细信息。要在 SVM 上查看 Active Directory 映射，需要输入 SVM 密钥。要查询特定映射的详细信息，必须输入映射密钥。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
GET
 a| 
`/storage-provider/active-directories-mappings`

`/storage-provider/active-directories-mappings/\{key}`

|===


[[add-active-directory-mapping]]
== 添加 Active Directory 映射

您可以使用以下方法在 SVM 上创建 Active Directory 映射。您必须输入映射详细信息作为输入参数。

[cols="3*"]
|===
| 类别 | HTTP 谓词 | 路径 


 a| 
storage-provider
 a| 
POST
 a| 
`/storage-provider/active-directories-mappings`

|===
