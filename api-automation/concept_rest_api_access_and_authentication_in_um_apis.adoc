:icons: font
:imagesdir: ../media/

+
** `_IP address/hostname_` 是 API 服务器的 IP 地址或完全限定的域名（FQDN）。
** 端口 443
+
443 是默认的 HTTPS 端口。如果需要，您可以自定义 HTTPS 端口。



+
要从 Web 浏览器发出 HTTP 请求，您必须使用 REST API 浏览器插件。您还可以使用脚本平台（如 cURL 和 Perl）访问 REST API。





[[authentication]]
== 身份验证

Unified Manager 支持 API 的基本 HTTP 身份验证方案。为了确保信息流（请求和响应）的安全，REST API 只能通过 HTTPS 访问。API 服务器向所有客户端提供自签名 SSL 证书以进行服务器验证。此证书可由自定义证书（或 CA 证书）替换。

必须配置用户对 API 服务器的访问权限以调用 REST API。用户可以是本地用户（存储在本地数据库中的用户配置文件）或 LDAP 用户（如果已将 API 服务器配置为通过 LDAP 进行身份验证）。您可以通过登录到 Unified Manager 管理控制台用户界面来管理用户访问。
