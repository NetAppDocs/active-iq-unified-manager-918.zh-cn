= 了解 Active IQ Unified Manager 的虚拟基础架构和硬件要求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在虚拟基础架构或物理系统上安装 Unified Manager 应满足内存、CPU 和磁盘空间的最低要求。

下表显示了建议的内存、CPU 和磁盘空间资源值。这些值已经过验证，以确保 Unified Manager 达到可接受的性能水平。

[cols="2*"]
|===
| 硬件配置 | 建议的设置 


 a| 
RAM
 a| 
12 GB



 a| 
处理器
 a| 
4 个 CPU



 a| 
CPU 周期容量
 a| 
总共 9572 MHz（最低要求 9572 MHz）



 a| 
可用磁盘空间
 a| 
150 GB，其中容量分配如下：

* 安装目录的 100 GB 磁盘空间
* 用于 MySQL 数据目录的 50 GB 磁盘空间


|===
Unified Manager 可以安装在内存较小的系统上，但建议使用 12 GB RAM，以确保有足够的内存来实现最佳性能，并使系统能够在配置增长时容纳更多的集群和存储对象。您不应在部署 Unified Manager 的虚拟机上设置任何内存限制，也不应启用任何阻碍软件利用系统上分配的内存的功能（例如内存气球机制）。

此外，在安装 Unified Manager 的第二个实例之前，Unified Manager 的单个实例可以监视的节点数是有限制的。有关节点限制、CPU 和内存建议，请参阅 https://www.netapp.com/pdf.html?item=/media/13504-tr4621.pdf["Unified Manager 最佳实践指南"^]。

内存页面交换会对系统和管理应用程序的性能产生负面影响。竞争由于整体主机利用率而无法使用的 CPU 资源可能会降低性能。



[[requirement-for-dedicated-use]]
== 专用要求

安装 Unified Manager 的物理或虚拟系统应专门用于 Unified Manager，不应与其他应用程序共享。其他应用程序可能会消耗系统资源，并可能大幅降低 Unified Manager 的性能。



[[space-requirements-for-backups]]
== 备份的空间要求

如果您计划使用 Unified Manager 备份和还原功能，请分配额外的容量，以便“`data`”目录或磁盘具有 150 GB 的空间。备份可以写入本地目标或远程目标。最佳做法是确定 Unified Manager 主机系统外部具有至少 150 GB 空间的远程位置。



[[requirements-for-host-connectivity]]
== 主机连接要求

安装 Unified Manager 的物理系统或虚拟系统应进行相应配置，以便您可以从主机本身成功 `ping`主机名。如果是 IPv6 配置，您应验证对主机名的 `ping6`是否成功，以确保 Unified Manager 安装成功。

您可以使用主机名（或主机 IP 地址）访问产品 Web UI。如果在部署期间为网络配置了静态 IP 地址，则您已为网络主机指定了名称。如果使用 DHCP 配置了网络，则应从 DNS 获取主机名。

如果您计划允许用户使用短名称而不是使用完全限定的域名（FQDN）或 IP 地址来访问 Unified Manager，则您的网络配置必须将此短名称解析为有效的 FQDN。
