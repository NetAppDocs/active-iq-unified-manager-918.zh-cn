= 在 Active IQ Unified Manager 中更改 Windows 上的 JBoss 密码
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以重置在安装过程中设置的特定于实例的 JBoss 密码。如果您的站点需要此安全功能来覆盖 Unified Manager 安装设置，您可以选择重置密码。此操作还会更改 JBoss 用于访问 MySQL 的密码。

.开始之前
* 您应具有安装 Unified Manager 的系统的 Windows 管理员权限。
* 您应该拥有 MySQL root 用户的密码。
* 您应该能够访问目录中由 NetApp 提供的 `password.bat`脚本
+
`C:\Program Files\NetApp\essentials\bin`。



.步骤
. 以 admin 用户身份登录到 Unified Manager 主机。
. 使用 Windows 服务控制台停止以下 Unified Manager 服务：
+
** NetApp Active IQ 采集服务（Ocie-au）
** NetApp Active IQ 管理服务器服务（Oncommandsvc）


. 启动  `password.bat` 脚本以开始密码更改过程：
+
`C:\Program Files\NetApp\essentials\bin> password.bat resetJBossPassword`

. 出现提示时，输入 MySQL root 用户密码。
. 出现提示时，请输入新的 JBoss 用户密码，然后再次输入以确认。
+
请注意，密码应介于 8 到 16 个字符之间，必须至少包含一个数字、一个大写字母和一个小写字母，并且必须至少包含以下特殊字符之一：

+
`+!@%^*-_+=[]:<>.?/~+`

. 脚本完成后，使用 Windows 服务控制台启动 Unified Manager 服务：
+
** NetApp Active IQ 管理服务器服务（Oncommandsvc）
** NetApp Active IQ 采集服务（Ocie-au）


. 所有服务启动后，您可以登录到 Unified Manager UI。
