= 在 Windows 上升级 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以通过在 Windows 平台上下载并运行安装文件，将 Unified Manager 9.14 或 9.16 升级到 9.18。

.开始之前
* 您要升级 Unified Manager 的系统应满足系统和软件要求。
+
请参阅 link:concept_virtual_infrastructure_or_hardware_system_requirements.html["硬件系统要求"]。

+
请参阅 link:reference_windows_software_and_installation_requirements.html["Windows 软件和安装要求"]。

+
[NOTE]
====
从 Unified Manager 9.5 开始，安装包中提供了 OpenJDK 并会自动安装。从 Unified Manager 9.5 开始，不再支持 Oracle Java。

====
+
[NOTE]
====
开始升级之前，请确保系统上已安装 Microsoft .NET 4.5.2 或更高版本。

====
* MySQL Community Edition 在 Unified Manager 升级期间自动升级。如果系统上安装的 MySQL 版本早于 8.4.10，则 Unified Manager 升级过程会自动将 MySQL 升级到 8.4.10。您不得对早期版本的 MySQL 单独执行升级至 8.4.10 的操作。
* 除 ASA r2 系统外，支持所有集群。
* 您应具有 Windows 管理员权限。请确保您的用户名不以感叹号“`!`". Installation of Unified Manager might fail if the user name of user running the installation begins with "`!`”开头。
* 您应具有有效的凭据才能登录到 NetApp 支持站点。
* 为了避免数据丢失，您应该已经创建了 Unified Manager 计算机的备份，以防在升级期间出现问题。
* 您应该有足够的磁盘空间来执行升级。
+
安装驱动器上的可用空间应比数据目录的大小大 2.5 GB。如果可用空间不足，升级将停止并显示一条错误消息，指示要添加的空间量。

* 在升级期间，系统可能会提示您确认是要保留先前将性能数据保留 13 个月的默认设置，还是将其更改为 6 个月。确认后，超过 6 个月的历史性能数据将被清除。
* 在升级之前，应关闭_<InstallDir>\JDK_和_MySQL 数据目录_中任何打开的文件或文件夹。
* 如果您的 Windows 系统上安装了活动的防病毒软件，则 Unified Manager 升级可能会失败。在升级 Unified Manager 之前，应禁用系统中的所有病毒扫描软件。


在升级过程中，Unified Manager 不可用。在升级 Unified Manager 之前，您应完成所有正在运行的操作。

如果 Unified Manager 与 OnCommand Workflow Automation 实例配对，并且这两种产品都有可用的新版本软件，则必须断开这两种产品的连接，然后在执行升级后设置新的 Workflow Automation 连接。如果您仅对其中一款产品执行升级，则应在升级后登录 Workflow Automation，并验证其是否仍在从 Unified Manager 获取数据。

.步骤
. 登录到 NetApp 支持站点，然后导航到 Unified Manager 的下载页面：
+
https://mysupport.netapp.com/site/products/all/details/activeiq-unified-manager/downloads-tab["NetApp 支持站点"^]。

. 选择所需的 Unified Manager 版本并接受最终用户许可协议（EULA）。
. 将 Unified Manager Windows 安装文件或 zip 文件下载到 Windows 系统上的目标目录。如果需要，请提取 zip 文件，然后导航到安装文件所在的目录。右键单击并以管理员身份运行 Unified Manager 安装程序可执行文件（.exe）。
+
Unified Manager 将提示您以下消息：

+
[listing]
----
This setup will perform an upgrade of Unified Manager. Do you want to continue?
----
. 单击*是*，然后单击*下一步*。
. 输入安装过程中设置的 MySQL84 root 密码，然后单击 *下一步*。
. 在受支持的 Web 浏览器上的新窗口中启动 Web UI，然后登录以使用升级版本的 Unified Manager。
. 如果您的 Windows 系统上安装了处于活动状态的防病毒软件，请确保在升级完成后从防病毒扫描中手动排除以下路径：
+
** Unified Manager 数据目录
** Unified Manager 安装目录
** MySQL 数据目录




[NOTE]
====
要执行 Unified Manager 的静默升级，请运行以下命令：
`ActiveIQUnifiedManager-<version\>.exe /s /v"MYSQL_PASSWORD=<password> /qn /l*v <system_drive>:\install.log"`

====
