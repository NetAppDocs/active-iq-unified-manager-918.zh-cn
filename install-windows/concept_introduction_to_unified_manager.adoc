= 了解Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager（以前称为 OnCommand Unified Manager）使您能够从单个界面监控和管理 ONTAP 存储系统的运行状况和性能。您可以在 Linux 服务器、Windows 服务器或 VMware 主机上作为虚拟应用装置部署 Unified Manager。

完成安装并添加要管理的集群后，Unified Manager 将提供显示受监视存储系统的容量、可用性、保护和性能状态的图形界面。
