= 在 Windows 上安装 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以安装 Unified Manager 来监控和排除数据存储容量、可用性、性能和保护问题。

.开始之前
* 您计划安装 Unified Manager 的系统应满足系统和软件要求。
+
请参阅 link:concept_virtual_infrastructure_or_hardware_system_requirements.html["硬件系统要求"]。

+
请参阅 link:reference_windows_software_and_installation_requirements.html["Windows 软件和安装要求"]。

+
[NOTE]
====
从 Unified Manager 9.5 开始，安装包中提供了 OpenJDK 并会自动安装。从 Unified Manager 9.5 开始，不再支持 Oracle Java。

====
* 您应具有 Windows 管理员权限。请确保您的用户名不以感叹号“`!`". Installation of Unified Manager might fail if the user name of user running the installation begins with "`!`”开头。
* 支持所有集群，但 ASA r2 系统除外。
* 您应具有受支持的 Web 浏览器。
* Unified Manager 维护用户密码应介于 8 到 20 个字符之间，应包含大写字母或小写字母、数字和特殊字符。
* 维护用户或 MySQL root 用户的密码字符串中不允许使用以下特殊字符：" ' ` % , = & < > | ^ \ / ( ) [ ] ;:
+
允许使用以下特殊字符：~ ! @ # $ * - ? .+ { }



.步骤
. 使用默认本地管理员帐户登录到 Windows。
. 登录到 NetApp 支持站点，然后导航到 Unified Manager 的下载页面：
+
https://mysupport.netapp.com/site/products/all/details/activeiq-unified-manager/downloads-tab["NetApp 支持站点"^]

. 选择所需的 Unified Manager 版本并接受最终用户许可协议（EULA）。
. 将 Unified Manager Windows 安装文件或 zip 文件下载到 Windows 系统上的目标目录。
. 如果需要，请提取 zip 文件，然后导航到安装文件所在的目录。
. 右键单击并以管理员身份运行 Unified Manager 安装程序可执行文件（.exe）。
+
Unified Manager 检测缺失或预安装的第三方软件包并将其列出。如果系统中未安装所需的第三方软件包，Unified Manager 会在安装过程中将其安装。

. 单击*下一步*。
. 输入用户名和密码以创建维护用户。
. 在数据库连接向导中，输入 MySQL root 密码。
. 单击*更改*以指定 Unified Manager 安装目录和 MySQL 数据目录的新位置。
+
如果不更改安装目录，则将在默认安装目录中安装 Unified Manager。

. 单击*下一步*。
. 在 Ready to Install Shield 向导中，单击 *Install*。
. 安装完成后，单击 *Finish*。
. 如果您的 Windows 系统上安装了活动的防病毒软件，请在安装完成后从防病毒扫描中手动排除以下路径：
+
** Unified Manager 数据目录
** Unified Manager 安装目录
** MySQL 数据目录




安装将创建多个目录：

* 安装目录
+
这是在安装过程中指定的 Unified Manager 的根目录。示例： `C:\Program Files\NetApp\`

* MySQL 数据目录
+
这是存储 MySQL 数据库的目录，您在安装过程中指定了此目录。示例： `C:\ProgramData\MySQL\MySQLServerData\`

* Java 目录
+
这是安装 OpenJDK 的目录。示例： `C:\Program Files\NetApp\JDK\`

* Unified Manager 应用程序数据目录（appDataDir）
+
这是存储所有应用程序生成的数据的目录。这包括日志、支持捆绑包、备份和所有其他附加数据。示例： `C:\ProgramData\NetApp\OnCommandAppData\`



您可以访问 Web UI 以执行 Unified Manager 的初始设置，如 link:../config/concept_configure_unified_manager.html["配置 Active IQ Unified Manager"] 中所述。
