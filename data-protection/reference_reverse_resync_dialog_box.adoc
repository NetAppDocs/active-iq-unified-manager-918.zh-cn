= 在 Active IQ Unified Manager 中反向重新同步
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果由于源卷被禁用而导致保护关系中断，并且目标卷被设置为读/写卷，则反向重新同步将使您能够反转关系方向，从而使目标卷成为新的源卷，并且源卷将成为新的目标卷。

当灾难导致保护关系中的源卷不可用时，您可以将目标卷转换为读/写模式来提供数据，同时修复或更换源、更新源并重新建立关系。当您执行反向重新同步操作时，源上比通用 Snapshot 副本上的数据更新的数据将被删除。



[[before-reverse-resync]]
== 反向重新同步之前

在反向重新同步操作之前显示关系的源和目标。

* *源卷*
+
反向重新同步操作之前的源卷的名称和位置。

* *目标卷*
+
反向重新同步操作之前目标卷的名称和位置。





[[after-reverse-resync]]
== 反向重新同步之后

显示保留重新同步操作后关系的源和目标。

* *源卷*
+
反向重新同步操作后源卷的名称和位置。

* *目标卷*
+
反向重新同步操作后目标卷的名称和位置。





[[command-buttons]]
== 命令按钮

通过命令按钮，您可以执行以下操作：

* *提交*
+
开始反向重新同步过程。

* *取消*
+
关闭“反向重新同步”对话框，而不启动反向重新同步操作。
