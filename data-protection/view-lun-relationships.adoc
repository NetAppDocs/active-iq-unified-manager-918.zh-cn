= 在 Active IQ Unified Manager 中监控一致性组 LUN 关系
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您的 ONTAP 环境支持 SnapMirror 主动同步以保护具有 LUN 的应用程序，则可以在 Active IQ Unified Manager 上查看和监控这些 LUN。

SnapMirror 主动同步可确保在 SAN 环境中故障转移期间实现零恢复时间目标（RTO）。在支持 SnapMirror 主动同步的典型部署中，卷上的 LUN 受一致性组关系保护。

这些主 LUN 和辅助 LUN 是复合 LUN，或者是具有相同 UUID 和序列号的副本 LUN 对。I/O 操作（读取和写入）在这些复合 LUN 上的源站点和目标站点之间进行多路复用，以确保透明度。

要查看复合 LUN，应在 Unified Manager 上添加并发现包含属于一致性组关系的 LUN 的主集群和辅助集群。仅支持 iSCSI 和 FCP LUN。

有关 SnapMirror 活动同步的信息，请参见 link:https://docs.netapp.com/us-en/ontap/smbc/index.html["ONTAP 9 SnapMirror 活动同步文档（以前称为 SM-BC）"]。

要查看环境中的复合 LUN，请按照以下步骤操作：

.步骤
. 在左侧导航窗格中，单击*存储* > *LUN*。
. 在视图菜单中，选择 *关系* > *所有 LUN*。
+
此时将显示 Relationship: All LUNs 视图。



您可以查看 LUN 详细信息，例如 LUN 名称、卷、托管 LUN 的存储 VM、集群、一致性组和配对 LUN。您可以单击这些组件中的每一个以深入查看详细视图。单击一致性组将转到“关系”页面。

通过单击伙伴 LUN，您可以在托管伙伴 LUN 的存储 VM 的 Storage VM Details 页面的 SAN 选项卡上查看其配置详细信息。此时将显示启动器和启动器组以及伙伴 LUN 的其他方面等信息。

您可以执行标准网格级功能，对环境中的受保护 LUN 进行排序、筛选、生成和上传报告。
