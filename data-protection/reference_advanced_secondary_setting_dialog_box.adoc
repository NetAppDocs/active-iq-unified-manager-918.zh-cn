= 使用 Active IQ Unified Manager 中的"高级二级设置"对话框
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用“高级辅助设置”对话框在辅助卷上启用版本灵活的复制、多副本备份和与空间相关的设置。当您想要更改、启用或禁用当前设置时，可以使用“高级辅助设置”对话框。

空间相关设置会最大化存储的数据量，包括：重复数据删除、数据压缩、自动增长和空间保证。

对话框包括以下字段：

* *启用版本灵活的复制*
+
启用具有版本灵活复制功能的 SnapMirror。版本灵活的复制可实现对源卷的 SnapMirror 保护，即使目标卷运行的 ONTAP 版本早于源卷。

+
** 启用备份
+
如果启用了版本灵活的复制，则还可以将 SnapMirror 源数据的多个快照副本传输并保留在 SnapMirror 目标上。



* *启用重复数据删除*
+
在 SnapVault 关系中的辅助卷上启用重复数据删除，从而消除重复数据块以节省空间。当节省的空间至少为 10% 并且数据覆盖率不高时，您可以使用重复数据删除。重复数据删除通常用于虚拟化环境、文件共享和备份数据。默认情况下，此设置处于禁用状态。启用后，此操作将在每次传输后启动。

+
** 启用数据压缩
+
启用透明数据压缩。当节省的空间至少为 10% 时，当潜在的开销可以接受时，以及当有足够的系统资源在非高峰时段完成压缩时，您可以使用压缩。在 SnapVault 关系中，默认情况下会禁用此设置。仅当选择了重复数据删除时，压缩才可用。

** 实时数据压缩
+
通过在将数据写入磁盘之前压缩数据来实现即时的空间节省。当您的系统在高峰时段的利用率不超过 50%，并且系统可以在高峰时段容纳新的写入和额外的 CPU 时，您可以使用内联压缩。此设置仅在选择 "`启用压缩`" 时可用。



* *启用自动增长*
+
允许您在可用空间百分比低于指定阈值时自动扩展目标卷，前提是关联聚合中有可用空间。

* *最大大小*
+
设置卷可以增长到的最大百分比。默认值为比源卷大小大 20%。如果当前大小大于或等于最大自动增长百分比，则卷不会自动增长。仅当启用了自动增长设置时，才会启用此字段。

* *增量大小*
+
指定在达到源卷的最大百分比之前，卷自动增长的百分比增量。

* *空间保证*
+
确保在辅助卷上分配足够的空间，以便数据传输始终成功。空间保障设置可为以下选项之一：

+
** 文件
** 卷
** 无 + 例如，您可能有一个 200 GB 的卷，其中包含总共 50 GB 的文件；但是，这些文件仅包含 10 GB 的数据。无论源上的内容如何，卷保证都会将 200 GB 分配给目标卷。文件保证分配 50 GB，以确保为源上的文件保留足够的空间；在这种情况下，选择“无”意味着在目标上仅为源上文件数据使用的实际空间分配 10 GB。


+
默认情况下，空间保证设置为 Volume。





[[command-buttons]]
== 命令按钮

这些命令按钮可用来执行下列任务：

* *应用*
+
保存选定的效率设置，并在“配置保护”对话框中单击 *应用* 时应用它们。

* *取消*
+
放弃您的选择并关闭“高级目标设置”对话框。
