= 在 Active IQ Unified Manager 中创建具有版本灵活复制功能的 SnapMirror 关系
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用版本灵活的复制创建 SnapMirror 关系。版本灵活的复制使您能够实施 SnapMirror 保护，即使源卷和目标卷运行不同版本的 ONTAP。

.开始之前
* 您必须具有应用程序管理员或存储管理员角色。
* 您必须已设置 Workflow Automation。
* 源和目标 SVM 都必须启用 SnapMirror 许可证。
* 源和目标 SVM 必须各自在支持版本灵活复制的 ONTAP 软件版本下运行。


采用版本灵活复制的 SnapMirror 使您即使在并非所有存储都运行在同一版本 ONTAP 下的异构存储环境中，也能实施 SnapMirror 保护；但是，在采用版本灵活复制的 SnapMirror 下执行的镜像操作，其执行速度不如在传统数据块复制 SnapMirror 下执行得快。

.步骤
. 显示要保护的卷的*配置保护*对话框。
+
** 如果正在查看“卷/运行状况详细信息”页面的“保护”选项卡，请在具有要保护的卷名称的拓扑视图中单击鼠标右键，然后从菜单中选择 *保护* > *SnapMirror*。
** 如果正在查看“运行状况：所有卷”视图，请找到要保护的卷并右键单击它；然后从菜单中选择 *保护* > *SnapMirror*。此时将显示“配置保护”对话框。


. 单击 *SnapMirror* 以查看 *SnapMirror* 选项卡。
. 在*配置保护*对话框中填写*目标信息*区域和*关系设置*区域。
+
如果指定的目标 SVM 运行的 ONTAP 版本早于您要保护的源卷，并且该早期版本支持版本灵活的复制，则此任务会自动将 SnapMirror 配置为使用版本灵活的复制。

. 如果您指定的目标 SVM 运行的 ONTAP 版本与源卷相同，但您仍希望配置具有版本灵活复制功能的 SnapMirror，请单击 *高级* 以启用版本灵活的复制，然后单击 *应用*。
. 单击*应用*。
+
将返回到卷/运行状况详细信息页面。

. 单击 *Volume / Health* 详细信息页面顶部的保护配置作业链接。
+
作业任务和详细信息显示在作业详细信息页面中。

. 在*作业*详细信息页面中，单击*刷新*以更新与保护配置作业关联的任务列表和任务详细信息，并确定作业何时完成。
. 作业任务完成后，单击浏览器上的 *返回* 以返回 *卷 / 运行状况* 详细信息页面。
+
新关系将显示在卷/运行状况详细信息页面拓扑视图中。
