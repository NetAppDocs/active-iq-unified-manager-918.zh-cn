= 在 Active IQ Unified Manager 中管理 Storage VM 关联
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Storage virtual machine (storage VM) 关联是从源存储虚拟机到目标存储虚拟机的映射，合作伙伴应用程序将其用于资源选择和辅助卷配置。

无论目标 Storage VM 是辅助目标还是第三目标，都会在源 Storage VM 和目标 Storage VM 之间创建关联。您不能使用辅助目标 Storage VM 作为源来创建与第三目标 Storage VM 的关联。

作为应用程序管理员或存储管理员，您可以在 *保护* > *存储 VM 关联* 页面上查看环境中的存储 VM 关联。

您可以通过三种方式关联 SVM：

* *关联任何存储虚拟机*：您可以在任何主源存储虚拟机和一个或多个目标 SVM 之间创建关联。这意味着当前需要保护的所有现有 SVM 以及未来创建的任何 SVM 都与指定的目标 SVM 相关联。例如，您可能希望将来自不同位置的多个不同来源的应用程序备份到一个位置中的一个或多个目标 SVM。
* *关联特定存储 VM*：可以在特定源存储 VM 和一个或多个特定目标 SVM 之间创建关联。例如，如果要向许多客户端提供存储服务，而这些客户端的数据必须彼此独立，则可以选择此选项将特定源存储 VM 关联到仅分配给该客户端的特定目标存储 VM。
* *与外部存储虚拟机关联*：您可以在源存储虚拟机与目标存储虚拟机的外部灵活卷之间创建关联。




[[create-storage-vm-associations]]
== 创建存储 VM 关联

Create Storage Virtual Machine Associations 向导使合作伙伴保护应用程序能够将源存储虚拟机与目标存储虚拟机关联，以便与 SnapMirror 和 SnapVault 关系一起使用。合作伙伴应用程序在初始配置目标卷时使用这些关联来确定要选择哪些资源。dd

.开始之前
* 您要关联的存储 VM 必须已存在。
* 您必须具有应用程序管理员或存储管理员角色。


对于任何源存储虚拟机和关系类型，您在每个目标集群上只能选择一个目标存储虚拟机。

使用“删除”和“创建”功能更改关联仅会影响将来的配置操作。它不会移动现有目标卷。

.步骤
. 在左侧导航窗格中，单击*保护* > *存储虚拟机关联*。
. 在 *Storage VM Associations* 页面上，单击 *Create*。
+
*创建 Storage Virtual Machine 关联*向导已启动。

. 选择以下源之一：
+
** *任意*
+
如果要在任何主存储 VM 源与一个或多个目标存储 VM 之间创建关联，请选择此选项。这意味着当前需要保护的所有现有存储 VM 以及将来创建的任何存储 VM 都与指定的目标存储 VM 关联。例如，您可能希望将来自不同位置的多个不同源的应用程序备份到一个位置中的一个或多个目标存储 VM。

** *单个*
+
如果要选择与一个或多个目标存储 VM 关联的特定源存储 VM，请选择此选项。例如，如果要向许多数据必须彼此分离的客户端提供存储服务，请选择此选项将特定存储 VM 源关联到仅分配给该客户端的特定存储 VM 目标。

** *无（外部）*
+
如果要在源存储 VM 和目标存储 VM 的外部灵活卷之间创建关联，请选择此选项。



. 选择要创建的一个或两个保护关系类型：
+
** *SnapMirror*
** *SnapVault*


. 单击*下一步*。
. 选择一个或多个 storage VM 保护目标。
. 单击 *Finish*。




[[delete-storage-vm-associations]]
== 删除 storage VM 关联

您可以删除伙伴应用程序的存储虚拟机关联，以移除源和目标存储虚拟机之间的辅助配置关系；例如，当目标存储虚拟机已满并且您要创建新的存储虚拟机保护关联时，可以执行此操作。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

在至少选择一个存储 VM 关联之前，*删除* 按钮将被禁用。使用删除和创建功能更改关联仅影响未来的配置操作；它不会移动现有目标卷。

.步骤
. 在左侧导航窗格中，单击*保护* > *存储虚拟机关联*。
. 至少选择一个存储 VM 关联。
+
*删除*按钮已启用。

. 单击 *Delete*。
+
此时将显示警告对话框。

. 单击 *Yes* 继续。
+
选定的 Storage VM 关联将从列表中删除。
