= 在 Active IQ Unified Manager 中使用“创建 SnapVault 策略”对话框
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
可使用“创建 SnapVault 策略”对话框创建策略以设置 SnapVault 传输的优先级。可使用策略最大限度地提高从主卷到辅助卷的传输效率。

* *目标集群*
+
您在“配置保护”对话框的 SnapVault 选项卡中选择的集群名称。

* *目标 SVM*
+
在“配置保护”对话框的 SnapVault 选项卡中选择的 SVM 名称。

* *Policy Name*
+
您为新策略提供的名称。策略名称可以由字符 A 到 Z、a 到 z、0 到 9、句点（.）、连字符（-）和下划线（_）组成。

* *传输优先级*
+
传输运行的优先级。您可以选择“正常”或“低”。具有指定正常传输优先级策略的传输关系会在具有指定低传输优先级策略的传输关系之前运行。默认设置为“正常”。

* *Comment*
+
一个可选字段，您可以在其中添加最多 255 个字符的有关 SnapVault 策略的注释。

* *忽略访问时间*
+
指定对于仅更改了访问时间的文件，是否忽略增量传输。

* *复制标签*
+
在表格中列出与 ONTAP 选择的 Snapshot 副本关联的规则，这些副本在策略中具有特定的复制标签。还提供以下信息和操作：

+
** 命令按钮
+
通过命令按钮，您可以执行以下操作：

+
*** 添加
+
使您能够创建 Snapshot 副本标签和保留计数。

*** 编辑保留数量
+
使您能够更改现有 Snapshot 副本标签的保留计数。保留计数必须为介于 1 到 251 之间的数字。所有规则的所有保留计数之和不得超过 251。

*** 删除
+
使您能够删除现有 Snapshot 副本标签。



** Snapshot 副本标签
+
显示 Snapshot 副本标签。如果选择具有相同本地 Snapshot 副本策略的一个或多个卷，则会显示该策略中每个标签的条目。如果选择具有两个或多个本地 Snapshot 副本策略的多个卷，则该表将显示所有策略中的所有标签

** 计划
+
显示与每个 Snapshot 副本标签关联的计划。如果一个标签有多个与其关联的计划，则该标签的计划将以逗号分隔的列表显示。如果选择具有相同标签但具有不同计划的多个卷，计划将显示 "`Various`"，以指示多个计划与所选卷相关联。

** 目标保留数量
+
显示在 SnapVault 辅助上保留的具有指定标签的 Snapshot 副本数。具有多个计划的标签的保留计数显示每个标签和计划对的保留计数总和。如果选择具有两个或多个本地 Snapshot 副本策略的多个卷，则保留计数为空。
