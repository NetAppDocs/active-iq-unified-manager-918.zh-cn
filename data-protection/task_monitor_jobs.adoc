= 监控 Active IQ Unified Manager 中的作业
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用“作业”页面来监视作业状态并查看作业属性，例如存储服务类型、状态、提交时间和完成时间，以确定作业是否已成功完成。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

.步骤
. 在左侧导航窗格中，单击*保护* > *作业*。
+
此时将显示作业页面。

. 查看*状态*列以确定当前正在运行的那些作业的状态。
. 单击作业名称可查看该特定作业的详细信息。
+
此时将显示作业详细信息页面。
