= 了解 Active IQ Unified Manager 中的作业详细信息页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
作业详细信息页面使您能够查看有关正在运行、已排队或已完成的特定保护作业任务的状态和其他信息。您可以使用此信息来监控保护作业进度并排除作业故障。



[[job-summary]]
== 作业摘要

作业摘要显示以下信息：

* 作业 ID
* 类型
* 州/省
* 提交时间
* 完成时间
* 持续时间




[[command-buttons]]
== 命令按钮

这些命令按钮可用来执行下列任务：

* *刷新*
+
刷新任务列表以及与每个任务关联的属性。

* *查看作业*
+
将您返回到“作业”页面。





[[job-tasks-list]]
== 作业任务列表

“作业任务”列表在表格中显示与特定作业关联的所有任务以及与每个任务相关的属性。

* *开始时间*
+
显示任务开始的日期和时间。默认情况下，最新任务将显示在列顶端，旧任务将显示在底端。

* *类型*
+
显示任务类型。

* *State*
+
特定任务的状态：

+
** *已完成*
+
任务已完成。

** *已排队*
+
该任务即将运行。

** *运行中*
+
任务正在运行。

** *正在等待*
+
已提交作业，一些关联的任务正在等待排队和执行。



* *状态*
+
显示任务状态：

+
** *错误（image:../media/sev_error.gif[""]）*
+
任务失败。

** *正常（image:../media/sev_normal.gif[""]）*
+
任务成功。

** *已跳过（image:../media/icon_skipped.gif[""]）*
+
任务失败，导致后续任务被跳过。



* *持续时间*
+
显示自任务开始以来的运行时间。

* *完成时间*
+
显示任务完成的时间。默认情况下，此列处于隐藏状态。

* *任务 ID*
+
显示标识作业的单个任务的 GUID。可以对该列进行排序和筛选。默认情况下，此列处于隐藏状态。

* *依赖关系顺序*
+
显示一个表示图形中任务序列的整数，其中零被分配给第一个任务。默认情况下，此列处于隐藏状态。

* *任务详细信息窗格*
+
显示有关每个作业任务的其他信息，包括任务名称、任务描述以及（如果任务失败）失败的原因。

* *任务消息窗格*
+
显示特定于所选任务的消息。消息可能包含错误原因和解决建议。并非所有任务都显示任务消息。
