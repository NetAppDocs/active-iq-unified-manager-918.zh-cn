= 从 Active IQ Unified Manager 的"卷关系"页面反转保护关系
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当灾难导致保护关系中的源卷不可用时，您可以在修复或更换源卷期间，通过将目标卷转换为读/写卷来使用它提供数据。当源再次可用于接收数据时，您可以使用反向重新同步操作反向建立关系，将源上的数据与读/写目标上的数据进行同步。

.开始之前
* 您必须具有应用程序管理员或存储管理员角色。
* 您必须已设置 Workflow Automation。
* 此关系不得为 SnapVault 关系。
* 保护关系必须已存在。
* 必须中断保护关系。
* 源和目标必须处于联机状态。
* 源不能是其他数据保护卷的目标。
* 执行此任务时，源上比通用 Snapshot 副本上的数据更新的数据将被删除。
* 在反向重新同步关系上创建的策略和计划与原始保护关系上的策略和计划相同。
+
如果策略和计划不存在，则会创建这些策略和计划。



.步骤
. 从*卷关系*页面中，选择一个或多个具有要反向的关系的卷，然后在工具栏上单击*反向重新同步*。
+
此时将显示反向重新同步对话框。

. 验证*反向重新同步*对话框中显示的关系是否是要执行反向重新同步操作的关系，然后单击*提交*。
+
反向重新同步操作已启动，您将返回到卷关系页面，并在页面顶部显示作业链接。

. *可选：* 单击 *卷关系* 页面上的 *查看作业* 以跟踪每个反向重新同步作业的状态。
+
此时将显示与此操作相关的作业筛选列表。

. *可选：*单击浏览器上的*后退*箭头返回*卷关系*页面。
+
当所有作业任务成功完成时，反向重新同步操作完成。
