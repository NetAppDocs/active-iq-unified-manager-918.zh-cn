= 使用 Active IQ Unified Manager 中的还原对话框
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用“还原”对话框从特定 Snapshot 副本将数据还原到卷。



[[restore-from]]
== 还原自

通过“还原来源”区域，可以指定要从何处还原数据。

* *卷*
+
指定要从中还原数据的卷。默认情况下，将选择启动还原操作的卷。您可以从下拉列表中选择一个不同的卷，该列表包含与启动还原操作的卷具有保护关系的所有卷。

* *Snapshot 副本*
+
指定要用于还原数据的 Snapshot 副本。默认情况下，将选择最新的 Snapshot 副本。您还可以从下拉列表中选择其他 Snapshot 副本。Snapshot 副本列表会根据所选的卷而变化。

* *列出最多 995 个文件和目录*
+
默认情况下，列表中最多显示 995 个对象。如果要查看所选卷中的所有对象，可以取消选中此复选框。如果项目数量非常大，此操作可能需要一些时间。





[[select-items-to-restore]]
== 选择要还原的项

选择要还原的项目区域允许您选择要还原的整个卷或特定文件和文件夹。最多可以选择 10 个文件、文件夹或两者的组合。当选择的项目数量达到上限时，项目选择复选框将被禁用。

* *路径字段*
+
显示要还原的数据的路径。您可以导航到要还原的文件夹和文件，也可以键入路径。在您选择或键入路径之前，此字段为空。选择路径后，单击 image:../media/icon_upfolder.gif["向上文件夹图标"] 将使您在目录结构中向上移动一个级别。

* *文件夹和文件列表*
+
显示输入路径的内容。默认情况下，最初将显示根文件夹。单击文件夹名称将显示文件夹的内容。



您可以按以下方式选择要还原的项：

* 当您在路径字段中输入指定了特定文件名的路径时，指定的文件将显示在“文件夹和文件”中。
* 输入路径而不指定特定文件时，文件夹的内容将显示在“文件夹和文件”列表中，您可以选择最多 10 个文件、文件夹或两者的组合进行还原。
+
如果文件夹包含 995 个以上的项，则会显示一条消息，指示要显示的项过多，如果继续此操作，则将还原指定文件夹中的所有项。如果要查看所选卷中的所有对象，可以取消选中 "`最多列出 995 个文件和目录`" 复选框。



[NOTE]
====
您不能还原 NTFS 文件流。

====


[[restore-to]]
== 还原至

通过“还原到”区域，您可以指定要还原数据的位置。

* *Volume_Name 中的原始位置*
+
将所选数据还原到最初备份数据的源目录。

* *备用位置*
+
将所选数据还原到一个新位置：

+
** 还原路径
+
指定还原所选数据的替代路径。路径必须已存在。您可以使用 *Browse* 按钮导航到要还原数据的位置，也可以使用以下格式手动输入路径 `cluster://svm/volume/path`。

** 保留目录层次结构
+
选中后，保留原始文件或目录的结构。例如，如果源是 /A/B/C/myFile.txt，目标是 /X/Y/Z，则 Unified Manager 使用目标上的以下目录结构还原数据：/X/Y/Z/A/B/C/myFile.txt。







[[command-buttons]]
== 命令按钮

这些命令按钮可用来执行下列任务：

* *取消*
+
放弃选择并关闭“还原”对话框。

* *还原*
+
应用您的选择并开始还原过程。
