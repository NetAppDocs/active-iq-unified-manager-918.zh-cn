= 重新安装或升级 OnCommand Workflow Automation 如何影响 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在重新安装或升级 OnCommand Workflow Automation 之前，您必须首先删除 OnCommand Workflow Automation 和 Unified Manager 之间的连接，并确保停止当前正在运行或计划的所有 OnCommand Workflow Automation 作业。

您还必须从 OnCommand Workflow Automation 手动删除 Unified Manager。

重新安装或升级 OnCommand Workflow Automation 后，必须再次设置与 Unified Manager 的连接。
