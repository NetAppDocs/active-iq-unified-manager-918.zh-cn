= 配置 Workflow Automation 和 Active IQ Unified Manager 之间的连接
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以配置 OnCommand Workflow Automation (WFA) 和 Unified Manager 之间的安全连接。通过连接到 Workflow Automation，您可以使用 SnapMirror 和 SnapVault 配置工作流等保护功能，以及管理 SnapMirror 关系的命令。

.开始之前
* Workflow Automation 的安装版本必须为 5.1.1P6 或更高版本。
+
[NOTE]
====
"用于管理 Clustered Data ONTAP 的 WFA pack"包含在 WFA 5.1.1P6 中，因此无需像过去要求的那样从 NetAppStorage Automation Store 下载此包并将其单独安装到 WFA 服务器上。 https://mysupport.netapp.com/site/products/all/details/ocwfa/downloads-tab["WFA 下载"^]

====
* 您必须具有在 Unified Manager 中创建的数据库用户的名称，以支持 WFA 和 Unified Manager 连接。
+
此数据库用户必须已被分配集成架构用户角色。

* 必须在 Workflow Automation 中为您分配 Administrator 角色或 Architect 角色。
* 要进行 Workflow Automation 设置，您必须具有主机地址、端口号 443、用户名和密码。
* 您必须具有应用程序管理员或存储管理员角色。


.步骤
. 在左侧导航窗格中，单击*常规* > *Workflow Automation*。
. 在 *Workflow Automation 页面*的*数据库用户*区域中，选择名称，然后输入您为支持 Unified Manager 和 Workflow Automation 连接而创建的数据库用户的密码。
. 在页面的 *Workflow Automation Credentials* 区域中，输入主机名或 IP 地址（IPv4 或 IPv6），以及 Workflow Automation 设置的用户名和密码。
+
您必须使用 Unified Manager 服务器端口（端口 443）。

. 单击 *Save*。
. 如果使用自签名证书，请单击*是*以授权安全证书。
+
此时将显示 Workflow Automation 页面。

. 单击 *是* 重新加载 Web UI，并添加 Workflow Automation 功能。
