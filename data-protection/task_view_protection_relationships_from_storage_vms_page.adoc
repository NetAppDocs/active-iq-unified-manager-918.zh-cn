= 从 Active IQ Unified Manager 的 Storage VM 页面查看保护关系
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用“存储虚拟机”页面，您可以查看现有存储虚拟机的灾难恢复关系状态。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

您还可以查看保护关系的详细信息，包括传输和滞后状态、源和目标详细信息。您可以按所需格式计划报告或下载现有报告。*显示/隐藏*按钮使您能够将所需列添加到报告中，因为它们默认情况下不会显示。

.步骤
. 在左侧导航窗格中，单击 *存储* > *存储 VM*。
. 从*视图*菜单中，选择*关系* > *所有关系*。
+
“关系：所有关系”视图将与所有已配置的存储虚拟机一起显示。
