= 使用 Active IQ Unified Manager 中的 Initialize/Update 对话框
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
初始化/更新对话框使您能够对新保护关系执行首次基线传输，或者在关系已初始化且您希望执行手动、非计划性增量更新时更新该关系。



[[transfer-options-tab]]
== 传输选项选项卡

通过“传输选项”选项卡，您可以更改传输的初始化优先级并更改传输期间使用的带宽。

* *传输优先级*
+
运行传输的优先级。您可以选择“正常”或“低”。具有指定正常传输优先级的策略的关系在指定低传输优先级的策略之前运行。默认情况下选择正常。

* *最大传输速率*
+
指定通过网络在群集之间传输数据的最大速率。如果选择不使用最大传输速率，则关系之间的基线传输不受限制。如果选择多个具有不同最大传输速率的关系，则可以指定以下最大传输速率设置之一：

+
** 使用设置或编辑各个关系期间指定的值
+
选中后，初始化和更新操作将使用每个关系创建或编辑时指定的最大传输速率。此字段仅在初始化或更新具有不同传输速率的多个关系时可用。

** 无限制
+
表示关系之间的传输没有带宽限制。此字段仅在初始化或更新具有不同传输速率的多个关系时可用。

** 将带宽限制为
+
选中后，网络带宽将限制为您指定的值。您可以输入一个数值，然后选择千字节/秒（KBps）、兆字节/秒（MBps）、千兆字节/秒（GBps）或太字节/秒（TBps）。您指定的最大传输速率必须大于 1 KBps 且小于 4 TBps。







[[source-snapshot-copies-tab]]
== 源 Snapshot 副本选项卡

“源 Snapshot 副本”选项卡将显示有关用于基线传输的源 Snapshot 副本的以下信息：

* *源卷*
+
显示相应源卷的名称。

* *目标卷*
+
显示选定目标卷的名称。

* *源类型*
+
显示卷类型。类型可以是读/写或数据保护。

* *Snapshot 副本*
+
显示用于数据传输的 Snapshot 副本。单击 Snapshot 副本值将显示“选择源 Snapshot 副本”对话框，您可以在其中为传输选择特定的 Snapshot 副本，具体取决于您拥有的保护关系类型和正在执行的操作。指定其他 Snapshot 副本的选项不适用于数据保护类型源。





[[command-buttons]]
== 命令按钮

这些命令按钮可用来执行下列任务：

* *取消*
+
放弃您的选择并关闭“初始化/更新”对话框。

* *提交*
+
保存选择并启动初始化或更新作业。
