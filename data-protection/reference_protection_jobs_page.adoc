= 了解 Active IQ Unified Manager 中的作业页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
通过“作业”页面，您可以查看当前正在运行的所有合作伙伴应用程序保护作业的当前状态和其他信息，以及已完成的作业。您可以使用此信息查看哪些作业仍在运行，以及作业是否成功或失败。



[[command-buttons]]
== 命令按钮

这些命令按钮可用来执行下列任务：

* *中止*
+
中止所选作业。此选项仅在所选作业正在运行时可用。

* *重试*
+
重新启动保护配置或保护关系操作类型的失败作业。一次只能重试一个失败的作业。如果选择了多个失败作业，则禁用*重试*按钮。无法重试失败的存储服务作业。

* *刷新*
+
刷新作业列表以及与其关联的信息。





[[jobs-list]]
== 作业列表

“作业”列表以表格形式显示正在进行的作业列表。默认情况下，该列表仅显示过去一周内生成的作业。您可以使用列排序和筛选来自定义要显示的作业。

* *状态*
+
显示作业的当前状态。状态可以是 Error （image:../media/sev_error.gif[""]） 或 Normal （image:../media/sev_normal.gif[""]）。

* *作业 ID*
+
显示作业的标识号。默认情况下，此列处于隐藏状态。

+
作业标识号是唯一的，由服务器在启动作业时分配。可以通过在列筛选器提供的文本框中输入作业标识号来搜索特定作业。

* *名称*
+
显示作业的名称。

* *类型*
+
显示作业类型。作业类型如下：

+
** *集群采集*
+
Workflow Automation 作业正在重新发现集群。

** *保护配置*
+
保护作业正在启动 Workflow Automation 工作流，例如 cron 计划、SnapMirror 策略创建等。

** *保护关系操作*
+
保护作业正在运行 SnapMirror 操作。

** *保护工作流链*
+
Workflow Automation 作业正在执行多个工作流。

** *还原*
+
正在运行还原作业。

** *清理*
+
作业正在清理不再需要用于还原目的的存储服务成员项目。

** *符合*
+
作业正在检查存储服务成员的配置，以确保其符合要求。

** *销毁*
+
作业正在销毁存储服务。

** *导入*
+
作业正在将非托管存储对象导入现有存储服务。

** *修改*
+
该作业正在修改现有存储服务的属性。

** *订阅*
+
该作业正在为成员订阅存储服务。

** *取消订阅*
+
该作业正在从存储服务中取消订阅成员。

** *更新*
+
正在运行保护更新作业。

** *WFA 配置*
+
Workflow Automation 作业正在推送群集凭据并同步数据库缓存。



* *State*
+
显示作业的运行状态。状态选项如下：

+
** *已中止*
+
此作业已中止。

** *中止*
+
作业正在中止。

** *已完成*
+
作业已完成。

** *运行中*
+
作业正在运行。



* *提交时间*
+
显示作业提交时间。

* *持续时间*
+
显示作业完成所需的时间。默认情况下会显示此列。

* *完成时间*
+
显示作业完成的时间。默认情况下，此列处于隐藏状态。
