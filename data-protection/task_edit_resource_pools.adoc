= 在 Active IQ Unified Manager 中编辑资源池
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当要更改资源池名称和描述时，可以编辑现有资源池。

.开始之前
您必须具有应用程序管理员或存储管理员角色。

仅当选择了一个资源池时，才会启用*编辑*按钮。如果选择了多个资源池，则会禁用*编辑*按钮。

.步骤
. 在左侧导航窗格中，单击 *保护* > *资源池*。
. 从列表中选择一个资源池。
. 单击 *Edit*。
+
此时将显示 Edit Resource Pool（编辑资源池）窗口。

. 根据需要编辑资源池名称和描述。
. 单击 *Save*。
+
新名称和描述显示在资源池列表中。
