= 了解 Active IQ Unified Manager 中的资源池页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
“资源池”页面显示现有资源池及其成员，并使您能够创建、监控和管理资源池以进行配置。



[[command-buttons]]
== 命令按钮

这些命令按钮可用来执行下列任务：

* *创建*
+
启动“创建资源池”对话框，可用于创建资源池。

* *编辑*
+
使您能够编辑您创建的资源池的名称和说明。

* *删除*
+
用于删除一个或多个资源池。





[[resource-pools-list]]
== 资源池列表

“资源池”列表（以表格格式）显示现有资源池的属性。

* *资源池*
+
显示资源池的名称。

* *说明*
+
描述资源池。

* *SnapLock 类型*
+
显示资源池中的聚合正在使用的 SnapLock 类型。SnapLock 类型的有效值为 Compliance、Enterprise 和 Non-SnapLock。一个资源池只能包含一种 SnapLock 类型的聚合。

* *总容量*
+
显示资源池的总容量（以 MB、GB 等为单位）。

* *已用容量*
+
显示资源池中使用的空间量（以 MB、GB 等为单位）。

* *可用容量*
+
显示资源池中可用的空间量（以 MB、GB 等为单位）。

* *已用 %*
+
显示资源池中使用的空间百分比。





[[members-list-command-buttons]]
== 成员列表命令按钮

成员列表命令按钮可用于执行以下任务：

* *添加*
+
使您能够将成员添加到资源池。

* *删除*
+
用于从资源池中删除一个或多个成员。





[[members-list]]
== 成员列表

当选择资源池时，“成员”列表将（以表格形式）显示资源池成员及其属性。

* *状态*
+
显示成员聚合的当前状态。状态可以是 Critical（image:../media/sev_critical_um60.png[""]）、Error（image:../media/sev_error_um60.png[""]）、Warning（image:../media/sev_warning_um60.png[""]）或 Normal（image:../media/sev_normal_um60.png[""]）。

* *聚合名称*
+
显示成员聚合的名称。

* *State*
+
显示聚合的当前状态，可以是以下选项之一：

+
** 脱机
+
不允许读取或写入访问。

** 联机
+
允许对该聚合上托管的卷进行读取和写入访问。

** 受限
+
允许进行有限的操作（例如奇偶校验重建），但不允许访问数据。

** 正在创建
+
正在创建此聚合。

** 正在销毁
+
此聚合正在被销毁。

** 失败
+
聚合体无法联机。

** 已冻结
+
此聚合（暂时）不为请求提供服务。

** 不一致
+
聚合已被标记为已损坏；您应该与技术支持联系。

** 受 Iron 限制
+
无法在聚合上运行诊断工具。

** 正在安装
+
聚合正在挂载过程中。

** 部分
+
至少为聚合找到了一个磁盘，但缺少两个或多个磁盘。

** 正在暂停
+
此聚合正在静止。

** 已暂停
+
聚合已静止。

** 已还原
+
聚合还原已完成。

** 已卸载
+
已卸载此聚合。

** 正在卸载
+
此聚合正在脱机。

** 未知
+
已发现聚合，但 Unified Manager 服务器尚未检索到聚合信息。



+
默认情况下，此列处于隐藏状态。

* *集群*
+
显示聚合所属的集群的名称。

* *节点*
+
显示聚合所在的节点的名称。

* *总容量*
+
显示聚合的总容量（以 MB、GB 等为单位）。

* *已用容量*
+
显示聚合中使用的空间量（以 MB、GB 等为单位）。

* *可用容量*
+
显示聚合中可用的空间量（以 MB、GB 等为单位）。

* *已用 %*
+
显示聚合中使用的空间百分比。

* *磁盘类型*
+
显示 RAID 配置类型，可为以下选项之一：

+
** RAID0：所有 RAID 组的类型均为 RAID0。
** RAID4：所有 RAID 组均为 RAID4 类型。
** RAID-DP：所有 RAID 组的类型均为 RAID-DP。
** RAID-TEC：所有 RAID 组的类型均为 RAID-TEC。
** 混合 RAID：聚合包含不同 RAID 类型（RAID0、RAID4、RAID-DP 和 RAID-TEC）的 RAID 组。默认情况下，此列处于隐藏状态。
