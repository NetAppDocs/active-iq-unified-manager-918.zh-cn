= 在 Active IQ Unified Manager 中显示"关系：所有关系"视图
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
“关系：所有关系”视图显示有关存储系统上的保护关系的信息。

默认情况下，当您访问“关系”页面时，显示的报告将包括卷和存储 VM 的顶级保护关系。页面顶端的控件使您能够选择特定视图、执行搜索以查找特定对象、创建和应用筛选器以缩小显示数据的列表、在页面上添加/删除/重新排序列以及将页面上的数据导出为 .csv、.pdf 或 .xlsx 文件。自定义页面后，您可以将结果保存为自定义视图，然后计划定期生成此数据的报告并通过电子邮件发送。默认情况下，当您选择 *关系* 菜单时，显示的报告包括数据中心中卷和存储 VM 的保护关系。您可以使用 *筛选器* 选项仅查看选定的存储系统，如仅查看卷或仅查看存储 VM。相同的报告显示在“存储”页面中，仅适用于选定的存储实体。如果要查看卷或存储 VM 关系，可以访问 *存储* > *卷* > *关系：所有关系* 页面或访问 *保护* > *关系* > *关系：所有关系*，然后使用 *筛选器* 中的 *关系对象类型* 选项仅过滤卷或存储 VM 数据。

"关系"页面列出了所有保护关系，其中包含目标集群的 *View in System Manager* 链接，可用于在 ONTAP System Manager 中查看相同的对象。

* *状态*
+
显示保护关系的当前状态。

+
状态可以是错误（image:../media/sev_error_um60.png[""]）、警告（image:../media/sev_warning_um60.png[""]）或正常（image:../media/sev_normal_um60.png[""]）之一。

* *源 Storage VM*
+
显示源 SVM 的名称。您可以通过单击 SVM 名称来查看有关源 SVM 的更多详细信息。

+
当集群上存在 SVM 但尚未添加到 Unified Manager 清单中时，或者该 SVM 是在集群上次刷新后创建时，此字段将为空。您必须确保 SVM 存在，或者对集群执行重新发现以刷新资源列表。

* *源*
+
根据您的选择显示受保护的源卷或源存储 VM。您可以通过单击卷或存储 VM 名称来查看有关源卷或存储 VM 的更多详细信息。

+
如果显示消息 `Resource-key not discovered`，这可能表示该卷存在于集群上但尚未添加到 Unified Manager 清单中，或者该卷是在集群上次刷新后创建的。您必须确保卷存在，或在集群上执行重新发现以刷新资源列表。

* *目标 Storage VM*
+
显示目标 SVM 的名称。您可以通过单击 SVM 名称查看有关目标 SVM 的更多详细信息。

* *目的地*
+
根据您的选择显示目标卷或 storage VM 的名称。您可以通过单击相应的对象名称来查看有关目标卷或 storage VM 的更多详细信息。

* *关系对象类型*
+
显示关系中使用的对象类型，例如 Storage VM、卷和一致性组。对于一致性关系中的对象，关系源和目标将显示一致性组，单击它们将转到 LUN 页面以查看关系。

* *策略*
+
显示 SnapMirror 关系的保护策略的名称。您可以单击策略名称以查看与该策略关联的详细信息，包括以下信息：

+
** 传输优先级
+
指定为异步操作运行传输的优先级。传输优先级为“正常”或“低”。“正常”优先级的传输会计划在“低”优先级的传输之前进行。默认值为“正常”。

** 忽略访问时间
+
仅适用于 SnapVault 关系。此选项用于指定增量传输是否忽略只更改了访问时间的文件。其值为“True”或“False”。默认值为“False”。

** 当关系不同步时
+
指定无法同步同步关系时 ONTAP 执行的操作。如果无法与辅助卷同步，StrictSync 关系将限制对主卷的访问。如果无法与辅助卷同步，Sync 关系不会限制对主卷的访问。

** 尝试次数限制
+
指定每次为 SnapMirror 关系执行手动传输或计划传输的最大尝试次数。默认值为 8。

** 注释
+
提供一个文本字段，用于为选定策略输入特定注释。

** SnapMirror 标签
+
指定与 Snapshot 副本策略关联的第一个计划的 SnapMirror 标签。如果要将 Snapshot 副本备份到 SnapVault 目标，则 SnapVault 子系统将使用此 SnapMirror 标签。

** 保留设置
+
根据备份时间或备份数量指定备份的保留时间。

** 实际 Snapshot 副本
+
指定此卷上与指定标签匹配的 Snapshot 副本的数量。

** 保留 Snapshot 副本
+
指定即使达到策略最大限制也不会自动删除的 SnapVault Snapshot 副本的数量。其值为“True”或“False”。默认值为“False”。

** 保留警告阈值
+
指定一个 Snapshot 副本限制，如果到达此限制，系统将发送警告，指出即将达到最大保留限制。



* *滞后持续时间*
+
显示镜像中的数据滞后于源的时间长度。

+
对于 StrictSync 关系，延迟持续时间应接近或等于 0 秒。

* *滞后状态*
+
显示受管关系以及具有与该关系关联的计划的非受管关系的滞后状态。滞后状态可以是：

+
** 错误
+
滞后持续时间大于或等于滞后错误阈值。

** 警告
+
滞后持续时间大于或等于滞后警告阈值。

** 确定
+
滞后持续时间处于正常限制范围内。

** 不适用
+
滞后状态不适用于同步关系，因为无法配置计划。



* *上次成功更新*
+
显示上次成功执行 SnapMirror 或 SnapVault 操作的时间。

+
上次成功更新不适用于同步关系。

* *成分关系*
+
显示所选对象中是否存在任何卷。

* *关系类型*
+
显示用于复制卷的关系类型。关系类型包括：

+
** 异步镜像
** 异步存储
** 异步 MirrorVault
** StrictSync
** 同步


* *传输状态*
+
显示保护关系的传输状态。传输状态可以是下列状态之一：

+
** 正在中止
+
SnapMirror 传输已启用；但是，正在执行一个传输中止操作，此操作可能需要删除检查点。

** 正在检查
+
正在对目标卷进行诊断检查，当前未进行传输。

** 正在完成
+
SnapMirror 传输已启用。卷当前处于增量 SnapVault 传输的传输后阶段。

** 闲置
+
已启用传输，但当前未进行传输。

** 同步
+
处于同步关系的两个卷中的数据处于同步状态。

** 不同步
+
目标卷中的数据与源卷不同步。

** 正在准备
+
SnapMirror 传输已启用。卷当前处于增量 SnapVault 传输的传输前阶段。

** 已排队
+
SnapMirror 传输已启用。当前未进行传输。

** 已暂停
+
SnapMirror 传输已禁用。当前未进行传输。

** 正在暂停
+
正在进行 SnapMirror 传输。其他传输已禁用。

** 正在传输
+
已启用 SnapMirror 传输，且传输正在进行中。

** 正在过渡
+
从源卷到目标卷的异步数据传输完成，并且已开始过渡到同步操作。

** 正在等待
+
SnapMirror 传输已启动，但某些关联任务正在等待排队。



* *上次传输持续时间*
+
显示上次数据传输完成所用的时间。

+
传输持续时间不适用于 StrictSync 关系，因为传输应同时进行。

* *上次传输大小*
+
显示上次数据传输的大小（以字节为单位）。

+
传输大小不适用于 StrictSync 关系。

* *调解器*
+
显示调解器状态。

+
** 不适用
+
如果集群不支持 SnapMirror 活动同步。

** 未配置
+
如果未配置，或者已配置但仅添加了目标集群且未在 Unified Manager 中添加源集群。

** 调解器 IP 地址
+
如果已配置，并且源集群和目标集群都已添加到 Unified Manager 中。



* *State*
+
显示 SnapMirror 或 SnapVault 关系的状况。该状况可以是“未初始化”、“已执行 SnapMirror”或“已断开”。如果选择源卷，则关系状况不适用，也不会显示。

* *关系健康状况*
+
显示集群的关系运行状况。

* *不健康的原因*
+
关系运行状况不正常的原因。

* *传输优先级*
+
显示传输的运行优先级。传输优先级为“正常”或“低”。“正常”优先级的传输会计划在“低”优先级的传输之前进行。

+
传输优先级不适用于同步关系，因为所有传输的优先级均视为相同。

* *计划*
+
显示分配给关系的保护计划的名称。

+
计划不适用于同步关系。

* *版本灵活复制*
+
显示“是”、“是，使用备份选项”或“无”。

* *源集群*
+
显示 SnapMirror 关系中的源集群的 FQDN、短名称或 IP 地址。

* *Source Cluster FQDN*
+
显示 SnapMirror 关系中的源集群的名称。

* *源节点*
+
显示卷 SnapMirror 关系的源节点名称链接的名称，并在对象是 Storage VM 或一致性组时显示 SnapMirror 关系节点计数链接。



在自定义视图中，单击节点名称链接时，可以查看和扩展对这些一致性组的卷属于 SnapMirror 活动同步关系的存储对象的保护。

当您单击节点计数链接时，它会将您带到具有与此关系关联的相应节点的节点页面。当节点计数为 0 时，由于没有与此关系关联的节点，因此不会显示任何值。

* *目标节点*
+
显示卷的 SnapMirror 关系的目标节点名称链接的名称，并在对象为 Storage VM 或一致性组时显示 SnapMirror 关系节点计数链接。

+
当您单击节点计数链接时，它会将您带到具有与此关系关联的相应节点的节点页面。当节点计数为 0 时，由于没有与此关系关联的节点，因此不会显示任何值。

* *目标集群*
+
显示 SnapMirror 关系中的目标集群的名称。

* *目标集群 FQDN*
+
显示 SnapMirror 关系中的目标集群的 FQDN、短名称或 IP 地址。

* *受保护*
+
显示不同的关系。在此列中，您可以查看集群和存储虚拟机顺序的卷和一致性组关系，包括：

+
** SnapMirror
** Storage VM 灾难恢复
** SnapMirror，Storage VM 灾难恢复
** 一致性组
** SnapMirror，一致性组。
