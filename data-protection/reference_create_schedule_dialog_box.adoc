= 使用 Active IQ Unified Manager 中的"创建计划"对话框
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
“创建计划”对话框可用于为 SnapMirror 和 SnapVault 关系传输创建基本或高级保护计划。由于数据频繁更新，您可以创建新计划以增加数据传输频率，也可以在数据不经常更改时创建不太频繁的计划。

无法为 SnapMirror 同步关系配置计划。

* *目标集群*
+
您在“配置保护”对话框的 SnapVault 选项卡或 SnapMirror 选项卡中选择的集群名称。

* *计划名称*
+
您为计划提供的名称。计划名称可以由字符 A 至 Z、a 至 z、0 至 9 以及以下任意特殊字符组成：! @ # $ % {caret} & * ( ) _ -。计划名称不得包含以下字符：< >。

* *基本或高级*
+
要使用的计划模式。

+
基本模式包括以下元素：

+
** 重复
+
计划传输发生的频率。选项包括每小时、每天和每周。

** 天
+
当选择每周重复时，传输发生的星期几。

** 时间
+
当选择“每日”或“每周”时，发生传输的时间。



+
高级模式包括以下元素：

+
** 个月
+
表示一年中月份的逗号分隔的数字列表。有效值为 0 到 11，零表示 1 月，依此类推。此元素是可选的。将字段留空意味着每个月都会发生传输。

** 天
+
以逗号分隔的数字列表，表示每月的某一天。有效值为 1 到 31。此元素是可选的。将该字段留空意味着每月的每一天都会发生传输。

** 工作日
+
一个以逗号分隔的数字列表，表示一周中的几天。有效值为 0 到 6，其中 0 表示星期日，依此类推。此元素是可选的。将该字段留空意味着一周中的每一天都会进行传输。如果指定了一周中的某一天，但未指定一个月中的某一天，则仅在指定的一周中的某一天进行传输，而不是每天进行传输。

** 小时
+
以逗号分隔的数字列表，表示一天中的小时数。有效值为 0 至 23，0 表示午夜。此元素是可选的。

** 分钟
+
一个以逗号分隔的数字列表，表示一小时内的分钟数。有效值为 0 到 59。此元素是必需的。
