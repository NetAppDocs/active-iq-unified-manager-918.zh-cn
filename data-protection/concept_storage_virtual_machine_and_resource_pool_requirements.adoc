= 支持 Active IQ Unified Manager 中存储服务的 SVM 和资源池要求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您遵守某些特定于存储服务的 SVM 关联和资源池要求，则可以更好地确保合作伙伴应用程序的一致性：例如，当您在 Unified Manager 中关联 SVM 并创建资源池，以支持由合作伙伴应用程序提供的存储服务中的保护拓扑时。

某些应用程序与 Unified Manager 服务器合作，提供自动在二级或三级位置的源卷和保护卷之间配置和执行 SnapMirror 或 SnapVault 备份保护的服务。要支持这些保护存储服务，必须使用 Unified Manager 配置必要的 SVM 关联和资源池。

要支持存储服务单跳或级联保护，包括从 SnapMirror 源或 SnapVault 主卷复制到目标 SnapMirror 或驻留在二级或三级位置的 SnapVault 备份卷，请遵守以下要求：

* 必须在包含 SnapMirror 源或 SnapVault 主卷的 SVM 与辅助卷或第三卷所在的任何 SVM 之间配置 SVM 关联。
+
** 例如，要支持源卷 Vol_A 驻留在 SVM_1 上、SnapMirror 辅助目标卷 Vol_B 驻留在 SVM_2 上、第三 SnapVault 备份卷 Vol_ C 驻留在 SVM_3 上的保护拓扑，您必须使用 Unified Manager Web UI 配置 SVM_1 和 SVM_2 之间的 SnapMirror 关联以及 SVM_1 和 SVM_3 之间的 SnapVault 备份关联。
+
在此示例中，SVM_2 和 SVM_3 之间的任何 SnapMirror 关联或 SnapVault 备份关联都是不必要的，并且不会使用。

** 要支持源卷 Vol_A 和 SnapMirror 目标卷 Vol_B 都驻留在 SVM_1 上的保护拓扑，您必须配置 SVM_1 和 SVM_1 之间的 SnapMirror 关联。


* 资源池必须包括可用于关联 SVM 的集群聚合资源。
+
您可以通过 Unified Manager Web UI 配置资源池，然后通过合作伙伴应用程序分配存储服务辅助目标和第三目标节点。
