= 从 Active IQ Unified Manager 中的卷/运行状况详细信息页面重新同步保护关系
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以重新同步已中断且目标已变为读/写的 SnapMirror 或 SnapVault 关系上的数据，以便源上的数据与目标上的数据相匹配。当源卷上所需的通用 Snapshot 副本被删除，导致 SnapMirror 或 SnapVault 更新失败时，您也可以重新同步。

.开始之前
* 您必须具有应用程序管理员或存储管理员角色。
* 您必须已设置 OnCommand Workflow Automation。


.步骤
. 从*卷/运行状况*详细信息页面的*保护*选项卡中，在拓扑中找到要重新同步的保护关系，然后右键单击它。
. 从菜单中选择*重新同步*。
+
或者，从*操作*菜单中，选择*关系* > *重新同步*以重新同步您当前查看详细信息的关系。

+
此时将显示重新同步对话框。

. 在*重新同步选项*选项卡中，选择传输优先级和最大传输速率。
. 单击*源 Snapshot 副本*；然后，在*Snapshot 副本*列中，单击*默认*。
+
此时将显示选择源 Snapshot 副本对话框。

. 如果要指定现有 Snapshot 副本而不是传输默认 Snapshot 副本，请单击 *现有 Snapshot 副本* 并从列表中选择 Snapshot 副本。
. 单击*提交*。
+
此时将返回到“重新同步”对话框。

. 如果选择了多个要重新同步的源，请单击要指定现有 Snapshot 副本的下一个源的 *默认值*。
. 单击*提交*以开始重新同步作业。
+
重新同步作业已启动，您将返回到卷/运行状况详细信息页面，并在页面顶部显示作业链接。

. *可选：* 单击 *卷 / 运行状况详细信息* 页面上的 *查看作业* 以跟踪每个重新同步作业的状态。
+
此时将显示已筛选的作业列表。

. *可选：*单击浏览器上的*后退*箭头返回*卷/运行状况*详细信息页面。
+
当所有作业任务成功完成时，重新同步作业完成。
