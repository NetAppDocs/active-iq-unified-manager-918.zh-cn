= 使用 Active IQ Unified Manager 中的"配置保护"对话框
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用“配置保护”对话框为集群上的所有读取、写入和数据保护卷创建 SnapMirror 和 SnapVault 关系，以确保复制源卷或主卷上的数据。



[[source-tab]]
== 源选项卡

* *拓扑视图*
+
显示要创建的关系的可视化表示。默认情况下，突出显示拓扑中的源。

* *源信息*
+
显示有关所选源卷的详细信息，包括以下信息：

+
** 源集群名称
** 源 SVM 名称
** 累计卷总大小
+
显示所选所有源卷的总大小。

** 累计卷使用大小
+
显示所有选定源卷的累计已用卷大小。

** 源卷
+
在表中显示以下信息：

+
*** 源卷
+
显示选定源卷的名称。

*** 类型
+
显示卷类型。

*** SnapLock 类型
+
显示卷的 SnapLock 类型。选项包括合规、企业和非 SnapLock。

*** Snapshot 副本
+
显示用于基线传输的 Snapshot 副本。如果源卷为读/写，则 Snapshot copy 列中的 Default 值表示默认情况下会创建新的 Snapshot 副本，并用于基线传输。如果源卷是数据保护卷，则 Snapshot copy 列中的 Default 值表示未创建新的 Snapshot 副本，并且所有现有 Snapshot 副本都将传输到目标。单击 Snapshot 副本值将显示 Snapshot 副本列表，您可以从中选择要用于基线传输的现有 Snapshot 副本。如果源类型为数据保护，则无法选择其他默认 Snapshot 副本。









[[snapmirror-tab]]
== SnapMirror 选项卡

使您能够在创建 SnapMirror 关系时，为保护关系指定目标集群、存储虚拟机 (SVM) 和聚合，以及目标的命名约定。您还可以指定 SnapMirror 策略和计划。

* *拓扑视图*
+
显示您正在创建的关系的可视化表示。默认情况下，拓扑中的 SnapMirror 目标资源会突出显示。

* *目标信息*
+
使您能够为保护关系选择目标资源：

+
** 高级链接
+
在创建 SnapMirror 关系时启动“高级目标设置”对话框。

** 集群
+
列出可用作保护目标主机的群集。此字段为必填项。

** 存储虚拟机 (SVM)
+
列出选定集群上可用的 SVM。在填充 SVM 列表之前，必须选择集群。此字段必填。

** 聚合
+
列出选定 SVM 上可用的聚合。在填充聚合列表之前，必须选择一个集群。此字段必填。聚合列表显示以下信息：

+
*** 排名
+
当多个聚合满足目标的所有要求时，根据以下条件，排名表示列出聚合的优先级：

+
.... 首选位于与源卷节点不同的节点上的聚合，以实现故障域分离。
.... 首选卷较少的节点上的聚合，以便在集群中的节点之间实现负载均衡。
.... 为了实现容量平衡，首选可用空间多于其他聚合的聚合。排名为 1 表示根据这三个标准，该聚合是最优选的。


*** 聚合名称
+
聚合的名称

*** 可用容量
*** 聚合上可用于数据的空间量
*** 资源池
+
聚合所属的资源池的名称



** 命名约定
+
指定应用于目标卷的默认命名约定。您可以接受所提供的命名约定，也可以创建自定义约定。命名约定可以具有以下属性：%C、%M、%V 和 %N，其中 %C 是集群名称，%M 是 SVM 名称，%V 是源卷，%N 是拓扑目标节点名称。

+
如果您的输入无效，命名约定字段将以红色突出显示。单击 "`Preview Name`" 链接将显示您输入的命名约定的预览，并且当您在文本字段中键入命名约定时，预览文本会动态更新。创建关系时，系统会将 001 到 999 之间的后缀附加到目标名称，以替换预览文本中显示的 nnn，其中首先分配 001，其次分配 002，依此类推。



* *关系设置*
+
使您能够指定保护关系使用的最大传输速率、SnapMirror 策略和计划：

+
** 最大传输速率
+
指定通过网络在集群之间传输数据的最大速率。如果选择不使用最大传输速率，则关系之间的基线传输将不受限制。

** SnapMirror 策略
+
为关系指定 ONTAP SnapMirror 策略。默认值为 DPDefault。

** 创建策略
+
启动“创建 SnapMirror 策略”对话框，可使用此对话框创建和使用新 SnapMirror 策略。

** SnapMirror 计划
+
指定关系的 ONTAP SnapMirror 策略。可用的计划包括 None、5min、8hour、daily、hourly 和 weekly。默认值为 None，表示没有计划与此关系关联。没有计划的关系没有滞后状态值，除非它们属于存储服务。

** 创建计划
+
启动“创建计划”对话框，可使用此对话框创建新 SnapMirror 计划。







[[snapvault-tab]]
== SnapVault 选项卡

使您能够在创建 SnapVault 关系时为保护关系指定辅助集群、SVM 和聚合，以及辅助卷的命名约定。您还可以指定 SnapVault 策略和计划。

* *拓扑视图*
+
显示要创建的关系的可视化表示。默认情况下，拓扑中的 SnapVault 辅助资源会突出显示。

* *二级信息*
+

+
** 高级链接
+
启动“高级辅助设置”对话框。

** 集群
+
列出可用作辅助保护主机的群集。此字段为必填项。

** 存储虚拟机 (SVM)
+
列出选定集群上可用的 SVM。在填充 SVM 列表之前，必须选择集群。此字段必填。

** 聚合

*** 聚合名称
+
聚合的名称

*** 可用容量
*** 聚合上可用于数据的空间量

[[command-buttons]]
== 命令按钮

这些命令按钮可用来执行下列任务：

* *取消*
+
放弃选择并关闭“配置保护”对话框。

* *应用*
+
应用所选内容并开始保护过程。
