= 使用 Active IQ Unified Manager 中的"浏览目录"对话框
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当您想要将数据还原到与原始源不同的集群和 SVM 上的目录时，可以使用“浏览目录”对话框。默认情况下会选择原始源集群和卷。

通过“浏览目录”对话框，您可以选择要将数据还原到的集群、SVM、卷和目录路径。

* *集群*
+
列出可以还原的可用群集目标。默认情况下，将选择初始源卷的群集。

* *SVM 下拉列表*
+
列出可用于选定集群的可用 SVM。默认情况下，将选择原始源卷的 SVM。

* *卷*
+
列出所选 SVM 中的所有读/写卷。您可以按名称和可用空间筛选卷。空间最多的卷将列在首位，依此类推，按降序排列。默认情况下，将选择原始源卷。

* *文件路径文本框*
+
使您能够键入要将数据还原到的文件路径。您输入的路径必须已存在。

* *名称*
+
显示所选卷的可用文件夹的名称。单击名称列表中的文件夹将显示子文件夹（如果有）。不显示文件夹中包含的文件。选择文件夹后，单击 image:../media/icon_upfolder.gif["向上文件夹图标"] 可在目录结构中向上移动一级。





[[command-buttons]]
== 命令按钮

这些命令按钮可用来执行下列任务：

* *选择目录*
+
应用您的选择并关闭“浏览目录”对话框。如果未选择目录，则禁用此按钮。

* *取消*
+
放弃您的选择并关闭“浏览目录”对话框。
