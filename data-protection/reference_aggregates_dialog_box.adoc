= 使用 Active IQ Unified Manager 中的聚合对话框
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
可以使用“聚合”对话框选择要添加到资源池的聚合。



[[command-buttons]]
== 命令按钮

这些命令按钮可用来执行下列任务：

* *添加*
+
将所选聚合添加到资源池。在至少选择一个聚合之前，不会启用“添加”按钮。

* *取消*
+
放弃更改，并关闭“聚合”对话框。





[[aggregates-list]]
== 聚合列表

“聚合”列表（以表格格式）显示受监控聚合的名称和属性。

* *状态*
+
显示卷的当前状态。状态可以是 Critical（image:../media/sev_critical_um60.png[""]）、Error（image:../media/sev_error_um60.png[""]）、Warning（image:../media/sev_warning_um60.png[""]）或 Normal（image:../media/sev_normal_um60.png[""]）。

+
可以将指针移到状态上，以查看有关为卷生成的一个或多个事件的详细信息。

* *聚合名称*
+
显示聚合的名称。

* *State*
+
显示聚合的当前状态，可以是以下选项之一：

+
** 脱机
+
不允许读取或写入访问。

** 受限
+
允许进行有限的操作（例如奇偶校验重建），但不允许访问数据。

** 联机
+
允许对该聚合上托管的卷进行读取和写入访问。

** 正在创建
+
正在创建此聚合。

** 正在销毁
+
此聚合正在被销毁。

** 失败
+
聚合体无法联机。

** 已冻结
+
此聚合（暂时）不为请求提供服务。

** 不一致
+
聚合已被标记为已损坏；您应该与技术支持联系。

** 受 Iron 限制
+
无法在聚合上运行诊断工具。

** 正在安装
+
聚合正在挂载过程中。

** 部分
+
至少为聚合找到了一个磁盘，但缺少两个或多个磁盘。

** 正在暂停
+
此聚合正在静止。

** 已暂停
+
聚合已静止。

** 已还原
+
聚合还原已完成。

** 已卸载
+
此聚合已脱机。

** 正在卸载
+
此聚合正在脱机。

** 未知
+
已发现聚合，但 Unified Manager 服务器尚未检索到聚合信息。



* *集群*
+
显示聚合所在的集群的名称。

* *节点*
+
显示包含聚合的存储控制器的名称。

* *总容量*
+
显示聚合的总数据大小（以 MB、GB 等为单位）。默认情况下，此列处于隐藏状态。

* *已提交的容量*
+
显示为聚合中的所有卷提交的总空间（以 MB、GB 等为单位）。默认情况下，此列是隐藏的。

* *已用容量*
+
显示聚合中使用的空间量（以 MB、GB 等为单位）。

* *可用容量*
+
显示可用于聚合中数据的空间量（以 MB、GB 等为单位）。默认情况下，此列处于隐藏状态。

* *可用 %*
+
显示聚合中可用于数据的空间百分比。默认情况下，此列是隐藏的。

* *已用 %*
+
显示聚合中数据使用的空间百分比。

* *RAID 类型*
+
显示选定卷的 RAID 类型。RAID 类型可以是 RAID0、RAID4、RAID-DP、RAID-TEC 或混合 RAID。
