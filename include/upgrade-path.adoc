= 请对 Active IQ Unified Manager 版本使用受支持的升级路径
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager 支持每个版本的特定升级路径。

并非所有版本的 Unified Manager 都可以就地升级到更高版本。Unified Manager 升级仅限于 N-2 模式。这意味着您只能在所有平台上升级到接下来的两个版本。例如，您只能从 Unified Manager 9.14 和 9.16 升级到 Unified Manager 9.18。

如果运行的版本早于受支持的版本，则需要先将 Unified Manager 实例升级到受支持的版本之一，然后再升级到当前版本。

例如，如果安装的版本是 Unified Manager 9.9，并且要升级到 Unified Manager 9.14，则需要执行一系列升级。

.升级路径示例：
. 升级 9.11 -> 9.13
. 升级 9.13 -> 9.14
. 升级 9.13 -> 9.16
. 升级 9.14 或 9.16 -> 9.18


有关升级路径矩阵的更多信息，请参见此 https://kb.netapp.com/Advice_and_Troubleshooting/Data_Infrastructure_Management/Active_IQ_Unified_Manager/What_is_the_upgrade_path_for_Active_IQ_Unified_Manager_versions["知识库（KB）文章"]。
