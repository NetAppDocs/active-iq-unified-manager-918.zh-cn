= 查看 Active IQ Unified Manager 上所有集群中可用的 QoS 策略组
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以显示 Unified Manager 正在监视的群集上可用的所有 QoS 策略组的列表。这包括传统 QoS 策略、自适应 QoS 策略以及由 Unified Manager 性能服务级别策略管理的 QoS 策略。

.步骤
. 在左侧导航窗格中，单击*存储* > *QoS 策略组*。
+
默认显示性能：传统 QoS 策略组视图。

. 查看每个可用传统 QoS 策略组的详细配置设置。
. 单击 QoS 策略组名称旁边的展开按钮（image:../media/chevron_down.gif[""]）可查看有关策略组的更多详细信息。
. 在视图菜单中，选择其中一个附加选项以查看所有自适应 QoS 策略组或查看使用 Unified Manager 性能服务级别创建的所有 QoS 策略组。
