= 在 Active IQ Unified Manager 中验证 MetroCluster 配置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
通过确保正确设置 MetroCluster 配置，您可以防止在基于 FC 和 IP 的 MetroCluster 配置中镜像工作负载出现性能问题。您还可以通过更改配置或升级软件或硬件组件来提高工作负载性能。

请参阅 https://docs.netapp.com/us-en/ontap-metrocluster/index.html["MetroCluster 文档"]，了解有关在 MetroCluster 配置中设置集群的说明，包括光纤通道（FC）交换机、电缆和交换机间链路（ISL）。它还可以帮助您配置 MetroCluster 软件，以便本地和远程集群可以进行通信并镜像卷数据。有关您的 MetroCluster over IP 设置的特定信息，请参阅 https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/index.html["安装 MetroCluster IP 配置"]。

您可以将您的 MetroCluster 配置与 https://docs.netapp.com/us-en/ontap-metrocluster/index.html["MetroCluster 文档"]中的要求进行比较，以确定更改或升级 MetroCluster 配置中的组件是否可以提高工作负载性能。此比较可以帮助您回答以下问题：

* 控制器是否适合您的工作负载？
* 是否需要将 ISL 捆绑包升级到更大的带宽以处理更多吞吐量？
* 是否可以调整交换机上的缓冲区到缓冲区信用（BBC）以增加带宽？
* 如果您的工作负载对固态驱动器（SSD）存储具有高写入吞吐量，是否需要升级 FC 到 SAS 网桥以适应吞吐量？
