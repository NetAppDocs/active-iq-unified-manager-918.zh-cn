= 监控 Active IQ Unified Manager 检测到的配置更改
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 监控您的集群的配置更改，以帮助您确定更改是否可能导致或促成性能事件。性能资源管理器页面显示更改事件图标（image:../media/opm_change_icon.gif["更改事件图标"]），以指示检测到更改的日期和时间。

您可以在“性能资源管理器”页面和“工作负载分析”页面中查看性能图表，以查看更改事件是否影响所选集群对象的性能。如果在性能事件发生的同时或前后检测到更改，则该更改可能是导致问题的原因，从而触发了事件警报。

Unified Manager 可以检测到以下变更事件，这些事件被归类为信息事件：

* 卷在聚合之间移动。
+
Unified Manager 可以检测移动是正在进行、已完成还是已失败。如果 Unified Manager 在卷移动期间停止运行，则在恢复运行时，它会检测到卷移动并为其显示一个更改事件。

* 包含一个或多个受监控工作负载的 QoS 策略组的吞吐量（MB/s 或 IOPS）限制发生更改。
+
更改策略组限制可能会导致延迟（响应时间）出现间歇性峰值，这也可能触发策略组的事件。延迟会逐渐恢复正常，由峰值引起的任何事件都会过时。

* HA 对中的节点接管或交还其伙伴节点的存储。
+
Unified Manager 可以检测接管、部分接管或交还操作何时完成。如果接管是由崩溃的节点引起的，则 Unified Manager 不会检测到该事件。

* 已成功完成 ONTAP 升级或还原操作。
+
将显示先前版本和新版本。
