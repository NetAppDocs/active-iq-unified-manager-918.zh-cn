= 使用 Active IQ Unified Manager 中的工作负载分析器对工作负载进行故障排除
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
工作负载分析器提供了一种方法，可以在单个页面上查看单个工作负载的重要运行状况和性能标准，以帮助进行故障排除。通过查看工作负载的所有当前和过去事件，您可以更好地了解为什么工作负载现在可能存在性能或容量问题。

使用此工具还可以帮助您确定存储是否是应用程序任何性能问题的原因，或者该问题是否由网络或其他相关问题引起。

您可以从用户界面中的多个位置启动此功能：

* 从左侧导航菜单上的工作负载分析选项中
* 在事件详细信息页面中，单击*分析工作负载*按钮
* 从任何工作负载清单页面（卷、LUN、工作负载、NFS 共享或 SMB/CIFS 共享），单击更多图标 image:../media/more_icon.gif[""]，然后单击 *分析工作负载*
* 从 Virtual Machines 页面，通过单击任意 Datastore 对象中的 *Analyze Workload* 按钮


当您从左侧导航菜单启动该工具时，您可以输入要分析的任何工作负载的名称，并选择要进行故障排除的时间范围。当您从任何工作负载或虚拟机清单页面启动该工具时，系统会自动填写工作负载的名称，并以默认的 2 小时时间范围显示工作负载的数据。当您从事件详细信息页面启动该工具时，系统会自动填写工作负载的名称，并显示 10 天的数据。
