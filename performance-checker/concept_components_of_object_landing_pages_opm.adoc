= 查看 Active IQ Unified Manager 中对象登录页面的组成部分
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
对象登录页面提供有关所有关键、警告和信息事件的详细信息。它们提供了所有集群对象性能的详细视图，使您能够选择和比较不同时间段内的单个对象。

通过“对象登录”页面，您可以检查所有对象的整体性能，并以并排格式比较对象性能数据。这在评估性能和排除事件故障时非常有用。

[NOTE]
====
计数器摘要面板和计数器图表中显示的数据基于五分钟的采样间隔。页面左侧的对象清单网格中显示的数据基于一小时的采样间隔。

====
下图显示了显示资源管理器信息的对象登录页面的示例：

image::../media/perf_manager_page_1.gif[显示包含资源管理器信息的对象登录页面示例的 UI 屏幕截图。]

根据正在查看的存储对象，“对象登录”页面可以具有以下选项卡，这些选项卡提供有关对象的性能数据：

* 摘要
+
显示三个或四个计数器图表，其中包含前 72 小时期间每个对象的事件和性能，包括显示该期间高值和低值的趋势线。

* 资源管理器
+
显示与当前对象相关的存储对象的网格，使您能够将当前对象的性能值与相关对象的性能值进行比较。此选项卡包括最多十一个计数器图表和一个时间范围选择器，使您能够执行各种比较。

* 信息
+
显示有关存储对象的非性能配置属性的值，包括安装的 ONTAP 软件版本、HA 配对节点名称以及端口和 LIF 的数量。

* 性能最佳的对象
+
对于群集：根据所选性能计数器显示性能最高或性能最低的存储对象。

* 故障转移规划
+
对于节点：如果节点的 HA 伙伴发生故障，则显示对节点性能影响的估计。

* 详细信息
+
对于卷：显示选定卷工作负载的所有 I/O 活动和操作的详细性能统计信息。此选项卡适用于 FlexVol 卷、FlexGroup 卷以及 FlexGroups 的组成部分。
