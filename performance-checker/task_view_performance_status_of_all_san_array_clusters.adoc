= 在 Active IQ Unified Manager 中查看所有 SAN Array 集群的性能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用性能：所有群集视图显示 All SAN Array 群集的性能状态。

.开始之前
您必须具有操作员、应用程序管理员或存储管理员角色。

您可以在“性能：所有集群”视图中查看 All SAN Array 集群的概述信息，并在“集群/性能资源管理器”页面中查看详细信息。

.步骤
. 在左侧导航窗格中，单击 *存储* > *集群*。
. 确保在 *运行状况：所有集群* 视图中显示 "`Personality`" 列，或使用 *显示 / 隐藏* 控件添加它。
+
此列为您的 All SAN Array 集群显示 "`All SAN Array`"。

. 要查看有关这些集群中性能的信息，请选择*性能：所有集群*视图。
+
查看 All SAN Array 集群的性能信息。

. 要查看有关这些集群性能的详细信息，请单击全 SAN 阵列集群的名称。
. 单击*资源管理器*选项卡。
. 在*集群/性能资源管理器*页面上，从*查看和比较*菜单中选择*此集群上的节点*。
+
您可以比较此集群上两个节点的性能统计信息，以确保两个节点的负载几乎相同。如果两个节点之间存在较大差异，您可以将第二个节点添加到图表中，并在更长的时间范围内比较值，以识别任何配置问题。
