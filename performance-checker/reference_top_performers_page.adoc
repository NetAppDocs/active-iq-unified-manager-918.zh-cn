= 在 Active IQ Unified Manager 中查看性能最佳者页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Top Performers 页面根据您选择的性能计数器显示性能最高或性能最低的存储对象。例如，在 Storage VM 类别中，您可以显示具有最高 IOPS、最高延迟或最低 MB/s 的 SVM。此页面还显示是否有任何最高性能对象具有任何活动的性能事件（新建或已确认）。

“最佳执行者”页面显示每个对象最多 10 个。请注意，Volume 对象包括 FlexVol 卷和 FlexGroup 卷。

* *时间范围*
+
您可以选择查看表现最佳者的时间范围；选定的时间范围适用于所有存储对象。可用时间范围：

+
** 过去 1 小时
** 过去 24 小时
** 最近 72 小时（默认）
** 过去 7 天


* *指标*
+
单击 *Metric* 菜单选择其他计数器。计数器选项因对象类型而异。例如，*Volumes* 对象的可用计数器为 *Latency*、*IOPS* 和 *MB/s*。更改计数器会根据所选计数器重新加载面板数据，以显示表现最佳的项。

+
可用计数器：

+
** 延迟
** IOPS
** MB/秒
** 已用性能容量（用于节点和聚合）
** 利用率（用于节点和聚合）


* *排序*
+
单击*排序*菜单为所选对象和计数器选择升序或降序排序。选项为*从高到低*和*从低到高*。这些选项可用于查看性能最高或性能最低的对象。

* *计数器栏*
+
图形中的计数器栏显示每个对象的性能统计信息，表示为该项目的条形图。条形图采用颜色编码。如果计数器未超出性能阈值，则计数器栏显示为蓝色。如果阈值违规处于活动状态（新的或已确认的事件），条形图将以事件的颜色显示：警告事件显示为黄色（image:../media/treemapstatus_warning_png.gif["用于 TreeMap 的图标 – 警告状态"]），严重事件显示为红色（image:../media/treemapred_png.gif["图标 TreeMap – 红色"]）。警告和严重事件的严重程度事件指示器图标会进一步指示阈值违规。

+
image::../media/top_10_example.gif[显示图形中以计数器条表示的每个对象的性能统计信息的 UI 屏幕截图。]

+
对于每个图形，X 轴显示选定对象类型的最高性能对象。Y 轴显示适用于选定计数器的单位。单击每个垂直条形图元素下方的对象名称链接，导航到选定对象的性能登录页面。

* *严重程度事件指示器*
+
*严重性事件* 指示器图标显示在对象名称的左侧，用于最佳性能图表中的活动严重（image:../media/sev_critical_um60.png["事件严重性图标 – 严重"]）或警告（image:../media/sev_warning_um60.png["事件严重性图标 – 警告"]）事件。单击 *严重性事件* 指示器图标以查看：

+
** *一个事件*
+
导航到该事件的“事件详细信息”页面。

** *两个或两个以上的事件*
+
导航到“事件清单”页面，该页面经过筛选以显示选定对象的所有事件。



* *导出按钮*
+
创建包含计数器栏中显示的数据的 `.csv`文件。您可以选择为正在查看的单个集群或数据中心中的所有集群创建文件。
