= 查看 Active IQ Unified Manager 中 Performance/Node Failover Planning 页面的组件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
“性能/节点故障转移计划”页面的组件显示在网格和“比较”窗格中。这些部分使您能够评估节点故障转移对接管节点性能的影响。



[[performance-statistics-grid]]
== 性能统计网格

性能/节点故障转移规划页面显示一个包含延迟、IOPS、利用率和已用性能容量统计信息的网格。

[NOTE]
====
此页面和“性能/节点性能资源管理器”页面中显示的延迟和 IOPS 值可能不匹配，因为使用不同的性能计数器来计算值以预测节点故障转移。

====
在网格中，每个节点被分配以下角色之一：

* 主云
+
当 HA 配对方发生故障时接管该配对方的节点。根对象始终是主节点。

* 合作伙伴
+
在故障转移场景中发生故障的节点。

* 估计接管
+
与主节点相同。为此节点显示的性能统计信息显示了接管节点在接管故障配对节点后的性能。



[NOTE]
====
虽然接管节点的工作负载相当于故障转移后两个节点的合并工作负载，但预计接管节点的统计数据不是主节点和配对节点统计数据的总和。例如，如果主节点的延迟为 2 ms/op，配对节点的延迟为 3 ms/op，则预计接管节点的延迟可能为 4 ms/op。此值是 Unified Manager 执行的计算。

====
如果您希望 Partner 节点成为根对象，可以单击该 Partner 节点的名称。显示性能/节点性能资源管理器页面后，您可以单击 *故障转移计划* 选项卡，查看此节点故障场景中的性能变化情况。例如，如果 Node1 是 Primary 节点，Node2 是 Partner 节点，则可以单击 Node2 将其设置为 Primary 节点。通过这种方式，您可以看到估计的性能如何根据发生故障的节点而变化。

== 比较窗格

以下列表描述了默认情况下“比较”窗格中显示的组件：

* *事件图表*
+
它们以与“性能/节点性能资源管理器”页面中相同的格式显示。它们仅与主节点相关。

* *计数器图表*
+
它们显示网格中显示的性能计数器的历史统计信息。在每个图表中，估计接管节点的图表显示了在任何给定时间发生故障转移时的估计性能。

+
例如，假设利用率图表显示预估接管节点在 2 月 8 日上午 11 点的利用率为 73%。如果当时发生了故障转移，则接管节点的利用率将为 73%。

+
历史统计数据可帮助您找到启动故障转移的最佳时间，最大限度地减少接管节点过载的可能性。您只能在接管节点的预测性能可接受时安排故障转移。



默认情况下，根对象和配对节点的统计信息都显示在“比较”窗格中。与性能/节点性能资源管理器页面不同，此页面不会显示 *添加* 按钮，供您添加用于统计比较的对象。

您可以像在“性能/节点性能资源管理器”页面中那样自定义“比较”窗格。以下列表显示了自定义图表的示例：

* 单击节点名称可在计数器图表中显示或隐藏该节点的统计信息。
* 单击*缩放视图*以在新窗口中显示特定计数器的详细图表。
