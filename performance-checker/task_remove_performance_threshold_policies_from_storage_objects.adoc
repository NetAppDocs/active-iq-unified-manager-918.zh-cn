= 从 Active IQ Unified Manager 中的存储对象删除性能阈值策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当您不再希望 Unified Manager 监视性能计数器的值时，可以从存储对象中删除用户定义的性能阈值策略。

.开始之前
您必须具有应用程序管理员角色。

一次只能从所选对象中删除一个策略。

您可以通过在列表中选择多个对象来从多个存储对象中删除阈值策略。

.步骤
. 从任何存储对象的*清单*页面中，选择至少应用了一个性能阈值策略的一个或多个对象。
+
|===
| 要从……清除阈值 | 操作 


 a| 
单个对象
 a| 
选中该对象左侧的复选框。



 a| 
多个对象
 a| 
选中每个对象左侧的复选框。



 a| 
页面上的所有对象
 a| 
单击列标题中的 image:../media/select_dropdown_65_png.gif["选择下拉列表图标"]。

|===
. 单击 *清除性能阈值策略*。
+
此时将显示“清除阈值策略”页面，其中显示当前分配给存储对象的阈值策略列表。

. 选择要从对象中删除的阈值策略，然后单击*清除策略*。
+
选择阈值策略时，将显示策略的详细信息，以便确认已选择适当的策略。
