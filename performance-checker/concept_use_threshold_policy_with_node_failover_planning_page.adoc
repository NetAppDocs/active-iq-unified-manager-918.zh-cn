= 在 Active IQ Unified Manager 中为节点故障转移规划创建阈值策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以创建节点阈值策略，以便在潜在的故障转移将接管节点的性能降至不可接受的水平时，在“性能/节点故障转移计划”页面中通知您。

名为 "`Node HA pair over-utilized`" 的系统定义性能阈值策略会在连续六个收集周期（30 分钟）内违反阈值时生成警告事件。如果 HA 对中节点使用的总性能容量超过 200%，则认为该阈值已被违反。

来自系统定义阈值策略的事件提醒您，故障转移将导致接管节点的延迟增加到不可接受的水平。当您看到此策略为特定节点生成的事件时，可以导航到该节点的性能/节点故障转移规划页面，以查看由于故障转移而导致的预测延迟值。

除了使用此系统定义的阈值策略外，您还可以使用 "`Performance Capacity Used - Takeover`" 计数器创建阈值策略，然后将该策略应用于选定节点。指定低于 200% 的阈值可让您在违反系统定义策略的阈值之前接收事件。如果希望在生成系统定义的策略事件之前收到通知，您还可以将超过阈值的最短时间段指定为小于 30 分钟。

例如，您可以定义一个阈值策略，以便在 HA 对中节点使用的总性能容量超过 175% 且持续 10 分钟以上时生成警告事件。您可以将此策略应用于形成 HA 对的 Node1 和 Node2。收到 Node1 或 Node2 的警告事件通知后，您可以查看该节点的性能/节点故障转移计划页面，以评估对接管节点的估计性能影响。您可以采取纠正措施，以避免在发生故障转移时使接管节点过载。如果在节点使用的总性能容量低于 200% 时采取行动，则即使在此期间发生故障转移，接管节点的延迟也不会达到不可接受的水平。
