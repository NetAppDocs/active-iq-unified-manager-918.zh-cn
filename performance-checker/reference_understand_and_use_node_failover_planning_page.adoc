= 使用 Active IQ Unified Manager 中的节点故障转移规划页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果节点的高可用性（HA）配对节点出现故障，“性能/节点故障转移规划”页面将估计对节点的性能影响。Unified Manager 基于 HA 对中节点的历史性能进行估计。

评估故障转移对性能的影响有助于您在以下情况下进行规划：

* 如果故障转移始终将接管节点的估计性能降低到不可接受的水平，则可以考虑采取纠正措施，以减少故障转移对性能的影响。
* 在启动手动故障转移以执行硬件维护任务之前，您可以估计故障转移如何影响接管节点的性能，以确定执行任务的最佳时间。
