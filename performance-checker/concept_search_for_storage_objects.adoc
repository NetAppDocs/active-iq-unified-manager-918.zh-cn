= 在 Active IQ Unified Manager 中搜索存储对象
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用菜单栏顶端的*搜索所有存储对象*字段快速访问特定对象。这种对所有对象进行全局搜索的方法使您能够按类型快速定位特定对象。搜索结果按存储对象类型排序，您可以使用下拉菜单进行筛选。有效的搜索必须至少包含三个字符。

全局搜索显示结果总数，但只有前 25 个搜索结果可供访问。因此，如果您知道要快速查找的项目，则可以将全局搜索功能视为查找特定项目的快捷方式工具。对于完整的搜索结果，您可以使用对象清单页面中的搜索及其相关的筛选功能。

您可以单击下拉框并选择 *全部* 以同时搜索所有对象和事件。或者，您可以单击下拉框来指定对象类型。在 *搜索所有存储对象* 字段中至少输入三个字符的对象或事件名称，然后按 *Enter* 键显示搜索结果，例如：

* 集群：集群名称
* 节点：节点名称
* 聚合：聚合名称
* SVM：SVM 名称
* 卷：卷名
* LUN：LUN 路径


image::../media/opm_search_field_jpg.gif[Unified Manager 中的搜索字段]

[NOTE]
====
LIF 和端口在全局搜索栏中不可搜索。

====
在此示例中，下拉框选择了 Volume 对象类型。在 *Search all Storage Objects* 字段中键入“`vol`”将显示名称包含这些字符的所有卷的列表。对于对象搜索，您可以单击任何搜索结果以导航到该对象的“性能资源管理器”页面。对于事件搜索，单击搜索结果中的项目将导航到“事件详细信息”页面。
