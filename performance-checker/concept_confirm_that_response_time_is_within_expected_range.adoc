= 确认延迟在 Active IQ Unified Manager 中处于预期范围内
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当集群组件处于争用状态时，使用它的卷工作负载的响应时间（延迟）可能会变长。您可以查看争用组件上每个受影响工作负载的延迟，以确认其实际延迟在预期范围内。您还可以单击卷名称以查看该卷的历史数据。

如果性能事件处于过时状态，则事件中涉及的每个受害者的延迟可能已恢复到其预期范围内。
