= 在 Active IQ Unified Manager 中查看性能摘要页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
摘要页面显示计数器图表，其中包含有关前 72 小时内每个对象的事件和性能的详细信息。此数据不会自动刷新，但截至最后一次页面加载时是最新的。摘要页面中的图表回答了问题 _我需要进一步查看吗？_



[[charts-and-counter-statistics]]
== 图表和计数器统计

摘要图表提供了过去 72 小时内的快速、高级别概述，并帮助您识别需要进一步调查的可能问题。

摘要页面的计数器统计信息以图形方式显示。

您可以将光标悬停在图表中的趋势线上，以查看特定时间点的计数器值。摘要图表还显示以下计数器在过去 72 小时内的活动严重和警告事件总数：

* *延迟*
+
所有 I/O 请求的平均响应时间；以每个操作的毫秒数为单位表示。

+
为所有对象类型显示。

* *IOPS*
+
平均运行速度；以每秒的输入/输出操作表示。

+
为所有对象类型显示。

* *MB/s*
+
平均吞吐量；以 MB/秒 表示。

+
为所有对象类型显示。

* *已用性能容量*
+
节点或聚合正在消耗的性能容量百分比。

+
仅针对节点和聚合显示。

* *利用率*
+
节点和聚合的对象利用率或端口的带宽利用率百分比。

+
仅针对节点、聚合和端口显示。



将光标悬停在活动事件的事件计数上，即可显示事件的类型和数量。严重事件显示为红色（image:../media/treemapred_png.gif["图标 TreeMap – 红色"]），警告事件显示为黄色（image:../media/treemapstatus_warning_png.gif["用于 TreeMap 的图标 – 警告状态"]）。

灰色条中图表右上角的数字是过去 72 小时内的平均值。趋势线图底部和顶部显示的数字是过去 72 小时内的最小值和最大值。图表下方的灰色条包含过去 72 小时内的活动（新事件和已确认事件）和过时事件的计数。

image::../media/iops_graph.gif[显示 IOPS 图形的 UI 屏幕截图。]

* *延迟计数器图表*
+
“延迟”计数器图表提供了前 72 小时内对象延迟的高级概述。延迟是指所有 I/O 请求的平均响应时间；以每次操作的毫秒数表示，即所考虑的集群存储组件中的数据包或块所经历的服务时间、等待时间或两者。

+
*Top （计数器值）：* 标题中的数字显示前 72 小时内的平均值。

+
*中间（性能图）：* 图表底部的数字显示最低延迟，图表顶部的数字显示前 72 小时内的最高延迟。将光标悬停在图表趋势线上，以查看特定时间的延迟值。

+
*底部（事件）：*悬停时，弹出窗口显示事件的详细信息。单击图表下方的 *活动事件* 链接，导航到事件清单页面以查看完整的事件详细信息。

* *IOPS 计数器图表*
+
IOPS 计数器图表提供了前 72 小时内对象 IOPS 运行状况的高级概述。IOPS 以每秒输入/输出操作的数量表示存储系统的速度。

+
*Top （计数器值）：* 标题中的数字显示前 72 小时内的平均值。

+
*中间（性能图表）：*图表底部的数字显示最低 IOPS，图表顶部的数字显示前 72 小时内的最高 IOPS。将光标置于图表趋势线上，可查看特定时间的 IOPS 值。

+
*底部（事件）：*悬停时，弹出窗口显示事件的详细信息。单击图表下方的 *活动事件* 链接，导航到事件清单页面以查看完整的事件详细信息。

* *MB/s 计数器图表*
+
MB/s 计数器图表显示对象的 MB/s 性能，并指示与对象之间传输的数据量（以兆字节/秒为单位）。MB/s 计数器图表提供了前 72 小时内对象 MB/s 运行状况的高级概述。

+
*Top （计数器值）：* 标题中的数字显示前 72 小时内的平均 MB/s 数。

+
*中间（性能图）：*图表底部的值显示最低的 MB/s 数，图表顶部的值显示前 72 小时内的最高 MB/s 数。将光标悬停在图表趋势线上，以查看特定时间的 MB/s 值。

+
*底部（事件）：*悬停时，弹出窗口显示事件的详细信息。单击图表下方的 *活动事件* 链接，导航到事件清单页面以查看完整的事件详细信息。

* *已用性能容量计数器图表*
+
Performance Capacity Used 计数器图表显示对象正在消耗的性能容量的百分比。

+
*Top（计数器值）：* 标头中的数字显示前 72 小时内的平均已用性能容量。

+
*中间（性能图）：* 图表底端的值显示最低已用性能容量百分比，图表顶端的值显示前 72 小时内的最高已用性能容量百分比。将光标悬停在图形趋势线上，以查看特定时间的已用性能容量值。

+
*底部（事件）：*悬停时，弹出窗口显示事件的详细信息。单击图表下方的 *活动事件* 链接，导航到事件清单页面以查看完整的事件详细信息。

* *利用率计数器图表*
+
利用率计数器图表显示对象利用率百分比。利用率计数器图表提供了前 72 小时内对象或带宽利用率百分比的总体概述。

+
*Top（计数器值）：*标题中的数字显示前 72 小时内的平均利用率百分比。

+
*中间（性能图）：*图表底部的值显示最低利用率百分比，图表顶部的值显示前 72 小时内的最高利用率百分比。将光标悬停在图表趋势线上，以查看特定时间的利用率值。

+
*底部（事件）：*悬停时，弹出窗口显示事件的详细信息。单击图表下方的 *活动事件* 链接，导航到事件清单页面以查看完整的事件详细信息。

== 事件

事件历史记录表（如适用）列出了该对象上发生的最新事件。单击事件名称会在“事件详细信息”页面上显示事件的详细信息。
