= 确定 Active IQ Unified Manager 中性能事件的来源
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
性能事件是与集群上的工作负载性能相关的问题。它们可帮助您识别响应时间较慢的存储对象，也称为高延迟。结合同时发生的其他运行状况事件，您可以确定可能导致或促成响应时间缓慢的问题。

Unified Manager 从下列来源接收性能事件：

* *用户定义的性能阈值策略事件*
+
基于您设置的自定义阈值的性能问题。您可以为存储对象（例如聚合和卷）配置性能阈值策略，以便在超过性能计数器的阈值时生成事件。

+
必须定义性能阈值策略并将其分配给存储对象以接收这些事件。

* *系统定义的性能阈值策略事件*
+
基于系统定义的阈值的性能问题。这些阈值策略包含在 Unified Manager 的安装中，以涵盖常见的性能问题。

+
默认情况下会启用这些阈值策略，您可能会在添加集群后不久看到事件。

* *动态性能阈值事件*
+
由于 IT 基础架构中的故障或错误，或由于工作负载过度使用集群资源而导致的性能问题。这些事件的原因可能是一个简单的问题，可以在一段时间内自行纠正，也可以通过修复或配置更改来解决。动态阈值事件表示，由于其他工作负载对共享集群组件的使用率较高，ONTAP 系统上的工作负载速度较慢。

+
默认情况下会启用这些阈值，从新集群收集数据三天后，您可能会看到事件。
