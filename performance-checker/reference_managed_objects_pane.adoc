= 查看 Active IQ Unified Manager 中的托管对象窗格
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
“性能摘要”选项卡中的“托管对象”窗格提供了集群的存储对象类型和计数的顶级概述。通过此窗格，您可以跟踪每个集群中对象的状态。

托管对象计数是截至上一个收集周期的时间点数据。每 15 分钟发现一次新对象。

单击任何对象类型的链接编号将显示该对象类型的对象性能清单页面。对象清单页面经过筛选，仅显示此集群上的对象。

托管对象包括：

* *节点*
+
集群中的物理系统。

* *聚合*
+
一组多个独立磁盘冗余阵列（RAID）组，可作为一个单位进行保护和调配管理。

* *端口*
+
节点上用于连接到网络上其他设备的物理连接点。

* *存储 VM*
+
通过唯一网络地址提供网络访问的虚拟机。SVM 可以从不同的命名空间提供数据，并且可以与集群的其他部分分开管理。

* *卷*
+
通过一个或多个受支持的访问协议保存可访问用户数据的逻辑实体。该计数包括 FlexVol 卷和 FlexGroup 卷；它不包括 FlexGroup 成分卷。

* *LUN*
+
光纤通道 (FC) 逻辑单元或 iSCSI 逻辑单元的标识符。逻辑单元通常对应于存储卷，并在计算机操作系统中表示为设备。

* *网络接口*
+
表示到节点的网络接入点的逻辑网络接口。计数包括所有接口类型。
