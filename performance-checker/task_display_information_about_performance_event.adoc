= 在 Active IQ Unified Manager 中显示性能事件信息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用事件管理清单页面查看由 Unified Manager 监控的集群上的所有性能事件列表。通过查看此信息，您可以确定最关键的事件，然后深入查看详细信息以确定事件的原因。

.开始之前
* 您必须具有操作员、应用程序管理员或存储管理员角色。


事件列表按检测时间排序，最近的事件列在前面。您可以单击列标题，根据该列对事件进行排序。例如，您可以按“状态”列进行排序，以按严重程度查看事件。如果您正在查找特定事件或特定类型的事件，则可以使用筛选器和搜索机制来优化列表中显示的事件列表。

所有来源的事件都显示在此页面上：

* 用户定义的性能阈值策略
* 系统定义的性能阈值策略
* 动态性能阈值


“事件类型”列列出了事件的来源。您可以选择一个事件，在“事件详细信息”页面中查看有关该事件的详细信息。

.步骤
. 在左侧导航窗格中，单击*事件管理*。
. 在“视图”菜单中，选择 *活动性能事件*。
+
该页面显示过去 7 天内生成的所有“新建”和“已确认”性能事件。

. 找到要分析的事件，然后单击该事件名称。
+
此时将显示此事件的详细信息页面。

+
[NOTE]
====
您也可以通过单击 Performance Explorer 页面中的事件名称链接或警报电子邮件中的链接来显示事件的详细信息页面。
