= 了解 Active IQ Unified Manager 中的性能计数器图表类型
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
有标准性能图表显示选定存储对象的计数器值。每个细分计数器图表都会显示分为读取、写入和其他类别的总值。此外，当图表在缩放视图中显示时，一些细分计数器图表会显示更多详细信息。

下表显示了可用的性能计数器图表。

|===
| 可用图表 | 图表说明 


 a| 
事件
 a| 
显示与根对象的统计图表相关的关键、错误、警告和信息事件。除了性能事件之外，还会显示健康事件，以全面了解可能影响性能的原因。



 a| 
延迟 - 总计
 a| 
响应应用程序请求所需的毫秒数。请注意，平均延迟值是 I/O 加权的。



 a| 
延迟 - 细分
 a| 
与“延迟总计”中显示的信息相同，但性能数据分为读取、写入和其他延迟。此图表选项仅在所选对象为 SVM 、节点、聚合、卷、 LUN 或命名空间时适用。



 a| 
延迟 - 集群组件
 a| 
显示与“延迟总计”中相同的信息，但性能数据按集群组件划分为延迟。此图表选项仅在所选对象为卷时适用。



 a| 
IOPS - 总计
 a| 
每秒处理的输入/输出操作数。为节点显示时，选择 "`Total`" 将显示通过此节点移动的可能驻留在本地或远程节点上的数据的 IOPS，而选择 "`Total (Local)`" 将显示仅驻留在当前节点上的数据的 IOPS。



 a| 
IOPS - 细分
 a| 
与 IOPS 总计中显示的信息相同，但性能数据分为读取、写入和其他 IOPS。此图表选项仅适用于所选对象是 SVM、节点、聚合、卷、LUN 或命名空间时。

在缩放视图中显示时，如果在 ONTAP 中已配置，卷图表将显示 QoS 最小和最大吞吐量值。

为节点显示时，选择 "`Breakdown`" 将显示通过此节点移动的可能驻留在本地或远程节点上的数据的 IOPS 细分，而选择 "`Breakdown (Local)`" 将显示仅驻留在当前节点上的数据的 IOPS 细分。



 a| 
IOPS - 协议
 a| 
与 IOPS 总计中显示的信息相同，但性能数据分为 CIFS、NFS、FCP、NVMe 和 iSCSI 协议流量的单独图表。此图表选项仅在所选对象为 SVM 时适用。



 a| 
IOPS/TB - 总计
 a| 
基于工作负载正在消耗的总空间（以 TB 为单位）每秒处理的输入/输出操作数。此计数器也称为 I/O 密度，用于衡量给定存储容量可以提供多少性能。在缩放视图中显示时，如果在 ONTAP 中进行了配置，卷图表将显示 QoS 预期和峰值吞吐量值。

此图表选项仅在所选对象是卷时适用。



 a| 
MB/秒 - 总计
 a| 
每秒传输到对象和从对象传输的数据的兆字节数。



 a| 
MB/秒 - 细分
 a| 
与 MB/s 图表中显示的信息相同，但吞吐量数据分为磁盘读取、Flash Cache 读取、写入和其他。在缩放视图中显示时，如果在 ONTAP 中进行了配置，卷图表将显示 QoS 最大吞吐量值。

此图表选项仅在所选对象为 SVM、节点、聚合、卷、LUN 或命名空间时适用。

[NOTE]
====
只有节点才会显示 Flash Cache 数据，并且仅当节点中安装了 Flash Cache 模块时才会显示这些数据。

====


 a| 
已用性能容量 - 总计
 a| 
节点或聚合正在消耗的性能容量的百分比。



 a| 
已用性能容量 - 细分
 a| 
已用性能容量数据分为用户协议和系统后台进程。此外，还显示了可用性能容量。



 a| 
可用 IOPS - 总计
 a| 
此对象上当前可用（空闲）的每秒输入/输出操作数。此数字是从 Unified Manager 计算出该对象可执行的总 IOPS 中减去当前已用 IOPS 的结果。此图表选项仅在所选对象为节点或聚合时适用。



 a| 
利用率 - 总计
 a| 
当前正在使用的对象的可用资源百分比。Utilization 表示节点的节点利用率、聚合的磁盘利用率和端口的带宽利用率。此图表选项仅在所选对象为节点、聚合或端口时适用。



 a| 
缓存未命中率 - 总计
 a| 
从磁盘而不是从缓存返回的客户端应用程序读取请求的百分比。此图表选项仅在所选对象为卷时适用。

|===
