= 在 Active IQ Unified Manager 中使用用户定义的性能阈值策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以为存储对象（例如，聚合和卷）设置性能阈值策略，以便将事件发送给存储管理员，以通知管理员群集遇到性能问题。

您可以通过以下方式为存储对象创建性能阈值策略：

* 选择存储对象
* 选择与该对象关联的性能计数器
* 指定用于定义性能计数器上限的值，这些上限被视为警告和严重情况
* 指定一个时间段，该时间段定义计数器必须超过上限的时间长度


例如，您可以对卷设置性能阈值策略，以便在该卷的 IOPS 连续 10 分钟超过每秒 750 次操作时收到关键事件通知。此相同的阈值策略还可以指定在 IOPS 超过每秒 500 次操作达 10 分钟时发送警告事件。

[NOTE]
====
当前版本提供在计数器值超过阈值设置时发送事件的阈值。您不能设置计数器值低于阈值设置时发送事件的阈值。

====
