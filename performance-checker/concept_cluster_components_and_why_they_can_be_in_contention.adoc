= 了解 Active IQ Unified Manager 中的集群组件和争用情况
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当集群组件发生争用时，您可以识别集群性能问题。使用该组件的工作负载性能会下降，其对客户端请求的响应时间（延迟）会增加，这会在 Unified Manager 中触发事件。

处于争用状态的组件无法在最佳水平下运行。其性能会有所下降，并且其他集群组件和工作负载（称为 _victims_ ）的性能可能会出现延迟增加的情况。要使组件摆脱争用状态，必须减少其工作负载或提高其处理更多工作的能力，以便性能能够恢复到正常水平。由于 Unified Manager 每隔五分钟收集并分析一次工作负载性能，因此它仅在集群组件被持续过度使用时才会检测到。在五分钟间隔内仅持续很短时间的暂时性过度使用峰值不会被检测到。

例如，存储聚合可能存在争用，因为其上的一个或多个工作负载正在争用以满足其 I/O 请求。聚合上的其他工作负载可能会受到影响，导致其性能下降。为了减少聚合上的活动量，您可以采取不同的步骤，例如将一个或多个工作负载移动到不太繁忙的聚合或节点，以减少当前聚合的整体工作负载需求。对于 QoS 策略组，您可以调整吞吐量限制，或将工作负载移动到其他策略组，以便不再限制工作负载。

Unified Manager 可监控以下集群组件，以便在它们发生争用时向您发出警报：

* *网络*
+
表示集群上外部网络协议对 I/O 请求的等待时间。等待时间是指集群在对 I/O 请求做出响应前等待 "`transfer ready`" 事务完成的时间。如果网络组件存在争用，则意味着协议层的等待时间过长会影响一个或多个工作负载的延迟。

* *网络处理*
+
表示集群中涉及协议层和集群之间 I/O 处理的软件组件。自检测到事件以来，负责网络处理的节点可能已发生更改。如果网络处理组件处于争用状态，则意味着网络处理节点的高利用率正在影响一个或多个工作负载的延迟。

+
在双活配置中使用全 SAN 阵列集群时，将显示两个节点的网络处理延迟值，以便您验证节点是否平均分担负载。

* *服务质量（QoS）上限*
+
表示分配给工作负载的存储服务质量（QoS）策略组的吞吐量最大值（峰值）设置。如果策略组组件存在争用，则表示策略组中的所有工作负载都受到设置的吞吐量限制的限制，这会影响其中一个或多个工作负载的延迟。

* *QoS 限制下限*
+
表示分配给其他工作负载的 QoS 吞吐量最小（预期）设置导致的工作负载延迟。如果在某些工作负载上设置的 QoS 最小值使用了大部分带宽来保证承诺的吞吐量，则其他工作负载将受到限制并出现更高的延迟。

* *集群互连*
+
表示与已加入集群的节点物理连接的缆线和适配器。如果集群互连组件处于争用状态，则意味着在集群互连处等待 I/O 请求的时间较长，这会影响一个或多个工作负载的延迟。

* *Data Processing*
+
表示集群中涉及集群和包含工作负载的存储聚合之间的 I/O 处理的软件组件。负责 Data Processing 的节点可能会在检测到事件后发生更改。如果 Data Processing 组件存在争用，则意味着 Data Processing 节点的高利用率会影响一个或多个工作负载的延迟。

* *卷激活*
+
表示跟踪所有活动卷使用情况的过程。在超过 1000 个卷处于活动状态的大型环境中，此过程将跟踪有多少关键卷需要同时通过节点访问资源。当并发活动卷的数量超过建议的最大阈值时，某些非关键卷将出现此处指出的延迟。

* *MetroCluster 资源*
+
表示 MetroCluster 资源，包括 NVRAM 和交换机间链路（ISL），用于在 MetroCluster 配置中的集群之间镜像数据。如果 MetroCluster 组件存在争用，则意味着本地集群上工作负载的高写入吞吐量或链路运行状况问题正在影响本地集群上一个或多个工作负载的延迟。如果集群不在 MetroCluster 配置中，则不显示此图标。

* *聚合或 SSD 聚合操作*
+
表示运行工作负载的存储聚合。如果聚合组件存在争用，则意味着聚合的高利用率正在影响一个或多个工作负载的延迟。聚合由全部 HDD，或者 HDD 和 SSD 的混合（Flash Pool 聚合），或者 HDD 和云层的混合（FabricPool 聚合）组成。"`SSD Aggregate`" 由全部 SSD（全闪存聚合），或者 SSD 和云层的混合（FabricPool 聚合）组成。

* *云延迟*
+
表示集群和存储用户数据的云层之间的 I/O 处理所涉及的软件组件。如果云延迟组件发生争用，则意味着从云层上托管的卷进行的大量读取会影响一个或多个工作负载的延迟。

* *同步 SnapMirror*
+
表示集群中涉及在 SnapMirror 同步关系中将用户数据从主卷复制到辅助卷的软件组件。如果同步 SnapMirror 组件存在争用，则表示来自 SnapMirror 同步操作的活动正在影响一个或多个工作负载的延迟。
