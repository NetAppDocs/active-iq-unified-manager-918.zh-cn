= 在 Active IQ Unified Manager 中为存储对象分配性能阈值策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
将用户定义的性能阈值策略分配给存储对象，以便 Unified Manager 在性能计数器的值超过策略设置时报告事件。

.开始之前
您必须具有应用程序管理员角色。

要应用于对象的性能阈值策略必须存在。

一次只能将一个性能策略应用于一个对象或一组对象。

您最多可以为每个存储对象分配三个阈值策略。在为多个对象分配策略时，如果任何对象已分配了最大数量的策略，则 Unified Manager 将执行以下操作：

* 将策略应用于未达到最大值的所有选定对象
* 忽略已达到策略最大数量的对象
* 显示一条消息，指出未将策略分配给所有对象


.步骤
. 从任何存储对象的性能清单页面中，选择要向其分配阈值策略的对象：
+
|===
| 要将阈值分配给…… | 单击…… 


 a| 
单个对象
 a| 
该对象左侧的复选框。



 a| 
多个对象
 a| 
每个对象左侧的复选框。



 a| 
页面上的所有对象
 a| 
image:../media/select_dropdown_65_png.gif["选择下拉列表图标"] 下拉框，然后选择*选择此页面上的所有对象*。



 a| 
所有相同类型的对象
 a| 
image:../media/select_dropdown_65_png.gif["选择下拉列表图标"] 下拉框，然后选择*选择所有对象*。

|===
+
您可以使用排序和筛选功能来优化清单页面上的对象列表，以便更轻松地将阈值策略应用于许多对象。

. 进行选择，然后单击*分配性能阈值策略*。
+
此时将显示分配性能阈值策略页面，其中显示针对该特定类型存储对象的阈值策略列表。

. 单击每个策略可显示性能阈值设置的详细信息，以验证您选择的阈值策略是否正确。
. 选择适当的阈值策略后，单击*分配策略*。
+
页面顶端的一条成功消息可确认已将阈值策略分配给一个或多个对象，并提供指向“警报”页面的链接，以便您可以为此对象和策略配置警报设置。



如果希望通过电子邮件或 SNMP 陷阱发送警报，以通知您已生成特定的性能事件，则必须在“警报设置”页面中配置警报设置。
