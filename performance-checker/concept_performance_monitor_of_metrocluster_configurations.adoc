= 使用 Active IQ Unified Manager 监控 MetroCluster 性能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 使您能够监控 MetroCluster 配置中集群之间的写入吞吐量，以识别具有高写入吞吐量的工作负载。

如果这些高性能工作负载导致本地集群上的其他卷具有较高的 I/O 响应时间，则 Unified Manager 会触发性能事件以通知您。


NOTE: Unified Manager 将 MetroCluster 配置中的集群视为单独的集群。它不区分互为配对的集群，也不关联每个集群的写入吞吐量。

当 MetroCluster 配置中的本地群集将其数据镜像到其伙伴群集时，数据将写入 NVRAM，然后通过交换机间链路（ISL）传输到远程聚合。Unified Manager 分析 NVRAM 以识别高写入吞吐量过度使用 NVRAM 的工作负载，从而使 NVRAM 处于争用状态。

响应时间偏差超过性能阈值的工作负载称为 _victims_，而对 NVRAM 的写入吞吐量偏差高于平时并导致争用的工作负载称为 _bullies_。由于只有写入请求才会镜像到配对集群，因此 Unified Manager 不会分析读取吞吐量。

您可以通过从以下屏幕分析相应 LUN 和卷的工作负载来查看 MetroCluster 配置中任何集群的吞吐量。您可以按集群筛选结果。在左侧导航窗格中：

* *存储 > 集群 > 性能：所有集群*视图。请参阅
* *存储 > 卷 > 性能：所有卷*视图。
* *存储 > LUN > 性能：所有LUN* 视图。
* *工作负载分析 > 所有工作负载*
