= 了解 Active IQ Unified Manager 中的组合阈值策略对象和计数器

组合策略中只能同时使用某些性能计数器。当指定主性能计数器和辅助性能计数器时，在生成事件之前，两个性能计数器都必须超过其最大限制。

[NOTE]
====
将卷组合策略应用于 FlexGroup 卷而不是 FlexVol 卷时，只能选择“`Volume IOPS`”和“`Volume MB/s`”属性作为辅助计数器。如果阈值策略包含节点或聚合属性之一，则该策略将不会应用于 FlexGroup 卷，并且您将收到描述此情况的错误消息。这是因为 FlexGroup 卷可以存在于多个节点或聚合上。

====
