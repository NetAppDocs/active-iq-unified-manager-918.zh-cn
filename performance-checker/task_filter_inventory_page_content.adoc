= 在 Active IQ Unified Manager 中筛选清单页面内容
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在 Unified Manager 中筛选清单页面数据，以根据特定条件快速查找数据。您可以使用筛选功能来缩小 Unified Manager 页面的内容范围，以仅显示您感兴趣的结果。这提供了一种非常有效的方法，仅显示您感兴趣的数据。

使用 *过滤* 根据您的偏好自定义网格视图。可用的过滤器选项基于在网格中查看的对象类型。如果当前已应用过滤器，则已应用过滤器的数量将显示在“过滤器”按钮的右侧。

支持三种类型的过滤器参数。

|===
| 参数 | 验证 


 a| 
字符串（文本）
 a| 
运算符是*包含*、*以……开头*、*以……结尾*和*不包含*。



 a| 
数字
 a| 
运算符包括*大于*、*小于*、*在最后*和*之间*。



 a| 
枚举（文本）
 a| 
运算符是 *is* 和 *is not*。

|===
每个筛选器都需要 Column（列）、Operator（运算符）和 Value（值）字段；可用的筛选器反映当前页面上的可筛选列。您最多可以应用四个筛选器。筛选结果基于组合的筛选器参数。筛选结果适用于筛选搜索中的所有页面，而不仅仅是当前显示的页面。

您可以使用“过滤”面板添加过滤器。

. 在页面顶部，单击*筛选*按钮。此时将显示筛选面板。
. 单击左侧下拉列表并选择一个对象；例如，_Cluster_ 或性能计数器。
. 单击中部下拉列表，然后选择要使用的运算符。
. 在最后一个列表中，选择或输入一个值以完成此对象的筛选器。
. 要添加其他过滤器，请单击 *+添加过滤器*。此时将显示一个额外的过滤器字段。使用前述步骤中描述的过程完成此过滤器。请注意，添加第四个过滤器后，*+添加过滤器* 按钮不再显示。
. 单击*应用过滤器*。过滤器选项将应用于网格，过滤器的数量将显示在“过滤器”按钮的右侧。
. 使用“筛选”面板，通过单击要删除的筛选器右侧的垃圾箱图标来删除单个筛选器。
. 要删除所有过滤器，请点击过滤面板底部的*重置*。
