= 在 Active IQ Unified Manager 中查看基于本地工作负载的节点 IOPS
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
节点 IOPS 计数器图表可以突出显示仅通过本地节点使用网络 LIF 对远程节点上的卷执行读/写操作的情况。IOPS - "`Total (Local)`" 和 "`Breakdown (Local)`" 图表显示仅驻留在当前节点上本地卷中的数据的 IOPS。

这些计数器图表的“`Local`”版本类似于性能容量和利用率的节点图表，因为它们也仅显示驻留在本地卷上的数据的统计信息。

通过将这些计数器图表的 "`Local`" 版本与这些计数器图表的常规总版本进行比较，您可以查看是否有大量流量通过本地节点访问远程节点上的卷。如果有太多操作通过本地节点到达远程节点上的卷，这种情况可能会导致性能问题，这可能表现为节点上的高利用率。在这些情况下，您可能需要将卷移动到本地节点，或者在远程节点上创建 LIF，以便连接来自访问该卷的主机的流量。

.步骤
. 在您所选节点的*性能/节点资源管理器*页面中，从 IOPS 图表中，从下拉菜单中选择*总计*。
+
此时将显示 IOPS - 总计图表。

. 单击 *缩放视图*，在新的浏览器选项卡中显示较大版本的图表。
. 返回*性能/节点资源管理器*页面，在 IOPS 图表中，从下拉菜单中选择*总计（本地）*。
+
此时将显示 IOPS - 总计（本地）图表。

. 单击 *缩放视图*，在新的浏览器选项卡中显示较大版本的图表。
. 查看彼此相邻的两个图表，并确定 IOPS 值似乎完全不同的区域。
. 将光标移动到这些区域上，以比较特定时间点的本地 IOPS 和总 IOPS。
