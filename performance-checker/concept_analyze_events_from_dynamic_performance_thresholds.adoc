= 分析 Active IQ Unified Manager 中动态性能阈值的事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
由动态阈值生成的事件表明，与预期响应时间范围相比，工作负载的实际响应时间（延迟）过高或过低。您可以使用“事件详细信息”页面分析性能事件，并在必要时采取纠正措施，使性能恢复正常。

[NOTE]
====
在 Cloud Volumes ONTAP、ONTAP Edge 或 ONTAP Select 系统上未启用动态性能阈值。

====
