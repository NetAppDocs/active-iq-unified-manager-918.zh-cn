= 解释 Active IQ Unified Manager 中的性能横幅消息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 可能会在通知页面（来自通知铃）上显示横幅消息，提醒您注意特定集群的状态问题。

|===
| 横幅消息 | 问题描述 | 解决方法 


 a| 
`No performance data is being collected from cluster _cluster_name_. Restart Unified Manager to correct this issue.`
 a| 
Unified Manager 收集服务已停止，并且未从任何集群收集任何性能数据。
 a| 
重新启动 Unified Manager 以更正此问题。如果无法解决问题，请联系技术支持。



 a| 
`More than x hour(s) of historical data is being collected from cluster _cluster_name_. Current data collections will start after all historical data is collected.`
 a| 
当前正在运行数据连续性收集周期以检索实时集群性能收集周期之外的性能数据。
 a| 
无需执行操作。在数据连续性收集周期完成后将收集当前性能数据。

当添加新集群或 Unified Manager 由于某种原因无法收集当前性能数据时，将运行数据连续性收集周期。

|===
