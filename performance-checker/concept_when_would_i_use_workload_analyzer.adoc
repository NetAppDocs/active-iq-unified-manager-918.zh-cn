= 了解何时在 Active IQ Unified Manager 中使用工作负载分析器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您通常会使用工作负载分析器对用户报告的延迟问题进行故障排除，更全面地分析报告的事件或警报，或者探索您发现运行异常的工作负载。

如果用户联系您说他们正在使用的应用程序运行非常缓慢，您可以检查应用程序正在运行的工作负载的延迟、吞吐量和利用率图表，以查看存储是否是性能问题的原因。您也可以使用容量图表查看容量是否较低，因为容量使用率超过 85% 的 ONTAP 系统可能会导致性能问题。这些图表将帮助您确定问题是由存储还是由网络或其他相关问题引起的。

如果 Unified Manager 已生成性能事件，并且您希望更彻底地查看问题的原因，则可以通过单击 *分析工作负载* 按钮从事件详细信息页面启动工作负载分析器，以研究工作负载的一些延迟、吞吐量和容量趋势。

如果您在查看任何工作负载清单页面（卷、LUN、工作负载、NFS 共享或 SMB/CIFS 共享）时发现工作负载似乎运行异常，则可以单击更多图标 image:../media/more_icon.gif[""]，然后单击 *分析工作负载* 打开工作负载分析页面以进一步检查工作负载。
