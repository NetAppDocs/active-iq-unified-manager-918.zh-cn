= 将 Active IQ Unified Manager 性能数据发送到外部服务器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 从其监控的所有集群收集各种性能数据。您可以将特定数据组发送到外部服务器。

根据要绘制的性能数据，可以选择发送以下统计信息组之一：

|===
| 统计组 | 包含的数据 | 详细信息 


 a| 
性能监视器
 a| 
以下对象的高级性能统计信息：

* LUN 数
* 卷

 a| 
此组为所有受监视群集中的所有 LUN 和卷提供总 IOPS 或延迟。

此组提供的统计数据数量最少。



 a| 
资源利用率
 a| 
以下对象的资源利用率统计信息：

* 节点
* 聚合

 a| 
此组提供所有受监视集群中节点和聚合物理资源的利用率统计信息。

它还提供在性能监视器组中收集的统计信息。



 a| 
向下钻取
 a| 
所有跟踪对象的底层读/写和各协议统计信息：

* 节点
* 聚合
* LUN 数
* 卷
* 磁盘
* LIF
* 端口/NIC

 a| 
此组提供所有受监控集群中所有七种跟踪对象类型的读/写和每协议细分。

它还提供在性能监视器组和资源利用率组中收集的统计信息。

此组提供最大数量的统计数据。

|===
[NOTE]
====
如果在存储系统上更改了群集或群集对象的名称，则旧对象和新对象都将包含外部服务器上的性能数据（称为“`metric_path`”）。这两个对象不会作为同一个对象相关联。例如，如果将卷的名称从“`volume1_acct`”更改为“`acct_vol1`”，则会看到旧卷的旧性能数据和新卷的新性能数据。

====
