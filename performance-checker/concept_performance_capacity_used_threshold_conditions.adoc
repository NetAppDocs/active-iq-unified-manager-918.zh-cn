= 在 Active IQ Unified Manager 中配置已用性能容量阈值
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以创建用户定义的性能阈值策略，以便在节点或聚合的性能容量使用值超过定义的性能容量使用阈值设置时触发事件。

此外，可以使用 "`使用的性能容量接管`" 阈值策略来配置节点。此阈值策略汇总 HA 对中两个节点的使用的性能容量统计信息，以确定如果另一个节点发生故障，其中一个节点是否会缺乏足够的容量。由于故障转移期间的工作负载是两个伙伴节点的工作负载的组合，因此可以将相同的使用的性能容量接管策略应用于两个节点。

[NOTE]
====
这种已用性能容量的等效性在节点之间通常是成立的。但是，如果通过其故障转移配对节点发往其中一个节点的跨节点流量明显更多，则在一个配对节点与另一个配对节点上运行所有工作负载时所使用的总性能容量可能会略有不同，具体取决于发生故障的节点。

====
性能容量已用条件还可以用作辅助性能阈值设置，以便在定义 LUN 和卷的阈值时创建组合阈值策略。性能容量已用条件应用于卷或 LUN 所在的聚合或节点。例如，您可以使用以下条件创建组合阈值策略：
