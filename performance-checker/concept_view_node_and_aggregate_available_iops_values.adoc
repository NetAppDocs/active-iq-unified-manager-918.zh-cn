= 查看 Active IQ Unified Manager 中节点和聚合的可用 IOPS 值
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以监控集群中所有节点或所有聚合的可用 IOPS 值，也可以查看单个节点或聚合的详细信息。

可用的 IOPS 值显示在“性能清单”页面以及节点和聚合的“性能资源管理器”页面图表中。例如，在“节点/性能资源管理器”页面中查看节点时，您可以从列表中选择 "`可用 IOPS`" 计数器图表，以便比较该节点以及该节点上多个聚合的可用 IOPS 值。

image::../media/available_iops_zoom.gif[显示如何在“节点/性能资源管理器”页面中查看节点并从列表中选择“可用 IOPS”的 UI 屏幕截图。]

通过监控可用 IOPS 计数器，您可以识别：

* 具有最大可用 IOPS 值的节点或聚合，以帮助确定可以部署未来工作负载的位置。
* 可用 IOPS 值最小的节点或聚合，用于确定应监视以防将来可能出现性能问题的资源。
* 可用 IOPS 值较小的聚合中最繁忙的卷和 LUN。
