= 在 Active IQ Unified Manager 中将工作负载移动到不同的聚合
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Unified Manager 来帮助识别比当前工作负载所在的聚合更不繁忙的聚合，然后可以将选定的卷或 LUN 移动到该聚合。将高性能工作负载移动到不太繁忙的聚合或启用了闪存的聚合，可以使工作负载更高效地运行。

.开始之前
* 您必须具有操作员、应用程序管理员或存储管理员角色。
* 您必须已记录当前存在性能问题的聚合的名称。
* 您必须已记录聚合接收事件的日期和时间。
* Unified Manager 必须已收集并分析了一个月或更长时间的性能数据。


这些步骤可帮助您确定以下资源，以便将高性能工作负载移动到利用率较低的聚合中：

* 同一集群上利用率较低的聚合
* 当前聚合中性能最高的卷


.步骤
. 确定集群中利用率最低的聚合：
+
.. 在*事件*详细信息页面中，单击聚合所在的集群的名称。
+
集群详细信息显示在性能/集群登录页面中。

.. 在*摘要*页面上，单击*托管对象*窗格中的*聚合*。
+
此时将显示此集群上的聚合列表。

.. 单击*利用率*列，按利用率最低对聚合进行排序。
+
您还可以识别具有最大*空闲容量*的聚合。这将提供一个潜在聚合列表，您可能希望将工作负载移动到这些聚合上。

.. 写下要将工作负载移动到的聚合的名称。


. 从接收到该事件的聚合中识别高性能卷：
+
.. 单击存在性能问题的聚合。
+
聚合详细信息显示在“性能/聚合资源管理器”页面中。

.. 从*时间范围*选择器中，选择*过去 30 天*，然后单击*应用范围*。
+
这使您能够查看比默认 72 小时更长的性能历史记录周期。您希望移动一个持续使用大量资源的卷，而不仅仅是在过去 72 小时内。

.. 从*查看和比较*控件中，选择*此聚合上的卷*。
+
此时将显示此聚合上的 FlexVol 卷和 FlexGroup 组成卷的列表。

.. 按最高 MB/s 对卷进行排序，然后按最高 IOPS 对卷进行排序，以查看性能最高的卷。
.. 写下要移动到其他聚合的卷的名称。


. 将高性能卷移动到您确定的利用率较低的聚合。
+
您可以使用 ONTAP System Manager、OnCommand Workflow Automation、ONTAP 命令或这些工具的组合来执行移动操作。



几天后，请检查您是否从此节点或聚合接收到相同类型的事件。
