= 在 Active IQ Unified Manager 中创建用户定义的性能阈值策略
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以为存储对象创建性能阈值策略，以便在性能计数器超过特定值时发送通知。事件通知表明集群遇到性能问题。

.开始之前
您必须具有应用程序管理员角色。

您可以在"Create Performance Threshold Policy"页面上输入阈值来创建性能阈值策略。您可以通过在此页面上定义所有策略值来创建新策略，也可以复制现有策略并更改副本中的值（称为_克隆_）。

数字的有效阈值为 0.001 至 10,000,000，百分比的有效阈值为 0.001-100，已用性能容量百分比的有效阈值为 0.001-200。

[NOTE]
====
当前版本提供在计数器值超过阈值设置时发送事件的阈值。您不能设置计数器值低于阈值设置时发送事件的阈值。

====
.步骤
. 在左侧导航窗格中，选择*事件阈值* > *性能*。
+
此时将显示性能阈值页面。

. 根据您是要创建新策略，还是要克隆类似策略并修改克隆版本，单击相应的按钮。
+
|===
| 目的 | 单击…… 


 a| 
创建新策略
 a| 
*创建*



 a| 
克隆现有策略
 a| 
选择现有策略并单击*克隆*

|===
+
此时将显示“创建性能阈值策略”页面或“克隆性能阈值策略”页面。

. 通过指定要为特定存储对象设置的性能计数器阈值来定义阈值策略：
+
.. 选择存储对象类型并指定策略的名称和描述。
.. 选择要跟踪的性能计数器，并指定定义“警告”和“严重”事件的限制值。
+
必须至少定义一个警告或一个严重限制。无需同时定义两种类型的限制。

.. 如果需要，请选择辅助性能计数器，并指定警告和严重事件的限制值。
+
包含辅助计数器要求在超出阈值并报告事件之前，两个计数器都必须超过限制值。只能使用组合策略配置某些对象和计数器。

.. 选择必须突破限制值才能发送事件的持续时间。


+
克隆现有策略时，必须为策略输入一个新名称。

. 单击 *Save* 保存策略。
+
您将返回到“性能阈值”页面。页面顶端的成功消息确认阈值策略已创建，并提供指向此对象类型的清单页面的链接，以便您可以立即将新策略应用于存储对象。



如果此时要将新的阈值策略应用于存储对象，可以单击 *立即转到 object_type* 链接转到清单页面。
