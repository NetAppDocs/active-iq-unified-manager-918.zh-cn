= 在 Active IQ Unified Manager 中定义用于比较图形的相关对象
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在计数器图表窗格中定义用于数据和性能比较的相关对象列表。例如，如果您的存储虚拟机（SVM）遇到性能问题，则可以比较 SVM 中的所有卷，以确定可能导致问题的卷。

您可以将相关对象网格中的任何对象添加到比较窗格和计数器图表窗格中。这使您能够查看和比较多个对象的数据以及根对象的数据。您可以在相关对象网格中添加和移除对象；但是，比较窗格中的根对象不可移除。

[NOTE]
====
将许多对象添加到“比较”窗格可能会对性能产生负面影响。要保持性能，您应该选择有限数量的图表进行数据比较。

====
.步骤
. 在对象网格中，找到要添加的对象，然后单击*添加*按钮。
+
*Add* 按钮变为灰色，该对象将被添加到“比较”窗格中的附加对象列表中。对象的数据将被添加到“计数器图表”窗格中的图形中。对象的眼睛图标（image:../media/eye_icon.gif[""]）的颜色与图形中对象的数据趋势线的颜色相匹配。

. *可选：* 隐藏或显示所选对象的数据：
+
|===
| 要执行该操作…… | 执行此操作…… 


 a| 
隐藏选定对象
 a| 
在“比较”窗格中单击所选对象的眼睛图标（image:../media/eye_icon.gif[""]）。对象的数据将被隐藏，且该对象的眼睛图标变为灰色。



 a| 
显示隐藏对象
 a| 
单击“比较”窗格中选定对象的灰色眼睛图标。

眼睛图标恢复其原始颜色，对象数据将重新添加到“计数器图表”窗格的图形中。

|===
. *可选：* 从*比较*窗格中删除所选对象：
+
|===
| 要执行该操作…… | 执行此操作…… 


 a| 
删除选定对象
 a| 
将鼠标悬停在比较窗格中所选对象的名称上以显示删除对象按钮 (*X*)，然后单击该按钮。对象将从比较窗格中删除，其数据将从计数器图表中清除。



 a| 
删除所有选定对象
 a| 
单击比较窗格顶部的删除所有对象按钮（*X*）。所有选定对象及其数据都将被删除，只留下根对象。

|===
