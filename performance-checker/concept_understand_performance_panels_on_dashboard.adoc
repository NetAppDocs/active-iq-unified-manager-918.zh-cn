= 查看 Active IQ Unified Manager 控制面板上的性能面板
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 仪表板提供了几个面板，显示环境中正在受监控的所有集群的高级性能状态。您可以选择查看所有集群或单个集群的状态。

除了显示性能信息外，大多数面板还显示该类别中活动事件的数量，以及过去 24 小时内添加的新事件的数量。这些信息有助于您确定可能需要进一步分析哪些集群以解决报告的事件。单击事件将显示前几个事件，并提供指向事件管理清单页面的链接，该页面已过滤以显示该类别中的事件。

以下面板提供性能状态。

* *性能容量面板*
+
在查看所有群集时，此面板显示每个群集的性能容量值（过去 1 小时的平均值）以及直到性能容量达到上限的天数（基于每日增长率）。单击条形图将转到该群集的节点清单页面。请注意，节点清单页面显示过去 72 小时的平均性能容量，因此该值可能与仪表板值不匹配。

+
查看单个集群时，此面板显示集群性能容量、总 IOPS 和总吞吐量值。

* *工作负载 IOPS 面板*
+
启用工作负载活动管理并查看单个集群时，此面板将显示当前在特定 IOPS 范围内运行的工作负载总数。

* *工作负载性能面板*
+
启用工作负载活动管理后，此面板将显示分配给每个定义的性能服务级别的符合和不符合工作负载的总数。单击条形图将转到“工作负载”页面中分配给该策略的工作负载。

* *使用概览面板*
+
查看所有集群时，您可以选择查看按最高 IOPS 或吞吐量 (MB/s) 排序的集群。

+
在查看单个集群时，您可以选择查看该集群上的工作负载，并按最高 IOPS 或吞吐量（MB/s）进行排序。
