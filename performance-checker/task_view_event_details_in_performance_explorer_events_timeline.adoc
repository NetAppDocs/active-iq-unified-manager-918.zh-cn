= 在 Active IQ Unified Manager 事件时间线中查看事件详细信息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在 Performance Explorer 的 Events Timeline 窗格中查看所有事件及其相关详细信息。这是一种快速有效地查看根对象在指定时间范围内发生的所有运行状况和性能事件的方法，在排除性能问题时会有所帮助。

“事件时间线”窗格显示在选定时间范围内发生在根对象上的关键事件、错误事件、警告事件和信息事件。每个事件严重级别都有自己的时间线。单个和多个事件由时间线上的事件点表示。您可以将光标悬停在事件点上以查看事件详细信息。要增加多个事件的视觉粒度，您可以缩短时间范围。这会将多个事件分散为单个事件，使您能够分别查看和调查每个事件。

事件时间轴上的每个性能事件点与事件时间轴下方显示的计数器图表趋势线中的相应尖峰垂直对齐。这在事件和整体性能之间提供了直接的视觉相关性。健康事件也会显示在时间轴上，但这些类型的事件不一定与性能图表中的某个尖峰对齐。

.步骤
. 在*事件时间轴*窗格中，将光标悬停在时间轴上的事件点上，以查看该事件点上的事件摘要。
+
弹出对话框显示有关事件类型、事件发生的日期和时间、状态和事件持续时间的信息。
