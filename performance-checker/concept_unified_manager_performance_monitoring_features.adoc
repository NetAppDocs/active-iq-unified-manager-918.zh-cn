= 探索 Active IQ Unified Manager 性能监控功能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 从运行 ONTAP 软件的系统收集和分析性能统计数据。它使用动态性能阈值和用户定义的性能阈值来监控许多集群组件上的各种性能计数器。

高响应时间（延迟）表明存储对象（例如卷）的运行速度低于正常水平。此问题还表明使用该卷的客户端应用程序的性能已下降。Unified Manager 确定性能问题所在的存储组件，并提供您可以采取的建议操作列表，以解决该性能问题。

Unified Manager 包括以下功能：

* 监控和分析来自运行 ONTAP 软件的系统的工作负载性能统计数据。
* 跟踪群集、节点、聚合、端口、SVM、卷、LUN、NVMe 命名空间和网络接口（LIF）的性能计数器。
* 显示绘制一段时间内工作负载活动的详细图表；包括 IOPS（操作）、MB/s（吞吐量）、延迟（响应时间）、利用率、性能容量和缓存比率。
* 使您能够创建用户定义的性能阈值策略，以便在超出阈值时触发事件并发送电子邮件警报。
* 使用系统定义的阈值和动态性能阈值来学习您的工作负载活动，以识别并提醒您注意性能问题。
* 标识应用于您的卷和 LUN 的服务质量 (QoS) 策略和性能服务级别策略 (PSL)。
* 清楚地识别处于争用状态的集群组件。
* 识别过度使用集群组件的工作负载，以及性能受活动增加影响的工作负载。
