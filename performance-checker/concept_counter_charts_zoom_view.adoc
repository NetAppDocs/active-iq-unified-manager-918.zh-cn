= 了解 Active IQ Unified Manager 中计数器图表的缩放视图
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
计数器图表提供了缩放视图，使您能够放大指定时间段内的性能详细信息。这使您能够以更高的粒度查看性能详细信息和事件，这在对性能问题进行故障排除时非常有用。

在缩放视图中显示时，某些细分图表提供的信息比图表不在缩放视图中时显示的信息更多。例如，IOPS、IOPS/TB 和 MBps 细分图表缩放视图页面会显示卷和 LUN 的 QoS 策略值（如果在 ONTAP 中设置了这些值）。

[NOTE]
====
对于系统定义的性能阈值策略，*Policies* 列表中仅提供“`Node resources over-utilized`”和“`QoS throughput limit breached`”策略。其他系统定义的阈值策略此时不可用。

====
