= 评估集群操作如何影响 Active IQ Unified Manager 中的工作负载延迟
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
操作（IOPS）表示集群上所有用户定义和系统定义工作负载的活动。IOPS 统计数据可帮助您确定集群进程（如进行备份或运行重复数据删除）是否影响工作负载延迟（响应时间），或者是否可能导致或促成了性能事件。

在分析性能事件时，您可以使用 IOPS 统计信息来确定性能事件是否由集群上的问题引起。您可以确定可能是性能事件主要促成因素的特定工作负载活动。IOPS 以每秒操作数（ops/sec）衡量。

image::../media/opm_ops_chart_png.png[Unified Manager IOPS 图表]

此示例显示了 IOPS 图表。实际操作统计数据为蓝线，操作统计数据的 IOPS 预测为绿线。

[NOTE]
====
在某些情况下，如果集群超载，Unified Manager 可能会显示消息 `Data collection is taking too long on Cluster _cluster_name_`。这意味着没有收集足够的统计数据供 Unified Manager 进行分析。您需要减少集群正在使用的资源，以便可以收集统计信息。
