= 在 Active IQ Unified Manager 中识别动态性能事件中的欺凌工作负载
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 Unified Manager 中，您可以识别哪些工作负载对处于争用状态的集群组件的使用量偏差最大。识别这些工作负载有助于您了解集群中某些卷的响应时间（延迟）较慢的原因。

.开始之前
* 您必须具有操作员、应用程序管理员或存储管理员角色。
* 必须有新的、已确认的或过时的动态性能事件。


“事件详细信息”页面显示用户定义和系统定义的工作负载列表，这些工作负载按组件的最高使用率或受事件影响最大的程度进行排序。这些值基于 Unified Manager 在检测到并上次分析事件时识别的峰值。

.步骤
. 显示事件详细信息页面以查看有关事件的信息。
. 在 Workload Latency 和 Workload Activity 图表中，选择 *Bully Workloads*。
. 将光标悬停在图表上以查看影响组件的排名靠前的用户定义恶霸工作负载。
