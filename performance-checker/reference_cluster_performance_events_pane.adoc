= 在 Active IQ Unified Manager 中查看集群性能事件窗格
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
集群性能事件窗格显示集群的性能统计信息和所有活动事件。这在监控集群以及所有与集群相关的性能和事件时非常有用。



[[all-events-on-this-cluster-pane]]
== 此集群窗格上的所有事件

此集群窗格上的所有事件显示前 72 小时的所有活动集群性能事件。活动事件总数显示在最左侧；此数字表示此集群中所有存储对象的所有新事件和已确认事件的总数。您可以单击活动事件总数链接以导航到事件清单页面，该页面经过筛选以显示这些事件。

集群的活动事件总数条形图显示活动关键事件和警告事件的总数：

* 延迟（节点、聚合、SVM、卷、LUN 和命名空间的总计）
* IOPS（集群、节点、聚合、SVM、卷、LUN 和命名空间的总计）
* MB/s（集群、节点、聚合、SVM、卷、LUN、命名空间、端口和 LIF 的总计）
* 已用性能容量（节点和聚合的总计）
* 利用率（节点、聚合和端口的总计）
* 其他（卷的缓存未命中率）


该列表包含由用户定义的阈值策略、系统定义的阈值策略和动态阈值触发的活动性能事件。

对于关键事件，图形数据（垂直计数器条）以红色（image:../media/treemapred_png.gif["图标 TreeMap – 红色"]）显示，对于警告事件，以黄色（image:../media/treemapstatus_warning_png.gif["用于 TreeMap 的图标 – 警告状态"]）显示。将光标悬停在每个垂直计数器条上，以查看事件的实际类型和数量。您可以单击 *Refresh* 以更新计数器面板数据。

您可以通过单击图例中的*关键*和*警告*图标，在总活动事件性能图表中显示或隐藏关键事件和警告事件。如果隐藏某些事件类型，图例图标将以灰色显示。



[[counter-panels]]
== 计数器面板

计数器面板显示前 72 小时的集群活动和性能事件，并包括以下计数器：

* *IOPS 计数器面板*
+
IOPS 表示集群的运行速度，以每秒的输入/输出操作数表示。此计数器面板提供前 72 小时内集群 IOPS 运行状况的高级概述。您可以将光标放在图形趋势线上，以查看特定时间的 IOPS 值。

* *MB/s 计数器面板*
+
MB/s 表示进出集群的数据量，以 MB/秒 为单位。此计数器面板提供前 72 小时内集群 MB/s 运行状况的高级概述。您可以将光标悬停在图形趋势线上，以查看特定时间的 MB/s 值。



灰色条中图表右上角的数字是过去 72 小时内的平均值。趋势线图底部和顶部显示的数字是过去 72 小时内的最小值和最大值。图表下方的灰色条包含过去 72 小时内的活动（新事件和已确认事件）和过时事件的计数。

计数器面板包含两种类型的事件：

* *活动*
+
指示性能事件当前处于活动状态（新建或已确认）。导致事件的问题尚未自行更正或尚未解决。存储对象的性能计数器仍高于性能阈值。

* *已废弃*
+
指示该事件不再处于活动状态。导致该事件的问题已自行更正或已解决。存储对象的性能计数器不再高于性能阈值。



对于*活动事件*，如果有一个事件，您可以将光标悬停在事件图标上，然后单击事件编号以链接到相应的事件详细信息页面。如果存在多个事件，则可以单击*查看所有事件*以显示事件清单页面，该页面经过筛选以显示所选对象计数器类型的所有事件。
