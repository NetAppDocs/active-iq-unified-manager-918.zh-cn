= 使用 Active IQ Unified Manager 中的已用性能容量计数器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
通常，组织希望在已用性能容量百分比低于 100 的情况下运行，以便在有效利用资源的同时，保留一些额外的性能容量来支持高峰期的需求。您可以使用阈值策略自定义何时针对高已用性能容量值发送警报。

您可以根据自己的性能要求制定具体目标。例如，金融服务公司可能会保留更多的性能容量，以保证交易的及时执行。这些公司可能希望在 70-80% 的范围内设置已用性能容量阈值。利润率较低的制造公司如果愿意承担性能风险以更好地管理 IT 成本，可能会选择保留较少的性能容量。这些公司可能会在 85-95% 的范围内设置已用性能容量阈值。

当性能容量使用值超过用户定义的阈值策略中设置的百分比时，Unified Manager 会发送警报电子邮件并将事件添加到事件清单页面。这使您能够在潜在问题影响性能之前对其进行管理。这些事件也可用作指标，指示您需要在节点和聚合中进行工作负载移动和更改。
