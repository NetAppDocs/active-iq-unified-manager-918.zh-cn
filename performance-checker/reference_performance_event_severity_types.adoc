= 在 Active IQ Unified Manager 中按严重性对性能事件进行优先级排序
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
每个性能事件都与严重程度类型相关联，以帮助您对需要立即采取纠正措施的事件进行优先级排序。

* *严重*
+
发生了一个性能事件，如果不立即采取纠正措施，可能会导致服务中断。

+
严重事件仅从用户定义的阈值发送。

* *警告*
+
集群对象的性能计数器超出正常范围，应进行监控以确保其未达到严重级别。此严重级别的事件不会导致服务中断，可能不需要立即采取纠正措施。

+
警告事件从用户定义、系统定义或动态阈值发送。

* *信息*
+
当发现新对象或执行用户操作时，会发生此事件。例如，当删除任何存储对象或发生任何配置更改时，将生成严重性类型为“信息”的事件。

+
当检测到配置更改时，信息事件将直接从 ONTAP 发送。
