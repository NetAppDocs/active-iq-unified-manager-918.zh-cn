= 了解添加磁盘如何影响 Active IQ Unified Manager 中的聚合布局
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以向聚合添加磁盘，以增加该聚合的存储容量和性能。添加磁盘后，只有在重建聚合后才会看到性能提升。

当您在“事件详细信息”页面上收到系统定义的阈值事件时，事件描述文本会列出出现问题的聚合的名称。您可以在此聚合上添加磁盘和重建数据。

添加到聚合的磁盘必须已存在于集群中。如果集群没有可用的额外磁盘，您可能需要联系您的管理员或购买更多磁盘。您可以使用 ONTAP System Manager 或 ONTAP 命令向聚合添加磁盘。
