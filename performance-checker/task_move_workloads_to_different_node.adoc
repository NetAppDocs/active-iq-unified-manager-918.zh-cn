= 将工作负载移动到 Active IQ Unified Manager 中的其他节点
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Unified Manager 帮助识别其他节点上的聚合，该聚合的繁忙程度低于当前运行工作负载的节点，然后您可以将所选卷移动到该聚合。将高性能工作负载移动到不太繁忙的节点上的聚合，可以使两个节点上的工作负载更高效地运行。

.开始之前
* 您必须具有操作员、应用程序管理员或存储管理员角色。
* 您必须已记录当前存在性能问题的节点的名称。
* 必须已记录节点接收性能事件的日期和时间。
* Unified Manager 必须已收集并分析性能数据一个月或更长时间。


此过程可帮助您确定以下资源，以便将高性能工作负载移动到利用率较低的节点：

* 同一集群中空闲性能容量最大的节点
* 新节点上具有最大空闲性能容量的聚合
* 当前节点上性能最高的卷


.步骤
. 确定集群中具有最大可用性能容量的节点：
+
.. 在*事件详细信息*页面上，单击节点所在集群的名称。
+
集群详细信息显示在性能/集群登录页面中。

.. 在*摘要*选项卡上，单击*托管对象*窗格中的*节点*。
+
此时将显示此集群上的节点列表。

.. 单击*已用性能容量*列，按已用最少百分比对节点进行排序。
+
这提供了可能需要将工作负载移动到的潜在节点的列表。

.. 写下要将工作负载移动到的节点的名称。


. 识别新节点上利用率最低的聚合：
+
.. 在左侧导航窗格中，单击*存储* > *聚合*，然后从视图菜单中选择*性能* > *所有聚合*。
+
此时将显示“性能：所有聚合”视图。

.. 单击*过滤*，从左侧下拉菜单中选择*节点*，在文本字段中键入节点的名称，然后单击*应用过滤器*。
+
“性能：所有聚合”视图将与此节点上可用的聚合列表一起重新显示。

.. 单击*已用性能容量*列，按最少使用对聚合进行排序。
+
这提供了可能要将工作负载移动到的潜在聚合的列表。

.. 写下要将工作负载移动到的聚合的名称。


. 识别来自接收该事件的节点的高性能工作负载：
+
.. 返回此事件的*事件详细信息*页面。
.. 在*受影响的卷*字段中，单击卷数量的链接。
+
此时将显示"Performance: All Volumes （性能：所有卷）"视图，其中包含该节点上卷的筛选列表。

.. 单击*总容量*列，按分配的最大空间对卷进行排序。
+
这提供了可能需要移动的潜在卷的列表。

.. 记下要移动的卷的名称，以及它们所在的当前聚合的名称。


. 将卷移动到您确定在新节点上具有最大可用性能容量的聚合。
+
您可以使用 ONTAP System Manager、OnCommand Workflow Automation、ONTAP 命令或这些工具的组合来执行移动操作。



几天后，您可以检查是否从此节点或聚合接收到相同类型的事件。
