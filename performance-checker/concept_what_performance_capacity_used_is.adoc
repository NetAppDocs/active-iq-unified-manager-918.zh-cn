= 了解 Active IQ Unified Manager 中已用性能容量计数器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
已用性能容量计数器可帮助您确定节点或聚合的性能是否已达到如果工作负载增加性能可能会下降的临界点。它还可以显示节点或聚合当前是否在特定时间段内被过度使用。已用性能容量类似于利用率，但前者提供了有关特定工作负载的物理资源中可用性能功能的更多见解。

最佳已用性能容量是指节点或聚合具有最佳利用率和延迟（响应时间）并得到高效利用的点。下图显示了聚合的延迟与利用率示例曲线。

image::../media/headroom_chart.gif[显示聚合的样本延迟与利用率曲线的 UI 屏幕截图。]

在此示例中，_operational point_ 标识聚合当前以 50% 的利用率运行，延迟为 1.0 ms/op。根据从聚合中捕获的统计数据，Unified Manager 确定此聚合还有额外的可用性能容量。在此示例中，_optimal point_ 被标识为聚合处于 80% 利用率且延迟为 2.0 ms/op 的点。因此，您可以向此聚合添加更多卷和 LUN，以便更有效地使用您的系统。

已用性能容量计数器预计会大于“`utilization`”计数器，因为性能容量将对延迟的影响计算在内。例如，如果节点或聚合的已用量为 70%，则性能容量值可能在 80% 到 100% 的范围内，具体取决于延迟值。

但是，在某些情况下，仪表板页面上的利用率计数器可能会更高。这是正常的，因为仪表板会在每个收集期间刷新当前计数器值；它不会像 Unified Manager 用户界面中的其他页面那样显示一段时间内的平均值。已用性能容量计数器最适合用作一段时间内平均性能的指标，而利用率计数器最适合用于确定资源的即时使用情况。
