= 了解 Active IQ Unified Manager 中的计数器图表
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
“计数器图表”窗格中的图表可用于查看和比较根对象以及从相关对象网格中添加的对象的性能数据。这可以帮助您了解性能趋势，并隔离和解决性能问题。

默认显示的计数器图表为事件、延迟、IOPS 和 MBps。您可以选择显示的可选图表是利用率、已使用性能容量、可用 IOPS、IOPS/TB 和缓存未命中率。此外，您可以选择查看延迟、IOPS、MBps 和已使用性能容量图表的总值或细分值。

默认情况下，性能资源管理器会显示某些计数器图表，无论存储对象是否全部支持这些图表。当不支持某个计数器时，计数器图表将为空，并显示消息 `Not applicable for <object>`。

图表显示根对象以及您在“比较”窗格中选择的所有对象的性能趋势。每个图表中的数据排列如下：

* *X轴*
+
显示指定的时间段。如果未指定时间范围，则默认为前 72 小时。

* *Y 轴*
+
显示选定对象特有的计数器单位。



趋势线颜色与“比较”窗格中显示的对象名称的颜色相匹配。您可以将光标定位在任何趋势线上的点上，以查看该点的时间和值的详细信息。

如果要调查图表中的特定时间段，可以使用下列方法之一：

* 使用 *<* 按钮展开计数器图表窗格，使其跨越页面宽度。
* 使用光标（切换到放大镜时）在图表中选择一部分时间范围来聚焦和放大该区域。您可以单击重置图表缩放，将图表返回到默认时间范围。
* 使用*缩放视图*按钮可显示包含扩展详细信息和阈值指标的大型单个计数器图表。


[NOTE]
====
趋势线中偶尔会出现间隙。间隙意味着 Unified Manager 无法从存储系统收集性能数据，或者 Unified Manager 可能已停机。
