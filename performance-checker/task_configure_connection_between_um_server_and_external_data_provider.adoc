= 配置 Active IQ Unified Manager 与外部数据提供程序之间的连接
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Unified Manager 可以将群集性能数据发送到外部服务器。您可以指定发送的统计数据的类型以及发送数据的时间间隔。

.开始之前
* 您必须拥有授权的用户 ID 才能登录到 Unified Manager 服务器的维护控制台。
* 您必须具有下列有关外部数据提供程序的信息：
+
** 服务器名称或 IP 地址（IPv4 或 IPv6）
** 服务器默认端口（如果不使用默认端口 2003）


* 必须已配置远程服务器和第三方软件，以便它可以从 Unified Manager 服务器接收统计数据。
* 您必须知道您要发送哪一组统计信息：
+
** PERFORMANCE_INDICATOR: 性能监控统计信息
** RESOURCE_UTILIZATION：资源利用率和性能监视器统计信息
** DRILL_DOWN：所有统计信息


* 您必须知道要传输统计信息的时间间隔：5、10 或 15 分钟
+
默认情况下，Unified Manager 会以 5 分钟为间隔收集统计信息。如果将传输间隔设置为 10（或 15）分钟，则每次传输期间发送的数据量将比使用默认 5 分钟间隔时大两倍（或三倍）。

+
[NOTE]
====
如果将 Unified Manager 性能收集时间间隔更改为 10 或 15 分钟，则必须将传输时间间隔更改为等于或大于 Unified Manager 收集时间间隔。

====


您可以配置一个 Unified Manager 服务器和一个外部数据提供程序服务器之间的连接。

.步骤
. 请以维护用户身份登录到 Unified Manager 服务器的维护控制台。
+
此时将显示 Unified Manager 维护控制台提示。

. 在维护控制台中，键入*外部数据提供程序*菜单选项的编号。
+
此时将显示外部服务器连接菜单。

. 键入*添加/修改服务器连接*菜单选项的编号。
+
此时将显示当前服务器连接信息。

. 出现提示时，键入 `*y*`以继续。
. 出现提示时，输入目标服务器的 IP 地址或名称以及服务器端口信息（如果与默认端口 2003 不同）。
. 出现提示时，键入 `*y*`以确认您输入的信息正确无误。
. 按任意键返回“外部服务器连接”菜单。
. 键入*修改服务器配置*菜单选项的编号。
+
此时将显示当前服务器配置信息。

. 出现提示时，键入 `*y*`以继续。
. 出现提示时，请输入要发送的统计信息类型、发送统计信息的时间间隔以及是否要立即启用统计信息的传输：
+
|===
| 对于…… | 输入…… 


 a| 
统计组 ID
 a| 
`*0*` - PERFORMANCE_INDICATOR（默认）

`*1*` - RESOURCE_UTILIZATION

`*2*` - DRILL_DOWN



 a| 
供应商标记
 a| 
将在外部服务器上存储统计信息的文件夹的描述性名称。“`netapp-performance`”是默认名称，但您可以输入其他值。

通过使用点号表示法，您可以定义分层文件夹结构。例如，通过输入 `*stats.performance.netapp*`，统计信息将位于 *stats* > *performance* > *netapp* 中。



 a| 
传输间隔
 a| 
`*5*` （默认）、 `*10*` 或  `*15*` 分钟



 a| 
启用/禁用
 a| 
`*0*` - 禁用

`*1*` - 启用（默认）

|===
. 出现提示时，键入 `*y*`以确认您输入的信息正确无误。
. 按任意键返回“外部服务器连接”菜单。
. 键入 `*x*`以退出维护控制台。


配置连接后，所选性能数据将按指定的时间间隔发送到目标服务器。需要几分钟时间，指标才会显示在外部工具中。您可能需要刷新浏览器才能查看指标层次结构中的新指标。
