= 了解 Active IQ Unified Manager 中的数据连续性收集周期
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
数据连续性收集周期将在默认情况下每五分钟运行一次的实时集群性能收集周期之外检索性能数据。数据连续性收集使 Unified Manager 能够填补无法收集实时数据时出现的统计数据空缺。

当发生以下事件时，Unified Manager 将对历史性能数据执行数据连续性收集轮询：

* 集群最初被添加到 Unified Manager。
+
Unified Manager 收集过去 15 天的历史性能数据。这使您能够在添加集群几个小时后查看集群的两周历史性能信息。

+
此外，如果存在系统定义的阈值事件，则报告上一期间的事件。

* 当前性能数据收集周期未按时完成。
+
如果实时性能轮询超过了五分钟的收集周期，则会启动数据连续性收集周期以收集缺失的信息。如果没有数据连续性收集，则会跳过下一个收集周期。

* Unified Manager 已无法访问一段时间，然后重新上线，如以下情况所示：
+
** 它已重新启动。
** 它在软件升级或创建备份文件时被关闭。
** 修复了网络中断。


* 某个集群在一段时间内无法访问，然后重新上线，如以下情况所示：
+
** 修复了网络中断。
** 缓慢的广域网连接延迟了性能数据的正常收集。




数据连续性收集周期最多可收集 24 小时的历史数据。如果 Unified Manager 停机时间超过 24 小时，UI 页面中会出现性能数据缺失。

数据连续性采集周期和实时数据采集周期不能同时运行。数据连续性采集周期必须在启动实时性能数据采集之前完成。当需要数据连续性采集来收集超过一小时的历史数据时，您会在“通知”窗格顶部看到该集群的横幅消息。
