= 在 Active IQ Unified Manager 中选择预定义的时间范围
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
选择预定义的时间范围是您在查看集群对象性能数据时自定义和聚焦数据输出的一种快速有效的方法。选择预定义的时间范围时，最多可提供 13 个月的数据。

.步骤
. 在*性能资源管理器*页面的右上角，单击*时间范围*。
. 从*时间范围选择*面板的右侧，选择一个预定义的时间范围。
. 单击*应用范围*。
