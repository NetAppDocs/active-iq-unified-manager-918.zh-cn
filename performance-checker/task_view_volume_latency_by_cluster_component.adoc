= 在 Active IQ Unified Manager 中按集群组件查看卷延迟
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用“卷性能资源管理器”页面查看卷的详细延迟信息。Latency - Total 计数器图表显示卷上的总延迟，Latency - Breakdown 计数器图表可用于确定读取和写入延迟对卷的影响。

此外，“延迟-集群组件”图表显示了每个集群组件延迟的详细比较，以帮助确定每个组件如何影响卷上的总延迟。将显示以下集群组件：

* 网络
* 服务质量 (QoS) 上限
* 服务质量 (QoS) 下限
* 网络处理
* 集群互连
* 数据处理
* 聚合操作
* 卷激活
* MetroCluster 资源
* 云延迟
* 同步 SnapMirror


.步骤
. 在所选卷的*卷性能资源管理器*页面中，从延迟图表的下拉菜单中选择*集群组件*。
+
此时将显示延迟 - 集群组件图表。

. 要查看较大版本的图表，请选择*缩放视图*。
+
此时将显示集群组件对比图。您可以通过取消选择或选择与每个集群组件关联的 image:../media/eye_icon.gif["眼睛图标"] 来限制比较。

. 要查看具体值，请将光标移至图表区域以查看弹出窗口。
