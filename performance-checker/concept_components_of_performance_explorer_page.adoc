= 查看 Active IQ Unified Manager 中的性能资源管理器页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
“性能资源管理器”页面使您能够比较集群中类似对象的性能，例如集群中的所有卷。这在对性能事件进行故障排除和微调对象性能时非常有用。您还可以将对象与根对象进行比较，根对象是进行其他对象比较的基准。

您可以单击 *切换至运行状况视图* 按钮以显示此对象的运行状况详细信息页面。在某些情况下，您可以了解有关此对象的存储配置设置的重要信息，这可能有助于进行故障排除。

“性能资源管理器”页面显示集群对象及其性能数据的列表。此页面以表格格式显示相同类型的所有集群对象（例如，卷及其特定对象的性能统计信息）。此视图提供集群对象性能的有效概览。

[NOTE]
====
如果 "`N/A`" 出现在表的任何单元格中，则表示该计数器的值不可用，因为此时该对象上没有 I/O。

====
“性能资源管理器”页面包含以下组件：

* *时间范围*
+
使您能够为对象数据选择时间范围。

+
您可以选择预定义范围，也可以指定自己的自定义时间范围。

* *查看和比较*
+
使您能够选择在网格中显示哪种类型的相关对象。

+
可用的选项取决于根对象类型及其可用数据。您可以单击“查看和比较”下拉列表来选择对象类型。您选择的对象类型将显示在列表中。

* *筛选*
+
使您能够根据自己的偏好来缩小接收的数据量。

+
您可以创建应用于对象数据的筛选器——例如，IOPS 大于 4。您最多可同时添加四个筛选条件。

* *比较*
+
显示您已选择与根对象进行比较的对象列表。

+
“比较”窗格中对象的数据显示在计数器图表中。

* *查看统计信息*
+
对于卷和 LUN ，允许您选择是在每个收集周期（默认为 5 分钟）之后显示统计信息，还是将统计信息显示为每小时平均值。此功能使您能够查看延迟图表，以支持 NetApp “性能保证”计划。

* *计数器图表*
+
显示每个对象性能类别的图形化数据。

+
通常，默认情况下只显示三到四个图表。选择图表组件使您可以显示其他图表，或隐藏特定的图表。您还可以选择显示或隐藏事件时间轴。

* *事件时间轴*
+
显示在时间范围组件中选择的时间轴上发生的性能和运行状况事件。
