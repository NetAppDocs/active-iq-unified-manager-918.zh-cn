= 在 Active IQ Unified Manager 中的远程集群上分析 MetroCluster 性能事件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Unified Manager 分析 MetroCluster 配置中远程集群上的动态性能事件。该分析可帮助您确定远程集群上的事件是否导致了其伙伴集群上的事件。

.开始之前
* 您必须具有操作员、应用程序管理员或存储管理员角色。
* 您必须已在 MetroCluster 配置中分析本地集群上的性能事件，并获得了事件检测时间。
* 您必须已检查参与性能事件的本地集群及其伙伴集群的运行状况，并获取了伙伴集群的名称。


.步骤
. 登录到正在监视配对集群的 Unified Manager 实例。
. 在左侧导航窗格中，单击*事件*以显示事件列表。
. 从*时间范围*选择器中，选择*最近一小时*，然后单击*应用范围*。
. 在*过滤*选择器中，从左侧下拉菜单中选择*集群*，在文本字段中键入伙伴集群的名称，然后单击*应用过滤器*。
+
如果在过去一小时内选定集群没有发生任何事件，则表明该集群在其配对节点上检测到事件期间没有遇到任何性能问题。

. 如果所选集群在过去一小时内检测到事件，请将事件检测时间与本地集群上事件的事件检测时间进行比较。
+
如果这些事件涉及在数据处理组件上引发争用的恶霸工作负载，则其中一个或多个恶霸可能在本地集群上引发该事件。您可以单击事件以对其进行分析，并在事件详细信息页面上查看解决该事件的建议操作。

+
如果这些事件不涉及霸道工作负载，则它们并未导致本地集群上发生性能事件。
