= 了解 Active IQ Unified Manager 的协议和端口要求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
所需的端口和协议支持 Unified Manager 服务器与托管存储系统、服务器和其他组件之间的通信。



[[connections-to-the-unified-manager-server]]
== 到 Unified Manager 服务器的连接

在典型安装中，连接到 Unified Manager Web UI 时不必指定端口号，因为始终使用默认端口。例如，由于 Unified Manager 始终尝试在其默认端口上运行，因此您可以输入 `+https://<host>+`而不是 `+https://<host>:443+`。

Unified Manager 服务器使用特定协议访问以下接口：

[cols="4*"]
|===
| 接口 | 协议 | 端口 | 问题描述 


 a| 
Unified Manager Web UI
 a| 
HTTP
 a| 
80
 a| 
用于访问 Unified Manager Web UI；自动重定向到安全端口 443。



 a| 
Unified Manager Web UI 和使用 API 的程序
 a| 
HTTPS
 a| 
443
 a| 
用于安全地访问 Unified Manager Web UI 或进行 API 调用；只能使用 HTTPS 进行 API 调用。



 a| 
维护控制台
 a| 
SSH/SFTP
 a| 
22
 a| 
用于访问维护控制台并检索支持包。



 a| 
Linux 命令行
 a| 
SSH/SFTP
 a| 
22
 a| 
用于访问 Red Hat Enterprise Linux 命令行并检索支持捆绑包。



 a| 
系统日志
 a| 
UDP
 a| 
514
 a| 
用于从 ONTAP 系统访问基于订阅的 EMS 消息，并根据这些消息创建事件。



 a| 
REST
 a| 
HTTPS
 a| 
9443
 a| 
用于从经过身份验证的 ONTAP 系统访问基于实时 REST API 的 EMS 事件。



 a| 
MySQL 数据库
 a| 
MySQL
 a| 
3306
 a| 
用于启用 OnCommand Workflow Automation 和 OnCommand API Services 对 Unified Manager 的访问。



 a| 
AMQP QPID 代理
 a| 
TCP/IP
 a| 
56072
 a| 
用于内部消息通信。



 a| 
AMQP QPID 代理
 a| 
WebSocket over TCP
 a| 
56080
 a| 
用于在此端口上侦听从 ONTAP（云代理）接收的消息。



 a| 
AMQP QPID 代理
 a| 
WebSocket over TCP
 a| 
56443
 a| 
用于在此端口上侦听从 ONTAP（云代理）接收的消息。此端口上的通信支持 TLS 或 SSL 提供的加密。

|===
[NOTE]
====
在 VMware vSphere 系统上安装 Unified Manager 时，MySQL 的默认端口 3306 仅限于 localhost。这不会影响任何升级场景，在这些场景中会保留先前的配置。可以修改此配置，并且可以使用维护控制台上的  `Control access to MySQL port 3306` 选项使其他主机能够建立连接。有关信息，请参见 link:../config/reference_additional_menu_options.html["其他菜单选项"]。可以使用 Unified Manager 维护控制台更改用于 HTTP 和 HTTPS 通信的端口（端口 80 和 443）。有关详细信息，请参见 link:../config/concept_maintenance_console_menu.html["维护控制台菜单"]。

====


[[connections-from-the-unified-manager-server]]
== 来自 Unified Manager 服务器的连接

您应将防火墙配置为打开端口，以启用 Unified Manager 服务器与受管存储系统、服务器和其他组件之间的通信。如果端口未打开，则通信失败。

根据您的环境，可以选择修改 Unified Manager 服务器用于连接到特定目标的端口和协议。

Unified Manager 服务器使用以下协议和端口连接到托管存储系统、服务器和其他组件：

存储系统

HTTPS

NOTE: 如果要使用此端口或任何其他端口连接到 VMware vCenter Server 或 ESXi 服务器，请确保端口可用并且可以在安全站点中连接。



 a| 
存储系统
 a|
