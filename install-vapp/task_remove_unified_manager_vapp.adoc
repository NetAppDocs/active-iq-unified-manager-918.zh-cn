= 删除 Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以通过删除安装了 Unified Manager 软件的虚拟机（VM）来卸载 Unified Manager。

.开始之前
* 您应具有访问 VMware vCenter Server 和 vSphere Web Client 的凭据。
* 应关闭 Unified Manager 服务器到 Workflow Automation 服务器的任何活动连接。
* 在删除虚拟机（VM）之前，应从 Unified Manager 服务器中删除所有集群（数据源）。


.步骤
. 请使用 Unified Manager 维护控制台验证 Unified Manager 服务器没有到外部数据提供程序的活动连接。
. 在 vSphere 客户端中，单击 *主页* > *清单* > *虚拟机和模板*。
. 选择要删除的虚拟机，然后单击*摘要*选项卡。
. 如果虚拟机正在运行，请单击*电源* > *关闭客户机*。
. 右键单击要删除的虚拟机，然后单击*从磁盘删除*。
