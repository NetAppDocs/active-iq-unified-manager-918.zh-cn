= 下载 Active IQ Unified Manager 升级文件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在升级 Unified Manager 之前，请从 NetApp 支持站点下载 Unified Manager 升级文件。

.开始之前
您应该拥有 NetApp 支持站点的登录凭据。

.步骤
. 登录到 NetApp 支持站点：
+
https://mysupport.netapp.com/site/products/all/details/activeiq-unified-manager/downloads-tab["NetApp 支持站点"]

. 导航到下载页面以升级 VMware vSphere 上的 Unified Manager。
. 请下载要升级的 `.iso`映像，并将其保存到您的 vSphere Client 可访问的本地目录或网络目录。
. 验证校验和，以确保软件已正确下载。
