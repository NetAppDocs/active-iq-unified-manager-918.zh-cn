= 了解 Active IQ Unified Manager 的 VMware 软件和安装要求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
安装 Unified Manager 的 VMware vSphere 系统需要特定版本的操作系统和特定版本的支持软件。



[[operating-system-software]]
== 操作系统软件

支持的操作系统是 VMware ESXi 8.0。

[NOTE]
====
VMware vSphere 系统上的 Unified Manager OVA 在内部运行 Debian OS 13 (Trixie)。有关受支持版本的 ESXi 服务器可以支持的虚拟机硬件版本的信息，请参见 VMware 文档。

====
支持以下版本的 vSphere：

* VMware vCenter Server 7.0 和 8.0


有关受支持的 ESXi 版本的完整和最新列表，请参见互操作性列表。

http://mysupport.netapp.com/matrix["mysupport.netapp.com/cn/matrix"]

为了使虚拟设备正常运行，VMware ESXi 服务器时间应与 NTP 服务器时间相同。将 VMware ESXi 服务器时间与 NTP 服务器时间同步可防止时间故障。



[[installation-requirements]]
== 安装要求

支持 Unified Manager 虚拟应用装置的 VMware High Availability。

如果在运行 ONTAP 软件的存储系统上部署 NFS 数据存储，请使用适用于 VMware VAAI 的 NetApp NFS 插件来使用厚配置。

如果由于资源不足而导致使用启用了高可用性的环境部署失败，您可能需要通过禁用 VM 重新启动优先级并保持主机隔离响应处于开启状态，来修改群集功能虚拟机选项。


NOTE: 在安装或升级 Unified Manager 时，所需的第三方软件和安全修补程序会自动安装或升级到 VMware vSphere 系统上。由于 Unified Manager 安装和升级过程控制这些组件，因此不应尝试独立安装或升级任何第三方组件。
