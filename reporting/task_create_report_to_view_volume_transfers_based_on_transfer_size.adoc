= 在 Active IQ Unified Manager 中创建报告以按传输大小查看卷传输
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以创建报告，以根据传输大小查看卷传输。

.开始之前
* 您必须具有应用程序管理员或存储管理员角色。


使用以下步骤创建基于传输大小的卷传输的自定义视图，然后计划为该视图生成报告。

.步骤
. 在左侧导航窗格中，单击 *Storage* > *Volumes*。
. 在查看菜单中，选择 *关系* > *过去 1 个月的传输速率*。
. 单击 "`Total Transfer Size`" 列的顶部，按大小对卷传输进行排序。
. 使用反映视图显示内容的特定名称保存视图，例如“`Volumes by transfer size`”。
. 单击清单页面上的 *Scheduled Reports* 按钮。
. 输入报告计划的名称并填写其他报告字段，然后单击该行末尾的复选标记（image:../media/blue_check.gif[""]）。
+
此时将立即发送一个测试报告。之后，此报告将以指定频率生成并通过电子邮件发送给列出的收件人。



根据报告中显示的结果，您可以按传输大小调查卷关系。
