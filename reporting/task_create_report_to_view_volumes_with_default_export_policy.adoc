= 创建报告以查看在 Active IQ Unified Manager 中使用默认导出策略的卷
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以创建报告以查找正在使用默认导出策略的卷。

.开始之前
* 您必须具有应用程序管理员或存储管理员角色。


使用以下步骤为使用默认导出策略的卷创建自定义视图，然后计划为该视图生成报告。

.步骤
. 在左侧导航窗格中，单击*存储* > *NFS 共享*。
. 选择*显示/隐藏*以删除报告中不希望出现的任何列。
. 将 "`导出策略`" 列拖到 "`卷`" 列附近。
. 单击过滤器图标，添加以下过滤器，然后单击*应用过滤器*：
+
** 导出策略包含默认值


. 使用反映视图显示内容的特定名称保存视图，例如“`使用默认导出策略的卷`”，然后单击复选标记（image:../media/blue_check.gif[""]）。
. 单击清单页面上的 *Scheduled Reports* 按钮。
. 单击 *Add Schedule* 可在 Report Schedules 页面中添加新行，以便为新报告定义计划特征。
. 输入报告计划的名称并填写其他报告字段，然后单击该行末尾的复选标记（image:../media/blue_check.gif[""]）。
+
此时将立即发送一个测试报告。之后，此报告将以指定频率生成并通过电子邮件发送给列出的收件人。



根据报告中显示的结果，您可能需要配置自定义导出策略。
