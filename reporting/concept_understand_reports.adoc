= 了解 Active IQ Unified Manager 中的报告
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
报告显示有关存储、网络、服务质量和保护关系的详细信息，帮助您在潜在问题发生之前识别和解决问题。

自定义视图时，您可以使用唯一的名称保存视图，以备将来使用。您可以根据该视图计划定期运行报告并与其他人共享。您也可以以 Excel 格式下载视图，以使用高级 Excel 功能对其进行自定义，然后将该文件上传回 Unified Manager。如果您使用该视图计划报告，它将使用您上传的 Excel 文件来创建您可以共享的可靠报告。

您可以从“报告计划”页面管理已计划的所有报告。

[NOTE]
====
要管理报告，您必须具有应用程序管理员或存储管理员角色。

====
您可以将报告下载为逗号分隔值（CSV）、Excel 或 PDF 文件。
