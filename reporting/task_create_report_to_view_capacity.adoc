= 创建报告以在 Active IQ Unified Manager 中显示聚合容量表和图表
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用总计和簇状柱形图格式创建报表，以分析 Excel 文件中的容量。

.开始之前
* 您必须具有应用程序管理员或存储管理员角色。


使用以下步骤打开运行状况：所有聚合视图，在 Excel 中下载视图，创建可用容量图表，上传自定义的 Excel 文件，并计划最终报告。

.步骤
. 在左侧导航窗格中，单击*存储* > *聚合*。
. 选择 *报告* > *下载 Excel*。
+
image::../media/download_excel_menu.png[显示如何从报告中下载 Excel 的 UI 屏幕截图。]

+
根据您的浏览器，您可能需要单击*确定*以保存文件。

. 如果需要，请单击*启用编辑*。
. 在 Excel 中，打开下载的文件。
. 创建一个新工作表（image:../media/excel_new_sheet_icon.png[""]）在 `data`工作表之后，并将其命名为 *总数据容量*。
. 在新的总数据容量表中添加以下列：
+
.. 总数据容量（GB）
.. 已提交的容量（GB）
.. 已用数据容量（GB）
.. 可用数据容量（GB）


. 在每列的第一行输入以下公式，确保它引用数据表（data!），并引用捕获数据的正确列和行说明符（总数据容量从 E 列的第 2 行到第 20 行中提取数据）。
+
.. =SUM(data!E$2:data!E$20)
.. =SUM(data!F$2:data!F$50)
.. =SUM(data!G$2:data!G$50)
.. =SUM(data!H$2:data!H$50)


+
公式将根据当前数据对每列进行汇总。



image::../media/capacitysums.png[显示基于当前数据的总容量的数据表的 UI 屏幕截图。]

. 在数据表中，选择 *总数据容量（GB）* 和 *承诺容量（GB）* 列。
. 从*插入*菜单中选择*推荐图表*，然后选择*簇状柱形图*。
. 右键单击图表并选择*移动图表*将图表移动到 `Total Data Capacity`工作表。
. 使用*设计*和*格式*菜单（在选择图表时可用），您可以自定义图表的外观。
. 如果满意，请保存包含更改的文件。请勿更改文件名或位置。
+
image::../media/cluster_column_chart_2.png[显示总数据和承诺容量的图表的 UI 屏幕截图。]

. 在 Unified Manager 中，选择 *报告* > *上传 Excel*。
+
[NOTE]
====
确保您位于下载 Excel 文件的相同视图下。

====
. 选择已修改的 Excel 文件。
. 单击*打开*。
. 单击*提交*。
+
*报告* > *上传 Excel* 菜单项旁边会出现一个复选标记。

+
image::../media/upload_excel.png[显示如何将 excel 上传到报表的 UI 屏幕截图。]

. 单击*已计划报告*。
. 单击*添加计划*可将新行添加到“报告计划”页面，以便您可以定义新报告的计划特性。
+
[NOTE]
====
为报告选择 *XLSX* 格式。

====
. 输入报告计划的名称并填写其他报告字段，然后单击该行末尾的复选标记（image:../media/blue_check.gif[""]）。
+
此时将立即发送一个测试报告。之后，此报告将以指定频率生成并通过电子邮件发送给列出的收件人。



根据报告中显示的结果，您可能需要调查如何最好地利用整个网络中的可用容量。
