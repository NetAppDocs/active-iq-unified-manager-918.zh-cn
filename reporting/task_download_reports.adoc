= 在 Active IQ Unified Manager 中下载报告
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以下载报告并将数据以逗号分隔值（CSV）文件、Microsoft Excel（.XLSX）文件或 PDF 文件的形式保存到本地或网络驱动器。您可以使用电子表格应用程序（如 Microsoft Excel）打开 CSV 和 XLSX 文件，也可以使用阅读器（如 Adobe Acrobat）打开 PDF 文件。

.步骤
. 单击*报告*按钮将报告下载为以下格式之一：
+
[cols="2*"]
|===
| 选择 | 目的 


 a| 
下载 CSV
 a| 
将报告保存为逗号分隔值 (CSV) 文件。



 a| 
下载 PDF
 a| 
将报告另存为 .pdf 文件。



 a| 
下载 Excel
 a| 
将报告另存为 Microsoft Excel (XLSX) 文件。

|===
