= 了解 Active IQ Unified Manager 报告
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Active IQ Unified Manager（以前称为 OnCommand Unified Manager）提供查看、自定义、下载和计划 ONTAP 存储系统报告的功能。这些报告可以提供有关存储系统容量、运行状况、性能、安全性和保护关系的详细信息。

Active IQ Unified Manager 9.6 中引入的新 Unified Manager 报告和调度功能取代了 Unified Manager 9.5 版本中停用的先前报告引擎。

报告提供网络的不同视图，提供有关容量、运行状况、性能、安全性和保护数据的可操作情报。您可以通过显示、隐藏和重新排列各列、筛选数据、排序数据以及搜索结果来自定义视图。您可以保存自定义视图以供重复使用，将其下载为报告，并将其安排为通过电子邮件分发的定期报告。

您可以下载 Microsoft® Excel 格式的视图并进行自定义。您可以使用高级 Excel 功能，例如复杂排序、分层筛选器、数据透视表和图表。当对生成的 Excel 报告感到满意时，您可以上传 Excel 文件，以便在每次安排和共享报告时使用。

除了从用户界面生成报告外，您还可以使用以下其他方法从 Unified Manager 中提取健康、安全和性能数据：

* 使用开放式数据库连接 (ODBC) 和 ODBC 工具直接访问数据库中的集群信息
* 执行 Unified Manager REST API 以返回您有兴趣查看的信息


从此版本的 Active IQ Unified Manager 开始，对报告进行了以下增强：

* 系统会根据配置的计划发送报告电子邮件。即使您生成按需报告，您也会收到一封电子邮件。
* 报告的文件名和元数据包含生成报告的主机名。即使有人更改了文件名，借助此增强功能，您仍然可以识别生成报告的主机名。
