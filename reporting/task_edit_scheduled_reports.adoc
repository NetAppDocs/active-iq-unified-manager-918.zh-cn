= 在 Active IQ Unified Manager 中编辑计划报告
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
安排报告后，您可以在“报告计划”页面上对其进行编辑。

.开始之前
* 您必须具有应用程序管理员或存储管理员角色。


.步骤
. 在左侧导航窗格中，单击*存储管理* > *报告计划*。
+
image::../media/scheduled_reports_2.gif[显示计划报告的 UI 屏幕截图。]

+
[NOTE]
====
如果您拥有适当的权限，则可以更改系统中的任何报告及其计划。

====
. 单击要更改的时间表的更多图标 image:../media/more_icon.gif[""]。
. 单击 *Edit*。
. 您可以更改报表计划的*计划名称*、*收件人*列表、*频率*和*格式*。
. 完成后，单击复选标记以保存所做更改。
