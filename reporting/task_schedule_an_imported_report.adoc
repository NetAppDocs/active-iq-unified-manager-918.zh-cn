= 在 Active IQ Unified Manager 中计划导入的 .rptdesign 报告
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以计划在早期版本的 Unified Manager 中创建和导入的现有报告。

安排导入的报告需要满足以下条件：

* 在较早的 Unified Manager 版本中导入的 BIRT 设计的 .rptdesign 文件报告
* 升级到 Unified Manager 9.6 GA 或更高版本时适用


升级到 Unified Manager 9.6 GA 或更高版本后，报告计划页面将列出导入的报告。您可以编辑这些报告的计划，以指定收件人的电子邮件地址、频率和格式（PDF 或 CSV）。否则，无法在 Unified Manager UI 中编辑或查看这些报告。

.步骤
. 打开“报告计划”页面。如果您已导入报告，则会显示一条消息。
+
image::../media/message_non_scehduled_reports.png[显示导入报告存在时所出现消息的 UI 截图。]

. 单击*视图*名称以显示用于生成报告的 SQL 查询。
+
image::../media/importedreport1.png[显示用于生成报告的 SQL 查询的 UI 屏幕截图。]

. 单击更多图标 image:../media/more_icon.gif[""]，单击*编辑*，定义报告计划详细信息，并保存此报告。
+
[NOTE]
====
您还可以通过“更多”图标 image:../media/more_icon.gif[""] 删除任何不需要的报告。

====
