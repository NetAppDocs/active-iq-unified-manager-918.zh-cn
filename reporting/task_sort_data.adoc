= 在 Active IQ Unified Manager 中对数据排序
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要对结果进行排序，请单击一列并指定升序或降序。对数据进行排序可优先显示报告所需的信息。

.步骤
. 单击列顶端对结果进行排序，使最重要的信息显示在视图顶端。
. 为未保存的视图命名以保存您的更改。
